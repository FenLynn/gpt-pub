# GPT-Pub

GPT-Pub 是一个完全独立的公开项目仓库，独立制定规则、分配编号、维护项目、运行 CI 和发布版本。它不由任何其他仓库管理，也不是其他仓库的公开镜像或子仓库。

本仓库只维护已经确认可以公开的软件、工具和公共代码。私密专利、未公开科研、个人资料和内部工作记录不进入本仓库。

## 接入顺序

新对话或新维护者开始工作前，依次阅读：

1. [`GPT_RULES.md`](GPT_RULES.md)
2. [`目录.md`](目录.md)
3. [`projects/README.md`](projects/README.md)
4. 对应项目的 `README.md` 与 `阶段记录.md`

## 独立编号

GPT-Pub 的项目编号从 `P001` 独立开始，与任何外部仓库中的历史编号没有对应关系：

```text
projects/
├── 001-VideoUpright/   # P001，待迁移
└── 002-AtlasDesk/      # P002，待迁移
```

外部仓库中的旧编号只作为迁移历史事实保留，不决定 GPT-Pub 的目录、分支、标签或后续版本管理。

## 当前状态

当前只建立独立规则和目录骨架，尚未迁入任何项目源码。P001 与 P002 必须分别通过独立迁移 PR 接入。

迁移完成后，项目的唯一当前事实源、开发主线、CI、Issue、PR、标签和 Release 均在 GPT-Pub 内部维护；外部仓库只属于历史来源，不参与本仓库管理。

## 公开边界

本仓库禁止出现：

- 外部私有仓库的完整分支、完整历史或未经筛选的导出；
- 专利创意、未公开论文与实验资料；
- Token、密码、密钥、私有下载地址和内部访问凭据；
- 个人数据、真实用户文件、未脱敏日志和本机隐私路径。

跨仓迁移必须先过滤目标项目历史、执行公开安全扫描，并核对文件数量和 SHA-256。详细规则见 [`GPT_RULES.md`](GPT_RULES.md)。
