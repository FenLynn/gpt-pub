# GPT-Pub

GPT-Pub 用于统一维护已经确认可以公开的软件、工具和公共代码。私密专利、未公开科研、个人资料和内部工作记录不进入本仓库。

## 接入顺序

新对话或新维护者开始工作前，依次阅读：

1. [`GPT_RULES.md`](GPT_RULES.md)
2. [`目录.md`](目录.md)
3. 对应分类的 `README.md`
4. 对应项目的 `README.md` 与 `阶段记录.md`

## 公开边界

本仓库禁止出现：

- 私有仓库的完整分支、完整历史或未经筛选的导出；
- 专利创意、未公开论文与实验资料；
- Token、密码、密钥、私有下载地址和内部访问凭据；
- 个人数据、真实用户文件、未脱敏日志和本机隐私路径。

跨仓迁移必须先过滤项目历史、执行公开安全扫描，并核对文件数量和 SHA-256。详细规则见 [`GPT_RULES.md`](GPT_RULES.md)。
