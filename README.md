# GPT-Pub

GPT-Pub 是一个完全独立的公开项目仓库，独立制定规则、分配编号、维护项目、运行 CI 和发布版本。它不由任何其他仓库管理，也不是其他仓库的公开镜像或子仓库。

本仓库只维护已经确认可以公开的软件、工具和公共代码。私密专利、未公开科研、个人资料和内部工作记录不进入本仓库。

## 接入顺序

1. [`GPT_RULES.md`](GPT_RULES.md)
2. [`目录.md`](目录.md)
3. 对应分类的 `README.md`
4. 对应项目的 `README.md` 与 `阶段记录.md`

## 当前桌面软件

```text
projects/1-桌面软件/
├── 101-Mediova/
└── 102-AtlasDesk/
```

P101 与 P102 使用各自独立的长期分支，固定按 `项目 exp → 项目 stable → main` 推进。正式版本标签和 Release 只从 `main` 建立。

## 公开边界

本仓库禁止出现私有仓库完整历史、未经筛选的导出、Token、密码、密钥、私有下载地址、个人数据、真实用户文件、未脱敏日志和本机隐私路径。
