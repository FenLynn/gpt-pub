# 2｜专利计算

本分类保存经过公开安全审查、可独立运行和复现的专利相关计算代码、测试、公开算例、数据与自生成图件。

## 读取顺序

1. `/GPT_RULES.md`
2. `/目录.md`
3. 本目录 `开发约束.md`
4. 目标项目 `README.md`、`开发约束.md`（如存在）及运行资料
5. 相关分支、PR、CI、Artifact 和 Release

## 编号

- 正式编号：`PUB-P201–PUB-P299`；
- 只在真实公开计算项目创建时分配下一个未占用号码；
- 不继承、不预留、不猜测任何外部仓库编号；
- 终止或归档的号码永久保留，不复用；
- 一个项目可以被多个外部项目复用，也可以复用其他公开计算项目。

## 项目内容

允许保存：

- 通用或公开安全的模型代码；
- 单元测试、基准算例和收敛性验证；
- 公开参数与中性命名的 case；
- 小型关键数据、最终图件与结果清单；
- 运行环境、命令、输入输出格式和复现说明。

禁止保存：

- 私有专利编号、标题、路径和反向映射；
- 未公开结构的真实工程动机、布局判断、权利要求和审查分析；
- 能够从参数、几何、图件或元数据直接推导未公开技术核心的内容；
- 用户实验数据、私人配置和内部判断，除非已明确批准公开。

## 新建项目

首个正式项目使用：

```text
projects/2-专利计算/201-中性稳定名称/
```

只创建当前真正需要的文件和目录。项目名必须中性、稳定，不使用 Hub 编号、私有专利名或内部目标。
