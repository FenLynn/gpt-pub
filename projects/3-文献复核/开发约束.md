# 文献复核开发约束

> 约束层级：B｜分类级  
> 适用范围：`projects/3-文献复核/`  
> 上位规则：A｜`/GPT_RULES.md`

## B-00｜分支创建与写入安全

- 新任务必须从最新 `main` 显式创建非 `main` 工作分支；项目任务使用对应 `p3xx-*`，分类或仓库级任务使用范围明确的 `repo-*`；
- 继续已有任务前，必须核实开放 PR、项目记录或当前任务明确确认的未完成工作，并报告 base、head、ahead/behind 与实际差异；
- 禁止通过临时文件、探针、`noop`、空提交或默认分支写入测试分支是否存在；
- 所有写操作中的 `branch` 均视为必填，且不得为 `main`；
- 更新或删除文件所用 SHA 必须来自同一工作分支的最新读取结果；
- 分支不存在、权限错误、参数缺失、工具选错或写入失败时立即停止，不得省略分支重试、回退 `main` 或先写后删；
- 首次写入后及 PR 前必须比较工作分支与最新 `main`，确认来源、公开边界、允许路径和全部实际差异。

## B-01｜Pub 的唯一职责

GPT-Pub 是**公开计算产线**，不是研究笔记仓库。

本分类只允许保存：

- 计算代码；
- 自动化测试；
- 运行依赖与必要配置；
- 为复现实行所必需的最小机器输入；
- 用户明确要求保留的必要自生成图件。

以下内容一律不进入本分类：

- 项目背景、研究动机、文献介绍；
- 研究进展、阶段记录、handoff；
- 科学判断、结果解读、复现结论；
- 论文策略、实验解释、内部评价；
- 私有实验数据、未公开理论或专利布局；
- 面向人的结果摘要 JSON / Markdown / README。

这些内容全部由对应的私有 Hub 项目保存。

## B-02｜项目目录结构

P3xx 项目目录默认**不创建项目 README**。

项目目录只保留运行所需内容，例如：

```text
config/
src/
tests/
requirements.txt
```

如需跨仓识别，只允许用户明确授权的**最小标识**，例如 `HUB-P302`。不得附带项目名称、研究背景、论文题目、结论、解释或反向映射细节。

## B-03｜代码与配置边界

- 代码注释和 docstring 只写实现所必需的技术说明，不写研究故事、论文评价或阶段结论；
- 配置文件只保存运行所需参数，不附加来源叙述或科学解释；
- 测试只验证实现和数值性质，不把研究结论写成面向人的报告；
- 文件名、workflow 名和 Artifact 名使用中性编号，避免暴露研究背景。

## B-04｜版权与公开安全

- 不提交论文全文、出版物原图、付费补充材料或其他无权再发布的内容；
- 不提交私有实验数据、内部截图、未公开理论、论文策略或专利判断；
- 必要图件必须由代码自行生成；
- Pub 与私有 Hub 的关系只允许最小编号级标识，不保存背景说明或完整映射。

## B-05｜编号与命名

- 本分类独立使用 `PUB-P301–PUB-P399`；
- 编号与外部仓库编号体系独立，不预留、不复用；
- 项目目录优先使用 `NNN-HUB-Pxxx` 这类最小中性标识；
- 只有用户明确授权时才写入一个外部 Hub 编号；
- 不在公开文件、PR 正文、workflow 名、日志说明中展开该 Hub 编号对应的项目背景。

## B-06｜代码、输入与输出

- 计算核心接收明确输入与 `OUTPUT_ROOT`，不写死盘符或私人路径；
- 一次运行只能有一个输出根目录；
- 依赖、随机种子（如有）和必要运行参数必须可复现；
- notebook 必须清理私人路径、隐藏状态和无关输出；
- 机器生成的数值结果默认留在 runner 临时目录，不自动提交仓库。

## B-07｜验证质量

代码层至少执行与任务相称的验证：

- 单位、归一化和坐标定义核对；
- 解析极限或简单基准；
- 网格、步长或截断收敛性；
- 公平对照和误差度量；
- 对实现异常通过测试失败或机器状态码体现。

**验证的科学解释与最终结论只写回 Hub，不写入 Pub。**

## B-08｜CI 与公开输出

- CI 只读仓库并执行测试/计算；
- 默认不上传包含研究结论、结果摘要或背景信息的 Artifact；
- 默认不在日志中打印完整结果 JSON、参数解释或科学结论；
- 如用户明确要求保留图件，只上传必要的自生成图件；
- 不自动提交结果，不自动创建 Release；
- PR 标题和正文保持最小化，只使用 `PUB-Pxxx` / `HUB-Pxxx` 级标识。

## B-09｜Hub/Pub 分工

Pub 负责：

```text
代码
测试
配置
计算
必要图件
```

Hub 负责：

```text
背景
文献
进展
推导
结果
解释
结论
下一步
```

任何后续任务若发现 Pub 中出现背景、进展、结果解释或项目 README，应优先清理，再继续计算。
