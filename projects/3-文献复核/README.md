# 3｜文献复核

本分类保存对已公开论文、专利、标准或技术报告进行独立计算复现与数值核验的公开项目。

## 读取顺序

1. `/GPT_RULES.md`
2. `/目录.md`
3. 本目录 `开发约束.md`
4. 目标项目 `README.md`、`开发约束.md`（如存在）及运行资料
5. 相关分支、PR、CI、Artifact 和 Release

## 编号

- 正式编号：`PUB-P301–PUB-P399`；
- 只在形成独立公开复现项目时分配下一个未占用号码；
- 不继承任何外部仓库编号；
- 终止或归档的号码永久保留，不复用。

## 适用范围

适合独立立项：

- 复现公开论文中的公式、图、表或核心数值结论；
- 核验公开专利或标准中的定量效果；
- 比较多个公开模型在相同条件下的差异；
- 形成可供多个项目复用的公开基准实现。

不单独立项：

- 某个现有公开项目内部的普通测试；
- 只有文献摘录、综述或观点整理而没有独立计算复核；
- 包含私有实验对照、未公开理论或专利战略判断的工作。

## 项目内容

每个项目至少说明正式来源、复核对象、原文参数、自主假设、运行方法、结果差异和复现边界。只能保存合法获取并允许公开的资料；出版物原图和论文全文不进入仓库，复现图必须由本项目代码重新生成。
