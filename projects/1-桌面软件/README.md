## 开发原则

- 新功能先进入对应 `pNNN-exp`；
- 通过构建、测试和实机验证后再晋升 `pNNN-stable`；
- 正式版本只允许从稳定分支进入 `main`；
- 不在 `main` 上直接开发；
- 每个项目只修改自己的代码、文档、CI 和发布资产，不跨项目串改。

分类级规则见：`开发约束.md`。
