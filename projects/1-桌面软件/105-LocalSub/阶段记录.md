## 阶段目标

先把媒体解析、波形、VAD 与后台离线 ASR 从 WinForms GUI 进程中隔离到 `LocalSub.Core.exe`，验证重任务异常不会把 `LocalSub.exe` 一起拖成未响应。Core API 稳定后再继续实时链和 Web 主界面迁移。

## Phase 1A 已实现能力

- `LocalSub.Core.exe` 独立发布。
- Windows Named Pipe + UTF-8 newline-delimited JSON IPC。
- v1 方法：`ping / analyze / transcribe / cancel / shutdown`。
- 媒体解析、波形数据生成、后台离线 ASR 从 Shell 编译边界移出。
- `LocalSub.exe` 对上述功能只保留 Proxy，不允许 Core 失败后静默回进程内执行。
- Core 跟踪父进程，Shell 正常退出时 Core 应退出。
- Core 异常退出时当前后台任务失败，GUI 应保持存活，下一次重任务重新启动 Core。

## 实机状态

**待验证。**

尚需用户在真实 Windows 环境确认：后台重任务期间 GUI 持续响应，主要负载进入 Core；手动结束 Core 不导致 Shell 退出；下一次任务能重新启动 Core；关闭 Shell 后无长期孤儿 Core。
