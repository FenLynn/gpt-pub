## 2026-09-13 v0.1.11 meter 全链复查与同源 peak

- 用户确认 v0.1.10 在 PotPlayer 正常播放、字幕可持续识别时，顶部 meter 与 30 秒曲线仍几乎无响应。

- Core `LiveAsrPipeline.OnSamples` 对真正写入 ASR queue 的同一块 16 kHz mono PCM 计算 instantaneous peak：`max(abs(sample))`。同一方法随后把原样 samples 写入 ASR queue。

- Core 每秒记录 `LIVE_METER`，含 meter event count/min/max；Shell IPC 每秒记录 `LIVE_METER_RX` 到 `Logs/core-client.log`；WebShell 每秒记录 event count/min/max 到 `Logs/meter-web.log`。
- CI 新增 `Verify ASR-sample peak live meter and diagnostics`，明确要求 OnSamples 同时具备 peak 与 ASR queue 写入，并禁止 capture-only branch、RMS/dB 与 full snapshot meter 回归。
