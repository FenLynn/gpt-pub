## 2026-09-12 Phase 1B.2 与 Web 模型页第一闭环

在 realtime Web 第一闭环之后，模型管理完成了进程边界和 Web 页面两层收口：

- 重型 `ModelManager.cs` 只编入 `LocalSub.Core.exe`；Shell 编译使用轻量 `ModelManager.Proxy.cs`。
- `LocalSub.exe` 不再直接依赖 SharpCompress。
- Core IPC 增加 `model.download / model.delete`，下载/解压/校验/修复/目录替换/递归删除全部由 Core 执行。
- 旧 WinForms 的下载与删除也通过 proxy 进入 Core，不保留 GUI 进程内 fallback。
- 旧 WinForms realtime 改为与后台、模型任务共用 `CoreWorkerBroker.Shared`，Core operation slot 因而能统一阻止冲突重任务。
- Web 模型页已经接入 catalog 查看、筛选、安装状态、实时/后台默认选择、下载/修复、取消、删除和模型任务状态。
- 下载可取消；删除一旦进入破坏性目录脱离与清理阶段即完成收尾，不允许用户取消。
- WebShell snapshot coalescing 的最终状态丢失窗口已经修正。
- 默认启动继续保留旧 WinForms，未切换到 WebShell。
