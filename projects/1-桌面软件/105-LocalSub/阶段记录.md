- Shell 正常退出主动 shutdown Core。

## 2026-09-05 分支与发布治理最终收口

发布后发现原 cleanup 脚本对 PowerShell `$branch:` 插值处理不正确。最终将不可变 Release 与 branch hygiene 解耦：

- Release job 只负责显式 `RELEASE.md` 触发的不可变发布。
- 独立 `branch_hygiene` job 在成功的 P105 main push 后运行。
- branch hygiene 非强制 fast-forward `p105-exp / p105-stable` 到当前 main。
- 删除前先验证废弃 ref 没有 main 之外的独有提交。
- 修正 refspec 为 `${branch}` 形式。
- 最终强校验 P105 活跃长期分支只有 `p105-exp` 与 `p105-stable`。

## 实机状态

**用户特定高负载 GUI 响应性仍待真实机器验证。**

自动 fault injection 可以证明 Core supervisor/IPC 恢复状态机，但不能证明用户自己的媒体、模型和机器负载下 WinForms 消息循环绝不阻塞。Release Notes 已明确披露该边界，因此不得把自动 CI 成功改写成实机确认。

1. 以最新 `p105-exp` 作为后续开发入口。
2. 优先完成 Phase 1A 用户实机高负载 GUI 响应性与 Core 故障边界验证。
3. 实机边界确认后进入 Phase 1B，逐步迁移 realtime ASR、WASAPI、PotPlayer Process Loopback 与模型重任务到 Core。
