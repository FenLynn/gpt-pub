## Realtime IPC

Core 当前新增：

```text
live.start
live.stop

live.status
live.level
live.partial
live.final
live.discontinuity
live.failed
```

规则：

- `live.start` 成功后返回 session ID。
- realtime 事件按 session ID 长期推送。
- `live.level` 对外约 10 Hz 限频。
- Core shutdown、父进程退出和显式 `live.stop` 都会收口实时会话。
- realtime session 存在时，现阶段其他重任务明确拒绝并发，避免隐式资源竞争。
- 无效实时启动必须明确失败，并释放 operation slot，不能把 Core 卡死。

```text

        ↓ typed JSON bridge

        ↓ Named Pipe

```

当前只实现 Phase 2A 壳层，不替换现有业务页：

## 2026-09-12 模型重任务与 Web 模型页第一闭环

模型管理当前已经形成统一链路：

```text
旧 WinForms / Vue 模型页
        ↓
Shell ModelManager proxy / ModelCatalogController
        ↓
CoreWorkerClient
        ↓ Named Pipe
LocalSub.Core.exe
        ↓

├─ 下载与断点续传
├─ 解压
├─ 关键文件校验
├─ 修复与目录替换
└─ 递归删除
```

关键工程收口：

- 重型 `ModelManager.cs` 不再编入 `LocalSub.exe`。
- Shell 新增 `ModelManager.Proxy.cs`，只保留安装状态检查与 Core 代理。
- Shell 项目移除 SharpCompress 依赖。
- Core IPC 新增 `model.download / model.delete`，进度继续使用 `model-progress`，取消沿用现有 request cancellation。
- Web bridge 新增 `model.download / model.cancel / model.delete`。
- Web 模型页可以查看 catalog、筛选、选择默认模型、下载/修复、删除、查看 Core 进度与错误。
- 删除使用二次确认。下载可取消；删除进入目录脱离后不再接受用户取消，确保清理完整。
- 旧 WinForms realtime 改为 `CoreWorkerBroker.Shared`，与后台转写、模型任务使用同一个 Core operation slot。
- snapshot push coalescing 已修正最终状态丢失窗口。

## 当前唯一开发断点

下一阶段不提升 stable，也不动 main。

优先顺序：

1. 保留旧 WinForms 作为默认入口和 Web 迁移对照壳。
2. 在真实 Windows 上验证 realtime 与模型管理，包括 PotPlayer、真实字幕、模型下载/修复、断点续传、取消、大模型解压、删除与运行中强杀 Core。
3. 无阻断问题后，进入 Web 后台转写工作区，直接复用现有 Core `analyze / transcribe / cancel`。
4. 后台工作区完成后迁设置编辑与 Overlay 联动细节。
5. realtime、模型、后台和设置完成必要验证前，不切换默认主界面。
