## Realtime IPC

Core 当前新增：

```text
live.start
live.stop

live.status
live.level
live.partial
live.final
live.discontinuity
live.failed
```

规则：

- `live.start` 成功后返回 session ID。
- realtime 事件按 session ID 长期推送。
- `live.level` 对外约 10 Hz 限频。
- Core shutdown、父进程退出和显式 `live.stop` 都会收口实时会话。
- realtime session 存在时，现阶段其他重任务明确拒绝并发，避免隐式资源竞争。
- 无效实时启动必须明确失败，并释放 operation slot，不能把 Core 卡死。

## 当前唯一开发断点

下一阶段不提升 stable，也不动 main。

优先顺序：

1. Web UI 已作为默认主界面，旧 WinForms 只作为 `--legacy-ui` 迁移期备用入口。
2. 在真实 Windows 上验证 realtime 与模型管理，包括 PotPlayer、真实字幕、模型下载/修复、断点续传、取消、大模型解压、删除与运行中强杀 Core。
3. 下一步完成 Web 后台转写工作区，直接复用现有 Core `analyze / transcribe / cancel`。
4. 在真实 Windows 上验证 v0.1.6 字幕设置即时预览、开机启动注册、静默托盘、自动实时与 PotPlayer 等待语义。
5. Web 后台达到必要功能覆盖后，再进入 Phase 3 删除旧 WinForms 业务页。

## 当前验证原则

- stable/main 在新候选完成必要实机验证前保持 `042329ed...`。
- 自动截图和 CI 只证明自动化覆盖的边界，不替代用户 Windows 实机视觉和 realtime 体验。
- 正式 Release 仍必须由用户对明确版本单独人工授权。
