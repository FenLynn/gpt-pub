## 发布完成标准

只有同时满足下列条件才算本轮完成：

1. `p105-exp → p105-stable` 当前 head CI 成功。
2. `p105-stable → main` 当前 head CI 成功并合并。
3. main 发布 workflow 重新构建并通过完整 P105 Windows 门禁。
4. 创建不可复用标签 `p105-v0.1.1` 和 GitHub Release `LocalSub v0.1.1`。
5. Release 资产和 SHA-256 可核查。
6. `main / p105-stable / p105-exp` 最终指向同一发布 main SHA。
7. P105 项目分支最终只有 `p105-exp` 与 `p105-stable`。
