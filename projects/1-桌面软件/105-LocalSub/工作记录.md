## Realtime IPC

Core 当前新增：

```text
live.start
live.stop

live.status
live.level
live.partial
live.final
live.discontinuity
live.failed
```

规则：

- `live.start` 成功后返回 session ID。
- realtime 事件按 session ID 长期推送。
- `live.level` 对外约 30 Hz 限频；WebShell 另用轻量 `live.level` 事件转发到 Vue，不因电平样本刷新完整 snapshot。
- Core shutdown、父进程退出和显式 `live.stop` 都会收口实时会话。
- realtime session 存在时，现阶段其他重任务明确拒绝并发，避免隐式资源竞争。
- 无效实时启动必须明确失败，并释放 operation slot，不能把 Core 卡死。
