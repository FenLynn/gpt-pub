## Realtime IPC

Core 当前新增：

```text
live.start
live.stop

live.status
live.level
live.partial
live.final
live.discontinuity
live.failed
```

规则：

- `live.start` 成功后返回 session ID。
- realtime 事件按 session ID 长期推送。
- `live.level` 对外约 10 Hz 限频。
- Core shutdown、父进程退出和显式 `live.stop` 都会收口实时会话。
- realtime session 存在时，现阶段其他重任务明确拒绝并发，避免隐式资源竞争。
- 无效实时启动必须明确失败，并释放 operation slot，不能把 Core 卡死。

## 当前唯一开发断点

下一阶段不提升 stable，也不动 main。

优先顺序：

1. 保留当前 WinForms 作为 realtime 实机验证壳。
2. 使用本轮 Artifact 在用户 Windows 上验证真实 PotPlayer + 已安装模型。
3. 重点验证开始、停止、实时字幕、音量、快进快退、换片、全屏/窗口切换和长时间运行。
4. 验证 realtime 运行时强杀 `LocalSub.Core.exe` 后 Shell 不退出且错误可诊断。
5. 在不改变上述 Core 边界的前提下进入 Phase 2A，建立 WebView2 + Vue 3 + TypeScript 主 Shell。
6. Web UI 不直接翻译 `MainForm` 事件，而只消费 Application Contract。
