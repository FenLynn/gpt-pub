# DavBridge 用户手册

本文描述 DavBridge 当前长期工作原则和界面语义。stable/main 当前仍为 v0.4.26，p103-exp 已进入 v0.5.0 数据可发现与迁移候选。运行行为以源码、状态文件和准确 CI 为准，最终视觉事实以用户真实 Windows 为准。

## 1. 使用概览

DavBridge 用于长期维护 Zotero 附件从 InfiniCLOUD 到坚果云的单向强校验镜像。

日常情况下不需要人工干预。真实额度周期开始后，程序先对账，再处理历史修改，最后使用剩余额度继续普通迁移。只有回收站成熟候选、冲突、认证异常等无法安全自动决定的事项才要求人工处理。

## 2. 镜像原则

InfiniCLOUD 是唯一权威源，并且始终只读。

坚果云保存已经验证或正在迁移的镜像子集。新增源对象进入普通任务池，不插队。已验证对象如果源端发生真正内容变化，则优先修复。

DavBridge 不做双向同步，也不会把坚果云变化反写到 InfiniCLOUD。

## 3. StrongVerified

`StrongVerified` 表示文件在核准时刻已经完成源端 SHA256 与目标端重新下载 SHA256 的一致性确认。

该 SHA256 是后续维护的历史核准基线。普通 metadata 扫描不会随意覆盖它，只有重新完成强校验后才建立新基线。

## 4. Cycle 与额度

Cycle ID 使用启动当前坚果云额度周期的真实重置日期，格式固定为 `yyMMdd`。例如 2026-09-07 对应 `260907`。

程序不会仅按自然月或午夜盲目重置账本。到达配置重置日以后，会在 09:00 以后通过真实探测确认新的服务周期已经开始。只有确认成功后才进入新 Cycle，并优先执行源端对账。

## 5. 源端对账

每个已确认新 Cycle 开始后，DavBridge 自动读取 InfiniCLOUD 当前清单，并与历史 StrongVerified 账本比较。

源 metadata 未变化时不读取文件内容。metadata 发生变化时，只重新读取 InfiniCLOUD 并计算 SHA256：

- SHA256 没变，只更新源 metadata；
- SHA256 真改变，文件组进入 `SourceChanged`；
- `SourceChanged` 优先于普通任务刷新目标；
- 新目标重新 StrongVerified 后才建立新的核准基线。

## 6. 转移优先级

任务只有两个逻辑层级。

第一层是优先修复，即源端内容真正改变的历史 StrongVerified 组。

第二层是普通任务，包括既有 backlog 和本周期新增对象。

新增文件与历史未迁移对象同级，不额外插队。只要优先修复仍存在，普通任务就等待。

## 7. 回收站

源端删除采用跨周期逻辑回收站。

第一次发现一个历史 StrongVerified 组在 InfiniCLOUD 完全消失，只记录首次缺失 Cycle，坚果云内容完全不动。

至少跨到后续已确认额度周期仍然缺失，才进入待审查。待审查对象永远不会自动 DELETE，用户必须人工选择删除或本周期继续保留。

继续保留的对象如果下个周期仍缺失，会再次进入审查，因此回收站可以同时存在本月、上月以及更早周期留下的对象。

## 8. 删除安全

人工点击删除以后仍不会直接无条件 DELETE。

DavBridge 会再次：

1. 检查 InfiniCLOUD 准确成员路径；
2. 确认整个 Zotero `.zip + .prop` 组仍然缺失；
3. 检查坚果云目标仍然对应历史 StrongVerified 身份；
4. metadata 无法安全证明身份时，仅在下载安全额度允许时重新读取目标并比对历史 SHA256；
5. DELETE 后再次查询准确目标路径；
6. 网络或超时导致结果未知时先 reconciliation，绝不盲目重复 DELETE。

源端如果只恢复 `.zip` 或只恢复 `.prop`，属于组结构异常，禁止自动删除。

## 9. v0.4 主界面

当前一级入口为：

```text
总览 | 转移 | 回收站 | 文档
```

v0.4.5 采用固定左侧栏。设置和关于位于左侧栏下部，最底部显示当前运行状态与 Cycle。

### 总览

总览只回答最重要的运行问题：

- 从哪里迁到哪里；
- 当前处于哪个阶段；
- StrongVerified 覆盖率是多少；
- 当前正在处理什么；
- 本 Cycle 上传和下载额度用了多少；
- 现在需要暂停、继续还是人工审查。

StrongVerified、Cycle、阶段和端点角色等解释通过悬浮提示补充，避免长期占用主界面空间。

### 转移

v0.4.10 的转移页采用与首页一致的轻量分隔行。页面只常驻三类信息：变化修复、普通迁移、人工审查，每行显示图标、标题和数量。具体调度含义进入 info 悬浮提示。页面下部只保留当前动作或恢复后动作以及总体镜像覆盖率。

### 回收站

只处理跨周期成熟的人工审查对象。默认不自动选择对象，不存在后台自动删除。v0.4.9 放大了表头、行文字、状态标签和操作按钮，提高真实 Windows 下的可读性。

### 文档

在程序内解释长期安全语义和常见状态。v0.4.9 取消独立左侧目录，采用单列正文阅读布局，并让滚动条在正常状态下保持隐藏。

### 设置与关于

设置仍由 C# 原生宿主承载敏感配置和 Windows 级设置。v0.4.10 起，账户与端点字段可以正常点击、选择和编辑；如果已有迁移和 StrongVerified 记录，保存阶段仍会阻止 URL、目录或 User ID 切换到另一套端点，避免旧账本被错误复用。密码仍可正常更新。

v0.5.0 新增“数据与迁移”分类。这里集中显示当前持久 DataRoot、本机运行目录、最近一次备份状态，并提供打开目录、更改 DataRoot、备份和恢复入口。

About 页也新增同名“数据与迁移”区域。这里不是第二套状态系统，而是把现有真实路径和文件状态公开给用户。可展开的“文件与目录清单”会逐项显示文件名、类别、是否存在、大小或目录状态，并通过悬浮提示说明完整路径、用途和备份策略。

## 10. 打开、托盘与主操作

显式打开 DavBridge 的行为统一为显示主窗口并回到总览：

- Windows 登录自启动使用 `--background`，可直接进入托盘；
- 用户手工双击 EXE 时显示主窗口总览；
- 程序已运行时再次双击 EXE，应激活已有窗口并切回总览；
- 托盘双击或托盘菜单“打开 DavBridge”也应恢复主窗口并显示总览。

主操作根据真实状态动态变化。运行中可暂停，暂停后可继续；需要人工时进入对应人工入口；额度或网络等待时应显示真实等待原因。

## 11. 最近活动、启动自检与脱敏诊断

点击左下角运行状态块可以打开最近活动抽屉。状态块使用一个状态图标、一行主状态和一行副状态；如果主状态与路线状态相同，副状态显示 Cycle，避免重复两次“已暂停”等文字。最近活动抽屉已在 v0.4.9 放大时间、标题和说明字号。这里只记录启动、暂停、继续、等待额度、等待网络、Cycle 变化、连接诊断、就绪扫描和安全验证等通用状态事件，不记录真实 Zotero 文件名、远端目录或凭据。

DavBridge 启动时会检查 WebView2，进入程序后继续检查 Windows、.NET 8、WebView2、Data 目录读写、config/state/reconcile JSON 可读性及 `.bak` 可恢复性、DPAPI 凭据可读取性。

“设置 → 安全与维护 → 导出诊断信息”会生成脱敏 ZIP。它可包含版本、构建、环境、EngineState、Cycle、额度、自检、备份存在性、初始化步骤和最近活动，但不得包含密码、真实 Zotero 文件名、私人远端目录或本机私人绝对路径。

首次初始化未完成时，安全与维护页会临时显示“连接 → 扫描 → 流量 → 首组 → 既有副本”状态条；完成后自动隐藏。
### 本周期流量校准

流量校准现在有两个入口：总览“流量预算”重置日期后的“校准”，以及“设置 → 流量与限速 → 本周期流量校准”。两者最终都进入同一个原生 C# 校准流程。

校准项包括坚果云官方页面当前显示的上传已用量、下载已用量和下一次流量重置日期。若迁移正在运行，DavBridge 会先要求安全暂停，暂停完成后才允许修改本周期额度账本。

v0.4.9 将流量预算标题行和上传下载数据作为一个整体垂直居中，上下留白由同一布局规则控制。上传安全区进度条使用绿色渐变，下载安全区使用蓝色渐变，警告和危险状态仍使用黄色与红色语义。

v0.4.8 默认窗口为 1100×825，也就是 16:12 / 4:3。旧版没有窗口布局 SchemaVersion 的记录会在首次启动时一次性迁移：保持原宽度，高度按宽度的 3/4 调整；例如 1100×620 会迁移为 1100×825，1000×610 会迁移为 1000×750。迁移后写入 SchemaVersion=2，之后用户自己拖动的窗口尺寸会继续保留。
### 睡眠唤醒与网络恢复

v0.4.5 会监听 Windows 睡眠恢复和网络可用性变化。系统唤醒后会提前请求后台安全检查；如果当前为 `WaitNetwork`，网络恢复后会提前唤醒后台循环，而不是固定等待下一次约 10 分钟轮询。

提前唤醒不会跳过任何安全门，DavBridge 仍会重新执行额度、Cycle、源端对账、人工审查和 StrongVerified 等既有流程。

### 本地异常日志

未处理异常会写入本机 LocalAppData 下的 `startup-error.log`。v0.4.5 会对 URL 与用户目录做脱敏，并明确不把该文件加入“导出诊断信息”ZIP。

### 运行会话与异常退出识别

v0.4.8 会在本机 LocalAppData 保存一个轻量 `runtime-session.json` 活动会话 marker。正常退出时该 marker 会被清理；如果进程崩溃、断电或被强制终止，下一次启动会识别为“上次异常中断”，并在最近活动中显示最后心跳和通用运行状态。

这个 marker 不保存真实 Zotero 文件名、WebDAV 地址、密码或本机私人路径，也不参与迁移正确性判定。恢复仍以 `state.json`、`reconcile.json` 与既有 StrongVerified 安全链为准。

About 页的“运行会话”会显示当前运行时长和上次退出状态。

启动时还会清理上一次异常中断遗留的未完成 `.part` 临时文件和 reset probe 临时状态。清理发生在迁移开始之前，不会删除持久化迁移账本。
## 12. Web UI 安全边界

Vue 界面没有权限直接读取凭据或执行 WebDAV 写入。

当前前端命令仅通过 C# bridge 白名单进入既有逻辑。密码、DPAPI、原始 state/reconcile 文件和 WebDAV 客户端不进入 JavaScript。

DELETE 的前端确认也不是最终授权，仍会进入 C# 原生确认和既有删除安全链。

## 13. 界面设计原则

当前 UI 坚持：

- 左侧导航稳定；
- 总览结构稳定；
- 状态、数字和操作一眼可辨；
- 长解释进入 tooltip 或文档；
- 不为了压缩信息破坏页面结构；
- 不为了现代 UI 重写已经验证的 Core；
- 自动截图和浏览器预览只做前置检查，最终视觉事实以用户真实 Windows 为准。

v0.3.x 的 WinForms 布局试验保留在 Git 历史和源码中用于追溯，但不再是当前运行 UI 的设计准则。

## 14. 常见问题

### 为什么校核时坚果云流量可能几乎不变？

很多校核只执行 PROPFIND 或 metadata 探测，只有需要内容级身份确认时才会 GET 文件。

### 为什么新文件不优先？

新增文件与已有 backlog 角色相同。系统先保证已有镜像仍然正确，再扩大镜像覆盖范围。

### 为什么删除要等一个周期？

跨周期观察用于过滤临时不可见、服务故障和短期误判。即使跨周期确认，最终 DELETE 仍必须人工批准。

### 为什么坚果云不需要反复全库下载？

StrongVerified 已经保存历史双端 SHA256 核准基线。正常长期维护优先检查当前源端变化，并以目标 metadata 和历史核准证据维持可信链。只有目标身份存在异常时才按需重新读取目标内容。

### 为什么 v0.4 仍能看到一些 WinForms 历史源码？

它们用于历史回滚和追溯。当前业务 UI 已经由 Vue/WebView2 承担，WinForms 只保留 Windows 原生宿主职责。

### v0.4.10 悬浮提示

Web UI 的解释性悬浮提示现在统一由全局 tooltip 层显示，并 Teleport 到 body。它不会再被首页卡片、页面 overflow 或局部 stacking context 截断。悬浮提示仍只用于解释，不替代任何危险操作确认。


### v0.4.11 当前任务状态与动作

首页“当前任务”现在把对象、状态、进度和动作分开。左侧显示当前对象名称，中央持续显示真实 EngineState 和路线状态，并在有任务进度时显示中央进度条；右侧按钮只表示用户可执行的动作。

例如运行时中央显示“运行中 / 普通迁移中”，右侧按钮显示“暂停”；暂停后中央显示“已暂停”，右侧按钮显示“继续”。点击暂停、继续或重试后，中央状态会先立即显示“正在暂停 / 正在继续 / 正在重试”，随后以 C# 返回的真实状态为准。按钮本身不会再变成“处理中”。


### v0.4.12 阶段与流量状态

总览三阶段现在使用更直接的状态语言：完成只显示粗绿色对勾，正在工作的阶段显示绿色呼吸灯，等待阶段使用低对比度小点。

流量预算的上传和下载箭头统一为蓝色，它们只表示方向。真正的额度风险由进度条和百分比共同表达：0 到 59% 为绿色，60 到 79% 为黄色，80% 及以上为红色。

当前任务进度仍是 WebDAV 的真实字节进度。界面大约每 500 ms 接收一次状态，因此小文件可能很快直接显示 100%，大文件更容易看到连续增长。这不是按文件大小人为生成的动画。


### v0.4.13 安全暂停

暂停现在区分“已经请求暂停”和“已经安全停住”两个状态。

点击“暂停”后，界面会立即显示“正在暂停”。如果当前没有正在处理的文件，会很快进入“已暂停”；如果当前文件仍处于读取、上传、目标确认或强校验阶段，DavBridge 会先让这个文件完成必要的安全收尾，然后在下一个文件开始前停止。

这样做是为了避免在 WebDAV PUT 中途为了追求瞬时停止而留下远端写入结果不确定的状态。真正进入 `已暂停` 后，不会再启动新的文件，右侧动作变为“继续”。

可执行的“暂停 / 继续 / 重试”等按钮现在使用手型鼠标；动作已提交、正在等待安全结果时会给出立即的状态反馈。


### v0.4.14 重复暂停与按钮状态

主操作按钮现在始终保留在“当前任务”右侧的固定位置。

运行时，“暂停”为黄色可点击按钮。暂停请求提交后，同一位置会立即变成灰色“正在暂停”，表示 DavBridge 正在等待当前文件到达安全边界。安全暂停完成后，同一位置切换为绿色“继续”。

点击“继续”后，恢复命令只负责恢复调度，不再等待整轮迁移完成，因此按钮会很快重新变成黄色“暂停”。后续可以再次执行安全暂停，不应只在第一次有效。

等待额度、等待网络、已完成等当前没有可执行动作的状态，也会保留一个灰色按钮占位，从而避免界面布局来回变化。


### v0.4.15 上传进度与状态表达

首页当前任务中的进度条现在只表示目标端 WebDAV 上传进度。它使用目标端 Upload 的真实 BytesProcessed / TotalBytes，不再把源端下载或目标端重新下载强校验的进度混入同一条进度条。

因此上传进度显示 100% 时，只表示这个文件的上传字节已经完成。DavBridge 仍可能继续进行目标端重新读取、SHA-256 强校验或安全暂停收尾；这些过程通过状态文字单独显示。

安全暂停期间，当前任务中央显示“正在安全暂停”和“当前文件完成安全收尾后停止”，右侧固定按钮显示灰色“暂停中”。左下角只保留全局摘要“正在暂停 / 安全收尾中”。

### v0.4.15 最近活动

最近活动会合并短时间内同一状态转换产生的重复事件。例如“迁移已继续 + 迁移运行中”只显示一条恢复事件；安全暂停真正完成后，同一轮较早的“正在安全暂停”不会再和“迁移已暂停”重复占两行。

活动列表滚动条默认隐藏，鼠标进入列表时才轻量显示。

### v0.4.15 原生模态

流量校准等原生模态操作打开时，后方 Web UI 会轻度降饱和并覆盖一层很浅的遮罩，表示后台界面当前不可交互。DateTimePicker 和 MonthCalendar 保留 Windows 原生行为。


### v0.4.17 长期运行摘要

“关于”页新增四项轻量运行摘要，用于快速判断 DavBridge 长时间挂后台时最近发生了什么：

- 本周期：当前 Cycle，以及本周期上传、下载已用量；
- 最近完成：最近活动中可识别的清单或迁移完成事件；
- 最近暂停：最近一次暂停事件；
- 最近异常：最近一个 warning 活动，没有近期 warning 时显示“暂无近期异常”。

这些内容只来自已经存在的安全 snapshot 和通用活动记录，不新增私人数据持久化，不显示真实 Zotero 文件名、远端路径、凭据或 SHA。

活动列表只保留有限的最近事件，因此这里是“近期运行摘要”，不是永久审计日志。

脱敏诊断导出继续位于“设置 → 安全与维护”，v0.4.17 没有重复增加第二套诊断功能。


### v0.4.18 近 24 小时运行健康

“关于”页在 v0.4.17 长期运行摘要下方增加一条轻量健康状态条。

默认统计最近 24 小时活动中的：

- 当前清单完成次数；
- 等待网络次数；
- warning 事件数量；
- 安全暂停完成次数。

同一条状态条还显示当前 StrongVerified 数量和当前待处理 backlog，用于判断 DavBridge 长时间挂后台后是否仍在推进。

DavBridge 的通用活动 sidecar 最多保留 40 条事件。如果保留窗口不足以完整覆盖最近 24 小时，界面会显示“近期活动窗口”并提示“活动窗口可能已截断”，不会把不完整样本冒充完整 24 小时统计。

这套摘要不保存真实 Zotero 文件名、远端路径、URL、凭据或 SHA，也不参与迁移安全判断。


### v0.4.19 事件级健康账本

v0.4.18 的“近 24 小时运行健康”最初来自最近活动列表，而最近活动最多只保留 40 条。v0.4.19 改为使用独立的匿名健康账本，因此状态变化较多时也不会因为活动抽屉被截断而丢失近 24 小时统计。

健康账本只记录四类匿名事件和时间：

- warning；
- 等待网络；
- 安全暂停完成；
- 当前清单完成。

它不记录真实 Zotero 文件名、远端路径、URL、用户名、密码或 SHA，也不参与迁移正确性判定。

从旧版首次升级到 v0.4.19 时，About 页可能暂时显示“健康账本建立中”。这是正常现象。DavBridge 会尽量利用仍保留的近期通用活动，但不会把这些有限历史假装成完整 24 小时记录。健康账本累计满 24 小时后，界面自动恢复“近 24 小时”完整统计。

中间正常退出或重新启动不会清空这 24 小时建立过程，因为账本保存在本机 `product-experience.json`。删除或损坏该 UI sidecar 只会让健康摘要重新建立，不会影响 StrongVerified、迁移断点、额度、回收站或任何删除安全门。

### v0.4.20 运行健康观察连续性

About 页的健康摘要现在同时检查“账本时间长度”和“实际观察连续性”。

如果匿名健康账本尚未累计满 24 小时，会显示“健康账本建立中”。

如果账本已经足够长，但最近 24 小时内 DavBridge 曾经停止运行超过 15 分钟，会显示“近 24 小时观察不连续”，并给出最近一次空窗的大致时长。此时完成、网络等待、警告和暂停次数仍是真实记录，但只代表 DavBridge 实际运行期间，不能把未运行时间理解为零异常。

正常更新或快速重启在 15 分钟以内不会触发该状态。空窗离开最近 24 小时窗口以后，如果后续观察连续，界面会自动恢复完整“近 24 小时”状态。

该提示只是运行健康说明，不会暂停迁移，也不会改变 StrongVerified、流量账本、回收站或删除安全门。


## 15. v0.5.0 数据位置、备份与恢复

### 15.1 以后只需要记住一个“持久数据目录”

DavBridge 把长期数据分成两类。

第一类是持久数据，也就是迁移到其他电脑、重装软件或做灾难恢复时真正重要的内容。默认位置仍为：

```text
%APPDATA%\DavBridge
```

v0.5.0 起可以从软件内把它迁移到其他空目录。

第二类是本机运行数据，固定在：

```text
%LOCALAPPDATA%\DavBridge
```

这里主要是窗口位置、WebView2 缓存、临时文件、当前进程会话和产品体验记录。它不是用户必须长期记忆的唯一数据根目录。

### 15.2 DavBridge 怎么找到自定义目录

固定入口是：

```text
%LOCALAPPDATA%\DavBridge\bootstrap.json
%LOCALAPPDATA%\DavBridge\bootstrap.json.bak
```

它们只记录当前持久 DataRoot。

如果主 bootstrap 损坏，DavBridge 会从备份恢复。如果主、备都存在但都无法读取，程序会停止自动回退并明确报错，不会偷偷转回默认目录读取一套旧状态。

### 15.3 软件里如何查看所有文件

进入：

```text
关于 → 数据与迁移 → 文件与目录清单
```

可以看到 DavBridge 当前管理的核心配置、迁移账本、对账状态、兼容状态、DPAPI 凭据、备份目录，以及 LocalAppData 中的体验记录、窗口状态、运行会话、日志、Temp、WebView2 和 WebUi 缓存。

每一项都能确认：

- 它现在在哪里；
- 文件是否存在；
- 大概多大；
- 用来做什么；
- 是否进入迁移备份；
- 是否只是本机缓存。

因此以后即使忘记内部文件名，也应先从软件自身查，而不是手工翻 AppData 猜测。

### 15.4 更改数据目录

“更改”不是简单修改字符串。

DavBridge 会先安全暂停，要求新目录为空并可写，然后复制核心持久文件，逐项做 SHA-256 校验。只有全部校验成功后才切换 bootstrap。旧目录不会自动删除，可以继续作为人工回退副本。

新目录不能与旧目录互相嵌套，也不能放进 DavBridge 自己的 LocalAppData 运行目录。

### 15.5 一键备份

“备份”生成 DavBridge ZIP。

备份包内部带 `manifest.json`，记录产品版本、创建时间、每个文件大小和 SHA-256。DavBridge 在生成后会重新读取 ZIP 并校验，只有验证通过才登记为最近成功备份。

默认可以保存在当前 DataRoot 的 `Backups\`，也可以在保存对话框中选择其他位置。

### 15.6 一键恢复

恢复前 DavBridge 会先验证整个备份包，再安全暂停当前迁移，然后自动生成一份“恢复前快照”。

真正恢复时先解压到临时 staging，校验 SHA-256，再原子替换对应文件，并在替换后再次校验。完成后需要重启软件，让运行状态从恢复后的文件重新建立。

`secrets.dat` 使用 Windows DPAPI CurrentUser。如果备份来自另一个 Windows 用户或另一台机器，当前用户无法解密时，DavBridge 会跳过凭据文件并要求重新输入 WebDAV 密码，不会把不可用密文强行覆盖进去。

### 15.7 回退旧 v0.4.26 时特别注意

如果从未更改过 DataRoot，v0.4.26 和 v0.5.0 都使用默认 `%APPDATA%\DavBridge`，回退相对直接。

如果已经把 v0.5.0 的 DataRoot 改到其他目录，v0.4.26 **不会读取 bootstrap**。这时不能直接启动旧版。

正确做法是先退出 v0.5.0，备份当前自定义 DataRoot，再把当前核心持久文件安全复制回 `%APPDATA%\DavBridge`，核对无误后再启动 v0.4.26。

如果不确定，应优先保留两边目录，不删除任何旧数据。
