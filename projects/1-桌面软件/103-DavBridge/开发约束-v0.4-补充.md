# DavBridge v0.4 开发约束补充

> 约束层级：C｜项目级补充  
> 适用范围：P103 DavBridge v0.4 及其后续 UI 迁移阶段  
> 本文件只修订原 `开发约束.md` 中“技术栈固定为 WinForms”的 UI 实现部分。原文件所有数据安全、WebDAV、StrongVerified、Cycle、额度、回收站和 DELETE 约束继续完整生效。

## C-01A｜v0.4 UI 技术栈

用户已明确批准 v0.4 将显示层从 WinForms 控件 UI 迁移为：

```text
Vue 3 + TypeScript + Vite
→ Microsoft WebView2
→ C# / .NET 8 极薄 Windows 宿主
→ 既有 DavBridge.Core 与 C# 安全链
```

原 `C-01` 中“WinForms”只保留为 Windows 原生宿主能力，不再作为主业务页面 UI 框架。

## C-01B｜只换 UI，不动逻辑

本次迁移是 UI replacement，不是产品逻辑重构。

禁止因为前端迁移而修改或重新实现：

- `DavBridge.Core` 迁移与校验逻辑；
- WebDAV 客户端；
- StrongVerified；
- SourceChanged；
- WriteUnknown；
- 412 协调；
- Quota 与 Cycle；
- 每周期源端对账；
- 回收站状态机；
- `ReconciliationRemovalV030` 删除安全链；
- DPAPI 与 Data 文件格式。

如果 UI 需求与既有安全逻辑冲突，必须调整 UI，不得为了 UI 方便降低核心安全门。

## C-01C｜Web UI 最小权限

Web UI 无权直接访问凭据、私人 Data、WebDAV 写操作或删除操作实现。

所有动作必须通过 C# 宿主固定白名单命令进入既有逻辑。新增 bridge command 必须先说明为什么现有命令不足，并审查其是否扩大前端权限。

危险操作必须保留原生最终确认。前端确认不能替代 C# 安全确认。

## C-01D｜验收

每次 UI 候选至少满足：

1. 原 Core Smoke 全通过；
2. Git diff 不出现未经用户批准的 Core / Reconciliation / WebDAV / Data 逻辑修改；
3. Vue typecheck 与 production build 通过；
4. Windows 单 EXE publish 通过；
5. Web UI 至少在默认 900×620 尺寸完成视觉检查；
6. 最终视觉事实以用户真实 Windows 为准。

未经用户真实机器验收，不得把 v0.4 提升到 `p103-stable` 或 `main`。
