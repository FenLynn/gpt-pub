## 当前自动验证基线

P103 CI 当前要求：

```text
范围门禁
→ .NET 8 核心 restore
→ 11 项核心 smoke
→ Windows x64 restore / publish
→ framework-dependent 单 EXE Runtime 检查
→ 隔离 APPDATA / LOCALAPPDATA 自检
→ SHA-256
→ Windows 候选 Artifact
```

11 项 smoke 当前覆盖：

1. zip/prop 逻辑分组；
2. 50 MB 普通预留与 24 h 冲刺；
3. `state.json` 损坏后的 `.bak` 回退；
4. 正常端到端强校验；
5. PUT 返回成功但目标实际不存在；
6. 传输期间源端变化；
7. 未知目标同名冲突；
8. PUT 后崩溃恢复且不重复上传；
9. zip 已完成时只为剩余 prop 计算额度；
10. 超过单文件上限安全阻塞；
11. 6000 个 Zotero 附件 / 12000 个对象的大清单分组。
