## v0.4.3 本轮目标

本轮不改迁移逻辑，重点是把已经采用 Vue/WebView2 的 v0.4 UI 继续精修为更适合长期后台工具的紧凑桌面界面。

用户最终选定固定左侧栏方案，并要求真正落入软件，而不是只给概念图。

`sidebar-v043.css` 是本轮最后的布局比例补丁，只处理总览行高、覆盖卡窄窗口文本和低高度窗口兜底。

## 核心逻辑保持

本轮 `main → p103-exp` 的最终有效差异没有进入 `DavBridge.Core`。

以下语义继续保持：

- InfiniCLOUD 是唯一 authoritative source，源端只读；
- Zotero `.zip + .prop` Group；
- 双端 SHA256 StrongVerified；
- GoodSync 历史副本强校验接管；
- SourceChanged 优先修复；
- WriteUnknown reconciliation；
- HTTP 412 协调；
- quota / Cycle / 09:00 真实重置探测；
- 每周期源端对账；
- 新增对象普通 backlog；
- 跨周期逻辑回收站；
- DELETE 永远需要人工明确确认并在删除前再次核验；
- DPAPI 与既有 Data 文件不迁移。
