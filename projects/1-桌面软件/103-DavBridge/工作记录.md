## v0.4.9 本轮目标

本轮只做 UI 收束，不改迁移核心。来源是 v0.4.8 实机反馈，集中解决七类问题：

1. 总览流量预算上下留白不对称。
2. 流量进度条视觉单薄。
3. 转移页信息冗余，当前执行表达不清楚，字号偏小。
4. 回收站字号偏小。
5. 文档页左侧目录多余，滚动条常驻，正文比例不协调。
6. 设置页 User ID 标签换行，字段没有充分利用横向空间。
7. 左下角状态重复，最近活动抽屉字号过小。

## 已完成

总览流量模块已改为整组垂直居中，上下留白由同一布局规则控制。上传安全区使用绿色渐变，下载安全区使用蓝色渐变，警告和危险仍保留黄色与红色语义。

转移页已经重构为“当前队列结论 + 三类队列概览 + 当前动作或恢复后动作 + 总体覆盖率”。旧的长条队列说明和圆环式当前执行图标已经删除。

回收站表格、tabs、状态标签和操作按钮字号已整体放大。

文档页已移除左侧目录，改为单列正文，标题、正文、FAQ 字号重新配比，滚动条默认隐藏但仍可滚动。

设置页 InfiniCLOUD 用户字段简化为 `User ID`，文本输入框宽度统一增加到 430 px，标签列加宽。

左下角状态块改为“图标 + 主状态 + 非重复副状态”。主状态与路线状态相同时，副状态显示 Cycle。最近活动抽屉字号整体放大。
