# DavBridge 工作记录

## 当前阶段

P103 第一阶段已经完成并固化到 `main`，稳定基线为 **v0.1.7**。当前 `p103-exp` 已进入 **v0.2.0 通用任务化与 UI / 流程重构阶段**。

这一阶段的原则是：保留 v0.1.7 已经实机验证的迁移引擎与用户 Data，不为了通用化而重写可靠链路。

## v0.2 已推进

### 1. 产品定位扩展

DavBridge 不再限定为 Zotero 专用迁移器，重新定位为可靠、低速、可恢复、强校验的单向迁移、备份和镜像任务管理器。

明确不做双向同步，不引入删除传播、双向冲突合并或循环同步。

### 2. 通用任务模型

已新增：

- `TransferTaskDefinition`；
- `EndpointDefinition`；
- `TransferPolicyDefinition`；
- `QuotaDefinition`；
- 普通 WebDAV 单向模板；
- Zotero WebDAV 固定模板；
- `LegacyV017Adapter`。

当前 v0.1.7 配置可以只读投影成固定 Zotero 任务，不需要改写旧配置、状态和凭据。

### 3. v0.1.7 数据兼容

新增《数据兼容与升级.md》。Phase A/B 不迁移 `config.json`、`state.json`、`secrets.dat`。

v0.2 只新增独立 `v2-compat.json` sidecar，记录端点安全指纹。该文件不包含密码、TransferRecord 或配额账本，删除后 v0.1.7 仍可原样运行。

已有迁移记录后，当前旧任务的源/目标 URL、root 和用户名被视为任务身份，不允许直接改成另一套端点。以后从坚果云迁到其他服务应建立一个新 Zotero 任务，避免旧 StrongVerified 记录混入新任务。

### 4. 新任务型 UI 壳

主窗口已改造成第一版“左侧任务 + 右侧任务详情”布局：

- 左侧显示当前固定 Zotero 任务；
- 右侧只突出主状态、总体验证进度、当前周期流量、当前活动和主要操作；
- 初始化工具收进“初始化与诊断”；
- 状态开始转换为中文人类可读文案；
- Paused 时显示“暂停断点”；
- 窗口较窄时侧栏自动收窄，主区域可滚动，避免原版按钮互相遮挡。

### 5. 日常继续流程

两个真实安全门和端点安全指纹均有效时：

```text
暂停
→ 继续
→ 直接恢复
```

不再自动重新执行整库扫描，也不再每次弹出长期迁移确认框。

若端点身份变化，旧安全资格自动失效，不允许静默沿用。
