## v0.2.9 低流量安全事务

用户明确要求：**不加入高流量 Integrity Scrub**。本轮只推进几乎不增加额度或主要依赖元数据请求的安全机制。

已进入候选：

1. **HTTPS-only WebDAV**
   - 明文 HTTP 端点在客户端初始化阶段直接拒绝；
   - 不允许在 HTTP 上传输 Basic 凭据。

2. **禁止自动重定向**
   - WebDAV `HttpClientHandler.AllowAutoRedirect=false`；
   - 避免凭据行为在跨 host / 降级重定向中变得不明确。

3. **条件 PUT**
   - 新对象优先使用 `If-None-Match: *`；
   - 已有可信目标在需要覆盖时可使用 `If-Match: ETag`；
   - 目标在检查后被其他客户端抢先创建时由协议层返回前置条件失败，不盲目覆盖。

4. **WriteUnknown + Reconcile**
   - PUT 发生连接中断或响应丢失时，不立即二次上传；
   - 新增 `TransferStatus.WriteUnknown`，追加在枚举末尾以保持旧 `state.json` 数值兼容；
   - 先 PROPFIND 目标；
   - 目标存在且长度合理时再按现有下载预算做 GET + SHA-256；
   - 相同则直接 StrongVerified；
   - 不同则 Conflict；
   - 目标不存在则回到 SourceReady，留待后续安全重试。

5. **412 竞争窗口 reconciliation**
   - 条件 PUT 返回 `412 Precondition Failed` 时进入 reconciliation；
   - 不自动覆盖，不立即二次 PUT。

6. **完成前源 Manifest 二次快照**
   - 初始清单全部 StrongVerified 后，不立即宣布 Complete；
   - 再低流量读取一次源目录 manifest；
   - 如果迁移期间 Zotero 新增或修改附件，则进入下一安全 pass，而不是误报完成。

7. **错误语义分类基础**
   - 401、403、412、429、5xx 等已形成更明确的内部提示和 WaitNetwork / WaitRetry 分流；
   - 更细的自适应指数退避仍留在下一硬化阶段，不在本候选继续扩改。

8. **能力探测基础接口**
   - `OPTIONS` / `DAV` / `Allow` 的低流量 capability probe 已存在于协议层；
   - 尚未强制挂到日常迁移循环，避免每次运行产生无意义请求；
   - 后续只在首次连接、诊断或异常后按需使用。

## 新事务自动测试

v0.2.9 在原有 Smoke 之外增加以下测试：

- 新对象实际走 create-only 条件 PUT；
- PUT 已被服务器接收但响应丢失时，只 reconciliation，不发第二次 PUT；
- 目标竞争创建导致 412 时，对相同目标做强证明并安全接管，不盲目覆盖；
- 完成前第二次源 Manifest 能发现迁移过程中新增对象，并阻止 false Complete；
- 明文 HTTP WebDAV 在发送凭据前被拒绝。

## 明确不做

近期继续不做：

- 高流量 Integrity Scrub；
- 定期全量 GET + SHA-256；
- Client-side encrypted backup；
- HTTP/2 / HTTP/3 性能追逐；
- WebDAV LOCK；
- 双向同步；
- 删除传播；
- rename detection；
- 新建普通 WebDAV 用户任务。

如以后需要完整性巡检，只保留低流量 Metadata Probe 方向：对象存在性、size、ETag、LastModified；只有元数据异常时才进入已有安全处理流程。

- 低流量 Metadata Probe，仅异常时升级处理。
