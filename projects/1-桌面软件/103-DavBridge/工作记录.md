## v0.1.6 重置状态机

```text
坚果云账户页录入：下一重置日期 2026-09-07
→ DavBridge 内部按“日期”保存
→ 主界面只显示 2026-09-07
→ 2026-09-07 当天 09:00 以前保持 WaitQuota
→ 不清零旧周期上传/下载账本
→ 09:00 后寻找仍需真实 PUT 的最小完整 zip + prop Group
→ 执行真实 PUT
→ 准确资源 PROPFIND Depth:0
→ 目标重新 GET + SHA-256
→ 整个 Group StrongVerified
→ 才把新周期确认成功
→ 本次探测流量作为新周期第一笔计量
→ 下一重置日期推进到下一月同一日期
→ 继续长期迁移
```

若探测未通过：

```text
不清零旧账本
→ 保持 WaitQuota
→ 约 1 小时后再次尝试
```

09:00 只是 DavBridge 的保守探测起点，不记作坚果云官方公布的具体重置时间。
