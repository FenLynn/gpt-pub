## v0.1.7 既有副本验证流程

```text
长期迁移必须 Paused
→ 要求首个真实上传 Group 已经通过
→ 获取 InfiniCLOUD 完整源清单
→ 读取坚果云本次可见列表（750+ 时仍只视为部分列表）
→ 在本次可见对象中寻找 zip + prop 都已存在的未验证完整 Group
→ 选择其中较小的一组
→ 对两个准确目标路径再做 metadata 确认
→ 弹出计划窗口
→ 明确显示：NO-WRITE，本次上传上限严格 0 B
→ 用户确认
→ 源端 GET + SHA-256
→ 目标端 GET + SHA-256
→ 完全一致则 StrongVerified
→ 不一致则 Conflict
→ 任何代码路径尝试 PutFileAsync 都由 NO-WRITE 包装器直接拒绝
→ 两个成员 StrongVerified 且上传增量 = 0 B
→ ExistingReplicaValidationPassed = true
→ 仍保持 Paused
```
