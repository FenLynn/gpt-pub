# DavBridge 工作记录

## 当前阶段

P103 第一阶段已经完成并固化到 `main`，稳定基线为 **v0.1.7**。当前 `p103-exp` 处于 **v0.2.x 现有体验收口阶段**。

这一阶段的最高优先级已经调整为：**不新增功能，不追求通用能力完整，把当前正在运行的 Zotero 迁移任务做到稳定、顺手、清楚、耐用。**

通用任务模型保留在底层作为未来结构准备，但近期不开放“新建任务”，不继续扩展普通 WebDAV、更多端点或其他迁移类型。除非现有运行暴露真实问题，否则不改 v0.1.7 已验证的迁移核心。

## v0.1.7 已完成真实验证

- InfiniCLOUD 与坚果云真实 WebDAV 认证、目录访问；
- 9.97 GB / 3,465 个 Zotero 逻辑组迁移就绪扫描；
- 真实缺失目标 PUT + Depth:0 + GET + SHA-256；
- GoodSync 既有完整副本 NO-WRITE 零上传接管；
- 双安全门；
- 长期迁移连续运行；
- 暂停；
- 完全退出与重新启动恢复；
- 恢复后继续，不重复处理已 StrongVerified 对象；
- 主窗口关闭到托盘后后台继续迁移；
- 流量账本跨进程连续；
- 重置日期仅按日期保存，09:00 后探测策略进入代码和自动测试。

## v0.2.0 当前实机状态

v0.2.0 已成功读取并继续使用 v0.1.7 原有 Data，用户实机截图确认当前任务状态、StrongVerified 记录、上传/下载账本、初始化状态和运行状态均已正常接续，未发生数据重置或重新初始化。

第一版任务型 UI 已能使用，但仍有明显体验问题：

1. 主操作按钮宽高和间距不统一；
2. 顶部状态与状态卡存在重复信息；
3. 左侧仍存在“+ 新建任务”和未来能力提示，当前没有实际价值；
4. `Strong verification complete.` 等少数英文阶段文案仍会透出；
5. 左侧任务卡、右侧状态、按钮组和底部说明的视觉层级仍偏开发态；
6. 不同窗口宽度下仍需继续检查对齐、换行和遮挡；
7. 诊断工具是低频入口，不应与日常暂停/继续抢视觉。

## v0.2.x 产品策略冻结

近期明确不做：

- 不开放“新建任务”；
- 不新增普通 WebDAV 迁移模板；
- 不新增更多云端或本地端点；
- 不做双向同步；
- 不做删除传播、双向冲突合并或 rename detection；
- 不为了通用架构改写正在稳定工作的 MigrationEngine；
- 不迁移 `config.json`、`state.json`、`secrets.dat` 到新格式。

近期只允许推进以下现有体验：

- 主界面视觉层级；
- 窗口自适应与缩放稳定性；
- 按钮尺寸、间距、主次关系；
- 状态中文化和状态语义；
- 当前活动、暂停断点、等待原因显示；
- 暂停 / 继续直接操作；
- 托盘和后台运行体验；
- 设置页易用性；
- 初始化与诊断区域的弱化和整理；
- 错误、冲突、等待额度、等待网络的可理解提示；
- 现有日志与运行信息的可读性，不新增复杂日志系统。
