## v0.5.2 本轮信息架构收束

用户实机反馈 v0.5.1 的数据管理和 About 字号仍偏小，而且 About 仍然承担过多职责。

v0.5.2 最终采用：

```text
About
  [关于] [运行状态]

设置 → 数据与迁移
  持久数据目录  可修改
  本机运行目录  固定
  备份与恢复
  文件与目录清单  查看全部
```

About 不再显示数据目录、备份按钮和文件清单，也不再显示低价值的技术栈信息。

数据管理不新增左侧一级导航。原因是它属于低频维护，不是总览、转移、回收站那类日常业务页。所有数据操作集中在设置中，避免主导航继续膨胀。

数据设置页使用更大的原生字体和分块结构。完整文件清单通过单独原生窗口按需打开，保留“所有数据都能从软件内查到”的要求，同时避免常驻信息墙。

浏览器 CI 继续验证 About 1100×825 和 900×620，并新增运行状态 Tab 的 1100×825 预览。

## v0.5.3 实机反馈修正

本轮只处理四项实机问题。

第一，修复“打开持久数据 / 打开本机运行目录”后设置页被关闭并回到主页。根因是两个只读打开动作与更改、备份、恢复共用了同一套“关闭 Settings 后调用 MainForm”的维护入口。现在两个打开动作原地调用资源管理器，设置页保持不变。

第二，悬浮提示统一为 500 ms。Web UI 使用单一 global tooltip 定时器，移除旧 CSS `:after` 即时提示，避免双提示；Settings 和文件清单的 WinForms ToolTip 同步使用 500 ms InitialDelay / ReshowDelay。

第三，数据与迁移页继续减字。目录用途、备份说明、文件清单说明不再常驻显示，改为悬浮说明。页面保留标题、可修改/固定状态、路径和按钮。

第四，About 页面从垂直居中改为顶部固定锚点。两个 Tab 只替换下方内容，软件名、版本号、说明和 Tab 条不再上下跳。

代码验证 head `06bc26e20835481c64de31c72dc7d17634707b35` 已通过 P103 CI run `34847690721` 五项全绿。


## v0.5.4 数据按钮统一留页与 About 字号

用户实机继续发现“数据与迁移”中不止两个打开按钮，其他维护按钮仍会因为旧调用方式关闭 Settings 并返回主页。

v0.5.4 不再维护“哪些数据按钮允许留页”的白名单，而是直接删除数据维护入口关闭 Settings 的能力。所有数据动作都在当前设置上下文执行。

```text
打开持久目录      留在数据页
打开本机目录      留在数据页
更改位置          取消时留页，成功时按既有安全流程重启
立即备份          留页并刷新最近备份
从备份恢复        取消时留页，成功时按既有安全流程重启
查看全部          原地打开清单窗口
```

静态检查确认 `InvokeDataMaintenanceAsync` 不再包含 `Close()` 或 `DialogResult`。

About Tab 标题提高到 14 px，下方标签和值提高到约 13.5 / 14 px，并增加行高。浏览器预览确认顶部仍保持固定。
