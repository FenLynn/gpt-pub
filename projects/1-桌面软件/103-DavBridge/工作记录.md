## v0.4.16 可靠性封板

本轮不修改 UI，只扩展自动故障注入与恢复回归。

新增 Core Smoke：

- repeated pause resume remains idempotent；
- network list failure recovers on retry；
- verification network loss recovers without re-put；
- zero byte object verifies safely；
- quota exact boundary is deterministic。

加上既有测试，Core Smoke 共 19 项。

重点新增证明：

- 暂停、继续、再暂停可以重复，已经 StrongVerified 的成员不重复 PUT；
- manifest 网络中断进入 WaitNetwork，下一轮可恢复；
- PUT 已成功但强校验网络中断时，恢复不得二次 PUT或二次计上传额度；
- 零字节对象可以安全 StrongVerified；
- 安全额度等于所需字节时允许启动，多 1 byte 时禁止 PUT。

Windows native self-test 继续覆盖 config/state/reconcile/product sidecar 备份恢复、runtime session、background wake 和窗口迁移。
