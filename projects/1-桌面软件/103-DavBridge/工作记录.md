## v0.1.0 首个闭环

首个候选不得以 UI 完成为目标，必须先证明：

```text
Mock 源端对象
→ 下载并计算 SHA-256
→ 目标 PUT
→ 准确 URL Depth:0 确认
→ 目标重新 GET
→ SHA-256 一致
→ 源端传输前后未变化
→ 状态原子落盘
→ 重启后不会重复误判
```

同时必须证明 PUT 返回成功但目标端随后不存在时不会记成功。
