## v0.2.24 UI 收口

### 活动切换

新增 `UiActivityTabsV0224`。

右上角 `转移 | 校核` 改为一个轻量分段控件。选中项使用白色内层和低饱和蓝灰文字，未选中项为浅灰。校核运行只显示小型绿色圆点。

### 转移页

转移阶段改为连续节点流程：

`预核验 / 拉取 / 核验 / 上传 / 回读`

总体进度改为柔和 steel blue，当前文件改为 muted teal，周期流量按额度区间使用 muted sage、amber、coral。删除原总体偏紫和高饱和流量条效果。

顶部 InfiniCLOUD 到坚果云路由同样改为柔和状态色，状态文字采用深色，不再依赖大面积饱和色块和白字。

左栏宽度、任务卡、标题、区块间距、周期区和底部主操作进一步压缩和统一。

### 校核页

阶段条改为连续节点流程：

`探测 / 源读取 / 目标读取 / SHA256`

探测时显示完整确定性进度和百分比：

`探测已有副本 x / N · xx.x%`

校核结束后在当前应用会话保留紧凑摘要。不同结果分别显示完整副本数量、接管组数、实际下载量、停止或异常状态。

校核入口同时说明不可用原因，避免只有一个灰掉的按钮而不知道原因。

### 绘制层收口

运行时停止挂载旧：

- `UiVisualPolishV029`
- `UiMeterPolishV0219`
- `UiRouteOverallV0215`

新增 `UiRefinementV0224` 统一最终路由、阶段条和 meter 绘制，减少多个活动 Timer 重复覆盖同一区域。

### 按钮

`PrimaryActionSurfaceV0217` 改为低饱和圆角主操作。

`UiButtonPolishV0219` 同步统一校准、保存、取消、重新验证等普通按钮。

## 功能复核

本轮没有改 `MigrationEngine`、WaitQuota 核心、WebDAV 安全事务、状态文件 Schema 或配额语义。

认为值得立即补齐且已经实现的内容：

1. 校核扫描百分比。
2. 校核结束摘要。
3. 校核不可启动原因。
4. 校核运行中的轻量状态标识。
5. UI self-test 主动切换并验证转移页和校核页。

当前不做：

- 校核扫描游标持久化。实时重新探测更符合目标端可能被外部客户端继续改变的事实。
- 高流量完整性巡检。
- 新建普通 WebDAV 任务。
- 真正多任务持久化。
- 跨进程保存纯展示性的上次校核摘要。
