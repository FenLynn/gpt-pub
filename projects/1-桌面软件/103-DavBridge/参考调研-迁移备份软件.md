# DavBridge 迁移与备份软件参考调研

本文件记录 2026-08-12 针对 DavBridge v0.2.x 的三轮外部参考调研。目标不是扩充功能，而是从成熟开源和商业软件中提取真正适合当前 Zotero 单向迁移任务的交互与可靠性经验。

## 调研前提

近期硬边界：

- 不做双向同步；
- 不做删除传播；
- 不开放新建通用任务；
- 不扩展更多端点；
- 不为了 UI 重写已经实机验证的迁移引擎；
- v0.1.7 Data 必须继续可回滚；
- 主页优先服务当前长期运行的 Zotero 迁移。

## 第一轮｜GitHub 同类项目

### rclone-ui

值得学习：

- UI 是成熟传输引擎之上的轻量管理层，不试图把传输语义重新实现一遍；
- 将任务、调度、历史和通知分层；
- 调度执行器可以脱离 GUI 运行；
- 任务运行历史与通知是独立层。

不直接照搬：

- 大量远端类型和远端浏览能力；
- 完整调度器；
- 多任务创建和管理；
- 面向 rclone 的高级参数暴露。

对 DavBridge 的启示：继续保持 UI 与已验证迁移核心分离，托盘和主窗口只做状态与控制层。

### Kopia

值得学习：

- GUI 与核心备份能力分层；
- 长期后台任务按策略运行；
- WebDAV 只是众多存储端点之一，端点与任务本身不是同一个概念。

不直接照搬：

- 快照仓库；
- 去重；
- 压缩；
- 加密仓库；
- 恢复浏览器。

对 DavBridge 的启示：底层通用端点抽象保留即可，近期不要把这些备份系统能力带进产品。

### Duplicati

值得学习：

- 面向普通用户强调“设定后自动运行”；
- 调度、带宽限制和后台运行属于任务属性，不应长期挤占主页；
- 高级设置与普通使用明显分层。

不直接照搬：

- 增量归档格式；
- 压缩和加密备份链；
- 多目标备份策略。

### NPBackup

最值得学习的是“set and forget”思路：

- 任务长时间无人关注时，健康状态比功能数量重要；
- 后台工作默认使用较低 CPU / IO 优先级，避免影响日常使用；
- 不仅关注失败，也关注“任务很久没有成功运行”这种静默失效；
- GUI 主要让最终用户看到最近备份是否健康，复杂管理退到管理层。

对 DavBridge 的启示：以后可以增加轻量“最近一次强校验成功时间”和静默停滞提醒，但不进入 v0.2.2 首轮 UI 重构。

### RcloneBrowser 及传统双栏远端浏览器

可借鉴价值较低。它们解决的是文件浏览和手工传输，而 DavBridge 的核心是长期无人值守的可证明迁移。双栏文件浏览器不是当前主页应该发展的方向。

## 第二轮｜成熟商业和桌面软件

### TeraCopy

这是本轮对 DavBridge 运行态 UI 最有价值的参考。

值得学习：

- 总任务百分比始终是运行态主信息；
- 当前文件、当前速度、完成/失败计数和总体进度分层显示；
- 当前任务可以暂停，重启后继续未完成列表；
- 复制时计算校验值，完成后重新读取目标进行验证；
- 验证成功和失败使用明确状态图标；
- 失败、跳过和未处理对象可以单独重试；
- 详细文件列表可以按需展开，不占据默认紧凑视图。

DavBridge 采用：总体进度、当前文件真进度、强校验结果、异常按需展开。

DavBridge 不采用：速度图作为主页核心、多线程传输、复杂文件队列操作。

### Syncovery

最值得学习的是运行模式层级：

- Profile Overview 只显示任务当前状态、进度、上次结果和下次运行；
- Background 模式默认只显示基础进度；
- 需要时再打开 Detailed Progress；
- 配置和运行状态不是同一个页面层级；
- 支持复制后内容验证和既有文件的一致性检查。

DavBridge 采用：默认基础状态，详细维护按需打开；不在主页铺满诊断和日志。

### GoodSync

值得学习：

- 每个 Job 有独立运行状态和历史；
- 当前运行与历史结果分开；
- 后台 Runner 与管理 UI 解耦；
- 单线程、速度限制、重连时间等都是任务设置，不是主页信息；
- Data Transfer Usage 单独统计，不与文件进度混成一个数字。

DavBridge 采用：上传和下载额度独立显示；后台任务与 UI 解耦的思路继续保持。

DavBridge 不采用：Analyze / Sync 双阶段日常流程。初始化完成后“继续”必须直接恢复。

### Mountain Duck / Cyberduck

值得学习：

- 托盘 / 状态栏是常驻入口；
- Activity 只显示正在进行和待处理的少量活动；
- 网络断开、恢复、完成等事件使用系统通知；
- 详细传输窗口不是常驻主界面；
- 传输列表可以在关闭应用后保留并恢复。

DavBridge 采用：托盘优先，轻量状态面板，异常和关键状态使用系统通知。

### FreeFileSync

值得学习：

- Batch Job 可以最小化运行；
- 进度窗口不显示时可从托盘重新打开；
- 无人值守模式需要避免弹窗阻塞；
- 后台任务与交互式比较界面分开。

DavBridge 采用：运行中绝不能因为普通提示框阻塞后台迁移。

DavBridge 不采用：Mirror / Update / Two-way 等同步语义和预览比较界面。

### Arq Backup

值得学习：

- 主程序与后台 Agent 分离；
- 用户主要操作 Backup Plan，后台 Agent 持续执行；
- 可以提醒“多天没有成功备份”这种静默问题；
- Validation 会重新读取远端内容确认对象完整。

DavBridge 采用：主窗口是低频管理界面，托盘后台才是常态；以后可考虑静默停滞提醒。

### ChronoSync

值得学习：

- 菜单栏 / 托盘直接列出正在运行任务及进度；
- 每个任务保留自己的日志；
- 系统通知只关注完成和错误。

DavBridge 采用：托盘轻量状态与关键通知，不把日志长期露在主页。

## 第三轮｜按 DavBridge 真实约束反向筛选

### 立即采用

1. **服务流向成为主页视觉中心**
   - 左侧 InfiniCLOUD；
   - 中间方向箭头；
   - 右侧坚果云；
   - 箭头上方显示唯一主状态；
   - 状态文字与颜色同时表达，不只依赖颜色。

2. **总体进度以逻辑组强校验为主**
   - 源端显示总逻辑组；
   - 目标端显示已强校验逻辑组；
   - 中间显示百分比和总进度条；
   - 文件对象数作为次级统计；
   - 不使用坚果云 750 项列表推断目标总量。

3. **当前文件显示真实 I/O 字节进度**
   - 文件名放在进度条内；
   - 百分比来自真实 GET / PUT 已处理字节；
   - 下方只显示当前阶段，例如“读取源文件并计算 SHA-256”“校验已有副本”“上传目标”“重新读取目标并强校验”；
   - 不用人为阶段权重伪造整个文件生命周期百分比。

4. **当前周期使用上传、下载两条独立额度条**
   - 正常绿色；
   - 接近安全边界黄色；
   - 极接近停止阈值红色；
   - 安全预留作为右侧灰色区；
   - 重置日期和 09:00 后探测放在同一卡片底部。

5. **主页只保留一个动态主控制**
   - Running：暂停；
   - Paused：继续；
   - WaitQuota：等待新周期；
   - WaitNetwork：等待网络；
   - Complete：已完成；
   - 只有可执行动作的状态才显示为按钮。

6. **设置固定在左下角**
   - 设置页左侧四类：账户与端点、流量与限速、后台运行、安全与维护；
   - 右侧显示具体设置；
   - 诊断、扫描、安全验证全部进入安全与维护。

7. **托盘是第一入口**
   - 单击后显示轻量状态面板；
   - 只包含任务名、状态、总体百分比、本周期上传量和一个暂停或继续按钮；
   - “打开主界面”作为次级动作。

8. **异常只有出现时才占据视觉空间**
   - 正常时不长期显示“异常 0”；
   - 发生 Conflict / Failed / 网络或认证问题时，主页出现明确的问题条目；
   - 点击再看详细原因和安全操作。

9. **暂停增加过渡状态**
   - 用户点击暂停后，如当前 I/O 尚未到安全边界，界面显示“正在安全暂停”；
   - 到安全断点后再显示“已暂停”；
   - 不让用户误认为按钮无响应。

### 以后再考虑

- 最近一次 StrongVerified 时间；
- 长时间没有新强校验记录时的静默停滞提醒；
- 轻量历史，例如最近 10 次状态变化；
- 当前文件即时速度；
- Windows 系统通知的粒度设置。

这些都属于现有任务的可观察性增强，但不进入 v0.2.2 第一轮。

### 明确不采用

- 双向同步；
- 自动删除传播；
- 自动冲突覆盖；
- 依赖目标目录完整列举判断迁移完成；
- 多线程作为默认传输策略；
- 复杂双栏文件浏览器；
- 主页常驻日志；
- 主页常驻诊断按钮；
- 总任务 ETA。当前任务受月度配额和人工流量校准影响，跨周期 ETA 很容易制造假精确；
- 主页速度曲线。对当前低速、额度受限的长期迁移，速度波动不是主要决策信息；
- 每次继续重新 Analyze / Scan / Confirm；
- 虚假的阶段百分比。

## 不显示在日常主页的内容

- 连接诊断；
- 迁移就绪扫描；
- 首组验证；
- 既有副本验证；
- 端点 URL；
- 用户名和密码；
- 调试日志；
- 大段说明文字；
- 未来功能宣传。
