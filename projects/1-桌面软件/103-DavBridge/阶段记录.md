## v0.3 阶段目标

DavBridge 从一次性长周期迁移进一步收口为当前 Zotero 任务的**持续强校验单向镜像维护器**：

- InfiniCLOUD 是唯一 authoritative source；
- 坚果云保存经过 StrongVerified 核准的镜像子集；
- 每个真实额度周期开始后自动做源端对账；
- 修改过的历史副本优先修复；
- 新增对象进入普通 backlog，不插队；
- 源端删除先进入逻辑回收站；
- 跨至少一个后续已确认额度周期仍缺失后才允许人工审查；
- DELETE 永远需要人工明确确认。

## Cycle

Cycle ID 使用启动当前额度周期的真实重置日期，固定格式 `yyMMdd`。

例如 2026-09-07 的真实重置启动新周期，Cycle ID 为 `260907`。

实现专门避免 CI / 本机时区转换造成日期跨日。

## 周期对账

源 metadata 未变时不下载文件内容。

源 metadata 变化时重新读取 InfiniCLOUD 并计算 SHA256：

- SHA 相同，只更新源 metadata；
- SHA 不同，置为 `SourceChanged`，优先刷新目标；
- 重新 StrongVerified 前保留旧历史核准基线。

新增对象只进入普通 backlog。

## 回收站

第一次完整缺失只记录 `FirstMissingCycleId`，目标完全不动。

后续 Cycle 仍缺失才进入人工审查。人工可以删除或“本周期继续保留”。保留项下个 Cycle 若仍缺失会再次进入审查，因此允许跨很多周期继续存在。

删除前必须再确认：

- 源端仍然完整缺失；
- 不是 zip / prop 部分恢复；
- 目标仍然对应历史 StrongVerified 身份；
- ETag 无法证明时按需目标 GET + SHA256；
- 删除后准确路径确实不存在；
- 网络或超时不确定时先 reconciliation，不盲目重复删除。

人工删除成功后保留历史 SHA 证据，并把记录置为待恢复语义，以便源端以后重新出现时优先重建目标。
