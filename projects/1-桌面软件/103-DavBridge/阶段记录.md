## 安全与 Data

v0.4.3 没有修改 `DavBridge.Core`、迁移状态机、WebDAV 核心、StrongVerified、SourceChanged、WriteUnknown、HTTP 412、quota/Cycle、回收站和 DELETE 安全链。

核心 Data 继续兼容：

```text
config.json
state.json
state.json.bak
secrets.dat
reconcile.json
reconcile.json.bak
```

`MigrationState.SchemaVersion` 仍沿用既有兼容策略，不因为 UI 变化执行不可逆 Data 迁移。

## 提升规则

未经用户真实机器验收，不得把 v0.4.3 提升到 `p103-stable` 或 `main`。

候选 Artifact、CI 全绿或 `stable → main` 均不构成正式 Release 授权。正式发布必须在当前会话中得到用户针对明确版本的明确人工授权。

## 准确断点

从 `p103-exp` 当前实时 head 接续，优先响应用户对 v0.4.3 的实机反馈，不主动扩展功能，不回到旧 WinForms 业务 UI，不重写 Core。
