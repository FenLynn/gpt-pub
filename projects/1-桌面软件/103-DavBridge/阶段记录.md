## v0.3 阶段目标

DavBridge 当前继续作为 Zotero 持续强校验单向镜像维护器：InfiniCLOUD 是唯一 authoritative source，坚果云保存经过 StrongVerified 核准的镜像子集。每个真实额度周期开始后自动做源端对账，修改过的历史副本优先修复，新对象进入普通 backlog，完整源缺失先观察，跨周期仍缺失后才进入人工回收站审查，DELETE 永远需要人工明确确认。

Cycle ID 使用启动当前额度周期的真实重置日期，格式 `yyMMdd`，例如 2026-09-07 对应 `260907`。实现禁止通过运行机器时区转换该日历日期。

## v0.3.1 UI 精修

v0.3.0 实机反馈指出默认窗口存在底部遮挡和不必要滚动条，同时顶部云盘 Logo 在新壳中丢失。

v0.3.1 只调整 UI，不改变迁移、对账、配额、回收站和 DELETE 安全语义。

本轮完成：

- 默认 900×620 内容区改为 Fill 布局，不再依赖纵向 AutoSize 撑开；
- 默认内容区不显示横纵滚动条，极限小窗才启用紧凑滚动兜底；
- 总览重新分配路线、周期、覆盖、当前任务、流量和底部操作的行高；
- 底部主操作获得独立可用空间，新增越界硬测试；
- 恢复 InfiniCLOUD 橙色云形 Logo 和坚果云橡果 Logo；
- 保留双右箭头，并让新路由独占布局行，旧圆点路由退出布局；
- Header、Cycle、Tab、按钮、回收站表格统一低饱和蓝灰视觉；
- 转移页和回收站压缩无效留白；
- 默认 900×620、1200×760、125%、150% DPI 均纳入新 UI 硬门。

## Data 与安全语义

核心 Data 不迁移：`config.json`、`state.json`、`state.json.bak`、`secrets.dat`，`MigrationState.SchemaVersion` 仍为 1。

v0.3 独立使用 `reconcile.json` 与 `reconcile.json.bak` 保存 Cycle、缺失观察、人工决定和删除历史。sidecar 丢失只允许退化为重新观察，不允许让对象更容易删除。

InfiniCLOUD 继续只读，Zotero `.zip + .prop` 继续成组，条件 PUT、WriteUnknown、412 reconciliation、目标重读 SHA256、SourceChanged、WaitQuota NO-WRITE 等安全链全部保持。
