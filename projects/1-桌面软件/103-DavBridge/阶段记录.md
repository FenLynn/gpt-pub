# DavBridge 阶段记录

## 当前基线

P103 DavBridge 当前处于首次开发阶段，尚无正式版本、正式标签或 Release。

- 当前开发分支：`p103-exp`
- 稳定候选：尚未建立
- 正式版本：无
- 正式标签：无
- Release：无

## 当前已确认设计基线

- Windows x64，C# / .NET 8 / WinForms；
- framework-dependent 单文件发布，优先保持 Runtime 轻量；
- InfiniCLOUD 只读，坚果云为唯一目标写端；
- zip/prop 成组；
- 目标重新 GET 与 SHA-256 强校验后才算成功；
- 普通周期预留 50 MB，重置前 24 h 可进入冲刺；
- 官方流量不可稳定自动读取时允许人工不定期校准；
- 登录后可自动启动，默认托盘静默运行；
- 最终 `Content Complete` 与 `Exact Mirror` 分开判定。

## 尚未验证

- 真实 InfiniCLOUD 服务的完整目录扫描与属性表现；
- 真实坚果云对准确文件 URL 的 Depth:0 行为；
- 坚果云额度耗尽时的稳定 HTTP/响应特征；
- 坚果云超过 750 个目录项后的实际分页协议细节；
- 首个真实 Zotero zip/prop Group 的端到端强校验；
- Windows 11 实机托盘、自启动、睡眠/唤醒和长时间运行。

上述内容在获得真实证据之前不得记录为“已完成”。
