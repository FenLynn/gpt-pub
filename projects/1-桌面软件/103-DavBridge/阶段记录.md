## v0.1.6 当前设计基线

- Windows x64，C# / .NET 8 / WinForms，framework-dependent 单文件发布；
- InfiniCLOUD 正式产品代码只读，坚果云为唯一目标写端；
- `.zip` 与 `.prop` 成组处理；
- PUT 成功后必须针对准确资源执行 `PROPFIND Depth:0`，随后从坚果云重新 GET，并与源端做 SHA-256 强校验；
- GoodSync 或其他客户端已经存在于目标端的文件允许经过 GET 与 SHA-256 后安全接管，完全一致时不重复 PUT；
- 既有目标与源端不同且无法证明是 DavBridge 自己写入的旧版本时进入冲突，不自动覆盖；
- 上传 1 GB、下载 3 GB 都进入安全额度模型；普通阶段为其他服务保留 50 MB；
- 流量允许人工校准，DavBridge 在校准点以后保守累计真实 PUT 与目标验证 GET；
- 坚果云重置值在产品语义中只保存“日期”，不保存或显示未经用户提供的具体时刻；
- 例如用户输入 `2026-09-07`，主界面只显示该日期，不再显示旧版推导出的 `01:00`；
- 到重置日期当天 09:00 以前，DavBridge 不清零旧周期账本，只保持等待；
- 当地时间 09:00 以后，DavBridge 优先寻找一个仍需真实 PUT 的最小完整 zip + prop Group 做新周期上传探测；
- 探测必须真实完成 PUT、准确目标确认、目标重新 GET 和 SHA-256，只有完整 Group 强校验通过后，才把新周期记为已确认；
- 探测失败时旧周期账本保持不变，后台约 1 小时后重试，不因“日期已到”擅自恢复整库迁移；
- 09:00 是 DavBridge 的保守探测起点，不宣称为坚果云官方重置时间；
- 新周期探测成功后，本次探测产生的上传和校验下载会计入新周期账本，然后继续长期迁移；
- 登录后可以自动启动并托盘静默运行，暂停状态持久化；
- 已保存密码按真实长度显示为 `*`，眼睛按钮可临时显示明文；
- 坚果云目录列举达到 750 项时只表述为 `750+` 或“本次列举达到上限”；
- 完整源码统一以 `代码/DavBridge.sln` 恢复，开发期源码事实源为远端 `p103-exp`；
- 首组验证安全门仍保留，完整 Group 两成员均达到 `StrongVerified` 前不得开放整库长期迁移；
- 最终 `Content Complete` 与 `Exact Mirror` 分开判定。
