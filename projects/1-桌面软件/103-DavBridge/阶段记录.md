# DavBridge 阶段记录

## 第一阶段正式稳定基线

P103 DavBridge 已完成第一阶段核心迁移链验证，**v0.1.7 已按 `p103-exp → p103-stable → main` 正式固化**。

- 正式稳定基线：`v0.1.7`
- 正式主线：`main`
- 稳定基线分支：`p103-stable`
- 当前开发分支：`p103-exp`
- 当前开发版本：`v0.2.0`
- 源码统一入口：`代码/DavBridge.sln`

v0.1.7 是当前可靠回滚点。v0.2 不替换或改写 main 上的这一事实。

## v0.1.7 已验证能力

- Windows x64，C# / .NET 8 / WinForms，framework-dependent 单 EXE；
- InfiniCLOUD 源端只读，坚果云为目标写端；
- Zotero `.zip + .prop` 成组处理；
- PUT 后准确资源 `PROPFIND Depth:0`、目标重新 GET、SHA-256 对比后才记 `StrongVerified`；
- GoodSync 已有目标一致时 GET + SHA-256 后零上传接管，不一致则冲突，不自动覆盖；
- 首组真实上传与既有副本 NO-WRITE 接管双安全门；
- 上传 1 GB、下载 3 GB 双配额与普通 50 MB 安全预留；
- 人工流量校准；
- 坚果云重置只记录日期，重置日 09:00 后真实上传探测；
- 暂停、断点、完全退出恢复、恢复后继续、托盘后台运行；
- Windows DPAPI 凭据；
- 目录列举达到 750 时显示 `750+`，准确文件确认不依赖目录列表完整性。

## v0.2 产品定位

DavBridge 从 Zotero 专用迁移器扩展为：

> 可靠、低速、可恢复、强校验的单向迁移、备份和镜像任务管理器。

明确不做双向同步，不引入删除传播、双向冲突合并、双向 rename detection 或循环同步。

Zotero 保留为固定任务模板，未来同一模板可以用于 InfiniCLOUD → 坚果云、坚果云 → 其他 WebDAV 等不同单向任务。新端点组合必须创建新任务，不能把已有历史记录的旧任务直接改头换面。

## v0.2 当前代码状态

当前 `p103-exp` 已完成第一批架构与交互改造：

### 通用模型

- `TransferTaskDefinition`；
- `EndpointDefinition`；
- `TransferPolicyDefinition`；
- `QuotaDefinition`；
- 普通 WebDAV 单向模板；
- Zotero WebDAV 固定模板；
- `LegacyV017Adapter`，把 v0.1.7 当前单任务只读投影为一个固定 Zotero 任务。

### 兼容与回滚

v0.2 Phase A/B 不迁移、不重写：

```text
%APPDATA%/DavBridge/config.json
%APPDATA%/DavBridge/state.json
%APPDATA%/DavBridge/secrets.dat
```

允许新增 `v2-compat.json` sidecar，仅记录端点安全指纹，不记录密码、TransferRecord 或配额账本。删除 sidecar 后 v0.1.7 仍可继续使用原 Data。

已有 TransferRecord 后，设置页阻止直接修改源/目标 URL、root 和用户名。密码、限速、配额预留、托盘和自启动等运行参数仍可修改。

未来若真正进入多任务持久化，必须先执行自动备份、等价性验证和可回滚转换；如果内建转换不足以安全完成，则同时提供一次性转换工具或脚本。

### 第一版任务型 UI

- 左侧任务区域，右侧当前任务详情；
- 当前 v0.1.7 任务显示为“Zotero 附件迁移”；
- 日常首页只突出状态、强校验进度、周期流量、重置日期、当前活动和主操作；
- 连接诊断、就绪扫描、流量校准、两个安全门收到“初始化与诊断”区域；
- Running、Paused、WaitNetwork、WaitQuota、WaitRetry、Complete 转成人类可读中文；
- Paused 状态的 `CurrentGroupKey` 显示为“暂停断点”；
- 窄窗口时左侧自动收窄，右侧允许滚动，避免原布局按钮遮挡。

### 日常继续流程

当两个安全门已经通过且端点安全指纹仍匹配时：

```text
暂停
→ 继续
→ 直接恢复
```

不再重新执行整库就绪扫描，也不再每次弹长期迁移启用确认。

如果端点身份变化，则旧安全资格不沿用，任务重新进入初始化要求。
