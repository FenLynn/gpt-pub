## 本阶段结果

v0.5.1 解决的核心问题不是增加普通迁移功能，而是让软件自身成为数据位置和恢复方式的事实入口。

当前已经形成：

```text
唯一持久 DataRoot
+ 固定 bootstrap
+ 固定本机 LocalRoot
+ 文件与目录清单
+ DataRoot 安全迁移
+ manifest / SHA-256 备份
+ 恢复前安全快照
+ staging / 原子恢复
+ DPAPI 跨用户安全跳过
+ 明确的 v0.4.26 回退规则
```

DavBridge.Core、WebDAV、StrongVerified、quota/Cycle、Reconciliation、回收站和 DELETE 安全链没有因本轮数据管理主题改变。

## 后续

当前不再继续扩张 v0.5.1 功能。

下一步是用户真实 Windows 验收，重点检查 About、设置、打开目录、备份，以及使用非生产目录演练 DataRoot 迁移和恢复。

只有用户明确授权后才能提升 `p103-stable` / `main`。正式 GitHub Release 仍需要单独授权。


## v0.5.1 信息分层结果

v0.5.1 不改 DataRoot、备份、恢复和 bootstrap 语义，只修正信息层级。

About 不再承载完整文件管理清单，只显示持久数据摘要、最近备份和数据管理入口。完整文件与目录信息迁移到独立二级数据管理页。

数据管理页对两个目录做明确角色标识：持久数据目录为“可修改”，本机运行目录为“固定”。这解决了 v0.5.0 实机中“两个目录是否都能修改”的歧义。
