## v0.4.13 阶段目标与结果

本阶段修复人工暂停的交互和真实执行语义。

暂停现在是两阶段状态：

```text
用户点击暂停
→ UI 立即：正在暂停
→ 当前文件完成必要的安全收尾
→ MigrationEngine 在下一个 member 前命中 pause boundary
→ EngineState.Paused
→ UI：已暂停，动作变为继续
```

人工暂停不再通过取消活动 run token 强行中断当前 PUT。应用生命周期取消仍保留 cancellation token。

新增 Core Smoke 验证：提出暂停后，第一个正在处理的 member 必须完成 StrongVerified，第二个 member 不得启动，最终状态必须为 Paused。
