## 本阶段结果

v0.5 底层数据语义已经形成：

```text
唯一持久 DataRoot
+ 固定 bootstrap
+ 固定本机 LocalRoot
+ DataRoot 安全迁移
+ manifest / SHA-256 备份
+ 恢复前安全快照
+ staging / 原子恢复
+ DPAPI 跨用户安全跳过
+ v0.4.26 回退规则
```

v0.5.2 把 UI 信息架构进一步冻结为：

```text
About → 关于 / 运行状态
数据管理 → 设置 → 数据与迁移
文件清单 → 数据设置页内按需查看
```

数据管理不进入左侧一级导航，About 不再常驻数据维护功能。

DavBridge.Core、WebDAV、StrongVerified、quota/Cycle、Reconciliation、回收站和 DELETE 安全链没有因本轮改变。

## v0.5.4 留页规则冻结

数据与迁移页的维护动作统一遵守：**按钮本身不得关闭 Settings**。

只有真正成功的 DataRoot 迁移或恢复流程可以因为应用重启离开当前页面。用户取消、打开目录、备份和查看清单都必须保留当前上下文。

About 的 Tab 与正文同时放大，不再使用 v0.5.3 的偏小阅读尺度。
