## v0.4.9 阶段目标

v0.4.9 是一次 UI 收束轮，不增加迁移能力。目标是把 v0.4.8 实机反馈暴露出的页面密度、字号、留白和状态表达统一起来。

本阶段完成：

- 总览流量预算上下留白对称化。
- 上传与下载安全区进度条使用不同轻量渐变。
- 转移页改为三类队列概览和一条动作摘要。
- 回收站整体放大文字和交互控件。
- 文档页取消左侧目录，采用单列正文和隐藏式滚动条。
- 设置页 User ID 与文本字段横向布局修正。
- 左下角状态去重，最近活动抽屉提高可读性。

## 安全边界

v0.4.9 没有修改 `DavBridge.Core`、WebDAV、StrongVerified、SourceChanged、WriteUnknown、HTTP 412、quota/Cycle、Reconciliation、回收站状态机和 DELETE 安全链。

Web UI 仍只能通过固定白名单命令请求 C# 宿主。密码、DPAPI、原始 state/reconcile 和真实 WebDAV 写入逻辑仍不进入 JavaScript。
