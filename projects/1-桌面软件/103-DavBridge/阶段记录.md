# DavBridge 阶段记录

## 第一阶段固化基线

P103 DavBridge 已完成第一阶段核心迁移链验证，**v0.1.7 作为当前稳定基线固化**，并按 `p103-exp → p103-stable → main` 流程正式准入主线。

- 正式基线版本：`v0.1.7`
- 正式主线：`main`
- 稳定基线：`p103-stable`
- 下一阶段开发：`p103-exp`
- 源码统一入口：`代码/DavBridge.sln`

## v0.1.7 核心能力

- Windows x64，C# / .NET 8 / WinForms，framework-dependent 单文件发布；
- InfiniCLOUD 永久只读，坚果云为唯一写端；
- Zotero `.zip + .prop` 成组处理；
- 目标缺失时执行 PUT，之后必须准确资源 `PROPFIND Depth:0`、目标重新 GET、SHA-256 对比后才记 `StrongVerified`；
- GoodSync 等已有目标副本通过 GET + SHA-256 一致后零上传接管，不一致则冲突，不自动覆盖；
- 首组真实上传与既有副本 NO-WRITE 接管组成双安全门；
- 上传 1 GB、下载 3 GB 均进入本地配额模型，普通阶段固定保留 50 MB；
- 支持人工流量校准；
- 坚果云重置只记录日期，重置日 09:00 后才开始真实上传探测，探测成功后确认新周期；
- 支持暂停、断点恢复、完全退出后恢复、托盘后台运行；
- 密码由 Windows DPAPI 保存，界面按真实长度显示 `*` 并可临时查看；
- 坚果云目录单次列举达到 750 时只显示 `750+`，准确文件校验不依赖目录列表完整性。

## 真实实机证据

2026-08-12，Windows 11 实机已经验证：

```text
InfiniCLOUD 源目录可见条目：6,930
源端普通文件对象：6,929
Zotero 逻辑组：3,465
源端总量：9.97 GB
最大文件：89.8 MB
超过 500 MB：0
未配对 zip/prop：0
坚果云 /zotero 单次列举：750+
```

真实迁移链：

```text
目标缺失小组：
PUT → Depth:0 → 目标 GET → SHA-256 → 两成员 StrongVerified

GoodSync 已有完整小组：
NO-WRITE → 源 GET → 目标 GET → SHA-256 → 两成员 StrongVerified
本次上传增量：0 B
```

持续运行与恢复：

- 长期迁移运行后 StrongVerified 持续增加，异常保持 0；
- 暂停有效；
- 完全退出后重新启动，StrongVerified、额度账本、双安全门和 Paused 状态完整恢复；
- 恢复后继续直接进入新的未完成 Group，没有从头重复处理已验证对象；
- 点击主窗口 X 缩到托盘后，后台迁移继续，重新打开后进度继续增长。

## 下一阶段

下一轮进入 **UI 与日常流程优化阶段**，不改变 v0.1.7 已验证的数据安全语义。优先项：

1. 长期迁移已经启用后，“开始 / 继续”不再重复执行整套就绪扫描和启用确认；
2. 首次安全流程与日常运行流程分离；
3. `Running`、`Paused`、`WaitQuota`、`WaitNetwork`、`WaitRetry` 等状态改为清晰中文；
4. Paused 时 `CurrentGroupKey` 改成“暂停断点”语义；
5. 主界面重新组织状态、流量、进度、当前任务和操作按钮的视觉层级；
6. 设置页与托盘行为进一步简化。

下一阶段仍从 `p103-exp` 开始，所有功能修改继续按 `exp → stable → main` 提升。
