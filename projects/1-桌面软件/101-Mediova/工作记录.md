# Mediova 工作记录

本文件用于快速判断 Mediova 已完成、正在处理和计划中的工作。后续每完成一项，应将复选框改为 `[x]`，并把状态改为“完成”；不得只在对话中声明完成而不更新本表。

## 状态规则

| 复选框 | 状态 | 含义 |
|---|---|---|
| `[x]` | 完成 | 已实现并达到相应验证要求 |
| `[ ]` | 进行中 | 已开始处理，但尚未完成闭环验证 |
| `[ ]` | 计划 | 已确认需要做，但尚未开始 |
| `[ ]` | 暂缓 | 当前不进入近期版本，保留后续评估 |

## 更新要求

1. 新需求确认进入计划后，先在本表增加一行，再开始实现。
2. “进行中”项目必须写明尚缺的验证或闭环条件。
3. 完成项目时同步更新版本说明、开发总结和自动化测试。
4. 不得删除尚未完成的计划来制造“全部完成”；取消或延期项目应改为“暂缓”并说明原因。
5. 正式发布后必须补充标签、Release、准入运行、Runtime ZIP 与主 EXE 的最终 SHA-256。
