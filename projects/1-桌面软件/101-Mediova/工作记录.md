# Mediova 工作记录

本文件只回答当前正在做什么、怎样算完成、证据在哪里和尚缺什么。完整历史由 Git、标签、Release 和 `软件开发总结.md` 保存；正式基线由 `阶段记录.md` 保存。

## 当前状态

Mediova v4.5.0 已完成实现、实验准入、稳定候选、正式主线、标签、轻量 Release、真实 Windows 截图复核、62 项原生自检和 2500 项会话恢复压力测试。

本轮连续完成四个里程碑：

- v4.2.3：统一 footer 几何，修复视频与图片右下角按钮错位和禁用态残影；
- v4.3.0：增强时间与画面裁剪，加入比例、居中适配、键盘微调和批量应用；
- v4.4.0：扩展图片裁剪，并为 HEIC、HEIF、AVIF 增加 FFmpeg 解码预检；
- v4.5.0：完成版本化会话快照、原子保存、备份回退、文件级恢复和长队列压力门禁。

当前没有正式启动新的产品版本。`p101-exp` 正在进行不改变处理功能与文件格式的预备稳定性工作：扩大横屏窗口与 DPI 自适应检查，先从 footer 操作区的连续宽度矩阵开始。该工作不改变 v4.5.0 标签、Release 或 `main` / `p101-stable` 正式基线，也不替代后续用户实机验证。

竖屏显示器不列为当前像素级正式验收场景。当前自适应优先级为常见横屏窗口、最大化与还原、100%–175% DPI、多显示器切换和窄窗口降级；竖屏只要求程序不崩溃、不出现阻断操作的严重遮挡。

## 后续更新计划

### v4.5.1｜仅限稳定性热修

只有出现明确、可复现且不适合等待大版本的问题时才启动，例如：

- 特定 DPI、主题或窗口尺寸下仍出现控件错位；
- 会话快照在真实异常退出场景中出现恢复遗漏；
- 某类 HEIC/HEIF/AVIF 或复杂媒体产生错误分类或静默失败；
- 托盘、拖放、显卡驱动或外部播放器集成出现阻断性问题。

不得把功能扩张混入 v4.5.1。当前预备自适应检查不自动等同于启动 v4.5.1；只有形成明确问题、修复范围和正式验收标准后再决定版本归属。

### v4.6.0｜队列可观测性与重试闭环

建议作为下一主版本候选，先做设计和样本验证，再决定是否实施：

- 失败任务按原因筛选、批量重新预检和安全重试；
- 任务历史与当前队列更清楚地区分；
- 可导出精简处理报告，记录输入、输出、参数、引擎、耗时、校验和失败原因；
- 恢复摘要、动态追加、剩余任务和队列健康状态更易理解；
- 不增加复杂账户、数据库或云同步系统。

### v4.7.0｜预览效率与批量编辑

在 v4.6.0 稳定后再评估：

- 更低成本的时间轴缩略图或关键帧导航；
- 裁剪预设管理和更清晰的批量差异提示；
- 大图片与 4K 视频预览的缓存预算、取消和回收策略；
- 保持单一预览系统，不引入第二套渲染架构。

### v5.0.0｜只在真正架构变化时启动

只有现有任务、配置或 Runtime 模型无法承载明确需求时才考虑，例如跨机器可迁移任务包、插件边界或全新的处理图模型。不得仅为“升大版本”重写稳定的 Win32、队列或 FFmpeg 管线。

## 启动下一版本的前置条件

新版本开始前必须写清：

1. 可复现问题或明确用户价值；
2. 不做会造成什么实际损失；
3. 最小实现范围和不做范围；
4. 配置、会话、任务和 Runtime 的兼容边界；
5. 自动测试、真实 Windows 截图、原生自检和用户实机验证标准。

若没有满足这些条件的事项，v4.5.0 保持为当前正式稳定基线。
