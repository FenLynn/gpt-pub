# Mediova v4.4.0 版本说明

v4.4.0 是本轮连续开发的第三个里程碑，将 v4.3.0 的画面裁剪工作流扩展到图片，并明确现代图片格式的解码边界。该里程碑最终随 v4.5.0 正式交付。

## 新增能力

- 图片任务使用同一裁剪对话框，跳过无意义的时间范围校验。
- 图片支持自由、16:9、9:16、1:1、4:3 裁剪和批量应用到已选任务。
- 高清处理后预览按任务真实媒体类型生成，不再硬编码为视频。
- HEIC、HEIF、AVIF 在转换前执行最长 15 秒的 FFmpeg 解码预检。
- 当前 FFmpeg 不支持现代图片解码时，明确显示格式、解决方法和“源文件未修改”。
- JPG/PNG 继续走原有稳定管线；EXIF、拍摄时间、文件时间和目录时间继续由现有设置与完成链保留。

## 兼容边界

- HEIC、HEIF、AVIF 能否成功读取取决于用户当前 FFmpeg 构建是否包含对应解码能力，Mediova 不虚假声明所有 FFmpeg 版本都支持。
- 预检或实际转换失败不会修改源图片，也不会把失败任务记为成功。
- 超大图片和数千张批量任务继续使用有界探测、缩略图和转换工作池。

## 验证结论

该里程碑通过固定哈希、普通测试、全量竞态、`go vet` 和 Windows 双交叉构建，并随 v4.5.0 完成真实 FFmpeg Runtime、图片模式截图、原生 self-test 62/62 和私人 Data 边界检查。正式交付标签为 `p101-v4.5.0`。
