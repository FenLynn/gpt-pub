# Mediova v4.5.0 版本说明

v4.5.0 完成长队列会话恢复与可靠性收口，并正式交付本轮 v4.2.3、v4.3.0、v4.4.0 的全部改进。

- 正式标签与 Release：`p101-v4.5.0`
- 正式产品提交：`878e0463fe7329beb0f027401ae6f8821fe09e51`
- [下载轻量覆盖包](https://github.com/FenLynn/gpt-pub/releases/download/p101-v4.5.0/Mediova-v4.5.0-Light.zip)

## 本轮主要变化

### 底部按钮布局

- 视频和图片模式统一使用同一 footer 几何模型。
- 开始、暂停、停止按钮同高、同基线、固定间距并整体右对齐。
- 禁用态自绘前清除完整画布，消除旧边框和残影。

### 预览与裁剪

- 支持自由、16:9、9:16、1:1、4:3 比例。
- 支持最大居中适配、拖框比例锁定、逐帧/逐秒键盘微调和应用到已选任务。
- 图片复用同一裁剪工作流，跳过无意义的时间范围校验。

### 现代图片输入

- HEIC、HEIF、AVIF 转换前执行有界 FFmpeg 解码预检。
- 当前 FFmpeg 不支持对应格式时，明确显示失败原因和解决方式。
- 是否可解码取决于用户实际 FFmpeg 构建；源图片始终不被修改。

## 会话恢复协议

- 会话文件升级为 schema 2 包络，记录版本、保存时间、保存原因和是否正常退出。
- 兼容 v4.4 及更早的旧任务数组格式。
- 保存使用同目录临时文件、同步落盘、主文件与 `.bak` 轮换；主快照损坏时自动尝试备份。
- 运行中、队列中、暂停、搁置和已停止任务恢复为准备中，并从文件开头 0% 重新处理。
- 冻结参数、输出母目录和冲突策略保留；可能属于半成品的输出路径、进度、引擎、错误和运行时间清除。
- 完成、跳过和失败结果保持原状态，不伪造成功或无故重新执行。
- 源文件缺失时明确标记失败，不删除或修改任何媒体。
- 启动状态栏显示恢复来源、恢复数量、重新处理数量、缺失数量和保留的完成结果。

Mediova 不实现帧级断点续转。FFmpeg 中断任务始终按文件级边界从 0% 重新开始，以避免复用不完整输出或错误时间戳。

## 已知边界

- 正式资产未进行 Authenticode 代码签名。
- 125%–175% DPI、多显示器、不同主题、显卡驱动、托盘、PotPlayer 和特殊媒体仍需真实桌面持续观察。
- HEIC、HEIF、AVIF 的实际支持范围取决于当前 FFmpeg 构建。
- 会话恢复是文件级重新排队，不是帧级或编码器内部断点续转。
