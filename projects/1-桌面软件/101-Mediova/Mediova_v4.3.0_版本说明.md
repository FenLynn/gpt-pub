# Mediova v4.3.0 版本说明

v4.3.0 是本轮连续开发的第二个里程碑，在现有时长与画面裁剪对话框上完成可操作性升级，没有建立重复的第二套预览系统。该里程碑最终随 v4.5.0 正式交付。

## 新增能力

- 裁剪比例：自由、16:9、9:16、1:1、4:3。
- 居中适配：按所选比例在转正后的画面内生成最大居中区域。
- 拖框比例锁定：选择固定比例后，鼠标拖动保持该比例并自动限制在画面内。
- 键盘微调：左右方向键逐帧移动，Shift+左右逐秒移动，I/O 设置开始/结束，R 恢复全画面。
- “应用到已选任务”：当前任务保存后，将时长与裁剪按目标分辨率安全缩放到其他可编辑任务。
- 纯裁剪函数与边界测试固定偶数坐标、最小尺寸、比例和画面边界。

## 状态与边界

- 准备中任务可直接编辑；已入队任务继续遵守参数冻结和独立搁置会话规则。
- 批量应用只作用于可编辑目标，不绕过队列锁定状态。
- 裁剪仍按“转正 → 裁剪 → 缩放 → 编码”顺序进入同一次 FFmpeg 处理，避免额外重编码。

## 验证结论

该里程碑通过固定哈希、普通测试、全量竞态、`go vet`、Windows 双交叉构建，并随 v4.5.0 完成真实 Runtime、四套截图和原生 self-test 62/62。正式交付标签为 `p101-v4.5.0`。
