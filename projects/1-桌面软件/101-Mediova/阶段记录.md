## 产品定位

Mediova 是面向 Windows 10/11 x64 的本地媒体处理与创作工作站，覆盖视频和图片批量导入、转码、压缩、方向修正、缩放、裁剪、目标体积、复杂媒体轨道、历史恢复和本地播放器对比，并为轨道选择、字幕、分段、拼接和更完整的媒体工作流保留扩展空间。

## v4.1.0 主题一：界面视觉和交互统一

v4.1.0 不再逐个控件堆叠样式补丁，而是建立统一视觉规则：

- 主界面使用统一底色，减少卡片、白块、厚重底纹和重复边框；
- 顶部主图标缩小，工具按钮默认透明并使用淡边线；
- 按钮统一默认、悬停、按下、选中、禁用五态；
- 工具栏保持单行，按钮上下内边距和横向间隔重新整理；
- FFmpeg、GPU、PotPlayer 等状态灯放大，折叠按钮缩小；
- 开始、暂停和停止采用一致实心操作按钮体系；
- 右侧参数区与底部参数栏使用统一控件语言；
- 底部下拉框根据常用内容分别确定宽度。

输出区域统一为“输出母目录”：

- 支持可编辑地址；
- 支持最近目录下拉、去重和数量限制；
- 提供浏览按钮；
- 点击输出母目录入口可直接打开当前文件夹；
- 清除地址栏与底部参数区重复边框造成的黑线。

进度和压缩体积条改为单层绘制：

- 未完成部分使用极淡背景；
- 文字在完整条形区域中水平、垂直居中；
- 不再嵌套额外小框；
- 体积条按输入与输出体积总和计算真实左右比例；
- ±10% 变化显示黄色；
- 输出变大但最终小于 15 MB 时黄色优先；
- 明显压缩使用分级绿色；
- 明显增长使用分级红色。

相关比例、颜色、历史目录和布局规则已进入 Go 自动测试。

## v4.1.0 主题二：轻量透明 Runtime / 独立 Data

v4.0.0 虽然以单 EXE 交付，但 FFmpeg/FFprobe 和 DLL 会安装到 `%LOCALAPPDATA%\Mediova`，使运行组件与缓存、本机状态等 Data 混在一起。随着 HEIC/HEIF、HDR、字幕、分析器和辅助进程等潜在扩展增加，这种混合不利于更新、诊断、恢复和公开边界控制。

v4.1.0 因此采用：

```text
Mediova/
├── Mediova.exe
├── Components/FFmpeg/bin/
├── runtime-manifest.json
├── THIRD_PARTY_NOTICES.md
└── README.txt
```

- Runtime 可以公开、复制、覆盖、校验和删除后重建；
- `Mediova.exe` 仍是唯一直接主程序，不增加启动器或后台服务；
- FFmpeg/FFprobe 和相关 DLL 进入 Runtime，不再作为 Data 存入 AppData；
- `runtime-manifest.json` 记录逐文件路径、大小和 SHA-256；
- `THIRD_PARTY_NOTICES.md` 记录第三方来源和许可边界；
- 配置、历史、会话、缓存、日志和私人路径不得进入 Runtime 或 Release。

Data 继续分为：

```text
%APPDATA%\Mediova       # 配置、历史、会话、备份
%LOCALAPPDATA%\Mediova  # 缓存、临时文件、缩略图、本机状态、崩溃信息
```

## v4.1.0 组件迁移与兼容

- Runtime 已有有效 `ffmpeg.exe` 和 `ffprobe.exe` 时，不执行迁移；
- Runtime 缺失而旧 `%LOCALAPPDATA%\Mediova\ffmpeg` 完整时，只复制缺失文件；
- 不删除旧目录；
- 不覆盖 Runtime 已有文件；
- 复制后验证组件对；
- 旧 AppData 配置路径在 Runtime 有效时归一化为 Runtime 路径；
- 用户明确指定的系统路径、外部目录或自定义构建继续保持权威；
- v4.0.0 的配置、历史和会话格式继续兼容。
