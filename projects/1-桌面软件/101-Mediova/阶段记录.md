# P101 Mediova 阶段记录

## 当前状态

- 当前正式版本：`Mediova v4.0.0`；
- 正式路径：`projects/1-桌面软件/101-Mediova/`；
- 技术路线：Go、原生 Win32、FFmpeg/FFprobe、Windows x64；
- 当前阶段：公开迁移候选，等待 GPT-Pub 完整 Windows 原生验收、合并、标签和 Release；
- 长期分支：`p101-exp`、`p101-stable`；
- 正式主线：`main`。

## 已继承能力

- 视频与图片批量扫描、中文路径、目录递归和混合导入；
- H.264/H.265、质量与目标体积、缩放、旋转、裁剪、图片压缩；
- 多音轨、文本字幕、位图字幕安全处理与 VFR；
- 动态逻辑处理器并发、同名输出原子占用和任务结果闭合；
- 固定探测/缩略图工作池、进度节流和大批量任务保护；
- 100%–175% DPI、多窗口尺寸、两排状态区和完整行高进度条；
- 主配置损坏时备份恢复、工作线程异常保护和最低输出完整性门槛；
- Windows 原生自检、真实 FFmpeg、同名任务和故障注入。

## v4.0.0 品牌与兼容性

- 对外产品名称统一为 Mediova；
- 数据目录迁移采用“新目录不存在时复制旧目录”的保守策略；
- 旧数据保留，复制失败会返回错误，不静默删除或覆盖；
- 配置结构、任务包格式和内部模块名称保留兼容；
- 公开源码不包含私有仓库名称、内部编号、私有提交、私有附件或短时下载地址。

## 后续方向

- 视频剪辑、分段、无损拼接与合并；
- 音视频轨道选择、字幕编辑与批量封装；
- HEIC/HEIF、HDR、手机 MOV、多音轨和硬件编码扩展；
- 大批量长期运行、历史恢复、DPI和多显示器持续回归。

## 持续硬约束

- 不让用户承担主要回归测试；
- 不通过删减功能制造稳定缩水版；
- 每个输入必须有明确结果；
- 成功必须有真实且通过最低完整性检查的输出；
- P101 只能修改 P101 目录、P101 CI 与必要状态入口；
- 正式发布只从 `main` 建立标签和 Release。
