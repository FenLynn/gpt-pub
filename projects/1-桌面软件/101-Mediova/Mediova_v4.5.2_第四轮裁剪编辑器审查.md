# Mediova v4.5.2 第四轮裁剪编辑器审查

## 基线

- 从第三轮合并后的 `p101-stable` 建立；
- 第三轮 PR #328；
- 第三轮合并提交 `1ee487006fa5b07f91c6d4eb3f290d1f80ed7900`；
- 正式 `p101-v4.5.0` 标签和 Release 保持不变。

## 当前实现审查

现有裁剪窗口已经具备：

- 视频帧预览；
- 单点预览时间轨；
- 开始、结束和当前位置数值输入；
- 逐帧、逐秒跳转；
- 鼠标拖出新裁剪框；
- 自由、16:9、9:16、1:1、4:3 比例；
- 高清预览；
- 应用到当前任务或已选任务。

但尚未满足本轮目标：

1. 标题仍是“时长与画面裁剪”，未统一为“裁剪”；
2. 时间轨只有一个原生滑块，没有开始端、结束端、播放头与选中区间；
3. 现有裁剪框只能重新拖出，不能移动或从边、角缩放；
4. 鼠标拖动与数值输入缺少统一交互状态机；
5. 预览使用转正后尺寸，而输出滤镜顺序需要显式冻结，避免旋转与裁剪坐标理解不一致；
6. 多个静态标签仍使用系统灰底，视觉层级不统一；
7. 窗口尺寸、时间轴高度、控制区留白和提示文字需要重新收口。

## 冻结设计

### 时间区间

- 使用自绘双端区间时间轴，不再把原生单滑块承担全部语义；
- 同时显示开始端、结束端、播放头和区间高亮；
- 点击空白区域移动播放头；
- 拖动开始端或结束端调整区间；
- 拖动高亮区整体平移区间；
- 开始端不得越过结束端，最小区间按一帧或最小毫秒值约束；
- 数值输入、I/O 快捷键、设为当前、恢复完整时长与时间轴双向同步；
- 图片模式显示禁用时间轴，不伪造视频时长。

### 画面裁剪

- 在预览坐标系中支持创建、移动和八方向缩放；
- 边和角具有明确命中范围与鼠标光标；
- 比例锁定时，角缩放保持比例；
- 移动与缩放均限制在有效帧内，并统一偶数坐标和尺寸；
- 数值输入与鼠标操作共享同一裁剪归一化函数；
- 恢复全画面、居中适配和比例切换不产生越界瞬态。

### 坐标与输出

- 界面展示“转正后画面坐标”；
- 明确冻结 FFmpeg 滤镜顺序；
- 预览提取与最终输出使用同一旋转、裁剪顺序；
- 为 0°、90°、180°、270° 建立可逆坐标映射与测试；
- 不用截图近似代替坐标一致性测试。

### 视觉与交互

- 窗口标题统一为“裁剪”；
- 去除标签灰底，使用与主窗口一致的白色背景和文字层级；
- 提高时间轴高度和端点可点击面积；
- 选框内部、边框、手柄和遮罩层具有清晰但不过度醒目的层级；
- 窗口关闭、任务删除或预览生成迟到时不得回写已释放控件。

## 分阶段实施

1. 纯逻辑层：时间区间、命中测试、拖动状态和旋转坐标映射；
2. Win32 接线：自绘时间轴、选框移动与八向缩放、数值双向同步；
3. 视觉收口：标题、标签背景、布局和 DPI；
4. 一致性验证：FFmpeg 参数、真实预览、旋转矩阵和 Windows 原生截图；
5. 建立第四轮独立固定清单并恢复全量源码清单。

## 验证边界

每个阶段至少执行：

- P101 范围门禁；
- 全量源码清单；
- Go 普通全测；
- 全量竞态；
- `go vet -unsafeptr=false ./...`；
- Windows 测试程序和 GUI 双交叉构建；
- 最终阶段执行 Windows 原生源码测试、真实 FFmpeg、Runtime、Manifest、UI 截图、原生自测和产物上传。
