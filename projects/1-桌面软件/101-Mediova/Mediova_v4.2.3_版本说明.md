# Mediova v4.2.3 版本说明

v4.2.3 是本轮连续开发的第一个里程碑，专门修复视频与图片模式右下角“开始 / 暂停 / 停止”按钮错乱，不扩张新的产品功能。该里程碑未单独建立标签，最终随 v4.5.0 正式交付。

## 修复内容

- 底部进度条、状态文字和三个操作按钮统一由同一个 footer 几何模型布局。
- 三个按钮始终同高、同基线、固定间距并整体右对齐。
- 视频与图片复用相同几何规则，只保留各自“转换 / 压缩”文案与队列作用域。
- footer 间距使用统一逻辑像素并通过同一 DPI 缩放路径执行。
- 主按钮自绘前完整清除画布，消除禁用态残留像素造成的外框上下错位。
- 图标与文字作为整体居中；长状态文案使用较小字体，但不改变外框尺寸。

## 验证结论

- 覆盖 1120×720、1280×720、1450×820、1650×930 等窗口尺寸和 100%–175% DPI 几何契约。
- 覆盖视频、图片、空闲、运行、暂停和禁用状态。
- 固定哈希、普通测试、全量竞态、`go vet`、Windows 测试二进制与 GUI EXE 交叉构建通过。
- v4.5.0 稳定和正式准入均生成真实 Windows 截图；人工复核确认视频宽屏、视频紧凑、图片和搁置模式的三个按钮同高、同基线、间距一致，无旧残影。

该修复最终包含在正式标签与 Release `p101-v4.5.0` 中。
