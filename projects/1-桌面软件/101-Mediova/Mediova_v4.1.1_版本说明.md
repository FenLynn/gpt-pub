# Mediova v4.1.1 版本说明

> 当前状态：已正式发布。标签与 Release 为 `p101-v4.1.1`。

## 版本定位

v4.1.1 是一次专注于界面视觉兑现的修复版本。它不新增媒体处理功能，不改变 v4.1.0 已建立的 Runtime/Data 架构，也不重写已经验证的压缩比例逻辑。

本版修复的核心问题是：v4.1.0 虽然实现了输出母目录、体积比例、颜色规则和部分控件状态，但默认按钮仍像一排浅色卡片，条形仍有内嵌感，原生下拉框边线和截图级视觉没有完成验收。

## 用户可见变化

### 顶部工具栏

- 图标字体由 20 px 缩小为 18 px，避免贴近按钮边缘。
- 工具栏按钮增加上下留白和横向间距。
- 普通按钮默认不填充卡片底色，只保留极淡边线并自然嵌入主背景。
- 鼠标悬停时显示浅色表面和更清楚的边线。
- 按下、当前模式和禁用状态分别使用不同强度。

### 整体底色与按钮

- 主界面、自绘工具栏、普通操作按钮和状态区使用同一背景色。
- 普通操作按钮默认透明，减少层层圆角框和白色块。
- 开始、暂停和停止保持蓝、黄、红实心体系。

### 状态区

- FFmpeg、GPU、PotPlayer 和并发状态灯改为 11 px 实心圆。
- 右侧折叠按钮进一步缩小为紧凑尺寸。
- 状态项默认不显示卡片，悬停和按下时才显示反馈。

### 输出母目录与下拉框

- 保留输出母目录的编辑、最近目录、浏览和点击打开当前目录功能。
- 输出母目录和底部下拉框切换到更扁平的 Windows `CFD` 主题，以减少黑色下边线和重边框。
- 最近目录继续去重并保留最多 10 条。

### 进度与体积条

- 总进度条未完成区域改为更淡轨道，不再绘制明显外边框。
- 行内进度条和体积条左右仅留 1 px，更接近完整单元格宽度。
- 文字位于完整条形区域中央，不增加额外文本框。
- 体积条继续按 `输入体积 : 输出体积` 的真实总和比例绘制。
- `±10%` 和“输出变大但最终小于 15 MB”仍为黄色且优先级最高。
- 明显压缩使用随压缩程度加深的绿色，明显增长使用随增长程度加深的红色。

### 底部参数区

常用控件宽度重新按用途确定：

```text
输出：84 px
格式：78 px
质量：72 px
体积：126 px
旋转：98 px
```

这些数值随 DPI 统一缩放，并接受不同窗口宽度的布局检查。

## 验证方式

v4.1.1 增加并通过以下规则和视觉验证：

- 工具栏默认态无填充，悬停态明显强于默认态；
- 普通按钮默认态无填充；
- 底部参数宽度符合用途化上限；
- 行内条形接近完整单元格宽度并保持 5 px 上下留白；
- 压缩比例、黄色优先和最近目录测试继续通过；
- 正式 EXE 生成真实 1650×930 与 1120×720 截图；
- CI 使用 `GetWindowRect` 验证实际窗口尺寸，避免固定画布黑边造成假宽图；
- 两张正式截图经过人工复核，无黑边且分别采用宽布局与紧凑布局。

125%、150% 和 175% DPI、多显示器及不同 Windows 主题仍需要真实桌面或用户确认，不能由自动测试替代。

## 保持不变

- Runtime/Data 目录边界；
- FFmpeg/FFprobe 的 Runtime 位置和旧组件保守迁移；
- 输出母目录历史与打开行为；
- 视频和图片转换逻辑；
- 源媒体不修改、不删除原则；
- GPU 失败回退 CPU；
- 输出完整性和任务结果闭环；
- v4.1.0 的体积比例与颜色判定公式。

## 安装方式

请下载并完整解压：

```text
Mediova-v4.1.1-Runtime.zip
```

然后运行其中的 `Mediova.exe`。不要只复制 EXE，因为完整 Runtime 还包含 FFmpeg/FFprobe、相关 DLL、第三方说明和完整性清单。
