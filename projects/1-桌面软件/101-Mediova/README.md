# Mediova

Mediova 是一款面向 Windows 10/11 x64 的本地媒体处理与创作工作站。当前正式版本为 **v4.0.0**，支持视频与图片批量导入、转码、压缩、方向修正、缩放、裁剪、目标体积、复杂媒体轨道、历史恢复和本地播放器对比，并为后续剪辑、合并与更完整的媒体工作流保留扩展空间。

## 当前定位

- 视频与图片统一批处理；
- 所有媒体处理在本机完成；
- 不修改或删除源文件；
- 每个输入必须形成明确结果；
- 只有真实存在并通过最低完整性检查的输出才能记为成功。

## 构建

```powershell
cd projects/1-桌面软件/101-Mediova/代码
./build_v4.0.0.ps1
```

构建产物位于 `代码/build/Mediova_v4.0.0.exe`。程序运行时需要可用的 FFmpeg 与 FFprobe，可由程序管理或放置在可发现路径。

## 数据兼容

v4.0.0 使用新的 `Mediova` 数据目录。首次运行时，如新目录尚不存在而旧版数据目录存在，程序会将旧配置、历史、会话、缓存和 FFmpeg 组件**复制**到新目录；旧目录不会被删除，已存在的新文件不会被覆盖。便携模式同样从旧 `VideoUprightData` 复制到 `MediovaData`。

## 分支

```text
p101-exp → p101-stable → main → 标签与 Release → 回流 p101-stable / p101-exp
```

日常开发只在 `p101-exp` 推进；完整验收后提升到 `p101-stable`；正式版本只从 `main` 建立标签和 Release。P101 不得修改 AtlasDesk 的产品目录、源码、CI、分支或发布记录。
