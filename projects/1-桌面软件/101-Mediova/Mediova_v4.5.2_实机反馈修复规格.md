# Mediova v4.5.2 实机反馈修复规格

## 1. 文档定位

本文件是 Mediova v4.5.1 验证版完成用户真实桌面试用后形成的正式修复规格，记录已复现问题、目标交互、内部语义、实施顺序与验收标准。

本轮不是在 v4.5.1 上继续追加零散样式补丁，而是集中修复以下系统性问题：

1. 控件在启动、模式切换、选中、禁用、运行与暂停之间缺少统一状态模型；
2. 裁剪功能仍偏向参数输入，尚未形成可靠的鼠标可视化编辑器；
3. 导入、输出目录、队列、缩略图和通知缺少完整生命周期闭环；
4. 自动截图与几何测试曾判定部分 UI 已闭合，但用户真实桌面仍发现白底、蓝色焦点残留、错位、闪烁和不合格状态灯，因此后续不得再以坐标正确或截图存在替代人工视觉验收。

当前正式标签仍为 `p101-v4.5.0`。v4.5.1 仅作为验证产物，不转为正式 Release。本文定义下一验证候选 v4.5.2 的范围。

---

## 2. 总体设计原则

### 2.1 统一控件状态

所有主要控件必须由同一状态模型决定：

- 当前媒体模式：视频 / 图片；
- 当前选择：无选择 / 单选 / 多选；
- 任务状态：准备中 / 队列中 / 转换中 / 已暂停 / 搁置 / 完成 / 失败 / 停止；
- 控件状态：显示 / 隐藏、可用 / 禁用、可编辑 / 只读、普通 / 悬停 / 按下 / 选中；
- 窗口状态：普通 / 紧凑 / 最大化 / 不同 DPI。

模式切换必须主动清除旧焦点、旧选区和旧绘制状态，不能依赖系统下一次重绘偶然恢复。

### 2.2 统一视觉语言

- 主界面保持一个统一底色；
- 普通标签透明绘制，不使用灰色矩形底纹；
- 分区优先依靠留白、对齐和极淡分隔线；
- 下拉框、输入框、按钮和列表使用一致的淡边线；
- 禁用状态采用灰字与低对比边框，不使用蓝底或浓色块表示锁定；
- 三角形、暂停条和方形等具有明确几何形状的图标使用实心绘制，填充色跟随当前前景色。

### 2.3 生命周期闭环

任务加入、进入队列、退出队列、删除、清空、完成和程序退出，都必须同步处理：

- 队列状态；
- 冻结参数；
- 缩略图内存对象；
- 缩略图磁盘缓存；
- 输出路径与相对目录上下文；
- 当前选择与目录按钮回退目标；
- 提示消息。

## 3. 主界面修复

### 3.1 顶部工具栏启动显示与背景

#### 当前问题

- 软件初次进入时顶部工具按钮可能暂时不出现；
- 出现后工具栏或按钮容器带有明显白色底板，与主界面背景割裂。

#### 目标行为

- 主窗口首次可见前完成工具栏创建、字体、尺寸和布局；
- 第一次显示即完整，不允许依赖延迟刷新后出现；
- 工具栏容器背景与主窗口背景完全一致；
- 普通按钮无独立白底，只在悬停、按下和选中时显示轻量反馈；
- 视频转换和图片压缩的选中态使用淡色强调，但不能形成整块白色卡片；
- 100%–175% DPI、最大化、还原和模式切换均不得出现白底残留。

### 3.2 输出母目录蓝色背景残留

#### 当前问题

图片模式切回视频模式后，输出母目录地址框可能保留整块蓝色选择背景，且无法自然消除。

#### 目标行为

- 模式切换时清除文本选择和焦点；
- 可编辑时使用统一普通输入框状态；
- 不可修改时只显示灰字与淡边框，不显示蓝底；
- 地址文本仍允许复制；
- 浏览和打开目录按钮按目录解析规则保持可用。

### 3.3 列表编号列

在最前方新增 `#` 列：

- 从 1 开始；
- 反映当前可见列表顺序，不作为永久任务 ID；
- 删除、批量移除、清空、排序或重新导入后立即重编号；
- 居中显示，列宽只占满足当前最大位数所需空间；
- 不挤压缩略图与文件名的基本可读区域。

### 3.4 列标题和滚动条

#### 列标题

- 标题区域下方必须显示一条贯穿列表宽度的清晰淡分隔线；
- 不以浓重背景块代替下框线；
- 排序箭头、列标题文字与下框线互不遮挡。

#### 滚动条

- 横向与纵向滚动条平时低对比、接近不可见；
- 鼠标进入列表、滚轮滚动、拖动或悬停滑块时渐显；
- 停止交互约 1–1.5 秒后淡出；
- 滑块仍保持足够命中面积，不能为了视觉淡化而牺牲可操作性；
- 不改变原生滚动范围和键盘滚动行为。

### 3.5 下拉框边线

所有下拉框统一采用当前底部“输出 / 格式”控件的淡边线风格：

- 普通：淡边框；
- 悬停：略加深；
- 聚焦：柔和强调，不出现浓蓝块；
- 禁用：灰字、浅背景、更淡边框；
- 视频页、图片页、右侧参数区和底部全局参数区必须一致。

### 3.6 右下角转换、暂停、停止按钮

#### 布局

- 三个按钮继续由同一个 footer 几何模型计算；
- 同高、同基线、固定间距、整体右对齐；
- 普通、紧凑、视频、图片、禁用和暂停状态均不得分别反推坐标；
- 图标与文字共享垂直中心，不能出现图标或按钮框上下错位。

#### 图标

- 转换：实心三角形；
- 暂停：实心双竖条；
- 停止：实心方块；
- 填充色跟随当前按钮前景色；
- 普通、悬停、按下、暂停和禁用状态都需要同步变化；
- 不继续使用固定色线框字体符号冒充实心图标。

### 3.7 总进度、计时与暂停冻结

#### 计时语义

有效已用时只累计实际转换运行区间：

```text
有效已用时 = 所有运行区间时长之和
```

暂停期间：

- 已用时停止增长；
- 剩余时间停止重算；
- 总进度保持当前值；
- 文案变灰表示冻结；
- 恢复后从冻结点继续，不重置累计时间。

#### 防闪烁

- 总进度文本最多每 250–500 ms 更新一次；
- 文本内容没有变化时不得重复发送重绘；
- 进度条、文本与背景分层绘制；
- 不允许每个任务微小进度变化都擦除并重画整条 footer；
- 暂停时只在状态变化瞬间更新一次，不能持续闪烁。

#### 轮廓

- 总进度条必须有一条极淡但完整的外框；
- 0% 时仍能看出范围；
- 暂停时填充和文字降低饱和度，但保持当前进度可读。

### 3.8 右上角状态灯

- 运行时绘制真圆，不使用被拉伸的椭圆图像；
- 圆的宽度始终等于高度；
- 直径按状态文字实际字高计算，而不是整行控件高度；
- 圆与文字基线垂直居中；
- FFmpeg、GPU、PotPlayer 和并发状态使用相同尺寸和间距规则；
- DPI 改变后重新计算，不能沿用旧像素尺寸。

## 4. 目录与导入规则

### 4.1 原目录和输出目录按钮

目录目标按以下优先级解析：

1. 当前选中的最后一个任务；
2. 没有选中时，列表最后一个任务；
3. 列表为空时，最近一次有效导入目录和最近一次有效输出目录；
4. 仍无记录时，回退全局默认目录。

多选时以当前列表顺序中的最后一个选中任务为准。只要存在可推导目录，按钮就应可用。

### 4.2 直接拖入文件的输出层级

直接拖入一个或多个文件时，不再把所有输出平铺到输出母目录根部。

#### 同一业务树

以选中文件的最近公共父目录为导入根，并在输出母目录下保留该父目录名称及内部相对路径。

示例：

```text
D:\视频\电视剧\第1集.mp4
D:\视频\电视剧\花絮\片段.mp4

输出到：
Z:\转码\电视剧\第1集.mp4
Z:\转码\电视剧\花絮\片段.mp4
```

#### 不同磁盘或无合理公共业务目录

分别使用各文件最近一级父目录作为顶层目录；出现同名冲突时，逐级引入更高父目录名称，仍冲突再使用稳定序号，不得静默覆盖。

视频和图片共享同一算法。

### 4.3 文件夹导入统计

导入完成后按真正加入列表的结果提示：

```text
已导入：12 个视频、386 张图片
已跳过：4 个不支持文件、2 个重复文件
```

要求：

- 视频、图片分别计数；
- 重复、不支持、读取失败分别统计；
- 只导入一种类型时使用自然单项表达；
- 扫描到但未加入列表的文件不能计为成功导入；
- 大批量导入只显示汇总，不为每个文件弹提示。

## 5. 缩略图生命周期

缩略图缓存键至少包含：

- 规范化绝对路径；
- 文件大小；
- 修改时间。

生命周期：

1. 导入后异步登记并生成；
2. 生成过程中任务被移除时取消或丢弃结果；
3. 单个移除时释放图像句柄和内存引用，并删除对应磁盘缓存；
4. 多选移除和清空时批量清理；
5. 任务完成后可保留，直到任务离开列表；
6. 启动时清理没有任务引用、超过期限或超过容量上限的孤立缓存；
7. 程序退出时释放所有内存图像句柄；
8. 正在被其他任务复用的缓存使用引用计数或等效安全机制，不能提前删除。

不得继续采用“只生成、不回收”的单向缓存。

## 6. 队列中的退出队列

对右键菜单增加 `退出队列`，支持单选和多选。

适用范围：

- 队列中但尚未开始转换的任务；
- 已经转换中的任务不能按普通退出队列处理，仍使用安全暂停 / 搁置 / 临时解锁路径。

执行后：

- 从活动等待队列中移除；
- 状态改为 `搁置`；
- 保留文件、冻结参数和输出上下文；
- 解除普通队列锁；
- 允许修改参数、进入裁剪、删除或重新加入队列；
- 多选时只处理符合条件的任务，并汇总成功与跳过数量；
- 不得因为其中一个任务不符合条件而让整批操作失败。

## 7. “时长 / 画面”统一重构为“裁剪”

所有相关入口与文案统一为：

- 裁剪；
- 裁剪预览；
- 应用裁剪；
- 取消裁剪；
- 恢复完整时长；
- 恢复完整画面。

不得在菜单、按钮、标题、状态、历史或诊断中继续混用“时长 / 画面”。

### 7.1 去除标签灰底

“当前位置”等普通标签和说明文字使用透明背景。输入框、按钮和真正需要交互的区域才保留边界。分组依靠留白和细分隔线，不再堆叠灰色矩形底板。

### 7.2 时间裁剪轴

时间轴高度增加到能够清楚容纳：

1. 时间刻度；
2. 当前播放头；
3. 起点标记；
4. 终点标记；
5. 保留区间高亮。

设置起点和终点后：

- 起点、终点显示独立把手和时间标签；
- 起点至终点使用高透明度强调色高亮；
- 区间外区域可轻度变暗；
- 点击时间轴可跳转；
- 当前播放头、起点和终点均可拖动；
- 保留 ±1 秒、±1 帧精调；
- 起点不得越过终点；
- 拖动中使用低成本预览，松开后精确定位。

### 7.3 画面裁剪鼠标交互

画面裁剪必须支持：

- 在画面中拖出新选框；
- 拖动框内部移动；
- 拖动四角同时改变宽高；
- 拖动四边单向改变尺寸；
- 选框不能超出源画面；
- 显示 X、Y、宽度、高度；
- 比例锁定与自由裁剪；
- 双击或按钮恢复全画面；
- 选框外使用半透明遮罩；
- 边线和抓手在 100%–175% DPI 下均清楚且可命中。

鼠标和数值输入必须双向同步。

### 7.4 裁剪与旋转的坐标语义

裁剪区域始终绑定原始视频内容坐标，不绑定当前屏幕象限。

内部唯一事实源：

```text
sourceCrop = (x, y, width, height)
rotation = 0 / 90 / 180 / 270
```

显示时：

```text
显示裁剪框 = 旋转变换(sourceCrop)
```

用户在旋转后预览中拖动时：

```text
sourceCrop = 旋转逆变换(显示裁剪框)
```

因此：原视频选择第二象限后向右旋转 90°，裁剪内容随画面进入旋转后的第一象限，但仍是原先选中的同一块内容。

编码语义固定为：

```text
源画面 → 源坐标裁剪 → 旋转 → 缩放 → 输出
```

必须覆盖 0°、90°顺时针、180°、90°逆时针、横竖尺寸交换、自动方向元数据和非整画面裁剪。用户先裁剪后旋转与先旋转后裁剪，在最终源坐标上必须得到一致结果。

## 8. 右下角悬浮通知

当前通知 UI 废弃，重做为轻量右下角通知：

- 从窗口右下方向上移动进入；
- 同时由透明渐变为清晰；
- 进入动画约 200–300 ms；
- 使用柔和渐变背景、极淡边框和轻阴影；
- 标题、正文与数量信息有清晰层级；
- 右上角提供淡色关闭按钮；
- 普通通知停留约 5 秒；
- 鼠标进入暂停倒计时，移出后继续；
- 自动或手动关闭时淡出并向下退出；
- 多条通知排队，不互相覆盖；
- 短时间同类通知合并；
- 错误通知可延长停留，但不使用刺眼大红块。

典型内容：

```text
导入完成
已加入 12 个视频、386 张图片
跳过 3 个重复文件
```

## 9. 实施轮次

### 第一轮：基础 UI 与暂停语义

- 顶部工具栏首次显示和背景；
- 输出母目录蓝底与禁用态；
- 右下角按钮对齐和实心图标；
- 总进度防闪、暂停冻结和淡轮廓；
- 右上角状态灯真圆化；
- 下拉框统一淡边线；
- 标题下框线。

### 第二轮：列表、队列和资源生命周期

- 编号列；
- 缩略图释放和磁盘缓存清理；
- 原目录 / 输出目录回退；
- 多选退出队列；
- 淡化滚动条。

### 第三轮：导入与输出目录结构

- 直接拖入文件的最近公共父目录算法；
- 不同磁盘和同名父目录冲突；
- 视频 / 图片统一路径逻辑；
- 文件夹导入统计；
- 新悬浮通知。

### 第四轮：裁剪编辑器

- 全部更名；
- 去除灰底；
- 时间轴起止标记与区间高亮；
- 鼠标画面裁剪；
- 源坐标 / 旋转映射；
- 输入、预览和 FFmpeg 结果一致性。

### 第五轮：真实 Windows 收口

- 多尺寸、多 DPI、视频 / 图片交叉切换；
- 暂停、恢复、退出队列、搁置和删除；
- 缩略图缓存泄漏；
- 旋转裁剪矩阵；
- 通知动画和手动关闭；
- 生成 v4.5.2 验证 EXE，不直接创建正式标签或 Release。

## 10. 最低验收矩阵

- 冷启动 20 次，顶部工具栏每次首次显示完整且无白底；
- 视频 / 图片往返切换 20 次，输出母目录无蓝底残留；
- 900、980、1039、1040、1120、1280、1450、1650、1920 px 宽度下三个主按钮同高同基线；
- 100%、125%、150%、175% DPI 下状态灯保持真圆；
- 暂停 30 秒，已用时增量不得超过一次刷新容差；
- 暂停时总进度文字变灰且不闪烁；
- 删除、批量移除和清空后，缩略图内存与磁盘缓存均下降；
- 无选择时原目录和输出目录按列表最后任务解析；
- 多选队列任务可以批量退出为搁置；
- 直接拖入多层目录后输出结构保留最近公共父目录；
- 文件夹导入统计与最终列表数量一致；
- 时间轴显示起点、终点、播放头和区间高亮；
- 鼠标能够创建、移动和缩放画面选框；
- 0°、90°、180°、270°下裁剪始终对应同一源内容；
- 列标题下框线清楚；
- 滚动条平时淡化、交互时显现；
- 通知从下向上渐显，约 5 秒消失，可手动关闭；
- 所有自动化通过后仍必须由用户真实桌面复核，不得根据自动截图自行宣称视觉问题已闭合。
