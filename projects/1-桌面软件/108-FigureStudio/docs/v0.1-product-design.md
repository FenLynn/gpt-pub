# v0.1 产品设计

## 1. 目标

v0.1 不追求“Origin 功能覆盖率”，只验证 FigureStudio 最核心的闭环：

```text
导入数据
→ 选择模板
→ 自动得到规范科研图
→ 少量局部调整
→ 项目内保存
→ 重新载入
→ 导出
```

首版必须让用户明显感受到两件事：

1. 默认图比传统 Origin 默认图更接近 Matplotlib / 论文审美；
2. 数据、图和模板在同一个项目里是“活的”，而不是散落的导出图片。

## 2. v0.1 首批能力

### 数据

- CSV
- TSV / TXT
- Clipboard paste
- XLSX 暂列 P1，不阻塞首个可交互 Demo
- 一份 Dataset 可被多张 Figure 引用
- 支持 Replace Data
- Web 版以 Embedded 为主
- Tauri 版增加 Linked Data

### 图型

v0.1 第一阶段只实现 XY 家族：

- Line
- Scatter
- Line + Marker
- Multi-series
- Error bar
- Spectrum
- Offset Spectrum

Bar / Heatmap / 3D 在 XY 闭环稳定后追加，不和基础架构同时推进。

### 样式

首版只做三套：

- Scientific Default
- Nature
- Presentation

字体：

- Arial
- Times New Roman

数学文本：

- Unicode
- LaTeX / MathJax

### 导出

首个浏览器 Demo：

- SVG
- PNG

桌面 Publication Renderer 完成后扩展：

- PDF
- EPS
- TIFF

内部始终使用 mm / pt 作为出版尺寸事实源。

## 3. 主界面

固定三栏结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ File  Edit  Plot  Template  Export                    100%  │
├──────────────┬────────────────────────────┬───────────────────┤
│              │                            │                   │
│ Project/Data │        Figure Canvas       │   Properties      │
│              │                            │                   │
│ Project      │                            │ Figure            │
│ ├ Data       │                            │ Axes              │
│ ├ Figures    │                            │ Series            │
│ └ Templates  │                            │ Text              │
│              │                            │ Legend            │
│ Dataset      │                            │ Export            │
│ Series       │                            │                   │
├──────────────┴────────────────────────────┴───────────────────┤
│ Nature · 89 mm · Arial · 7 pt · SVG                           │
└──────────────────────────────────────────────────────────────┘
```

左侧负责“对象与数据”，中间只负责“看图和直接选择”，右侧负责“当前对象属性”。

## 4. Project Tree

Project Tree 不是 Windows 文件树，而是项目内部组织结构。

默认：

```text
Project
├─ Data
│  └─ Dataset 1
├─ Figures
│  └─ Figure 1
└─ Templates
```

以后允许用户自由建立：

```text
Paper
├─ Main
├─ Supplement
└─ Experiments
```

Figure 和 Dataset 通过稳定 ID 关联，拖动目录、重命名对象不得破坏引用。

## 5. 新建 Figure 工作流

### 快速路径

用户拖入两列数据时：

1. 自动识别 numeric columns；
2. 第一 numeric column 默认 X；
3. 第二 numeric column 默认 Y；
4. 自动创建 XY Line；
5. 应用 Scientific Default；
6. 若列名带单位，则自动生成轴标题；
7. 立即显示结果。

目标：最常见 XY 图在导入数据后不需要任何额外配置就能出现。

### 显式路径

```text
New Figure
→ Choose Template
→ Map Data
→ Choose Preset
→ Create
```

适合多列、多 Y、error bar、stacked spectrum 等场景。

## 6. 属性面板

属性面板不是把 Plotly / Matplotlib 的全部参数暴露出来。

首版常用参数：

### Figure

- width / height
- preset
- background
- margins

### Axes

- title
- range
- linear / log
- major ticks
- minor ticks
- spine visibility
- tick direction

### Series

- line visible
- line width
- line style
- marker visible
- marker type
- marker size
- color
- opacity

### Text

- Arial / Times New Roman
- font size
- LaTeX

### Legend

- visible
- position
- columns
- frame

每一个属性显示继承状态。只有当前 override 才显示 modified 标记，并允许 Reset。

## 7. 默认风格

Scientific Default 应接近 Matplotlib 科研图：

- 白底
- 无背景 grid
- 细轴线
- 细曲线
- restrained palette
- legend 无重边框
- 紧凑边距
- 轴标题与单位组合
- 默认 marker 不过大

Nature preset 在此基础上限制：

- Arial
- 物理尺寸 preset
- 更严格字号范围
- 禁止装饰性 grid
- 色盲友好 palette
- 默认适合单栏图

## 8. 直接交互

v0.1 允许：

- mouse wheel / drag zoom
- reset view
- click series → 右侧自动切到该 Series
- click axis → 右侧自动切到该 Axis
- legend item toggle
- drag reorder series（P1）

不在 canvas 上直接拖字体、拖坐标轴位置，避免产生不可控布局。

## 9. 数据替换

Dataset 提供：

```text
Replace Data
Reload
Duplicate
Detach
```

Replace Data 后：

- Dataset ID 不变；
- Figure 引用不变；
- 列映射优先按 Column ID / name 重连；
- 图样式不变；
- 不能可靠重连时明确提示，不静默猜错。

## 10. 保存模型

首版项目行为：

```text
New Project
Open Project
Save
Save As
Autosave Recovery
```

项目文件计划为 `.sfig`。

浏览器 Demo 阶段可先使用 IndexedDB / downloadable project package 模拟持久化；Tauri 后直接落地真实单文件容器。

## 11. Undo / Redo

从第一版就要求所有编辑动作可撤销：

- style change
- range change
- add/remove series
- apply template
- apply preset
- replace data mapping

Undo / Redo 不依赖组件局部 state 拼凑，后续实现时采用统一 command/action history。

## 12. v0.1 明确不做

- 全套数据分析
- 复杂拟合
- FFT
- 统计分析
- Origin worksheet 公式系统
- 脚本编辑器
- 多 panel UI
- AI 自动作图
- 插件市场
- 完整 Python runtime

这些都不能阻塞第一版核心闭环。

## 13. v0.1 成功标准

首个稳定 Demo 至少完成：

1. 导入两列或多列数据；
2. 自动创建 XY Figure；
3. 一键切换 Scientific / Nature / Presentation；
4. 修改线宽、marker、颜色、轴范围、字体和 legend；
5. 输入 LaTeX 轴标题；
6. 保存项目；
7. 重新打开后状态一致；
8. Replace Data 后图自动更新；
9. 导出 SVG / PNG；
10. 默认图无需细调也具备论文级观感。
