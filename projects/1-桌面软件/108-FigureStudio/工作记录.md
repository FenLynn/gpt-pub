### v0.3｜Origin-style Data Workspace

这一阶段根据实际使用反馈，重新把“数据”放回 FigureStudio 的核心。

完成：

- 从以 Graph 为中心的 Dataset 模型改为 Project / DataBook / Sheet / Graph；
- 左侧 Project Explorer 不再混放 Graph 内部曲线控制；
- Folder、DataBook、Sheet、Graph 使用不同的单色矢量图标；
- 中央加入 Data / Graph 文档 Tab；
- Sheet 在中央提供 Spreadsheet 编辑；
- 单元格支持 number / text / null；
- 列支持 name / unit / role；
- 支持 X / Y / Z / XErr / YErr / Label / None；
- 列头采用 A(X)、B(Y) 等科研习惯；
- Embedded Data 直接编辑；
- Linked Data 默认只读，避免外部源与项目内编辑冲突；
- Web Linked Data 支持重新选择并 Reload，或解除链接后编辑；
- Graph 改为稳定的 sheetId + columnId 引用；
- 列角色只影响新建 Graph 的默认映射，不会让已有 Graph 静默换数据；
- `.sfig` 升级 schema 0.3；
- 自动迁移 v0.1 / v0.2 项目。

当前仍不创建 stable、tag、Release 或额外桌面 CI。


### v0.4｜Workbook / Worksheet 收敛

继续对照 Origin 官方 Workbook、Worksheet、Column Designation、Plot Setup 与 Project Explorer 的高价值交互，完成：

- 顶层文档从 Sheet 改为 DataBook / Graph；
- Sheet 变为 DataBook 内部页签；
- Sheet 页签支持重命名、拖拽排序；
- Sheet 可以跨 DataBook 移动；
- 增加工作表备注与可展开列备注；
- 增加复制工作表 / 复制结构；
- 增加 Graph 数据映射页；
- 增加 Sheet → Graph Dependents；
- 新建图采用多 X 分段默认关联；
- 已有 Graph 禁止数据映射静默 fallback；
- 删除和 Replace / Reload 都加入引用完整性保护；
- Linked / Embedded source 从 DataBook 下沉到 Sheet；
- 同一 DataBook 可混合链接原始数据与项目内处理数据；
- 浏览器多项目通过多 Tab / Window 实现，sessionStorage 隔离自动恢复；
- UI 数据工作区残留开发术语改为中文；
- `.sfig` 升级 schema 0.4，并兼容迁移 0.1 / 0.2 / 0.3。

本轮没有加入公式引擎、XLSX、虚拟表格或跨 Sheet 多源 Series；这些是下一层能力，不再需要修改核心项目模型。
