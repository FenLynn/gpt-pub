# FigureStudio 工作记录

## 2026-09-19

### 立项与 v0.1

- 建立 P108 与 `p108-exp`。
- 完成架构基线、WYSIWYG Plotly 出图、真实 `.sfig`、项目工作流和首批图型。
- 参考 `FenLynn/laser-lab-analyzer` 的中文科研工具 UI 密度与 Plotly 工作流。

### v0.2 一次性升级

- UI Scale 提升可读性，默认 110%，并与 Figure 物理尺寸彻底解耦。
- 右侧改为图 / 曲线 / 轴 / 图例 / 检查 Tab Inspector。
- Plotly 曲线、轴、图例支持直接选择对应 Inspector。
- 曲线支持 Ctrl/Cmd 多选、批量修改、拖拽排序。
- Project Explorer 支持文件夹、Dataset/Figure 拖拽、重命名、复制、删除和 Figure 缩略图。
- Replace Data 增加旧/新数据差异预览。
- 新增 Publication Checker。
- `.sfig` 升级到 schema 0.2，并提供 v0.1 migration。
- 新增 Matplotlib Python script export。

### Desktop / Publication

- 建立 Tauri 2 shell。
- 建立 Linked Data read / identity / watcher backend。
- 建立 Matplotlib publication renderer，覆盖 SVG / PDF / EPS / PNG / TIFF。

当前仍不创建 stable、tag、Release 或额外桌面 CI。
