# FigureStudio 阶段记录

状态：**完成**。

本阶段已经冻结并在 v0.1 中落地：

- [x] Project Schema
- [x] Dataset Schema
- [x] Figure / PlotSpec 核心模型
- [x] Template Schema
- [x] Preset Schema
- [x] Factory → User → Project → Preset → Figure → Series 设置继承
- [x] `.sfig` ZIP 容器
- [x] Embedded 数据

- [x] Export capability 边界

- [x] v0.1 单视口 UI 信息架构

## 阶段 1｜v0.1 Web 工作闭环

状态：**完成，可交互评审**。

已完成：

- [x] 整页固定在 100vh，不产生页面级纵向滚动
- [x] 中央 Figure 画布按剩余空间最大化等比显示
- [x] 16:9 / 4:3 / 3:2 / 自定义比例
- [x] 预览与 SVG / PNG 导出共用同一 Plotly 画布
- [x] 中文紧凑工作台
- [x] 多 Dataset
- [x] 多 Figure
- [x] 一个 Dataset 被多 Figure 共享
- [x] CSV / TSV / TXT 导入
- [x] Clipboard 粘贴导入
- [x] Replace Data，Dataset ID 保持稳定
- [x] 列名一致时自动重连；列名变化时要求用户确认按顺序映射
- [x] Undo / Redo
- [x] 浏览器自动恢复
- [x] 真正的 `.sfig` 保存 / 打开
- [x] Scientific / Nature / Presentation
- [x] 用户默认 / 项目默认
- [x] Line / Scatter / Line+Marker / Errorbar
- [x] Spectrum / Offset Spectrum
- [x] Bar / Grouped Bar / Stacked Bar
- [x] Heatmap / beam-like field map
- [x] 3D Surface
- [x] 线型 / 线宽 / marker / 颜色 / 透明度 / 图层
- [x] X/Y 标题、线性/对数、手动范围、次刻度、刻度方向、网格
- [x] 图例位置、方向、列数、边框
- [x] Unicode / MathJax 路径
- [x] SVG / PNG 600 dpi 导出
- [x] GitHub Pages 自动部署

当前明确不进入 v0.1 的内容：

- 多 panel Figure
- 全量数据分析、拟合、FFT、统计
- Python runtime
- Matplotlib publication renderer
- PDF / EPS / TIFF 最终出版输出
- Tauri Linked File / file watcher
- 插件系统

这些保留为后续桌面出版阶段，不阻塞当前 Web v0.1 验收。
