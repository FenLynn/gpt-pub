# FigureStudio 开发约束

> 约束层级：C｜项目级  
> 适用范围：P108 FigureStudio  
> 上位规则：A｜`/GPT_RULES.md`；B｜`../开发约束.md`

## C-01｜项目身份与范围

- 项目编号固定为 **P108**。
- 正式路径固定为 `projects/1-桌面软件/108-FigureStudio/`。
- 当前日常分支为 `p108-exp`。
- 当前阶段允许实现 Web 工作台、Tauri 桌面基础层和 publication renderer。
- 允许唯一的 P108 GitHub Pages 预览工作流 `.github/workflows/p108-figurestudio-pages.yml`。
- 当前阶段不创建 stable、正式 tag、GitHub Release 或额外桌面 CI。
- P108 不修改其他项目源码、CI、长期分支或状态。

## C-02｜公开边界

- 只提交通用科研绘图架构、公开安全示例和公开可复用代码。
- 不提交真实实验数据、未公开论文图、专利相关数据、本机私人路径、真实用户项目文件或私人截图。

## C-03｜项目与数据模型

项目一级对象固定为：

```text
Project
├─ Folder
├─ DataBook
│  └─ Sheet
└─ Graph
```

- DataBook / Sheet 和 Graph 都是一等项目对象；UI 文档层后续优先采用 DataBook / Graph，Sheet 作为 DataBook 内部页签。
- 左侧 Project Explorer 只负责组织对象，不承载 Graph 内部 Series 控制。
- Sheet 是数据事实源；Graph 不复制 Sheet 数据。
- Graph 通过 `sheetId + columnId` 稳定引用数据。
- 移动文件夹、重命名 DataBook/Sheet、修改列角色不得破坏已有 Graph 引用。
- Column Role 只用于新建 Graph 时的默认映射；不得静默重映射已有 Graph。

## C-04｜Embedded / Linked

- Embedded Data 是项目内事实源，可以编辑。
- Linked Data 的外部文件是事实源，默认只读。
- Reload Linked Data 只能更新数值/结构，不得改变 Graph 样式。
- 用户要编辑 Linked Data，必须明确执行“解除链接”或未来的“创建副本”。
- Web 版允许用户重新选择同一源文件完成 Reload。
- Tauri 版允许使用 path / identity / watcher 做自动 Reload。
- Linked Source 不只依赖绝对路径，应保留 filename、relative path、size、modified time 和可选 hash。

## C-05｜列与绘图引用

支持角色：

```text
X / Y / Z / XErr / YErr / Label / None
```

- Sheet 单元格允许 number / text / null。
- Renderer 只能消费从 Sheet 派生出的 numeric PlotColumn。
- Figure 不允许直接持有 Spreadsheet 的可变行数据。
- Error / Z 等特殊引用也必须保存稳定 Column ID。

## C-06｜默认与覆盖

继承顺序：

```text
Factory → User → Project → Template/Preset → Figure → Series
```

- 临时 UI 修改默认写当前最小对象。
- 只有用户明确选择“项目默认 / 我的默认 / 模板”时才提升作用域。
- override 必须可恢复到继承值。

## C-07｜单位与 UI

- 科研出版尺寸内部使用 mm / pt；raster 才使用 dpi。
- CSS px 不是出版尺寸事实源。
- UI Scale 只缩放软件界面，绝不能改变 Figure 的 mm / pt / dpi。

## C-08｜项目文件

- `.sfig` 使用 ZIP 容器和 schemaVersion。
- 当前 schema 为 **0.3**。
- 必须可 migration 读取 0.1 / 0.2。
- 一个 Sheet 的数据只保存一份，多张 Graph 共享引用。
- 导出成品默认不重复嵌入项目。
- 不识别的未来 schemaVersion 不得擅自保存回旧格式。

## C-09｜Renderer

- Plotly.js 是交互 renderer。
- Matplotlib 是 publication renderer。
- 不允许把 Plotly 专属字段直接作为长期 FigureSpec。
- Renderer 只消费适配后的数据视图，不拥有 Spreadsheet 数据。
- React + TypeScript + Vite Web 与 Tauri 共用同一前端和 FigureSpec。
- GitHub Pages 只作为开发预览入口，不构成正式 Release。


## C-10｜单项目窗口

- 一个 Web 浏览器 Tab / Window 只持有一个 `.sfig` Project。
- 不在应用内部设计多 Project Tab 或多 ProjectState 并行工作区。
- 项目工作区自动恢复使用 sessionStorage，确保浏览器多 Tab 之间互不覆盖；用户级偏好才使用 localStorage。
- 同时打开多个项目由浏览器多 Tab / 多窗口解决。
- Desktop 也优先采用“一窗口一项目”；需要并行项目时使用多窗口。
- Project 内部可以同时打开多个 DataBook / Graph 文档，这与“多项目”是两件事。
