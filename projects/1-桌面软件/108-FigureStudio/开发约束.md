# FigureStudio 开发约束

> 约束层级：C｜项目级  
> 适用范围：P108 FigureStudio  
> 上位规则：A｜`/GPT_RULES.md`；B｜`../开发约束.md`

## C-01｜项目身份与范围

- 项目编号固定为 **P108**。
- 正式路径固定为 `projects/1-桌面软件/108-FigureStudio/`。
- 当前日常分支为 `p108-exp`。
- 当前阶段允许实现 Web 工作台、Tauri 桌面基础层和 publication renderer。
- 允许唯一的 P108 GitHub Pages 预览工作流 `.github/workflows/p108-figurestudio-pages.yml`。
- 当前阶段不创建 stable、正式 tag、GitHub Release 或额外桌面 CI。
- P108 不修改其他项目源码、CI、长期分支或状态。

## C-02｜公开边界

- 只提交通用科研绘图架构、公开安全示例和公开可复用代码。
- 不提交真实实验数据、未公开论文图、专利相关数据、本机私人路径、真实用户项目文件或私人截图。

## C-03｜核心模型边界

- Figure 不拥有数据，只通过稳定 ID 引用 Dataset。
- Dataset 与 Project Explorer 显示位置解耦；移动文件夹不得破坏引用。
- Template 决定“怎么画”，Preset 决定“长什么样”。
- Renderer 只负责把 FigureSpec 渲染为具体图形，不拥有项目事实。
- Exporter 不得改写 Figure 或 Dataset。
- Transform 不直接覆盖原始 Dataset。

## C-04｜默认与覆盖

继承顺序：Factory → User → Project → Template/Preset → Figure → Series。

- 临时 UI 修改默认写当前最小对象。
- 只有用户明确选择“项目默认 / 我的默认 / 模板”时才提升作用域。
- override 必须可恢复到继承值。

## C-05｜单位与 UI

- 科研出版尺寸内部使用 mm / pt；raster 才使用 dpi。
- CSS px 不是出版尺寸事实源。
- UI Scale 只缩放软件界面，绝不能改变 Figure 的 mm / pt / dpi。

## C-06｜项目文件

- `.sfig` 使用 ZIP 容器和 schemaVersion。
- 当前 schema 为 0.2，必须可 migration 读取 0.1。
- 同一 Dataset 被多张 Figure 引用时只保存一份数据。
- 导出成品默认不重复嵌入项目。
- 缩略图可重建，不是事实源。

## C-07｜桌面与可复现

- Web 使用 Embedded；Tauri 允许后续连接 Linked Data。
- Linked Source 不只依赖绝对路径，应保留文件身份与可校验元数据。
- Tauri watcher 只触发数据刷新，不得静默改变 Figure 样式。
- Python/Matplotlib 脚本是可复现导出，不是项目事实源。

## C-08｜Renderer

- Plotly.js 是交互 renderer。
- Matplotlib 是 publication renderer。
- 不允许把 Plotly 专属字段直接作为长期 FigureSpec。
- React + TypeScript + Vite Web 与 Tauri 共用同一前端与 FigureSpec。
- GitHub Pages 只作为开发预览入口，不构成正式 Release。
