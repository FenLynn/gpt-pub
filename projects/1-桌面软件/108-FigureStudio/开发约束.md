# FigureStudio 开发约束

> 约束层级：C｜项目级  
> 适用范围：P108 FigureStudio  
> 上位规则：A｜`/GPT_RULES.md`；B｜`../开发约束.md`

## C-01｜项目身份与范围

- 项目编号固定为 **P108**。
- 正式路径固定为 `projects/1-桌面软件/108-FigureStudio/`。
- 当前日常分支为 `p108-exp`。
- 当前阶段只进行产品与架构设计，不提前建立实现、CI、stable、tag 或 Release。
- P108 不修改其他项目源码、CI、长期分支或状态。

## C-02｜公开边界

- 只允许提交通用科研绘图架构、公开安全示例和公开可复用代码。
- 不提交真实实验数据、未公开论文图、专利相关数据、本机私人路径、真实用户项目文件或私人截图。
- 未来测试数据必须是自生成、公开或明确脱敏的数据。

## C-03｜核心模型边界

- Figure 不拥有数据，只通过稳定 ID 引用 Dataset。
- Dataset 与 Project Tree 显示路径解耦；移动文件夹不得破坏引用。
- Template 决定“怎么画”，Preset 决定“长什么样”，两者不得混为一层。
- Renderer 只负责把 PlotSpec 渲染为具体图形，不拥有项目事实。
- Exporter 不得改写 Figure 或 Dataset。
- Transform 只描述从原始数据到显示数据的可追溯变换，不直接覆盖原始 Dataset。

## C-04｜默认与覆盖

设置继承顺序固定为：

~~~text
Factory Default
→ User Default
→ Project Default
→ Template / Preset
→ Figure Override
→ Series Override
~~~

- 临时 UI 修改默认只写入当前最小对象的 override。
- 只有用户明确选择“保存为默认 / 项目默认 / 模板”时才提升作用域。
- 所有 override 必须可恢复到上级继承值。

## C-05｜物理单位

- 科研出版尺寸内部优先使用 mm 与 pt。
- raster 导出时才由尺寸与 dpi 推导像素。
- 不把 CSS px 作为出版尺寸事实源。
- Figure 尺寸、字体、线宽、marker 尺寸应具有明确物理含义。

## C-06｜项目文件

- 计划使用单文件 `.sfig` 容器。
- 项目格式必须带 `schemaVersion` 并支持 migration。
- Embedded 与 Linked Dataset 同时支持。
- 同一 Dataset 被多张 Figure 引用时只保存一份数据。
- 导出的 PNG/SVG/PDF/EPS/TIFF 默认不重复嵌入项目。
- 缩略图允许缓存，但不得作为 Figure 的事实源。

## C-07｜兼容与可复现

- 未知字段不得在读写过程中被无理由丢弃。
- Linked Source 不只保存绝对路径，应保留相对路径、文件身份和可校验元数据。
- Figure 应可记录 Dataset 身份、transform、template、preset、override、renderer/exporter 版本。
- 后续允许导出 Python/Matplotlib 脚本，但脚本不是项目事实源。

## C-08｜技术方向

- 第一交互 renderer 优先 Plotly.js。
- 架构必须允许后续接入 Matplotlib publication renderer。
- 不允许把 Plotly 专属字段直接当作长期 PlotSpec。
- 新增依赖前评估体积、许可证、Web/Tauri 双端兼容和离线能力。
