# FigureStudio 设计与演进

## 2026-09｜立项设计基线

### 背景

科研高频出图需求并不复杂，常见主要是 XY、bar、stack、heatmap、二维强度图和少量 3D。真正痛点不是“缺少图型”，而是：

- Origin 功能过重、默认审美和现代科研论文图存在距离；
- Python / Matplotlib 出图质量高，但反复写脚本不够直观；
- 脚本式工作流对“一个项目里长期维护几十张图”不够友好；
- 同一组数据被多张图复用、替换数据后批量更新，项目化管理比一次性导出更重要。

### 当前产品定位

> **Template-driven publication plotting workspace**

核心体验：

~~~text
Data → Template → Scientific Style → Figure → Publication Export

Project → Dataset → Figure → Dependency → Auto Update
~~~

### 已确定的设计方向

- Matplotlib 风格作为审美基线；
- Nature 类规范优先做成约束型 preset；
- Arial / Times New Roman 作为主要字体族；
- 数学符号支持 Unicode 与 LaTeX；
- 项目管理借鉴 Origin 的 Project / Folder / Worksheet / Graph 思路；
- 图形编辑使用 Plotly 交互能力；
- publication renderer 未来优先 Matplotlib；
- 项目容器以开放、可迁移、可恢复为优先；
- 用户提供的优秀样图后续可规范化为 Template / Preset。

### 暂不做

- Origin 全量分析功能；
- 大而全的数据清洗平台；
- 首版多 panel GUI；
- 首版复杂拟合、FFT、统计分析；
- 首版 AI 自动出图；
- 首版完整 Python runtime。
