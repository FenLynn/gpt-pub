## 视频状态

已完成 V001 至 V014 的合成 / 程序样例验证。

本轮新增最重要结论：

1. **共享片头和片尾会产生真正的 source ambiguity。**
2. **同一 source 内重复片段会产生多个 source intervals。**
3. **强竖屏裁剪可由 SIFT + RANSAC rescue，但不能过早丢掉候选。**
4. **视频不能把图片完整 signature 复制到每个 1 fps frame。**
5. **视频索引必须采用 Tier V0 / V1 / V2 分层。**
6. **Audio Lane C 成本较低，但只能作为 supporting evidence。**
7. **真实域验收工具与协议已经准备。**
