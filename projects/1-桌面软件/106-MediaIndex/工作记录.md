## Acceptance GUI

为进一步降低用户操作，新增 Windows Acceptance 壳：

```text
src/MediaIndex.Acceptance/
build/BuildAcceptancePortable.ps1
build_acceptance.bat
start_acceptance.bat
experiments/acceptance_worker.py
docs/acceptance-app.md
```

当前 `v0.0.1-dev` 设计：

- WinForms .NET 8 自包含 host。
- Python baseline 通过 PyInstaller 打包成私有 worker EXE。
- portable 运行时不要求用户安装 Python 或 .NET Runtime。
- GUI 自动生成 manifest。
- Query 支持拖放。
- 每条 Query 必须显式标注，防止漏填被误当 hard negative。
- 视频 source start 是可选项。
- 一键 A4 + V011。
- 一键导出匿名 JSON。

用户统一入口改为 `start_acceptance.bat`。portable 已存在时直接启动，不存在时自动调用 build 并启动。首次 build 仍为全自动。如果本机没有 .NET 8 SDK，build 脚本会下载私有 SDK；用户已有 Python 3 时会自动创建独立 build venv。

## 2026-09-16｜v0.0.2 自动验收真实反馈

用户在 Round 1 的 20 图库存上直接运行“自动验收”，无需手工标注。

40 个自动正样本：

- Top-50：100%
- Top-1：85%
- Confirmed：57.5%

6 个 Top-1 错误全部集中于 Crop30 / 非对称 Crop，且都出现在没有 candidate 被高置信确认的低置信路径。

已据此修改图片 rerank：

```text
有 Confirmed
→ verifier 排序

无 Confirmed
→ multi-region pHash fallback
→ verifier 仅 tie-break
```

同时修正 GUI 摘要，下一版显示：

```text
Top1
Top50
Confirmed
负样本是否实际测试
```

自动 smoke 也加入 synthetic unrelated negatives，避免“负样本 0 条却显示误确认 0”的误导。

版本推进到 v0.0.3-dev。

## 2026-09-16｜从 Acceptance 转入正式 MediaIndex Product Preview

用户要求不要继续让其充当测试员，而是把 hard negative 与正式产品入口一次推进。

本轮完成：

### Hard negative

新增：

```text
experiments/ci_hard_negative_suite.py
```

固定 known hard-negative 类型：

- same scene / different camera with parallax
- same poster template / different center content
- repeated texture / phase change
- low-texture look-alike

该套件接入 P106 Windows CI。若出现 high-confidence false same-source，则构建失败。

### Persistent MediaIndex core

新增：

```text
experiments/mediaindex_core.py
experiments/ci_mediaindex_core.py
```

当前实现：

- SQLite metadata
- compact region hash matrix
- image ID matrix
- incremental reuse
- lazy SHA-256
- persistent query
- offline-source candidate support
- deep verifier
- template fallback
