# P106｜MediaIndex 阶段记录

## 当前阶段

**Phase 0｜图片同源检索算法验证**

目标是在写正式产品代码前，先证明“几十万媒体库存中快速判断新媒体是否已经存在”这一核心能力可行。

## Phase 0A｜当前验证主线

### A0：受控合成样本

已完成。

结论：

- 精确文件 hash 不足以解决压缩、缩放和转格式。
- 全局 perceptual hash 对常规重新编码很强。
- 全局 hash 对裁剪存在明显算法与阈值敏感性。
- DoubleGradient 可覆盖轻裁剪，但强裁剪仍会失效。
- 局部特征可以恢复强裁剪候选。
- 仅靠宽松 SIFT/RANSAC verdict 会产生严重误报，因此“找到几何匹配”与“确认同源”必须分层。
