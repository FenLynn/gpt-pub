## Phase 0A｜图片验证

状态：**R001 至 R016 已完成。**

已经确认：

- 单一 pHash 不足。
- selected multi-region pHash 对压缩、resize、常规 crop 很有效。
- arbitrary crop / compound transformation 需要 local-feature Lane B。
- SIFT + RANSAC 不能单独作为 same-source 最终判据。
- 同场景不同 camera 可以出现大量 inliers 和很高 ratio。
- content consistency / NCC 能显著降低该类误报。
- 低纹理图片需要 grayscale / edge template fallback。
- 201-region 全表扫描过重，不作为默认生产设计。
- permanent full-SIFT cache 不作为默认生产存储。

目标图片链：

```text
exact / metadata
→ persistent pHash Lane A
→ persistent local-feature Lane B
→ candidate union
→ deep verifier
→ low-texture fallback
→ Exact / Confirmed / Probable / Candidate
```

## 用户真实图片自动验收

### Acceptance v0.0.2

用户在此前 Round 1 的 20 图库存上运行自动验收：

```text
40 positive queries
Top-50 = 100%
Top-1 = 85%
Confirmed = 57.5%
```

6 个 Top-1 错误集中在 Crop30 / asymmetric Crop。

诊断表明：

- 真源没有从候选集合丢失。
- 错误来自没有高置信 Confirmed 时，低置信 SIFT score 把错误候选顶到第一。

### Acceptance v0.0.4

加入 low-confidence template fallback 后，同一个用户库存重新运行：

```text
40 positive queries
4 automatic negative sanity queries

Top-1 positive = 100%
Top-50 recall = 100%
Confirmed recall = 57.5%
false Confirmed = 0
median query ≈ 1.50 s
P95 ≈ 2.29 s
```

当前解释：

- 候选与 Top-1 排序已经在该真实集上跑通。
- Confirmed 仍然故意保守。
- Acceptance 速度不代表正式持久索引速度。
- synthetic unrelated negative 不能替代 same-scene hard negative，因此 CI 已增加独立 known hard-negative gate。

## Hard-negative gate

当前 Windows CI 新增固定 known hard-negative suite：

- same synthetic scene / different camera with parallax。
- same poster template / different center content。
- repeated pattern / phase difference。
- low-texture look-alike。

规则：

```text
known hard negative
→ 不得进入 high-confidence same-source
```

若发生误确认，P106 Windows 构建失败。

## Phase 0V｜视频验证

状态：**V001 至 V014 已完成架构级验证。**

已经确认：

- 完整转码、分辨率/FPS 改变可由 temporal frame retrieval 覆盖。
- 3 s / 5 s / 8 s clip 可以恢复 source video 和时间关系。
- 1.05× speed 需要 affine time model。
- 插片头、中间删除需要 piecewise temporal model。
- 2 s / 4 s uniform sampling 对短 clip 过稀。
- 当前 V0 baseline 约 1 fps。
- strong vertical crop 需要 timestamp-aware local-feature rescue。
- composite Query 必须允许多个 source segments。
- shared intro/outro 会造成真正 ambiguity。
- 同一 source 内重复片段会造成多个 source intervals。
- Audio fingerprint 对 transcode/clip/speed 很强，但 same audio ≠ same video。
- 视频索引必须按总时长分层，不能给每个 sampled frame 保存完整图片 signature。

目标视频链：

```text
Tier V0
~1 fps lightweight temporal anchors

Tier V1
sparse timestamp local-feature keyframes

Tier V2
sparse verifier cache / source decode

Audio Lane C
compact sequence fingerprint

constant / affine / piecewise alignment
```

## Phase 1B｜Persistent Lane B 实现中

当前 v0.2.0 已实现：

- SQLite `local_words` schema migration。
- compact ORB-derived local words。
- persistent uint32 inverted postings。
- IDF 与 high-frequency stop-word 支持。
- Lane A / Lane B reciprocal-rank union。
- 查询结果显式显示候选来自 `A`、`B` 或 `A+B`。
- `Probable geometry` 与保守 `Confirmed` 分层。
- adaptive verification，避免固定 Top8 截断 Lane B rescue。

新的 CI stress 使用高度相关的大背景，并把真实差异压缩到小局部。Query 只保留该小局部，用于模拟强任意裁剪。

第一次 Lane B stress 已证明 12/12 真源进入 local Top20，其中存在 pHash Top20 完全漏掉而 Lane B 找回的样本。当前继续要求 end-to-end Top1 也必须恢复，不能只满足候选召回。
