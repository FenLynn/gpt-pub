# P106｜MediaIndex 阶段记录

## 当前阶段

**Phase 0｜图片同源检索算法验证**

目标是在写正式产品代码前，先证明“几十万媒体库存中快速判断新媒体是否已经存在”这一核心能力可行。

## Phase 0A｜当前验证主线

### A0：受控合成样本

状态：**已完成**

- 全局 perceptual hash 对常规重新编码很强。
- DoubleGradient 可覆盖轻裁剪，但强裁剪仍会失效。
- SIFT 可以恢复强裁剪候选。
- 仅靠宽松 SIFT/RANSAC verdict 会产生严重误报。

### A1：自然样例正样本鲁棒性

状态：**第一轮已完成**

20 张自然 / 实际样例图，17 类变换，共 340 个 Query。

- 多区域 pHash 对中心型 Crop70 很强。
- 任意位置 Crop50 和复合攻击会明显降低 pHash 排名。
- ORB 与 pHash 互补。
- 20 图小库结果明显过于乐观，后续相关场景压力集已修正候选预算。

### A2：难负样本与精确验证

状态：**第一轮已完成**

222 个 hard negative 中，同一真实场景不同相机视角是最危险类型。

因此高 inliers 与高 ratio 仍不能证明同源。

加入特征占比、覆盖度及 warp 后内容一致性后，本轮探索性高置信规则达到 173/200 true confirmed、0/222 hard-negative false positive。该规则仍不是生产阈值。

### A3：规模、候选索引与存储

状态：**R009 至 R016 已完成，真实 visual-word 分布仍待更大集验证**

#### Lane A

500k 图片全表 pHash warm scan：

- 28 regions：约 106.81 MiB，median 约 47 ms。
- 60 regions：约 228.88 MiB，median 约 67 ms。
- 201 regions：约 766.75 MiB，median 约 201 ms。

当前优先研究 28 至 60 个精选 regions。

#### Lane B

150 图相关场景压力集，250 个 Query：

- pHash + ORB LSH Top-50：248/250。
- pHash + ORB LSH + SIFT BoVW Top-50：250/250。
- Top-20 仍存在漏检。

500k synthetic visual-word inverted index：

- 约 47.9 unique words/image。
- 23.95M postings。
- uint32 postings 约 91.37 MiB。
- stop-word 过滤后，稀疏候选累计为亚毫秒至低毫秒量级。

该结果只证明工程量级，不证明真实图片召回率。

#### Metadata

500k files + 500k lightweight signatures 的 SQLite synthetic microbenchmark：

- DB 约 67.22 MiB。
- warm exact-hash / path lookup 均远低于 1 ms。
- 顺序读取 500k global hashes 约 0.44 s。

metadata 不是主要规模风险。

#### Verifier cache

R016 比较了全量 SIFT 与缩略图重建 SIFT。

当前更有吸引力的是 256 至 320px grayscale verifier thumbnail：

- 256 JPEG60：约 3.07 GiB / 500k。
- 320 JPEG60：约 4.26 GiB / 500k。
- 320 WebP70：约 3.63 GiB / 500k。

320 JPEG60 在当前 200 true pair / 194 hard negative 测试中，高置信规则确认 131/200 true，0/194 false positive。

它还能同时支持：

- SIFT 重建。
- warp NCC。
- 低纹理 template / edge fallback。
- 离线存储卷的视觉证据。

因此 verifier thumbnail + hot descriptor cache 已成为当前领先方案，但仍未冻结。

### A3-L｜低纹理 fallback

状态：**第一轮已完成**

对 clock、horse、cell 三类低纹理样本，共 30 个困难 Query：

- 多尺度 grayscale + edge template correlation Top-1：29/30。
- Top-5：30/30。

只能在候选已经缩小后运行。

### A4：用户真实域验收

状态：**未开始**

只在 visual-word、region layout、verifier cache 和候选预算基本冻结后进行。真实素材不得进入公开仓库。

## 当前架构候选

```text
SQLite metadata / exact hash
→ Lane A: 28 至 60 selected pHash regions
→ Lane B: compact visual-word inverted index
→ candidate union，当前继续按约 Top-50 保守设计
→ optional 256 至 320px verifier thumbnail
→ high texture: SIFT + RANSAC + content consistency
→ low texture: template / edge fallback
→ Confirmed / Probable / Similar / Not found
```
