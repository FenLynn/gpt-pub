# P106｜MediaIndex 阶段记录

## 当前阶段

**Phase 0｜图片同源检索算法验证**

目标是在写正式产品代码前，先证明“几十万媒体库存中快速判断新媒体是否已经存在”这一核心能力可行。

## Phase 0A｜当前验证主线

### A0：受控合成样本

状态：**已完成**

- 全局 perceptual hash 对常规重新编码很强。
- DoubleGradient 可覆盖轻裁剪，但强裁剪仍会失效。
- SIFT 可以恢复强裁剪候选。
- 仅靠宽松 SIFT/RANSAC verdict 会产生严重误报。

### A1：自然样例正样本鲁棒性

状态：**第一轮已完成**

20 张自然 / 实际样例图，17 类变换，共 340 个 Query。

- 多区域 pHash 对中心型 Crop70 很强。
- 任意位置 Crop50 和复合攻击会明显降低 pHash 排名。
- ORB 与 pHash 互补。
- 20 图小库中两路联合表现极好，但后续相关场景压力集证明该小库结果过于乐观。

### A2：难负样本与精确验证

状态：**第一轮已完成**

222 个 hard negative 中，同一真实场景不同相机视角是最危险类型：

- RANSAC inliers 最高 362。
- inlier ratio 最高 0.978。

因此高 inliers 与高 ratio 仍不能证明同源。

加入特征占比、覆盖度及 warp 后内容一致性后，本轮探索性高置信规则达到 173/200 true confirmed、0/222 hard-negative false positive。该规则仍不是生产阈值。

### A3：规模与候选索引

状态：**第二轮压力验证已完成，Lane B 尚未冻结**

连续内存随机 64-bit hash 微基准：

- 500k × 28 regions：约 106.8 MB raw hash，warm query 约 54.9 ms。
- 500k × 60 regions：约 228.9 MB raw hash，warm query 约 138.5 ms。

新增 150 图相关场景压力集，250 个 Query：

- pHash + ORB LSH Top-50：248/250。
- pHash + ORB LSH + SIFT BoVW Top-50：250/250。
- Top-20 仍存在漏检。

因此当前候选预算倾向约 Top-50，而不是早期小库显示的 Top-5。

compact verifier 消融：

- ORB / AKAZE 256 在 Crop70 与组合攻击上确认率不足。
- CV_8U SIFT 128 descriptors/image 在探索性规则下达到 159/200 true confirmed、0/198 hard-negative false positive。
- CV_8U SIFT 256 达到 168/200、0/198。
- 但 500k 全量 raw descriptor 约需 8.2 GB 或 16.4 GB，尚未计 keypoints 与索引。

### A3-L｜低纹理 fallback

状态：**第一轮已完成**

对 clock、horse、cell 三类低纹理样本，共 30 个困难 Query：

- 多尺度 grayscale + edge template correlation Top-1：29/30。
- Top-5：30/30。

朴素实现耗时过高，因此只能在候选已经缩小后作为 fallback，不能全库运行。

### A4：用户真实域验收

状态：**未开始**

只在 Lane B、精确验证和低纹理路径基本冻结后进行。真实素材不得进入公开仓库。

## 当前架构候选

```text
Exact hash
→ Lane A: global / multi-region pHash
→ Lane B: scalable local-feature index
→ candidate union，当前压力集倾向约 Top-50
→ cheap rerank
→ high texture: SIFT + RANSAC + content consistency
→ low texture: template / edge fallback
→ Confirmed / Probable / Similar / Not found
```

以下任一未解决，不进入正式 V1：

- 难负样本误报不可接受。
- Lane B 在大库无法紧凑召回任意裁剪。
- 强裁剪只能依赖全库暴力 SIFT。
- 生产阈值仅来自小型样本。
- compact SIFT 的存储 / 按需生成策略尚未确定。
