# P106｜MediaIndex 阶段记录

## 当前阶段

**Phase 0｜图片索引收敛 + 视频时间序列可行性验证**

目标是在正式 UI 与 MVP 之前，先把图片和视频共享的视觉底座、索引结构与视频时间层基本定型。

## Phase 0A｜图片验证

### A0：受控合成样本

状态：**已完成**

- 全局 perceptual hash 对常规重新编码很强。
- DoubleGradient 可覆盖轻裁剪，但强裁剪仍会失效。
- SIFT 可以恢复强裁剪候选。
- 仅靠宽松 SIFT/RANSAC verdict 会产生严重误报。

### A1：自然样例正样本鲁棒性

状态：**第一轮已完成**

20 张自然 / 实际样例图，17 类变换，共 340 个 Query。

- 多区域 pHash 对中心型 Crop70 很强。
- 任意位置 Crop50 和复合攻击会明显降低 pHash 排名。
- ORB 与 pHash 互补。
- 20 图小库结果明显过于乐观，后续相关场景压力集已修正候选预算。

### A2：难负样本与精确验证

状态：**第一轮已完成**

222 个 hard negative 中，同一真实场景不同相机视角是最危险类型。

加入特征占比、覆盖度及 warp 后内容一致性后，本轮探索性高置信规则达到 173/200 true confirmed、0/222 hard-negative false positive。该规则仍不是生产阈值。

### A3：规模、候选索引与存储

状态：**R009 至 R016 已完成，真实 visual-word 分布仍待更大集验证**

#### Lane A

500k 图片全表 pHash warm scan：

- 28 regions：约 106.81 MiB，median 约 47 ms。
- 60 regions：约 228.88 MiB，median 约 67 ms。
- 201 regions：约 766.75 MiB，median 约 201 ms。

当前优先研究 28 至 60 个精选 regions。

#### Lane B

150 图相关场景压力集，250 个 Query：

- pHash + ORB LSH Top-50：248/250。
- pHash + ORB LSH + SIFT BoVW Top-50：250/250。
- Top-20 仍存在漏检。

500k synthetic visual-word inverted index：

- 约 47.9 unique words/image。
- 23.95M postings。
- uint32 postings 约 91.37 MiB。
- stop-word 过滤后，稀疏候选累计为亚毫秒至低毫秒量级。

#### Metadata

500k files + 500k lightweight signatures 的 SQLite synthetic microbenchmark：

- DB 约 67.22 MiB。
- warm exact-hash / path lookup 均远低于 1 ms。

#### Verifier cache

当前领先候选为 256 至 320px grayscale verifier thumbnail：

- 256 JPEG60：约 3.07 GiB / 500k。
- 320 JPEG60：约 4.26 GiB / 500k。
- 320 WebP70：约 3.63 GiB / 500k。

该缓存可同时支持 SIFT 重建、NCC、低纹理 template / edge fallback 和离线卷视觉证据。

## Phase 0V｜视频验证

状态：**V001 至 V004 第一轮已完成**

视频不重新发明视觉算法，而是在图片视觉底座上增加采样帧与时间序列层。

### V001：完整转码

程序生成 6 个相关库存视频。

对单一源视频：

- H.264 CRF32 + 480p：24/24 时间一致 samples。
- H.265 CRF35 + 360p：23/24。
- 8 fps → 4 fps：24/24。

### V002：视觉修改

- 5% 边缘裁剪：18/24。
- 大水印：15/24。
- 8 s 强组合 crop + watermark + transcode：单全帧 pHash 仅 2/8 时间一致点，multi-region 提升到 3/8，仍不足以高置信确认。

结论：困难视频必须复用图片 local-feature Lane B 与 selected-frame verifier。

### V003：时间修改

- 7 s 处截取 8 s：8/8，source offset = 7.0 s。
- 1.05× 加速：0.5 s sampling 下 45/46，fitted slope = 1.05。
- 前插 3 s：主内容 24 samples 恢复，offset = -3.0 s。
- 删除中间 4 s：出现 offset 0 和 offset 4 两个 mode。强行单一 affine model 会误拟合。

结论：正式时间层必须支持 piecewise monotonic alignment。

### V004：多源与短片段

6 个相关库存视频：

- 6 个全长低质量转码 + 6 个 8 s clips：12/12 正确 Top-1。
- 3 s clips：6/6。
- 5 s clips：6/6。
- 所有 clip 的 source offset 均恢复为 7.0 s。

但一个 3 s 样本第二候选 score 达 0.953，而正确源为 1.000。短片段不能仅凭 pHash Top-1 自动 Confirmed。

无关 procedural video 本轮未形成高置信错误匹配。

## 当前统一架构候选

```text
SQLite metadata / exact hash
→ shared visual signature engine
   ├─ image query
   └─ video sampled frames
→ pHash + compact visual-word inverted retrieval
→ candidate media
→ image: spatial verifier
→ video: temporal correspondence + selected-frame verifier
→ Confirmed / Probable / Similar / Not found
```
