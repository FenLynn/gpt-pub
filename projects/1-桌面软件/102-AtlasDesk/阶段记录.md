## v0.9.0 项目驱动工作流

v0.9.0 将原有项目、工作区、终端、Git、环境标志和最近文件连接为一条显式工作链：

```text
选择项目
→ 后台读取项目上下文
→ 在工作区打开项目
→ 在项目目录建立终端
→ 显示 Git、环境与最近文件摘要
```

主要结果：

- 新增 `ProjectContextService`；
- 新增长期命名的 `ProjectWorkflowCoordinator`；
- 删除 `V070ProjectCenterEnhancer.cs` 和 `V070RuntimeVerifier.cs`；
- 保留现有“项目 / 环境 / 终端”界面，不增加第二套项目中心；
- 项目扫描只在用户明确进入“开发 → 项目”或点击刷新时启动；
- 项目控件不再通过 Loaded 或可见性变化自动扫描；
- 项目选择后才读取当前项目上下文；
- Git 只读取当前选择，使用 `--untracked-files=no`，三秒超时，取消时终止进程树；
- Git 缺失、非 Git、路径失效和超时均安全降级；
- 环境摘要只读取 Python、Node、.NET、LaTeX、Rust、Go 等项目标志，不启动语言运行时；
- 最近文件只过滤已保存列表，不递归扫描项目内容；
- 快速切换项目会取消前一请求，过期结果不能覆盖当前项目；
- 后台结果显式回到 WPF Dispatcher 后才更新界面；
- 工作区动作复用 `WorkspaceControl`；
- 项目终端动作复用 `WorkspaceTerminalCoordinator`。

## 当前已知限制

部分安装环境中，AtlasDesk 直接读取实时 `zotero.sqlite` 时不能与 Zotero 客户端稳定并行运行：

- 使用 AtlasDesk 资料库前关闭 Zotero；
- 该问题不阻塞 v0.9.0 项目工作流；
- 不继续在实时数据库上叠加并行、重试或长超时；
- 后续只有明确需求时才评估隔离只读快照方案。
