# AtlasDesk 阶段记录

本文件保存 AtlasDesk 当前正式发布基线和最新稳定候选。实时事项见 [工作记录](工作记录.md)，长期规则见 [开发约束](开发约束.md)。

## 当前正式基线

- 正式版本：`v0.8.0`；
- 正式标签与 Release：`p102-v0.8.0`；
- 正式主线：`main`；
- 目标平台：Windows 10/11 x64。

## v1.0.0 正式发布候选

状态：**版本、发布说明与正式就绪门禁已准备，等待稳定候选 CI 与 main 正式准入。**

- 候选分支：`p102-v100-release`；
- 目标版本：`v1.0.0`；
- 正式标签：`p102-v1.0.0`；
- Runtime 架构：透明文件夹 Runtime + 独立 Roaming/Local Data；
- 发布范围：Windows 10/11 x64。

### v1.0.0 主能力

- 项目选择、工作区、终端、Git、环境标志和最近文件形成显式工作链；
- 项目支持收藏、最近入口和失效路径重新定位；
- Zotero 使用紧凑只读三栏研究面板；
- 可快速复制标题、Citation Key、DOI、引用文本、LaTeX 与 Pandoc 引用；
- 可打开 PDF 或在资源管理器中显示 PDF 原文件；
- 工具与任务共享状态、进度、取消、结果和有限历史；
- 原生 ConPTY、Dashboard、窗口 WorkArea/DPI、Runtime/Data 和安全边界均受完整回归保护。

### 正式就绪门禁

- 版本必须为 1.0.0；
- 必需职责组件必须存在；
- V064、V065、V068 与 V070 已退休组件不得回归；
- Zotero 必须保持 SQLite ReadOnly 与 query_only；
- 项目 Git 读取必须有超时并排除 untracked 枚举；
- 任务与工具必须只有一个生命周期所有者；
- Windows WorkArea 最大化保护必须存在；
- 全部历史 smoke、真实窗口驻留、真实 CMD/ConPTY、Dashboard、Runtime/Data、安全、publish、manifest、ZIP 与 Artifact 必须通过。

## 当前已知限制

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出。

## 正式发布顺序

1. `p102-v100-release` 完整候选 CI；
2. 合入 `p102-stable` 并复核稳定树；
3. `p102-stable → main` 正式准入 CI；
4. 合入 main；
5. 更新正式发布记录；
6. 建立 `p102-v1.0.0` 标签和 Release；
7. 将正式 main 回流 `p102-stable` 与 `p102-exp`；
8. 下载并核验最终 Runtime。
