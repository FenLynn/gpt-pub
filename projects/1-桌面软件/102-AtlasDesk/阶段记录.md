### v1.0.5 键盘与可访问性

- 新增职责命名的 `AccessibilityCoordinator`；
- 在全部保留的历史表现层之后最后挂载，恢复旧层取消的焦点框与导航 Tab 入口；
- 八个主导航均可键盘到达，当前页是唯一 Tab 入口；
- 支持方向键、Home 与 End 导航；
- 交互控件共享 Windows 系统高亮色焦点框；
- 图标操作补齐自动化名称与帮助文本；
- 本地工作台状态使用礼貌级实时区域；
- Windows 高对比度只临时覆盖交互控件，关闭后恢复原本本地值。

### v1.0.5 UI 质量审计

- 检查交互控件、键盘可达性、导航焦点、Tab 入口、缺少名称、小目标和布局裁切；
- 裁切判断检查 LayoutClip 是否完整覆盖 `DesiredSize` 内容边界；
- 父布局额外分配的空白不再被误报为内容裁切；
- 未测量的页面切换瞬态控件不参与裁切判定；
- 审计不采集路径、网址、用户名、文件名、命令、终端输出或文档内容；
- 诊断中心显示键盘/可访问性和遗留组件审计结果。

### v1.0.5 真实可靠性修复

- 工作区和资料库异步导航在缺少 UI 线程所有权时整体回送 Dispatcher；
- 工作区失败显示增加独立 Dispatcher 防线；
- 修复异常目录读取路径可能从线程池修改 WPF 控件的真实跨线程异常；
- Zotero 搜索框提升到 32 px 收口高度；
- 资料库保持原有只读三栏结构，数据库访问继续使用 read-only 与 query_only。

### v1.0.5 编译与遗留边界

- nullable 警告提升为项目级编译错误；
- Zotero 类型标签显式接受可空输入并始终返回非空字符串；
- `LegacyComponentAudit` 固定保留 8 个仍承担实际职责的版本号组件；
- 任何新增版本号生产组件都会触发门禁失败；
- 下一阶段新功能必须使用职责命名的组件与协调器。

### v1.0.5 验证范围

- v1.0.0–v1.0.4 全量历史 smoke 与边界；
- nullable 零警告构建；
- 可访问性最后挂载与遗留白名单源码门禁；
- 真实 Windows 首页、工作区、资料库、开发、工具、任务与设置逐页驻留；
- 图标名称、目标尺寸与内容裁切逐页检查；
- 真实 CMD/ConPTY 连续会话；
- Dashboard、Runtime/Data、隐私和安全边界；
- WPF publish、manifest、ZIP 一致性和 Artifact 上传。

## 已知限制

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
- 正式标签与 GitHub Release 需要在具备对应平台写权限的环境中补建。

## Runtime 与数据

- Runtime 是透明、可覆盖、可公开的文件夹；
- 用户设置、日志、WebView2 Profile、终端状态和其他私人数据位于独立 Roaming/Local Data；
- 更新包和 Artifact 不包含私人 Data。
