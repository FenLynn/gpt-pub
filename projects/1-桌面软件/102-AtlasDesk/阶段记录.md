## v0.8.0 架构结论

### Runtime

用户自己建立的 `AtlasDesk` 文件夹就是 Runtime 根目录，不再额外套一层 `Runtime`：

```text
AtlasDesk/
├── AtlasDesk.exe
├── AtlasDesk.TerminalHost.exe
├── Assets/Terminal/
└── runtime-manifest.json
```

- `AtlasDesk.exe` 是真正 WPF 主程序，不再是 Go 自释放启动器；
- 删除活动源码中的 `personal-workbench-launcher`；
- 不再生成 `%LOCALAPPDATA%\AtlasDesk\App\<版本>\AtlasDesk.App.exe`；
- 终端资源直接随 Runtime 发布，不再释放到 AppData；
- Runtime 可公开，不含任何用户数据，并可直接覆盖更新。

### Data

```text
%APPDATA%\AtlasDesk
```

只保留轻量、重要、私人、值得备份的内容：普通设置、任务历史、安全元数据和加密保险库。

```text
%LOCALAPPDATA%\AtlasDesk
```

保存 WebView2 登录状态、终端浏览器状态、日志、启动状态、缓存和崩溃信息。该目录仍是私人 Data，但与机器绑定且可重新生成。

旧 AppData 迁移不写入正式产品代码。发布时单独提供一次性脚本，完成备份、目录移动和旧 App Runtime 清理。

## v0.8.0 安全中心

- 普通使用 AtlasDesk 默认不锁定；
- 主密码至少 20 位，用于真正的保险库加密，用户可保存到 Bitwarden；
- Google Authenticator 保存 TOTP，AtlasDesk 本地生成二维码并验证六位验证码；
- 主密码使用 Argon2id 派生密钥；
- 随机数据密钥使用 AES-256-GCM 加密 `vault.bin`；
- TOTP 共享密钥与数据密钥一同被主密码保护；
- 加密保险库用于保存密码、Token、密钥和私密备注；
- 可选四位临时锁只遮挡界面，不参与加密，不自动触发，可随时取消；
- 退出 AtlasDesk 或手动锁定保险库时清除内存中的解密密钥。

## v0.8.0 界面修复

- 左侧栏改为固定不透明中性浅色；
- Dashboard/Cloudflare 登录加载不再通过半透明混色使左侧短暂发黄；
- 设置页增加安全中心、立即临时锁定、打开配置目录和打开本机数据目录；
- 诊断中心分别校验 Runtime、Roaming Data 和 Local Data 边界。

## 发布与交付原则

- v0.8.0 首次交付完整 Runtime ZIP，因为主程序、终端宿主和终端资源均发生结构变化；
- 后续通常只交付修改过的 `AtlasDesk.exe`；
- 多文件更新时保留相对路径打包；
- 每次提供版本说明、变更、验证结果和 SHA-256；
- 永远不把 Data 打进 Runtime 或增量更新包。

## 验证要求

- 全量 smoke 与 WPF/XAML 编译；
- Argon2id、AES-GCM、TOTP、QR 依赖编译；
- Runtime/Data 边界源码检查；
- 旧自释放启动器不存在；
- TerminalHost 与 Runtime Assets 完整；
- 真实 CMD/ConPTY 路由通过；
- Runtime ZIP 中不存在 `settings.json`、`security.json`、`vault.bin`、任务历史、日志或浏览器 Profile；
- Runtime manifest、EXE 和 ZIP SHA-256 复核一致。
