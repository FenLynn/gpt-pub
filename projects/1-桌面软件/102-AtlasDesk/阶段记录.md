### v1.0.3 启动基线与日志上限

- 记录主窗口可用耗时、功能管线接入耗时和接入时工作集；
- 仅保存最近 20 个完整启动样本；
- 样本只包含版本、UTC 时间、安全启动状态、两个耗时与工作集；
- 不记录项目路径、网址、用户名、文件名、终端命令或文档内容；
- 诊断显示最近值、样本数与中位数；
- 无隐私性能历史可进入脱敏支持包；
- `atlasdesk.log` 超过 4 MiB 时在下次启动前轮换；
- 最多保留两代旧日志；
- 轮换失败不阻断启动或递归写入待轮换日志。

### v1.0.3 诊断生命周期

- 删除版本号组件 `V062StabilityEnhancer`；
- 使用职责命名的 `DiagnosticsCoordinator`；
- 协调器负责诊断按钮、单窗口激活与关闭生命周期；
- 主窗口关闭时同步关闭诊断窗口并释放引用；
- 保留异常退出与安全启动指示，不增加后台自动检查。

### v1.0.3 验证范围

- 20 条性能历史上限与摘要计算真实临时文件测试；
- 性能序列化字段隐私门禁；
- 首次与两代日志轮换真实文件测试；
- 旧 V062 文件与管线引用拒绝门禁；
- 全部 v1.0.2 与更早 smoke；
- 独立 Windows STA 真实窗口启动驻留；
- 真实 CMD/ConPTY 连续会话；
- Dashboard、Runtime/Data、隐私与安全边界；
- WPF publish、manifest、ZIP 一致性和 Artifact 上传。

## 停止与候选边界

- 自动开发停止在 v1.0.3；
- 不自动开始 v1.0.4 或 v1.1.0；
- v1.0.1 至 v1.0.3 均不得在用户验证前合入 `main`；
- 不为候选版本创建正式标签或 Release；
- 用户后续与 v1.0.0 集中实机比较。

## 已知限制

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
- 正式标签与 GitHub Release 需要在具备对应平台写权限的环境中补建。

## Runtime 与数据

- Runtime 是透明、可覆盖、可公开的文件夹；
- 用户设置、日志、WebView2 Profile、终端状态和其他私人数据位于独立 Roaming/Local Data；
- 更新包和 Artifact 不包含私人 Data。
