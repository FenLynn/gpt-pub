### v1.0.1 日常使用固化

- 主页不再因显示而读取 Zotero 数据库；
- 主页不启动项目扫描、Git、环境探测或外部工具；
- 主页只聚合已有设置、保存项目路径、最近文件与有上限任务历史；
- 主页刷新可取消，并通过 generation 门禁阻止过期结果覆盖；
- 原 Python/Workspace 状态卡转为项目与任务状态；
- 设置页增加 Dashboard URL 和常用文件、目录路径的即时状态；
- 路径不存在时只提示，不自动创建、搜索或猜测用户输入位置；
- 设置页增加 Runtime 与日志目录入口，继续保留 Roaming/Local Data 入口；
- Zotero 保留三栏结构，按窗口宽度分档收缩；
- Zotero 右侧只读详情最低保留 320 px，高频标题、Citation Key、DOI、引用与 PDF 操作优先可见；
- v1.0.0 正式能力基线门禁更新为支持后续补丁版本，但不得低于 1.0.0。

## v1.0.0 主能力

- 项目选择、工作区、终端、Git、环境标志和最近文件形成显式工作链；
- 项目支持收藏、最近入口和失效路径重新定位；
- Zotero 使用紧凑只读三栏研究面板；
- 可复制标题、Citation Key、DOI、快速引用、LaTeX 与 Pandoc 引用；
- 可打开 PDF 或在资源管理器中显示 PDF 原文件；
- 工具与任务共享状态、进度、取消、结果和有限历史；
- 任务与工具页面由一个职责命名生命周期协调器管理；
- 原生 ConPTY、Dashboard、窗口 WorkArea/DPI、Runtime/Data 和安全边界均受完整回归保护。

## 已知限制

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
- 正式标签与 GitHub Release 需要在具备对应平台写权限的环境中补建。

## Runtime 与数据

- Runtime 是透明、可覆盖、可公开的文件夹；
- 用户设置、日志、WebView2 Profile、终端状态和其他私人数据位于独立 Roaming/Local Data；
- 更新包和 Artifact 不包含私人 Data；
- v1.0.1 仅作为候选包等待用户与 v1.0.0 集中实机比较。
