### 核心功能

Development → 项目由项目列表升级为日常使用的选中项目工作台：

- 左侧保留显式项目发现、搜索、类型筛选、收藏、最近使用和失效路径恢复；
- 右侧汇总当前明确选中项目的 Git、环境标记、最近文件和项目上下文状态；
- 提供工作区、项目终端、Dashboard、资源管理器、复制路径和编辑上下文入口；
- 项目常用文件可在现有工作区打开或复制路径；
- 项目命令只在用户明确点击或双击后送入现有项目终端，绝不自动重放；
- AtlasDesk 侧关联文献可复制 Citation Key、打开现有本地 PDF 或在 Zotero 只读页面定位；
- 每个列表最多展示 8 项，避免项目页无限增长。

### 架构与数据边界

- `ProjectWorkflowCoordinator` 仍是 Development 项目工作流所有者；
- 项目上下文操作统一复用 `ProductivityContextCoordinator.TryExecuteAsync`；
- 项目配置继续由 `ProjectContextWindow` 负责；
- 项目状态继续通过 `ProjectContextService.ReadAsync` 有界读取，保留取消、generation gate 和 3 秒 Git 超时；
- 选中项目不会隐式创建或写入 profile；
- 项目上下文继续位于 `%APPDATA%\AtlasDesk\productivity-context.json` 并使用原子保存；
- Zotero SQLite 继续 `ReadOnly` 与 `query_only`，关联数据只是 AtlasDesk 侧快照；
- 不增加全盘索引、后台服务、定时器、命令自动执行、Zotero 写权限或 Data schema；
- v1.1.12 紧凑外壳、v1.1.11 纯黑终端和 v1.1.10 同进程 WPF WebView2 Dashboard 均保持不变。
