### 核心功能

本轮只做小范围的入口和查找收口：

- 首页复用现有 `ProductivityContextStore.Session.ProjectRoot` 与 `WorkspacePath`；
- 首页增加一个紧凑的最近项目入口，点击后进入现有 Development 页面；
- 原首页“最近工作”标题收紧为“最近文件”；
- Development → 项目在现有文件、显式命令和只读文献列表上方增加一个共同搜索框；
- 搜索只过滤已加载且受 v1.2.0 上限约束的列表，不创建索引；
- 资源区标题收紧为“文件 / 命令 / 文献”；
- 原有打开、复制、终端执行、PDF 与 Zotero 定位动作不变。

### 明确暂缓与边界

本候选没有引入：

- 新的最近使用数据库或 Data schema；
- 后台扫描、文件监控、定时器或全盘索引；

- WPF 原生外壳；
- ConPTY 原生终端；
- 同进程 WPF WebView2 Dashboard；
- Zotero SQLite 严格只读；
- Runtime 与 Data 分离；
- 项目目录无污染；
- 文件、命令、Dashboard、网页和文献继续由原模块负责。

- 没有降低任何项目工作台功能与边界检查。

#### 2. Runtime README

第一份 v1.2.1 Artifact 中程序与 manifest 正确，但 `README.txt` 首行仍为 v1.2.0。

已经修正打包链：

- 打包时强制检查 README 首行必须包含当前版本；
- 最终 Artifact README 首行为 `AtlasDesk v1.2.1 compact home and project resources`。
