### v1.0.4 视觉与层级收口

- 新增集中式 `UiConvergenceResources.xaml`；
- 统一页面标题、说明、区块标题、卡片、导航、按钮、输入框、标签页和列表密度；
- 收口卡片使用单层细边框，不再叠加阴影层；
- 主按钮、次按钮、文本按钮和图标按钮统一高度、圆角与交互状态；
- 深色终端保持独立视觉，不被浅色收口层覆盖；
- 诊断结果由固定三列改为状态与名称同一行、详情下一行；
- 诊断底部操作支持自动换行，窗口最小宽度降至 620 px。

### v1.0.4 自适应与页面结构

- 新增职责命名的 `UiConvergenceCoordinator`；
- 根据窗口宽度、高度和 DPI 切换宽屏、标准、紧凑三档密度；
- 自动调整外边距、侧栏、顶部栏、导航和低优先级说明；
- 首页指标卡在四列与两列之间切换；
- 首页上下文卡、最近工作与快捷入口可在窄宽度下纵向排列；
- 设置页自动压缩标签列、卡片内边距和底部操作；
- 开发、项目、任务、工具和工作区页面统一减少外层空白；
- 内容区低于安全尺寸时进一步压缩侧栏，但保留用户主动折叠状态。

### v1.0.4 自适应审计与首页宿主修复

- 诊断显示当前布局模式、窗口与内容区尺寸、侧栏宽度和 DPI；
- 审计不记录路径、网址、用户名、文件名、命令或文档内容；
- 仅在布局健康状态变化时写日志，避免拖动窗口产生大量记录；
- 体验层显式持有并公开首页与设置页；
- 首页安装同时支持 `Panel` 与 `ContentControl`；
- 修复 `HomeView` 实际为 `ScrollViewer/ContentControl`、旧安装器却只接受 `Panel` 的真实挂载问题；
- UI 收口协调器直接接收页面实例，不再从视觉树猜测首页或设置页。

### v1.0.4 验证范围

- 统一视觉资源完整性、TextBox `PART_ContentHost` 与无新增阴影门禁；
- 宽屏、标准、紧凑三档模式和隐私边界源代码门禁；
- ScrollViewer 首页宿主与显式页面所有权门禁；
- 真实 Windows 1080×720 紧凑顶层窗口驻留；
- 使用生产 `ResolveMode` 与 `ApplyHome` 对 1320×780 标准首页和 1500×860 宽屏首页进行离屏实际测量；
- 真实诊断窗口加载与关闭；
- 全部 v1.0.3 与更早 smoke；
- 真实 CMD/ConPTY 连续会话；
- Dashboard、Runtime/Data、隐私与安全边界；
- WPF publish、manifest、ZIP 一致性和 Artifact 上传。

## Runtime 与数据

- Runtime 是透明、可覆盖、可公开的文件夹；
- 用户设置、日志、WebView2 Profile、终端状态和其他私人数据位于独立 Roaming/Local Data；
- 更新包和 Artifact 不包含私人 Data。
