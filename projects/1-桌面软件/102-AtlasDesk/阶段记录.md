### v1.1.0｜Command Center 上下文

- 复用既有 `Ctrl+K` Command Center，不建立第二套命令面板；
- 合并页面、项目、文件、任务、工具、Zotero、项目命令、常用文件和关联文献；
- 空查询优先当前项目的高频入口，输入关键词后再跨项目检索；
- 原有目录、项目和 Zotero 搜索继续有界、可取消并使用 generation gate；
- 新旧结果统一去重，不破坏原有快捷入口。

### v1.1.1｜项目上下文配置

- 每个项目可保存显示名称、默认 PowerShell/CMD、Python 环境说明、Dashboard 地址、常用文件和显式命令；
- 项目终端和命令均遵守项目自己的默认 shell；
- 命令只有在用户主动选择后才写入新终端会话；
- 命令编辑支持直接单行命令或 `名称 :: 命令 :: 可选工作目录`；
- 配置位于 `%APPDATA%\AtlasDesk\productivity-context.json`；
- 保存复用 `AtomicFileStore`，具备同目录临时文件、落盘、原子替换、`.bak` 与损坏回退；
- 配置属于私人 Roaming Data，不进入 Runtime、Artifact 或仓库。

### v1.1.2｜安全会话续接

- 只保存和恢复主页面、项目根、工作区文件/目录、Zotero 查询与时间；
- 不保存终端输出、任意终端输入、Cookie、Token、Zotero 数据库内容或失效路径；
- 不自动重放任何命令；
- 安全模式下自动续接关闭；
- 手动恢复只恢复仍然有效的部分；
- 自动续接可在 Command Center 中关闭或重新开启。

### v1.1.3｜项目—Zotero 只读桥接

- 资料库增加“关联项目”操作；
- AtlasDesk 只保存 Item ID、Item Key、Citation Key、标题、DOI 和本地 PDF 路径快照；
- Zotero SQLite 继续使用 `ReadOnly` 与 `query_only`；
- 不写集合、标签、笔记、附件、Extra 或数据库行；
- 项目窗口可复制引用键、打开 PDF 和解除关联；
- Command Center 可检索项目文献并返回 Zotero 只读界面；
- 解除关联只删除 AtlasDesk 自己的记录。

### v1.1 架构边界

- `ProductivityContextCoordinator` 是唯一业务所有者；
- `ProductivityContextStore` 负责 schema、归一化、有界搜索投影与原子持久化；
- `ProjectContextWindow` 负责显式项目编辑；
- 没有新增 `V11x` 版本号 Enhancer；
- `AccessibilityCoordinator` 仍在全部业务和历史表现层之后最后挂载；
- `AD-D11` 固化“项目上下文是显式索引，不是后台自动化”；
- 不引入全盘索引、后台常驻服务、命令重放、Zotero 写权限或项目源码污染。
