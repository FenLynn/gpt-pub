### v1.0.2 配置与启动保护

- `settings.json` 使用同目录临时文件、落盘刷新和原子替换；
- 最近有效配置保留为 `settings.json.bak`；
- 主配置损坏时先隔离，再尝试从有效备份恢复；
- 主配置与备份均不可用时才使用安全默认值；
- 配置恢复来源进入诊断与脱敏支持包；
- StartupGuard 状态同样使用原子写入和备份；
- 一次异常退出只警告，连续两次异常启动进入安全模式；
- 安全模式仅抑制本次 Dashboard 自动打开，保存设置保持不变；
- 正常退出后连续异常计数复位。

### v1.0.2 诊断与生命周期

- 检查配置与备份、安全模式、Runtime/Data、WebView2、工作区、Zotero、终端宿主和日志；
- 检查 CMD、PowerShell、Git 以及已配置的 Conda、uv；
- 工具定位只检查保存路径与 PATH，不启动外部程序；
- Dashboard 使用四秒有界、可取消的连接测试；
- 重复诊断和支持包导出会取消旧操作，并拒绝过期结果覆盖；
- 支持包继续脱敏项目路径、最近文件、用户名和完整 Dashboard 路径。

### v1.0.2 验证范围

- 一次异常提示、两次异常安全启动和正常退出复位纯函数测试；
- 诊断禁止启动外部进程；
- 全部 v1.0.1 与更早 smoke；
- 独立 Windows STA 真实窗口启动驻留；

- WPF publish、manifest、ZIP 一致性和 Artifact 上传。

## 候选边界

- v1.0.1、v1.0.2 和后续 v1.0.3 均不得在用户验证前合入 `main`；
- 不创建正式标签或 Release；
- 用户后续将与 v1.0.0 集中实机比较。

## 已知限制

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
- 正式标签与 GitHub Release 需要在具备对应平台写权限的环境中补建。

## Runtime 与数据

- Runtime 是透明、可覆盖、可公开的文件夹；
- 用户设置、日志、WebView2 Profile、终端状态和其他私人数据位于独立 Roaming/Local Data；
- 更新包和 Artifact 不包含私人 Data。
