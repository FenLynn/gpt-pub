## 本版本得到的结果

### Runtime

v0.8.0 取消旧 Go 自释放启动器和 `AtlasDesk.App.exe`。用户建立的 `AtlasDesk` 文件夹直接作为 Runtime 根目录：

```text
AtlasDesk/
├── AtlasDesk.exe
├── AtlasDesk.TerminalHost.exe
├── WebView2Loader.dll
├── e_sqlite3.dll
├── Assets/Terminal/
├── runtimes/
├── README.txt
└── runtime-manifest.json
```

正式 Runtime 共 11 个公开文件，不再向 `%LOCALAPPDATA%\AtlasDesk\App\<版本>` 释放应用程序。

### Data

v0.8.0 将私人数据分为：

```text
%APPDATA%\AtlasDesk
→ 轻量、重要、可备份的私人配置与保险库

%LOCALAPPDATA%\AtlasDesk
→ WebView2、终端状态、日志、启动状态、缓存和崩溃数据
```

历史 AppData 由独立临时 PowerShell 工具迁移，不在正式产品代码中保留一次性迁移器。用户已于 2026-08-02 完成实际迁移和收尾，Dashboard、终端 Profile 和启动状态均按 AtlasDesk 备份校正，旧 `PersonalWorkbench\App` Runtime 已删除。

### 安全中心

v0.8.0 建立：

- 主密码与 Argon2id 密钥派生；
- AES-256-GCM 本地保险库；
- Google Authenticator 兼容 TOTP 与本地二维码；
- 可选、可关闭且不参与加密的四位临时界面锁；
- Runtime、Roaming Data 和 Local Data 分区诊断。

### 终端与部署

- `AtlasDesk.exe` 为真正 WPF 主程序；
- `AtlasDesk.TerminalHost.exe` 负责原生 ConPTY 边界；
- xterm.js 等公开终端资源随 Runtime 发布；
- 首次结构迁移交付完整 Runtime ZIP，后续更新恢复增量覆盖模式。

## 当前已知限制

v0.8.0 发布后的真实 Windows 使用确认了以下问题，均未改变本版本发布证据，但需要后续修复：

- 主壳左右区域使用过多大圆角框、底纹和阴影，视觉层级偏重；
- 最大化时自定义标题栏顶部存在裁切和垂直偏移，底部区域可能进入任务栏后方；
- 增加项目中心后，旧终端增强层会隐藏“环境”页面内容；
- Dashboard 跨域外链被无条件放入内部 WebView2，复杂网站可能触发 `RenderProcessUnresponsive`；
- WebView2 渲染无响应后的主 Dashboard 恢复路径不足。

这些事项的方案和进度以 [工作记录](工作记录.md) 为准。
