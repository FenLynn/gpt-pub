### 核心功能

本轮没有新建第二套快捷中心，而是聚焦既有 `Ctrl+K` Command Center：

- `Ctrl+K` 与顶部现有命令按钮打开同一个快捷面板；
- 可快速到达主页、Dashboard、工作区、Zotero、开发、工具、任务和设置；
- 可检索当前项目及其现有动作；
- 可检索已配置的项目文件、显式命令和只读关联文献；
- 可检索现有最近文件；
- 可触发现有终端、目录和首页刷新动作；
- 项目命令仍然必须由用户明确选择后执行，不自动恢复或重放。

快捷面板交互：

- 窗口尺寸收紧为 `720 × 480`；
- 输入提示为“搜索页面、当前项目、文件、命令或文献”；
- `Ctrl+K` 提示位于页脚；
- 支持上、下方向键、Enter 和 Esc；
- 结果按精确匹配、前缀、标题、类别、描述和既有动作优先级排序；
- 当前项目、项目终端、Dashboard、项目文件和关联文献优先展示。

### 主动取消的重型职责

Command Center 刷新不再：

- 遍历工作区目录；
- 重新扫描项目目录；
- 加载任务历史；
- 直接查询 Zotero 数据库。

这些页面和原功能仍然存在，只是不再由快捷面板承担重型检索。

### 架构与数据边界

- `ProductivityContextStore` 仍是当前项目与显式项目资源的数据所有者；
- `ProductivityContextCoordinator.TryExecuteAsync` 仍是项目动作执行所有者；
- 页面、终端、Dashboard、工作区与 Zotero 继续由原模块负责；
- Zotero SQLite 继续严格只读；
- WPF 原生外壳、ConPTY 原生终端和同进程 WPF WebView2 Dashboard 不变；
- Runtime 与 Data 继续分离；
- 不增加 Command Center 索引、Data 文件、schema、后台服务、定时器、文件监控或全盘索引；
- 不增加浏览器工作区、插件系统、MCP 市场或 Agent。
