## v1.1 阶段目标

本阶段不新增孤立页面，而是把现有 Command Center、项目中心、工作区、终端和 Zotero 串成一条可恢复的项目工作流。

```text
Ctrl+K Command Center
→ 选择项目 / 文件 / 文献 / 命令
→ 恢复项目上下文
→ 工作区、终端、Dashboard、Zotero 进入同一项目语境
```

四个版本在同一候选中连续完成：

- `v1.1.0`：全局快捷中心升级；
- `v1.1.1`：项目工作台配置；
- `v1.1.2`：安全工作会话续接；
- `v1.1.3`：项目与 Zotero 文献只读关联及阶段收口。

## v1.1.0｜全局快捷中心升级

- 复用既有 `Ctrl+K` Command Center，不另造第二套搜索窗口；
- 在原有页面、项目、文件、任务、工具和 Zotero 搜索之外，加入项目上下文结果；
- 支持从一个入口打开当前项目、项目终端、项目 Dashboard、常用文件和关联文献；
- 支持从一个入口执行用户主动配置的项目命令；
- 原有目录扫描、Zotero 搜索和项目扫描仍保持有界、可取消；
- 新上下文结果与原目录结果合并去重，不破坏原有快捷入口；
- 空查询只显示当前项目的少量高频项，输入关键词后再跨全部项目检索。

## v1.1.1｜项目工作台配置

新增职责命名的项目上下文配置，不增加版本号 Enhancer。

每个项目可保存：

- 显示名称；
- 默认 PowerShell 或 CMD；
- Python / Conda / venv 环境说明；
- 项目 Dashboard 地址；
- 常用文件与目录；
- 常用命令及可选工作目录；
- 与项目关联的 Zotero 文献。

项目配置保存在：

```text
%APPDATA%\AtlasDesk\productivity-context.json
```

保存复用 `AtomicFileStore`，采用同目录临时文件、落盘、原子替换和 `.bak` 恢复；主文件损坏时逐文件回退到备份。配置属于私人 Roaming Data，不进入 Runtime、Artifact 或仓库。

普通“打开项目终端”和预设命令均使用项目自己的默认 PowerShell / CMD 设置。命令编辑支持直接单行命令，或：

```text
名称 :: 命令 :: 可选工作目录
```

使用 `::` 避免误切 PowerShell 管道符。

## v1.1.2｜安全工作会话续接

会话只保存并恢复：

- 上次所在主页面；
- 当前项目根目录；
- 工作区最后文件或目录位置；
- Zotero 最后检索词；
- 会话保存时间。

明确不保存或自动恢复：

- 终端输出；
- 临时输入的命令；
- 自动重新执行命令；
- Dashboard Cookie、Token 或网页登录内容；
- Zotero 数据库内容；
- 已失效的文件和目录。

连续异常启动进入安全模式时，自动会话恢复被跳过；用户仍可在 Command Center 手动恢复可用部分。

## v1.1.3｜项目—Zotero 只读关联

- Zotero 继续使用 SQLite `ReadOnly` 与 `query_only` 路径；
- 资料库右侧增加“关联项目”操作；
- 关联记录只保存 Item ID、Item Key、Citation Key、标题、DOI 和本地 PDF 路径快照；
- 不向 Zotero 写集合、标签、笔记、附件或 Extra 字段；
- 项目上下文窗口可查看、复制引用键、打开 PDF 和解除关联；
- Command Center 可按项目检索已关联文献并重新定位到 Zotero；
- 解除关联只删除 AtlasDesk 自己的关联记录。

## 架构与边界

- 新功能统一由 `ProductivityContextCoordinator` 拥有；
- 数据模型与持久化由 `ProductivityContextStore` 负责；
- 项目配置界面由 `ProjectContextWindow` 负责；
- 不新增 `V11x...Enhancer` 或新的版本号生产组件；
- `AccessibilityCoordinator` 仍在全部业务和历史表现层之后最后挂载；
- Runtime / Roaming Data / Local Data 边界保持不变；
- Dashboard 跨域外链仍交给 Windows 默认浏览器；
- 终端命令只有在用户主动选择时才写入新终端会话；
- `AD-D11` 固化“项目上下文是显式索引，不是后台自动化”的长期路线。
