## 当前准确断点

当前产品开发停在 **v1.2.1 极简首页与项目资源候选**。

下一步优先由用户实机验证最终 Runtime：

1. 首页是否出现“最近项目”，名称和最近工作区是否正确；
2. 点击最近项目后是否正常进入 Development；
3. Development → 项目中的“项目资源”搜索是否同时过滤文件、命令和文献；
4. 清空搜索后各列表是否完整恢复；
5. 原有项目工作台、终端、Dashboard、Zotero、任务和工具是否正常；
6. README 首行是否显示 v1.2.1。

处理原则：

- 若实机通过，再决定是否继续下一项小功能；
- 若只存在局部视觉或操作问题，只做定点修复；
- 不扩展任务、预览、布局、浏览器或 Agent 系统；
- 不为项目资源新增第二套业务所有者；
- 未经用户确认，不把 v1.2.1 合入 `main`，不创建正式标签或 Release。

## 历史稳定化门禁锚点

- `v1.0.1` 首页不扫描工作区、读取 Zotero 数据库或执行 Git；
- `v1.0.2` 保留原子配置、备份恢复、安全模式与可取消诊断；
- `v1.0.3` 保留启动历史上限、日志轮换和诊断生命周期；
- `v1.0.4` 保留集中式视觉资源和响应密度；
- `v1.0.5` 保留键盘导航、高对比度、nullable 零警告和真实 UI 回归；

- `v1.2.0` 保留有界项目工作台、显式命令和 Zotero 只读关联。
