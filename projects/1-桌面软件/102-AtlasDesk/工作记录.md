## v0.9.0 完成内容

```text
选择项目
→ 后台读取项目上下文
→ 在工作区打开项目
→ 在项目目录建立终端
→ 显示 Git、环境与最近文件摘要
```

- 新增 `ProjectContextService`；
- 新增 `ProjectWorkflowCoordinator`；
- `ProjectCenterControl` 增加选择事件、读取状态和上下文显示；
- 删除 `V070ProjectCenterEnhancer.cs` 和 `V070RuntimeVerifier.cs`；
- Pipeline 使用 `ProjectWorkflowCoordinator` 作为项目/环境/终端长期所有者；
- 项目工作区动作复用 `WorkspaceControl.OpenFromGlobalSearchAsync`；
- 项目终端动作复用 `WorkspaceTerminalCoordinator.OpenProjectTerminalAsync`；
- 项目扫描不绑定 Loaded 或可见性，只由用户进入“开发 → 项目”或刷新触发；
- 环境摘要不启动语言运行时；
- 最近文件不递归扫描；
- Git 只读取当前选择，排除 untracked 枚举，三秒超时并支持取消；
- 快速切换会取消旧读取并丢弃过期结果；
- 后台结果回到 WPF Dispatcher 后才更新界面；
- Git 缺失、非 Git、路径失效和超时均安全降级；
- 临时 Python 项目、最近文件、历史边界、真实窗口和终端回归均已覆盖。

## 长期规则

- 不再新增版本编号 Enhancer；
- 历史层只能逐项迁入职责命名组件后删除；
- 页面可见性不得触发数据库、Git 或外部工具；
- SQLite、Git、环境探测和文件扫描不得占用 WPF Dispatcher；
- 最近终端上下文只能由用户主动恢复；
- 项目上下文只由选择或刷新触发，并必须可取消、有超时；
- `main` 只在明确正式发布时更新。
