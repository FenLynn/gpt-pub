## v0.9.0 已完成内容

目标链路：

```text
选择项目
→ 后台读取项目上下文
→ 在工作区打开项目
→ 在项目目录建立终端
→ 显示 Git、环境与最近文件摘要
```

已实现：

- 新增 `ProjectContextService`；
- 新增 `ProjectWorkflowCoordinator`；
- `ProjectCenterControl` 增加选择事件、读取状态和上下文显示；
- 删除 `V070ProjectCenterEnhancer.cs`；
- 删除 `V070RuntimeVerifier.cs`，改用 `ProjectWorkflowRuntimeVerifier`；
- Pipeline 使用 `ProjectWorkflowCoordinator` 作为项目/环境/终端长期所有者；
- 项目工作区动作复用 `WorkspaceControl.OpenFromGlobalSearchAsync`；
- 项目终端动作复用 `WorkspaceTerminalCoordinator.OpenProjectTerminalAsync`；
- 项目扫描不再绑定 Loaded 或可见性，只在用户进入“开发 → 项目”或点击刷新时启动；
- 项目上下文只在选择项目后读取；
- 环境摘要只读取项目标志，不启动 Python、Node、.NET、Rust、Go 或 LaTeX 工具；
- 最近文件只过滤现有最近文件列表，不递归扫描项目；
- Git 只读取当前选择，使用 `--untracked-files=no`，三秒超时并支持取消和进程树终止；
- Git 缺失、非 Git、路径失效和超时均安全降级；
- 快速切换项目会取消旧读取，并通过 generation 门禁丢弃过期结果；
- 后台结果显式回到 WPF Dispatcher 后才更新界面；
- 新增临时 Python 项目和最近文件的真实上下文 smoke；
- 历史 v0.8.1、v0.8.3、v0.8.7 门禁已迁移到长期项目工作流组件。

## 长期规则

- 不再新增版本编号 Enhancer；
- 历史层只能逐项迁入职责命名组件后删除；
- 页面可见性不得触发数据库、Git 或外部工具；
- SQLite、Git、环境探测和文件扫描不得占用 WPF Dispatcher；
- 最近终端上下文只能由用户主动恢复；
- 项目上下文只由选择或刷新触发，并必须可取消、有超时；
- `main` 只在明确正式发布时更新。
