## v1.0.4 UI 收口

### 统一视觉层

- 新增集中式 `UiConvergenceResources.xaml`；
- 统一主按钮、次按钮、文本按钮、图标按钮与导航按钮的高度、圆角和交互状态；
- 输入框改为圆角、轻边框与清晰焦点态；
- 卡片统一为单层细边框，取消多重阴影堆叠；
- 页面标题、说明和区块标题统一字号与颜色层级；
- 列表、标签页和常用表单控件统一紧凑密度；
- 原有深色终端样式保持独立，不被浅色收口层覆盖。

### 主窗口自适应

- 新增职责命名的 `UiConvergenceCoordinator`；
- 根据窗口宽度、高度与 DPI 切换宽屏、标准、紧凑三档密度；
- 自动调整外边距、侧栏宽度、卡片圆角、顶部栏高度与导航高度；
- 窄窗口隐藏低优先级副标题，低高度窗口压缩分组标签；
- 保留用户手动折叠侧栏的选择，不强制展开；
- 内容区过小时自动进一步压缩侧栏，避免主内容被遮挡。

### 页面结构响应

- 首页取消固定最小宽度；
- 首页指标卡由四列自动切换为两列；
- 首页上下文卡在窄宽度下转为纵向布局；
- 最近工作与快捷入口在紧凑模式下纵向排列；
- 设置页自动压缩标签列、卡片内边距与路径输入组合；
- 设置页底部操作在窄宽度下改为纵向，避免按钮挤压；
- 开发、项目、任务、工具和工作区页面统一缩减外层空白。

### 自适应检查

- 记录当前布局模式、窗口尺寸、内容区尺寸、侧栏宽度与 DPI；
- 检查关键内容区是否低于安全尺寸；
- 检查结果进入诊断中心，显示当前自适应模式与布局健康状态；
- 自适应记录不包含路径、网址、用户名、文件名、命令或文档内容；
- 仅在布局健康状态发生变化时写入日志，避免尺寸拖动产生大量日志。

### 首页宿主与页面所有权

- 体验层显式持有并公开首页与设置页；
- UI 收口协调器直接接收页面实例，不再从视觉树猜测页面；
- 首页安装同时支持 `Panel` 和 `ContentControl`；
- 修复 `HomeView` 实际为 `ScrollViewer/ContentControl`、旧安装器只接受 `Panel` 导致新版首页可能未挂载的问题；
- 真实 Windows 驻留已验证首页挂载、紧凑指标两列和诊断窗口加载。

### 诊断中心精简

- 固定三列结果改为两层信息结构；
- 状态与检查名称同一行，详细说明在下一行自动换行；
- 底部按钮使用可换行布局；
- 取消诊断卡片阴影，减少边框与嵌套层级；
- 窗口最小宽度由 680 px 降为 620 px。
