## v1.0.1 已完成

### 主页日常入口

- 主页只读取已有设置、保存项目路径、最近文件与有上限任务历史；
- 不因显示主页而扫描工作区、读取 Zotero 数据库、执行 Git、探测环境或启动外部工具；
- 主页刷新可取消，过期结果不能覆盖当前状态；
- 项目卡显示收藏、最近项目和失效路径；
- 任务卡显示活动状态与最近任务；
- Zotero 卡只显示配置与只读模式，真正数据库读取仍只在进入资料库后发生。

### 设置页可理解性

- Dashboard URL 提供即时格式状态；
- 工作区、Zotero、PDF 阅读器、Conda 与 uv 提供即时存在性状态；
- 路径不存在时只提示，不自动创建、搜索或猜测位置；
- 增加 Runtime 和日志目录入口；
- 保留 Roaming Data、Local Data 入口和现有设置分组；
- 不修改设置文件格式或数据目录结构。

### 资料库布局

- 保留 Zotero 三栏结构和严格只读边界；
- 分类栏、间距和右侧详情按窗口宽度分档收缩；
- 右侧详情最低保留 320 px；
- 标题、Citation Key、DOI、引用和 PDF 操作继续位于高优先级区域；
- 不新增数据库读取、写入或编辑能力。

### 回归保护

- 新增主页无数据库、无 Git、无项目扫描门禁；
- 使用真实临时路径验证项目、任务与最近文件聚合；
- 新增设置路径和 Zotero 三栏自适应门禁；
- v1.0.0 正式基线门禁支持补丁版本，版本不得低于 1.0.0；
- 全部 v1.0.0 历史 smoke、真实窗口、ConPTY、Dashboard、Runtime/Data、安全、publish、manifest 与 ZIP 均已通过。

## 候选发布边界

- 状态文档后的准确 head 必须再次通过同等级完整 CI；
- 通过后合入 `p102-stable` 并回流 `p102-exp`；
- 下载并提供 `AtlasDesk-v1.0.1-Runtime` 候选包；
- 用户后续与 v1.0.0 集中实机比较；
- 未经用户确认，不合入 `main`，不创建正式标签或 Release；
- 本轮不继续自动扩展到 v1.0.2。

## 已知限制继续保留

- 使用 AtlasDesk 资料库前关闭 Zotero；
- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
- v1.0.0 标签与 GitHub Release 仍需在具备对应平台写能力的环境补建。
