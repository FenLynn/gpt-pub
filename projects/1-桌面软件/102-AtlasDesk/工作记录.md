# AtlasDesk 工作记录

本文件是滚动工作看板。正式版本与发布证据见 [阶段记录](阶段记录.md)，长期规则见 [开发约束](开发约束.md)。

## 当前状态

- 正式版本：`v1.0.0`；
- 正式主线：`main`，保持不动；
- 当前候选分支：`p102-v101-daily-polish`；
- 当前候选版本：`v1.0.1`；
- 用户暂时无法实机验证，允许继续完善其他页面，后续集中比较验证；
- 本轮只做日常使用固化、布局与可理解性优化，不增加大型功能，不修改数据格式；
- v1.0.1 完成后停在候选分支与候选 Runtime，不自动进入 main。

## v1.0.1 范围

### 主页日常入口

- 主页从装饰性总览收敛为日常入口；
- 只读取已经存在的设置、最近项目、最近文件与任务历史；
- 不因显示主页而扫描工作区、读取 Zotero 数据库、执行 Git 或启动外部工具；
- 提供最近项目、活动任务、最近文件、资料库状态与常用入口；
- 空状态和路径失效状态必须明确，不制造虚假数据。

### 设置页可理解性

- 按 Runtime、私人 Data、工作区、资料库、终端与外部工具重新组织说明；
- 路径输入提供即时存在性状态，但不自动创建或扫描目录；
- 增加打开 Roaming Data、Local Data、Runtime 与日志目录的明确入口；
- 明确哪些内容可覆盖升级，哪些内容不得打包或公开。

### 工作区与资料库布局

- 优化窄窗口和短高度下的按钮密度、空状态与底部可达性；
- 工作区保留单目录树和现有编辑链，不引入 IDE 式面板；
- Zotero 继续严格只读，右栏在窄宽度下优先保留标题、Citation Key、DOI、引用和 PDF 操作；
- 摘要、完整元数据、附件与分类允许下沉或折叠，但不删除。

### 结构收口

- 只迁移职责明确且完整 smoke 可以覆盖的旧 Enhancer；
- 不为追求文件名整齐而重写稳定组件；
- 不新增版本编号 Enhancer；
- 页面显示不得触发数据库、Git、环境探测或递归文件扫描。

## v1.0.0 已知限制继续保留

- Zotero 功能保持严格只读；
- GB/T 7714 与 APA 为快速引用，正式投稿使用 Zotero/CSL 输出；
