## 目标：v0.9.0 项目驱动工作流

```text
选择项目
→ 工作区切换到项目目录
→ 项目终端进入对应目录
→ 显示 Git 分支与工作区状态
→ 显示环境摘要
→ 关联最近文件和任务
```

约束：

- 项目状态只在用户选择或刷新时读取；
- Git、环境和文件扫描均在后台并有超时；
- 不恢复 v0.8.2 的启动期全目录扫描；
- 不制作通用 IDE，不复制 VS Code；
- v0.9.0 必须通过项目链路、快速切换、窗口驻留、ConPTY、Runtime/Data 与安全完整 CI。

## 长期规则

- 不再新增版本编号 Enhancer；
- 历史层只能逐项迁入职责命名组件后删除；
- 页面可见性不得触发数据库或外部工具；
- SQLite、Git、环境探测和文件扫描不得占用 WPF Dispatcher；
- 每一版本完成稳定合入和开发回流后，才进入下一版本。
