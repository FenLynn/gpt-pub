# AtlasDesk 工作记录

本文件是滚动工作看板。正式版本与稳定候选证据见 [阶段记录](阶段记录.md)，长期规则见 [开发约束](开发约束.md)。

## 当前状态

- 正式主线：`main`，正式版本仍为 `v0.8.0`，未改动；
- 稳定候选：`p102-stable`，当前为 `v0.9.1`；
- 实验长期分支：`p102-exp`，已回流相同产品树；
- 当前任务分支：`p102-v092-zotero-readonly`；
- 当前目标：从 `v0.9.2` 逐步固化至 `v1.0.0`，完成后停止本轮开发；
- 原则：不扩张为通用 IDE、通用浏览器或完整 Zotero 替代品，不为版本号机械增加功能。

## 用户确认的 v1.0.0 路线

### v0.9.2｜Zotero 只读详情与全局布局固化

优先处理资料库右侧详情区，并继续完成多尺寸布局收口。

Zotero 页面目标：

- 参考 Zotero 原生三栏结构与紧凑条目详情，不复制其可编辑能力；
- 所有数据只读，不向 `zotero.sqlite` 写入任何内容；
- 右侧高频信息固定为标题、作者、来源、年份、Citation Key、DOI 和引用预览；
- 支持复制标题、Citation Key、DOI、完整引用、LaTeX `\\cite{}` 与 Pandoc `[@key]`；
- 支持打开主 PDF；
- 支持在资源管理器中快速显示 PDF 所在位置，方便单独复制文件；
- Citation Key 兼容 Zotero 原生字段与旧 Better BibTeX `Extra` 写法；
- 摘要、附件、标签、分类和其余元信息仍可查看，但不抢占高频操作区；
- 右侧不得继续使用空泛、过大的卡片和低信息密度布局；
- 工具页、资料库和其他页面继续检查最大化、还原、100%—175% DPI 与底部可达性。

### v0.9.3｜项目与工作区使用链固化

- 收藏、最近项目、失效路径重新定位；
- 项目、工作区、资源管理器与终端动作一致；
- 最近文件严格归属当前项目；
- Git 仅提供轻量状态，不发展为 Git 客户端；
- 保持用户主动触发、可取消、有超时。

### v0.9.4｜任务与工具最小闭环

- 工具执行进入统一任务状态；
- 等待、执行、成功、失败、取消和有限历史清晰可见；
- 不引入后台常驻服务、插件市场或复杂调度系统；
- 退出时对未完成任务给出明确处理。

### v0.9.5｜稳定性与历史架构收敛

- 继续迁移并删除无必要的版本编号 Enhancer；
- 收敛重复导航、可见性和生命周期控制；
- 核查 WebView2、终端、Zotero、任务取消后的资源释放；
- 检查启动、内存、Runtime/Data 和隐私边界；
- 原则上不增加大功能。

### v1.0.0｜正式发布

- 核心页面达到日常可用；
- 常见窗口尺寸、最大化、还原、100%—175% DPI 和多显示器无已知阻断布局问题；
- Dashboard、项目、工作区、终端、资料库、工具和任务主链稳定；
- 无已知数据损坏风险；
- Runtime 可透明覆盖升级；
- 完整 Windows CI 与必要实机证据通过；
- `p102-stable` 再次完成正式准入后才合入 `main`，建立 `p102-v1.0.0` 标签与 Release。

## 当前已知限制

部分安装环境中，AtlasDesk 直接读取实时 `zotero.sqlite` 时不能与 Zotero 客户端稳定并行运行：

- 使用 AtlasDesk 资料库前关闭 Zotero；
- 不在实时数据库上叠加并行、长超时或破坏性重试；
- 后续只有必要时才评估隔离只读快照；
- 该限制不改变“绝不写入 Zotero 数据库”的边界。

## 长期规则

- 不再新增版本编号 Enhancer；
- 历史层只能逐项迁入职责命名组件后删除；
- 页面可见性不得触发数据库、Git 或外部工具；
- SQLite、Git、环境探测和文件扫描不得占用 WPF Dispatcher；
- 最近终端上下文只能由用户主动恢复；
- 项目上下文只由选择或刷新触发，并必须可取消、有超时；
- 每个版本都先完成准确 head CI，再合入 `p102-stable` 并回流 `p102-exp`；
- `main` 只在明确正式发布时更新。
