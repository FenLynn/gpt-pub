## v1.0.5 最终质量收尾

### 键盘与可访问性

- 新增职责命名的 `AccessibilityCoordinator`，并在全部历史表现层之后最后挂载；
- 恢复旧修正层取消的焦点框和导航 Tab 入口；
- 八个主导航均可获得键盘焦点，当前页作为唯一 Tab 入口；
- 导航支持方向键、Home 与 End；
- 按钮、输入框、导航、标签页和列表项使用 Windows 系统高亮色焦点框；
- 图标按钮根据现有名称、内容和 ToolTip 补齐自动化名称与帮助文本；
- 本地工作台状态使用礼貌级实时区域，不暴露用户私有信息；
- Windows 高对比度仅临时覆盖交互控件，关闭后恢复原本本地属性。

### 结构化 UI 质量审计

- 统计交互控件、键盘可达控件、导航焦点与 Tab 入口；
- 检查图标按钮缺名、低于 24 px 的目标和关键控件布局裁切；
- 裁切判断基于 `DesiredSize` 内容边界，而不是父布局额外分配的空白；
- 未完成测量的页面切换瞬态控件不被误报；
- 审计只记录结构、计数、控件通用名称和布局状态；
- 不读取路径、网址、命令、文件名、终端输出或文档内容；
- 诊断中心显示键盘/可访问性和遗留组件审计结果。

### 真实缺陷修复

- 工作区和资料库导航在缺少 UI 线程所有权时，将整个异步入口回送 WPF Dispatcher；
- 工作区失败显示增加独立 Dispatcher 防线；
- 修复异常目录读取路径可能从线程池修改 WPF 控件的真实跨线程异常；
- Zotero 搜索框提升到收口后的 32 px 输入高度；
- 搜索框仍位于原有 42 px 工具栏行内，不改变资料库三栏结构；
- Zotero 数据库访问仍严格只读。

### 编译与遗留层边界

- nullable 警告提升为项目级编译错误；
- `ZoteroLibrary.GetItemTypeLabel` 显式接受可空输入并始终返回非空字符串；
- `LegacyComponentAudit` 固定保留 8 个仍承担实际职责的版本号组件；
- 新增任何版本号生产组件会直接触发门禁失败；
- 下一阶段新功能必须使用职责命名的所有者与协调器。
