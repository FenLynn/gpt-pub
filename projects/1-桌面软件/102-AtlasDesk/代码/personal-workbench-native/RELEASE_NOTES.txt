Personal Workbench v0.6.7

- Replaced unreadable system tooltips with an explicit light, high-contrast WPF template.
- Rebuilt Local Workspace around one VS Code-style explorer tree containing folders and supported files.
- Removed the separate middle file table; the right side is now dedicated to editing and Markdown preview.
- Reorganized Zotero into a compact title row, a center search toolbar and icon-based type/PDF indicators.
- Improved the Zotero collection tree and made parent collections include all descendant collections in listing and search.
- Redesigned the integrated terminal as a tabbed main workspace with a right-side session and action panel.
- Added detachable terminal windows, optional always-on-top mode and automatic redocking to the bottom drawer.
- Fixed CMD and Conda terminal startup by using synchronous ConPTY channel handles on dedicated background threads.
- Corrected pseudoconsole channel-handle lifetime and buffered startup output that arrives before the UI subscribes.
- Preserved Dashboard state, read-only Zotero access, external PDF handling, Markdown editing and lightweight packaging.
