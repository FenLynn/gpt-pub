AtlasDesk v0.9.1

This patch fixes maximized-window and short-height layout clipping discovered on Windows taskbar work areas.

Window bounds
- The main window now handles WM_GETMINMAXINFO and uses the active monitor work area rather than the full monitor bounds.
- Maximizing on primary or secondary monitors preserves space for taskbars on any screen edge.
- Native pixel bounds are used directly so the correction remains valid under mixed-DPI scaling.
- Restoring and resizing keep the existing WPF window behavior.

Tools layout
- The Tools page now reduces only its vertical outer inset when the available height is constrained.
- The three-column layout, result area and bottom action buttons remain visible without changing the normal full-height design.

AtlasDesk v0.9.0

This feature release connects projects, workspace, terminal, Git status, environment markers and recent files into one explicit project-driven workflow.

Project workflow
- ProjectWorkflowCoordinator replaces and retires the version-named V070 project-center enhancer.
- The existing Project / Environment / Terminal surface remains intact; no duplicate project UI was added.
- Selecting a project creates a bounded project context and updates the existing selection summary.
- Workspace actions open the selected project in WorkspaceControl.
- Terminal actions use WorkspaceTerminalCoordinator and enter the selected project directory.

Context
- Environment summaries use project marker files already identified by ProjectCatalogService; Python, Node, .NET, LaTeX, Rust and Go runtimes are not launched.
- Recent-file summaries filter the existing recent-file list and do not recursively scan project contents.
- Git status runs only for the selected Git project, excludes untracked-file enumeration, and has a three-second timeout.
- Missing Git, invalid paths, non-Git projects and timeouts degrade to explicit status text instead of blocking the shell.
- Rapid project changes cancel the previous read and generation-gate stale results.

Lifecycle
- Project scanning remains explicit through the Project page or Refresh action.
- No project, Git or environment scan runs during AtlasDesk startup or from visibility changes.
- V070ProjectCenterEnhancer and V070RuntimeVerifier are removed; responsibility-named workflow and runtime-verifier components replace them.

Regression protection
- New smoke tests exercise a real temporary Python-marker project and recent-file context.
- Source gates require cancellation, Git timeout, stale-result rejection, workspace integration and terminal integration.
- Existing startup residency, Dashboard resilience, terminal continuity, ConPTY, Runtime/Data and security checks remain active.

Known limitation
- Close Zotero before opening the AtlasDesk library where the live database cannot be shared safely.
