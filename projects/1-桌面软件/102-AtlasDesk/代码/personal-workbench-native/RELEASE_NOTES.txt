Personal Workbench v0.7.2

This release advances only the planned Tools Center structure. It keeps File Integrity as the single installed tool and does not add new execution capabilities.

- Reframed the existing File Integrity page as a formal Tools Center.
- Added a left tool catalog with File Integrity as the only active, verified tool.
- Moved manifest generation, manifest verification, file comparison and cancellation into the tool action pane.
- Preserved the central verification-result table and right-side progress/detail panel.
- Kept all SHA-256, path-safety, atomic manifest writing, cancellation and comparison algorithms unchanged.
- Did not add automatic scanning, source-file modification, script execution or additional tool types.
- Retained the existing workspace badge, result copy and Explorer location actions.
