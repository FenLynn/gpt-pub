AtlasDesk v0.8.6

This maintenance release begins the controlled retirement of historical version-named corrective layers while preserving the current interface and data model.

Feature host ownership
- V068HotfixEnhancer has been removed from the repository and feature pipeline.
- Library and Development host normalization, terminal bottom docking, and page-transition terminal behavior now belong to FeatureHostTerminalCoordinator.
- The new component has a long-term responsibility-based name and retains the tested terminal session model.

Display ownership convergence
- ShellResilienceCoordinator remains the exclusive owner of monitor WorkArea, DPI and display-topology handling.
- V069 still supplies the current title bar, tree templates, Zotero presentation and terminal launch reliability.
- LegacyEnhancerConvergenceCoordinator removes V069's obsolete WorkArea hook after SourceInitialized and Loaded, preventing two window hooks from controlling maximize bounds.

Regression protection
- New smoke checks require V068 to be absent, require named feature-host ownership, and require legacy WorkArea neutralization.
- Existing startup residency, development lazy loading, Dashboard recovery, ConPTY, Runtime/Data and security boundaries remain active.

Known limitation
- Close Zotero before opening the AtlasDesk library on installations where the live database cannot be shared safely.
