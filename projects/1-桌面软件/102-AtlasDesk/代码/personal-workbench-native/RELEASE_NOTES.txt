Personal Workbench v0.7.0

This release advances the next planned core module only: Project Center. It preserves the verified Workspace, terminal, Zotero and environment backends.

- Integrated Project Center into the Development page instead of opening a separate window.
- Added a clear Project / Environment tab structure; existing Conda, uv, venv and system Python detection remains intact under Environment.
- Reused the existing bounded read-only project scanner for Git, Python, Node, .NET, LaTeX, Rust and Go projects.
- Added project search and type filters without adding a background index or executing project code.
- Added direct actions to open a project in Workspace, create a project terminal, reveal it in Explorer or copy its path.
- Removed the redundant global Project Center pop-out button after the integrated page is attached.
- Preserved scan cancellation, generated-directory skipping and the existing scan depth/item limits.

Verification checkpoint
- Windows WPF/XAML compilation and framework-dependent publishing passed.
- Project Center and Environment tabs constructed successfully in a real STA/WPF runtime.
- Project catalog scanning, filtering and cancellation smoke tests remained green.
- Production terminal routing and five consecutive real CMD/ConPTY sessions remained green.
- Final lightweight EXE packaging, size validation and artifact upload are required by this package build before merge.
