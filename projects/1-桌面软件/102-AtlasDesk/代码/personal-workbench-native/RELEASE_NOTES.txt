Personal Workbench v0.7.1

This release advances only the planned Task Center refinement. It preserves existing task types, history format and concurrency behavior.

- Reorganized Task Center into a left launch/filter pane, central task history and right result/details pane.
- Kept the existing SHA-256 and default-workspace statistics tasks; no new executable task type was added.
- Added task-history search by title, type or path.
- Added status filters for active, completed and failed/cancelled tasks.
- Kept cancellation, bounded concurrency, persisted history and interrupted-task recovery unchanged.
- Improved visible/total counts, empty states and compact task actions.
- Preserved open-location and copy-result actions for historical tasks.
