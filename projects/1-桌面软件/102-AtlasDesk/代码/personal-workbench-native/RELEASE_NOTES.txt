Personal Workbench v0.6.8

- Fixed the unreadable black tooltip boxes by enforcing high-contrast tooltip text throughout the WPF application.
- Consolidated Local Workspace into a single VS Code-style explorer tree with search, filtering, creation and location actions inside the left pane.
- Removed the separate full-width Workspace search bar and aligned the right side around the document header, editor modes and content area.
- Compacted the Zotero title area and fixed search at the top of the center results pane.
- Replaced document-type, source and local-PDF labels with compact icons and explanatory tooltips.
- Refined the Zotero collection tree and retained recursive parent-collection listing and search across every descendant collection.
- Reorganized the integrated terminal into a multi-tab terminal canvas on the left and a dedicated session-settings pane on the right.
- Added visible terminal loading, initialization timeout, failure details and one-click retry instead of leaving a blank panel when WebView2 cannot initialize.
- Preserved independent per-tab pop-out windows, optional always-on-top mode and redocking to the bottom drawer.
- Preserved the v0.6.7 synchronous ConPTY transport fixes for CMD, PowerShell, Conda and uv sessions.

Verification checkpoint
- Windows WPF/XAML compilation and framework-dependent publishing passed.
- The smoke suite launched a real CMD process through ConPTY, received terminal output, sent the exit command and observed clean process termination.
- Workspace, Zotero and terminal controls retained their existing named bindings and event entry points.
- The final main-branch package build repeats the complete regression suite before producing the lightweight executable.
