Personal Workbench v0.6.10

This is a corrective release for the five issues reported against v0.6.9. It does not advance the later module roadmap.

- Removed the Windows focus adornment that briefly painted the selected left navigation item with the system highlight color on entry.
- Rebuilt the Workspace and Zotero tree item templates with separate header and child rows, eliminating overlapping, drifting and visually interleaved descendants.
- Disabled recycling for the two relatively small lazy trees so expanding and collapsing a branch cannot reuse a container with stale indentation state.
- Removed the duplicated Zotero internal title strip. Connection state, load mode, refresh and settings now live in the global top bar and appear only on the Library page.
- Added distinct document-type glyphs for journal articles, theses, conference papers, books, patents, webpages, software, datasets, presentations, letters and other records.
- Replaced the generic PDF marker with a recognizable red PDF glyph. The attachment panel now distinguishes PDF, Word, PowerPoint, Excel, images and generic attachments.
- Added a persistent CMD launch policy using the system cmd.exe, an explicit /K command and the selected working directory without delayed synthetic cd input.
- Intercepts every integrated CMD entry point with the reliable policy and automatically replaces the first default CMD session if the legacy launch exits immediately.
- Replaced the blue native Windows title bar with a neutral compact custom title bar, preserving minimize, maximize, restore, close, drag and resize behavior.

Verification checkpoint
