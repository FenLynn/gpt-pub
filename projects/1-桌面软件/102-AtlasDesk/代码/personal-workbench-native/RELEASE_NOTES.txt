AtlasDesk v0.9.5

This stabilization release removes duplicate lifecycle ownership from the task and tools surfaces without adding product features.

Lifecycle convergence
- Task and tools pages are installed and switched by one responsibility-named TaskToolCoordinator.
- The coordinator owns task/tool navigation visibility, active-task exit confirmation, control disposal and shared task-hub shutdown.
- V064TaskEnhancer and V065ToolsEnhancer are retired and removed.
- The temporary standalone task-tool alias file is removed.
- WorkbenchFeaturePipeline now exposes one TaskTools owner rather than two version-named enhancers.

Regression protection
- New v0.9.5 checks require the retired files to stay absent.
- The pipeline must attach TaskToolCoordinator.
- Exactly one native component may call WorkbenchTaskHub.Shutdown.
- Existing task/tool sharing, cancellation, exit recovery, Runtime/Data and privacy checks remain active.

AtlasDesk v0.9.4

- File-integrity manifest generation, verification and file comparison share the task-center collection.
- Tool and task pages share status, cancellation, results and bounded history.
- Active work is confirmed before application exit.
- History remains limited to 100 records and interrupted work is recovered explicitly.

AtlasDesk v0.9.3

- Projects can be pinned and filtered as favorites.
- Workspace, terminal and Explorer actions maintain a bounded recent-project list.
- Missing saved paths stay visible and require explicit user relocation.
- AtlasDesk does not search disks or guess moved project locations.

AtlasDesk v0.9.2

- Zotero uses a compact read-only item pane modeled on the native information structure.
- Title, authors, source, year, Citation Key, DOI and quick citation actions are immediately available.
- PDF files can be opened or selected in Windows Explorer.
- Zotero SQLite access remains read-only with query_only enabled.

AtlasDesk v0.9.1

- Maximized windows use the active monitor work area and avoid taskbars on any edge.
- The tools page adapts its vertical inset when height is constrained.

AtlasDesk v0.9.0

- Projects, workspace, terminal, Git status, environment markers and recent files form one explicit user-driven workflow.
- Project context is cancellable, bounded and never starts from application startup or visibility changes.

Known limitation
- Close Zotero before opening the AtlasDesk library where the live database cannot be shared safely.
