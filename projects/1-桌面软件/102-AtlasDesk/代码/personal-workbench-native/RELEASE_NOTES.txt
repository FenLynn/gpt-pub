Personal Workbench v0.6.3

- Added a lightweight project center above the existing local workspace.
- Detects Git, Python, Node.js, .NET, LaTeX, Rust and Go projects without running project code.
- Reads the current Git branch directly from repository metadata, including worktree-style .git pointers.
- Opens a selected project in the existing workspace, Explorer or integrated ConPTY terminal.
- Skips generated, hidden and reparse-point directories to avoid expensive or cyclic scans.
- Project scans are cancellable; repeated refreshes replace stale scans safely.
- Preserves the v0.6.2 diagnostics, support bundle and startup protection.
