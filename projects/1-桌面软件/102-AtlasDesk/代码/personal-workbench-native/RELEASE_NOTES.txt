Personal Workbench v0.6.4

- Added a real task center in the existing Tasks navigation entry.
- Runs read-only SHA-256 file hashing and default-workspace directory statistics.
- Shows queued/running state, progress, elapsed time, results and errors.
- Supports cancellation, persisted history and interrupted-task recovery.
- Limits background I/O to two concurrent tasks; additional tasks remain cancellable in a queue.
- Directory statistics skip generated, hidden and reparse-point directories.
- Does not execute project scripts, package managers or arbitrary commands.
- Preserves project center, diagnostics, Dashboard, Markdown, Zotero and ConPTY behavior.

Verification checkpoint
- Iteration 1 passed known SHA-256 vectors, directory counts, cancellation and history recovery.
- Iteration 2 added bounded concurrency and explicit queued-state handling; all regressions passed.
- Iteration 3 is the final package build with the full inherited smoke-test suite.
