AtlasDesk v0.8.0

This release changes AtlasDesk from a self-extracting launcher into a transparent folder runtime.

Runtime and Data
- AtlasDesk.exe is now the real WPF application. It runs directly from the user-created AtlasDesk folder.
- AtlasDesk.TerminalHost.exe and terminal web assets remain beside the main program in the same public Runtime folder.
- No executable, DLL or terminal asset is written to AppData.
- %APPDATA%\AtlasDesk contains only small, important private settings and encrypted data.
- %LOCALAPPDATA%\AtlasDesk contains machine-local WebView2 state, terminal profile, logs, cache and startup state.
- Automatic legacy migration was removed from product code. A one-time external migration script is provided separately.

Security and privacy
- Added an optional local encrypted vault protected by a 20-character-or-longer master password and Google Authenticator compatible TOTP.
- Added local QR setup, Argon2id password derivation and AES-256-GCM encrypted vault storage.
- Added a generic encrypted key/value editor for passwords, tokens and private notes.
- Added an optional four-digit temporary UI lock. It is manual, can be disabled, and never participates in encryption.
- Runtime remains fully public and contains no user paths, cookies, logs, tokens or account data.

Interface and reliability
- Fixed the sidebar to an opaque neutral background so Dashboard login rendering cannot tint it yellow.
- Added direct access to the roaming configuration directory and the machine-local data directory.
- The encrypted vault key is cleared when AtlasDesk exits or when the user locks the vault.
