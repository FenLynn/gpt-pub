Personal Workbench v0.6.11

This is a corrective release for the terminal, Workspace and Zotero issues reported against v0.6.10.

- Fixed the terminal reliability root cause: the production terminal UI had continued to call the legacy managed ConPTY session directly, while CI exercised the newer native terminal factory. Production and regression tests now use the same TerminalSessionFactory path.
- Routed every Windows system CMD session through the native GUI bridge and Windows system ConPTY, including the default Development terminal, new CMD buttons, Workspace terminals and Python environment CMD sessions.
- Added a source-level regression guard that fails CI if the production terminal UI bypasses the verified factory again.
- Increased terminal action, tab, side-panel and status contrast. Enabled actions are bright and readable; disabled actions remain visibly distinct without disappearing into the dark background.
- Added inline Workspace image discovery and preview for PNG, JPEG, WebP, BMP, GIF and TIFF files without adding Node, Monaco or another bundled runtime.
- Kept Markdown rendering and enabled lightweight highlighted preview/split view for Python, LaTeX and common code files while preserving the editable plain-text source pane.
- Rebuilt the Zotero PDF-only control as a single compact icon toggle and tightened the type, sort and search action widths so the center toolbar no longer overlaps.

Verification checkpoint
- Windows WPF/XAML compilation and framework-dependent publishing passed.
- The complete smoke suite passed, including the production-routing invariant.
- Five consecutive real CMD sessions passed through the same factory used by the UI in a Unicode path, including multiple commands, resize, idle liveness and clean exit.
- Workspace image registration, Python/LaTeX highlighted rendering and the Zotero PDF toggle template passed STA/WPF runtime creation and rendering checks.
- Final lightweight EXE packaging, size validation and artifact upload are required for this delivery build.
