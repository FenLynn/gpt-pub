AtlasDesk v0.7.4

This is a deliberately small continuity release used to verify the complete GPT-Pub development path from p102-exp to p102-stable and main.

- Standardized all user-visible product wording on AtlasDesk.
- Changed the roaming configuration and log directory to %APPDATA%\AtlasDesk.
- Added safe first-start migration from %APPDATA%\PersonalWorkbench when the AtlasDesk directory does not yet exist.
- Changed the launcher extraction directory to %LOCALAPPDATA%\AtlasDesk\App\<version> and the extracted application name to AtlasDesk.App.exe.
- Updated launcher dialogs, diagnostics, support bundles, settings warnings and backup UI to AtlasDesk.
- Kept historical namespace, assembly, backup schema and embedded payload identifiers as internal compatibility details.
- Added automated path-migration tests and a source regression that rejects the old user-visible product phrase.

Verification checkpoint
- Windows WPF/XAML compilation and complete smoke tests are required.
- Legacy roaming data must move to AtlasDesk without overwriting an existing AtlasDesk directory.
- Existing backup files, settings, task history, Zotero, Markdown, Command Center and CMD/ConPTY regressions must remain green.
- Framework-dependent publishing, Go launcher embedding, lightweight size validation, ZIP/EXE consistency and SHA-256 are required before promotion.
