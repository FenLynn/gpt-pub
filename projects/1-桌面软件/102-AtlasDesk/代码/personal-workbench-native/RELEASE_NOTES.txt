AtlasDesk v1.0.1 candidate

This maintenance candidate improves daily-use clarity without changing the v1.0.0 data model or adding a large product feature.

Home dashboard
- Showing the home page no longer reads the Zotero database or starts project/Git discovery.
- Home status is assembled from already saved settings, recent files, saved project paths and bounded task history.
- Repeated refreshes are cancellable and generation-gated so stale snapshots cannot overwrite the current view.
- The former Python and Workspace metric cards now summarize saved projects and shared task activity.
- Zotero status shows configuration and read-only mode only; actual database reads remain exclusive to the Library page.

Settings clarity
- Dashboard URL and known file/directory paths receive immediate existence or format feedback.
- Validation is informative only: AtlasDesk does not create, search for or guess user-entered workspace, Zotero, Conda, uv or PDF paths.
- Settings adds direct Runtime and log-directory entries alongside roaming and local data folders.
- Runtime is identified as replaceable program content, while logs and user data remain private local state.

Library layout
- Zotero keeps its three-pane structure but now uses bounded responsive widths.
- At constrained window widths, the collection pane narrows gradually and the read-only detail pane retains at least 320 px.
- Title, Citation Key, DOI, reference and PDF operations remain in the high-priority upper detail area.
- No Zotero write capability or new database access path was added.

Regression protection
- New v1.0.1 checks prohibit Zotero, Git and project scans from returning to home-page visibility refresh.
- Real temporary paths validate project, task and recent-file snapshot aggregation.
- Settings path behavior and Zotero responsive-layout boundaries are source-gated.
- All v1.0.0 smoke, window residency, ConPTY, Dashboard, Runtime/Data, security, publish, manifest and ZIP checks remain mandatory.

Verification status
- v1.0.1 remains a candidate for combined user verification.
- It must not enter main or receive a formal tag/Release before user validation.

AtlasDesk v1.0.0

AtlasDesk 1.0 is the first formal release of the stabilized Windows research and development workbench.

Core workbench
- A bounded project workflow connects project selection, workspace, terminal, Git status, environment markers and recent files.
- Projects can be pinned, reopened from recent history and explicitly relocated when saved paths move.
- The native ConPTY terminal remains isolated behind AtlasDesk.TerminalHost.exe and does not store commands or output.

Zotero research pane
- The library follows a compact three-pane, read-only information structure.
- Title, authors, source, year, Citation Key and DOI are immediately visible.
- Title, DOI, Citation Key, quick reference text, LaTeX citations and Pandoc citations can be copied.
- PDF attachments can be opened or selected in Windows Explorer for direct file copying.
- Zotero SQLite access is read-only with query_only enabled.

Tasks and tools
- File-integrity manifest generation, verification and file comparison share one task collection.
- Task and tool pages share status, progress, cancellation, results and bounded history.
- Active work is confirmed before application exit.
- One TaskToolCoordinator owns task/tool navigation and shutdown lifecycle.

Window and runtime
- Maximized windows use the active monitor work area and avoid taskbars on every edge.
- Common window sizes, 100–175% DPI, restore/maximize and Runtime/Data boundaries are protected by regression checks.
- Runtime remains a transparent replaceable folder; private roaming and local data never enter the package.

Release verification
- v1.0.0 adds a formal release-readiness gate over the stabilized components and retired compatibility layers.
- Full smoke, real Windows window residency, real CMD/ConPTY sessions, Dashboard, Runtime/Data, security, publish, manifest and ZIP checks remain mandatory.

Known limitation
- Close Zotero before opening the AtlasDesk library where the live database cannot be shared safely.
- GB/T 7714 and APA previews are quick-copy references; use Zotero/CSL output for formal submission formatting.

Previous stabilization milestones

- v0.9.4: unified tool tasks, cancellation and bounded history.
- v0.9.3: project favorites, recents and explicit path relocation.
- v0.9.2: read-only Zotero research pane and PDF file-location action.
- v0.9.1: native work-area maximization and constrained-height layout fix.
- v0.9.0: explicit project-driven workflow.
