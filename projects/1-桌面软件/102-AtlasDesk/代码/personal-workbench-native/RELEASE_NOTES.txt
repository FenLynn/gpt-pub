Personal Workbench v0.6.6

- Added configuration backup and migration with a strict two-file allowlist.
- Backs up settings.json and task-history.json only.
- Explicitly excludes WebView2Profile, BrowserProfile, Access/GitHub sessions, cookies, logs, caches and startup state.
- Validates every payload with SHA-256, JSON parsing, entry count and size limits.
- Rejects unknown entries, duplicate entries, path traversal and undeclared archive data.
- Creates an automatic pre-restore snapshot and writes restored files atomically with rollback attempts.
- Requires application restart after restore instead of mutating live module state.
- Includes the complete regression suite for startup, diagnostics, projects, tasks and file integrity.
