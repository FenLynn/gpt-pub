# P111｜GameStation 阶段记录

## 当前基线

- 项目状态：19 款游戏已全部进入统一游戏库；首轮 UI 重构和游戏模块接入已完成，等待完整 CI 与 Pages 验收。
- 当前分支：p111-exp。
- 当前版本：开发预览，不作正式版本号。
- 稳定分支：尚未建立。
- 正式主线：main；开发必须经 PR 合入。
- 标签与 Release：无。
- 发布平台：GitHub Pages，统一发布入口 `/gpt-pub/p111/`；不使用 Cloudflare Pages。
- 运行边界：完全离线、file:// 优先、无账号/云服务/网络对战。

## 本轮实现

1. 重做 GameStation 主界面：深色品牌侧栏、精选 Hero、分类导航、搜索/状态筛选、网格/列表切换、收藏/最近游玩、本地运行状态。
2. 重做游戏工作区：独立标题与工具栏、AI 难度入口、沉浸模式、浏览器全屏、游戏信息侧栏和模块状态。
3. 游戏库扩充至 19 款，每款均有独立入口和 iframe 上下文。
4. 新增 9 款基础可玩模块：2048、记忆翻牌、黑白棋、四子棋、海战棋、国际跳棋、数独、推箱子、Pong。
5. 新增 4 款后续复杂模块入口：斗地主、麻将、三国杀、魂斗罗原创横版射击；其中前三者为基础规则原型，魂斗罗不含原作 ROM 或素材。
6. 更新共享游戏视觉样式，统一状态、按钮、面板和棋盘布局。

## 完成度分层

- 可直接游玩：扫雷、2048、记忆翻牌、黑白棋、四子棋、海战棋、国际跳棋、数独、推箱子、俄罗斯方块、贪吃蛇、Pong。
- 体验原型：五子棋、中国象棋、Klondike、魂斗罗原创横版射击、斗地主、麻将、三国杀。
- 不把原型标注为正式规则完成；AI 难度、完整规则、存档与性能仍需逐项回归。

## 已知限制

- 五子棋 AI 仍为启发式策略，未完成棋力校准；中国象棋仍缺完整合法走法、将军/将杀与 AI。
- Klondike 仍需补齐完整移动规则、自动收牌、撤销和胜负判定。
- 斗地主当前仅支持单张、对子、三张、炸弹和王炸；叫地主、顺子、连对、飞机、完整计分尚未实现。
- 麻将当前为 136 张基础牌摸打和基础胡牌结构；吃碰杠、番种和地方规则尚未实现。
- 三国杀当前为基础身份/攻防卡牌原型；完整卡牌、技能、角色和小乔版本尚未确认。
- 魂斗罗使用原创横版射击玩法，不含原作 ROM、图像、音乐或其他受保护素材。
- IndexedDB、JSON 存档备份、完整数据迁移和真实 Edge 断网实机验证仍待完成。

## 下一阶段验收

1. P111 CI 对 19 个入口执行离线扫描、JS 语法检查和 Chromium file:// 浏览器 smoke。
2. 统一 GitHub Pages 成功构建 P108、P109、P111，并确认三个精确 SHA。
3. 完成 1440px、1366px、窄屏布局检查；逐个打开 19 款游戏，检查 READY、退出清理和错误日志。
4. 逐款补齐核心规则与异常输入测试；AI 游戏校准三档难度。
5. 真实 Edge 断网实机确认后，再建立 p111-stable 候选。
