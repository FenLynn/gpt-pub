# P111 R20｜首页 Dashboard 调整

日期：2026-11-06  
仓库：FenLynn/gpt-pub  
开发分支：p111-exp

## 产品定位

首页继续作为个人游戏活动 Dashboard，不改成游戏启动器，不重复显示完整游戏库。全部游戏仍通过左侧“全部游戏”进入。

## 首页结构

桌面端采用左主列 + 右排行榜：
- 左主列从上到下：欢迎 Banner、全宽游戏活动热力图、横向最近游玩。
- 右侧排行榜从内容区顶部延伸到内容区底部。
- 主列三行按可用高度分配，最近游玩贴近页面底部，避免留下大块空白。
- 首页保留原浅蓝灰、白色卡片视觉，不动左侧导航与全局顶部框架。

## Banner 五项数据

1. 首次开始游戏：优先使用持久化 firstStartedAt；旧数据没有该字段时，从历史活动日期推断。
2. 最近游戏：按游戏的 lastPlayedAt 排序；旧数据回退到 lastPlayed 日期。
3. 已使用天数：跨所有游戏去重后的活跃日期数量。
4. 累计时间：所有游戏 totalMs 求和。
5. 今日时间：所有游戏当天 days[YYYY-MM-DD] 求和。

新增字段只追加，不覆盖原有统计数据。

## 活动热力图

- 保留过去 365 天、星期行、月份刻度、活动强度图例。
- 活动卡片占据左侧主列完整宽度；点阵维持 GitHub 风格小方块（桌面 11px、小屏 9px），在卡片内部居中，不因卡片变宽而放大单个日期格。
- 仍使用本地游戏时间数据，不请求外部服务。

## 最近游玩

- 位于热力图下方，横向从左到右排列。
- 最多展示 8 款，按最近启动时间降序。
- 每款游戏使用统一风格的本地 SVG 矢量图标和游戏名称，整项可点击再次进入。
- 只展示真实玩过的游戏，不以推荐游戏伪装最近记录；无历史时显示简洁空状态。

## 图标约束

- 使用统一线条粗细、比例和类别配色的本地 SVG 图标，确保不同操作系统下外观一致。
- 不制作自定义游戏 Logo，不引入在线图标库、CDN 或远程图片。
- 统一图标容器尺寸、背景和对齐方式。

## 验收要求

- 首页在 1752×860、1366×768 下无垂直溢出或底部大块空白。
- 排行榜卡片底部与首页内容区底部对齐。
- 热力图宽度覆盖左主列。
- 最近游玩是单行横向排列，顺序与启动时间一致。
- Banner 五项数据正确，旧 localStorage 记录不丢失。
- 首页无装饰性英文 kicker、重复“按类型开始”或精选游戏列表。
- 不修改 Cloudflare Pages/Workers、域名、部署配置，不改 main。


## R21｜首页视觉回归修正（2026-11-06）

用户实机截图指出 R20 首页存在三个视觉问题：热力图日期点被挤压成横向长条、Banner 五项统计被拆成五张小卡片、最近游玩被拆成多个矩形按钮；此外热力图卡片与最近游玩之间出现大块空白。

修正原则：
- 恢复 GitHub 风格的独立方形点阵：明确取消 53 个固定列，改用固定宽度的隐式列；每个日期格始终宽高相等（桌面 11px，小屏 9px），不随剩余宽度拉伸。
- Banner 五项统计只保留文字层级，不再有独立边框、底色或阴影。
- 最近游玩改为纯图标横向条带，名称作为图标下方的小字；单个游戏项无卡片边框、底色或阴影。
- 主列明确采用 Banner / 自适应热力图 / 最近游玩三行，热力图吸收剩余高度，最近游玩贴近主列底部；右侧排行榜同高。
- 增加 Chromium 回归断言，直接测量日期点宽高、统计项边框/背景、最近游戏边框/背景、热力图与最近游玩的垂直间距和页面底部对齐。


### R21.1｜宽屏热力图对齐微调

- 在不改变日期点尺寸与点阵密度的前提下，将“星期标签 + 月份刻度 + 53 周点阵 + 图例”作为整体居中；避免宽屏时点阵偏在卡片左侧。
- 最近游玩图标略微放大，名称仍为图标下方小字，继续保持无卡片边框/底色。


### R21.2｜热力图全宽自适应与游戏矢量图标（2026-11-06）

本轮针对 R21.1 实机截图暴露的问题进行根因修复，不改变首页既定结构（Banner / 活动热力图 / 最近游玩 + 右侧排行榜）：

- **热力图恢复全宽：** 不再给 53 周点阵设置固定 9/11px 后居中，也不再把内容容器缩成点阵自身宽度。点阵内容区占满活动面板可用宽度，按“(可用宽度 - 52 × 间距) / 53”动态计算日期格尺寸，按 0.5px 步进取值并限制在 7–22px；53 列仍然是 7 行，所有日期格严格正方形。
- **星期行同步：** --heat-cell 与 --heat-gap 同步写入 heatmap-layout 和 heatmap-grid，避免旧版桌面断点中的 12px 默认值覆盖动态尺寸；星期标签和日期格使用同一行高、行距。
- **月份刻度与图例：** 以实际点阵宽度为基准定位月份标签，并使图例与点阵右边缘对齐。
- **游戏图标统一：** 24 款游戏统一使用内嵌本地 SVG 矢量图标，不依赖系统 Emoji 字体、远程 CDN 或网络资源；分别设计五子棋、中国象棋、国际象棋、坦克、飞机、扫雷、方块、纸牌、麻将等辨识性符号。最近游玩与全部游戏库共用同一套图标。
- **回归验收：** Chromium 在 1752×860、1366×768 和 1440×1000 检查点阵宽度/方形比例/星期行对齐、统计项无卡片背景、最近游玩无矩形卡片、24 款图标完整渲染及 90 坦克专属图标；保留原有 24 款游戏全生命周期测试。


### R21.3｜最近游玩完整显示与图标类别配色（2026-11-06）

- 最近游玩区域从 108px 调整为 124px，图标、名称和间距不再被底边裁切；相应压缩中间热力图行的可分配高度，不改变首页底部对齐。
- 修正最近游玩图标类别色的 CSS 优先级，使棋类、益智、街机、卡牌使用对应配色，而不是全部继承同一蓝色。
- 修正 90 坦克图标回归测试选择器：图标属于 `.game-card-icon`，不是 `.game-card` 本身。
- 新增最近游玩名称完整可见断言、棋类与街机图标颜色区分断言；保留 24 款 SVG 图标总数与离线资源检查。


### R21.15｜恢复小尺寸居中点阵（2026-11-07）

- 用户实机截图指出 R21.2 的全宽动态放大使单个日期点过大、点阵纵向过重。问题根因是将活动卡片的全部宽度分配给 53 个日期格。
- 恢复 R21.1 的尺寸与密度：桌面端 11px 方块 / 3px 间距，窄屏 9px 方块 / 2px 间距；不再随容器宽度放大日期格。
- 活动卡片本身仍完整占据左侧主列；53 周点阵、月份刻度和图例作为一个固定宽度组在内容区水平居中，点阵垂直位置继续由热力图布局居中。
- 星期标签与日期格保持相同行高；保留 53 周、365 天数据、强度颜色和现有首页三段布局。
- Chromium 在 1752×860、1366×768、1440×1000 验收：点大小、间距、总宽度、正方形比例、水平居中、星期对齐，以及首页无底部溢出。
