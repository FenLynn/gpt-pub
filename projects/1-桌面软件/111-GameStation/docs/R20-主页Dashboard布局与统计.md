# P111 R20｜首页 Dashboard 调整

日期：2026-11-06  
仓库：FenLynn/gpt-pub  
开发分支：p111-exp

## 产品定位

首页继续作为个人游戏活动 Dashboard，不改成游戏启动器，不重复显示完整游戏库。全部游戏仍通过左侧“全部游戏”进入。

## 首页结构

桌面端采用左主列 + 右排行榜：
- 左主列从上到下：欢迎 Banner、全宽游戏活动热力图、横向最近游玩。
- 右侧排行榜从内容区顶部延伸到内容区底部。
- 主列三行按可用高度分配，最近游玩贴近页面底部，避免留下大块空白。
- 首页保留原浅蓝灰、白色卡片视觉，不动左侧导航与全局顶部框架。

## Banner 五项数据

1. 首次开始游戏：优先使用持久化 firstStartedAt；旧数据没有该字段时，从历史活动日期推断。
2. 最近游戏：按游戏的 lastPlayedAt 排序；旧数据回退到 lastPlayed 日期。
3. 已使用天数：跨所有游戏去重后的活跃日期数量。
4. 累计时间：所有游戏 totalMs 求和。
5. 今日时间：所有游戏当天 days[YYYY-MM-DD] 求和。

新增字段只追加，不覆盖原有统计数据。

## 活动热力图

- 保留过去 365 天、星期行、月份刻度、活动强度图例。
- 占据左侧主列完整宽度，按实际可用宽度动态放大日期格。
- 仍使用本地游戏时间数据，不请求外部服务。

## 最近游玩

- 位于热力图下方，横向从左到右排列。
- 最多展示 8 款，按最近启动时间降序。
- 每款游戏一个通用系统 Emoji/Unicode 图标和游戏名称，整张卡片可点击再次进入。
- 只展示真实玩过的游戏，不以推荐游戏伪装最近记录；无历史时显示简洁空状态。

## 图标约束

- 使用系统 Emoji / Unicode 中广泛识别的游戏、棋类、卡牌、交通工具和益智符号。
- 不制作自定义游戏 Logo，不引入在线图标库、CDN 或远程图片。
- 统一图标容器尺寸、背景和对齐方式。

## 验收要求

- 首页在 1752×860、1366×768 下无垂直溢出或底部大块空白。
- 排行榜卡片底部与首页内容区底部对齐。
- 热力图宽度覆盖左主列。
- 最近游玩是单行横向排列，顺序与启动时间一致。
- Banner 五项数据正确，旧 localStorage 记录不丢失。
- 首页无装饰性英文 kicker、重复“按类型开始”或精选游戏列表。
- 不修改 Cloudflare Pages/Workers、域名、部署配置，不改 main。
