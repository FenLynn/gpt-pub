## 3｜麻将与三国杀

| 项目 | 许可证/工程形态 | 有价值内容 | 判断 |
|---|---|---|---|
| [gregoryjayuk/mahjong](https://github.com/gregoryjayuk/mahjong) | GPL-2.0；静态浏览器游戏；含 classic.html 2D 牌桌 | 144 张牌、四人局、吃碰杠胡、番种计分、三名 AI；规则引擎可在 Node 中测试并做机机对战 | **麻将规则/AI 参考价值高，但不直接复制**。GPL-2.0 与 P111 当前授权边界不明确 |
| [libnoname/noname](https://github.com/libnoname/noname) | GPL-3.0；Node.js 20.19+ 或 22.12+、pnpm 工程化构建；GitHub 仓库元数据体积约 2.67 GB | 三国杀类规则、武将技能、扩展包和 AI 体系 | **仅作规则与技能架构参考**。不是一个可直接嵌入的单文件游戏；仓库 README 另有非商业使用请求，需单独审查 |
| [Mogara/QSanguosha](https://github.com/Mogara/QSanguosha) | GPL-3.0；C++ 桌面/客户端项目 | 三国杀规则、卡牌与 AI 历史实现 | **仅作规则研究**。技术栈和体量不适合直接嵌入 HTML 工作区 |

麻将候选项目采用的是一套明确的中国四人麻将规则，不等于覆盖所有地方麻将。第一版必须先选择基础规则；四川、广东、日本立直等玩法不能简单地全部化成几个布尔开关。

三国杀项目的引擎许可证不自动覆盖武将立绘、卡牌图像、语音、音乐和扩展包素材。小乔具体版本也尚未确认。

## 4｜魂斗罗模拟器

| 项目 | 许可证/用途 | 边界 |
|---|---|---|
| [bfirsh/jsnes](https://github.com/bfirsh/jsnes) | Apache-2.0；JavaScript NES 模拟器；支持传入 ROM 字节数据 | 可研究本地 file input 读取用户选择的 ROM，再交给模拟器运行；必须验证浏览器版资源本地打包 |
| [XadillaX/play-nes](https://github.com/XadillaX/play-nes) | 桌面 Node.js / 原生窗口方向 | 需要 Node、原生依赖，不适合纯 HTML file:// 首版 |

P111 不附带、下载或托管魂斗罗 ROM。模拟器代码和 ROM 是不同对象；只有用户自行提供且有权使用的 ROM 才能作为本机输入。若不采用 ROM 方案，替代路线是开发原创横版射击游戏，不复制原作素材。

## 5｜许可证和公开边界

当前检查发现 FenLynn/gpt-pub 仓库根目录没有 LICENSE 文件，因此不能假定仓库已有一个能自动兼容所有第三方代码的统一开源许可证。

P111 采用以下初筛原则：

1. 优先 MIT、BSD、Apache-2.0 等宽松许可证，并保留原始 LICENSE、版权声明和 NOTICE。
2. GPL-2.0 / GPL-3.0 项目暂时只作研究参考，不直接复制、编译或合并到 GameStation 主程序。
3. 如未来确实需要 GPL 引擎，必须先评估独立分发、衍生作品、完整对应源代码和许可证兼容性，再由用户明确决定。
4. 代码许可证与美术、音频、字体、商标、角色和 ROM 权利分开审查。
5. 每个实际引入依赖必须固定 tag/commit、文件清单、许可证文本、修改记录和 SHA-256；未完成这些步骤不能列为已批准依赖。

## 6｜当前候选决策

- 可优先进入原型验证：RetroArcade 的轻量游戏架构、Klondike Solitaire、zh-chess / Wukong 的中国象棋组合。
- 需要适配后再评估：Gomoku、Dou Dizhu 的 ES Module Worker。
- 仅作参考：GPL 中国象棋整合包、GPL 麻将、无名杀、QSanguosha。
- 条件候选：JSNES；只有在本地 ROM 选择和保存机制确定后才接入。
- 本文没有授权把任何外部仓库整个复制到 P111；所有候选均须逐文件审查。
