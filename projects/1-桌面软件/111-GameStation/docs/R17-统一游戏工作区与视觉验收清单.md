# R17｜统一游戏工作区与视觉验收清单

- 项目：P111 GameStation
- 仓库：FenLynn/gpt-pub
- 开发分支：p111-exp
- PR：#476（保持开放）
- 目标：恢复已确认的公共 UI 基线，并对 22 款游戏做真实浏览器逐项验收
- 禁止：修改/合并 main，临时删除测试断言，使用固定小画布，添加外部通知弹窗

## A. 公共标题栏

- [ ] 游戏名称位于左侧。
- [ ] 本局时间只显示在最上方宿主标题栏，并以该标题栏整体宽度为参照严格水平居中。
- [ ] 对战方式使用分段切换按钮，不使用原生下拉框。
- [ ] 难度使用分段切换按钮，不使用原生下拉框。
- [ ] 开始/结束、暂停/继续、新局、工具、帮助全部在同一行。
- [ ] 游戏打开时，宿主外层重复模式/难度/计时/按钮隐藏。
- [ ] 1366×768、1440×1000 下不换行、不重叠、不裁切。

## B. 通知与帮助

- [ ] 重要通知显示在游戏主画面内部顶部。
- [ ] 普通通知自动淡出，不阻塞点击和键盘操作。
- [ ] 暂停/结束状态持续显示，恢复/新局后清除。
- [ ] 不使用外部 toast、alert、confirm 或与游戏无关的弹窗。
- [ ] 玩法与按键提示只在帮助中显示。
- [ ] 帮助面板可拖动，只能点击 X 关闭；点击面板外部或按 Esc 不擅自关闭。

## C. 游戏画布

- [ ] 不存在常驻左侧提示栏。
- [ ] 不存在常驻右侧状态栏。
- [ ] 主画布使用全部可用宽高，上下保留约 8–14px 边缘。
- [ ] 保持每款游戏的原始比例，不拉伸、不裁切。
- [ ] 棋盘类按棋盘比例放大；横版动作类保持 16:9；俄罗斯方块按 1:2 纵向利用高度；卡牌桌面充分使用剩余空间。
- [ ] 所有主画面不越界、不出现横向页面滚动条。

## D. 鼠标与键盘

- [ ] 游戏区域右键阻止浏览器上下文菜单。
- [ ] 扫雷右键仍能插旗。
- [ ] Enter 在所有游戏中切换暂停/继续。
- [ ] P 保留暂停/继续快捷键。
- [ ] 暂停后计时与动画停止；继续后从原状态恢复。

## E. 专项视觉

- [ ] 扫雷数字字号不小于格子边长的 65%。
- [ ] 扫雷旗帜 SVG 宽高至少占格子边长的 65%。
- [ ] 扫雷地雷 SVG 宽高至少占格子边长的 65%。
- [ ] 扫雷中级/高级/初级棋盘与底部计数/表情/计时均完整可见。
- [ ] 首页 Hero 的标题、日期、描述、统计与装饰图形不相交；较窄宽度优先隐藏装饰图。
