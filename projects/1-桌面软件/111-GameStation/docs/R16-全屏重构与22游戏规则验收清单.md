# P111 R16｜游戏工作区重构与 22 款游戏全生命周期验收清单

> 仅允许修改 `FenLynn/gpt-pub` 的 `p111-exp`；PR #476 保持开放。严禁写入、合并 `main`。本清单按实际测试证据勾选，不能以“入口能打开/画面好看”代替规则完成。

## A. 宿主与游戏通用界面（22/22）

- [ ] 游戏工作区取消固定左侧操作说明和右侧统计/工具栏；iframe 只承载游戏自身画面，游戏可用宽高完整利用
- [ ] 统一游戏内 HUD：开始/结束、暂停/继续、下一局、用时、模式、难度、状态、分数等都在 iframe 内；顶部宿主不再重复按钮
- [ ] 游戏主画面优先最大化；宽画布铺满宽度，窄棋盘/俄罗斯方块优先吃满高度，非游戏背景不出现重叠大框
- [ ] 规则/按键说明只在宿主「帮助」悬浮窗；窗口可拖拽；只能点击右上角 X 关闭（Esc、外部单击不关闭），可边玩边阅读
- [ ] 在游戏区域拦截右键浏览器菜单，并保留扫雷插旗等游戏自定义右键逻辑
- [ ] Enter：全部游戏在开始/暂停/继续之间切换；宿主和 iframe 焦点都可用；输入控件编辑时不劫持
- [ ] 游戏通知与结束结果统一游戏内内联显示；停止游戏时不调用浏览器 alert/confirm，不用外部 toast
- [ ] 桌面 1440×1000 / 1366×768：不裁切、不出现网页横向滚动、按钮不遮挡棋盘；截图与实际操作均通过
- [ ] 首页/分类游戏卡缩小并提高信息密度，消除大面积空白；Hero/Banner 文字在所有常用宽度不重叠、不裁切
- [ ] 完全离线 file:// 运行，无远程依赖，清理过时代码与重复操作

## B. 特别视觉与操作问题

- [ ] 扫雷：Win7 蓝色风格；30×16/16×16/9×9 棋盘完整可见，底部剩余雷数/笑脸/计时器始终可见；左/右/中键分别翻开/插旗/快速展开；任意难度在同一画布内适配
- [ ] 超级玛丽：宽屏画布尽可能大，HUD 内置，镜头与游戏场景不偏移，暂停/终局覆盖在游戏内部
