# 超级玛丽的内置关卡与原版卡带

内置关卡使用 P111 的像素绘制与碰撞系统。地形核对以 16 像素为一格，参考 FullScreenMario 的 `World11` 排列。开场四根管道位于第 28、38、46、57 列，高度分别为 2、3、4、4 格。地面在第 69–70、86–88、153–154 列断开。地图含问号砖、阶梯、敌人、旗杆和城堡。

内置关卡与原版有明确差别。问号砖只给金币，敌人按内置逻辑巡逻，地下奖励房、蘑菇、无敌星、乌龟壳及原版物理由原版卡带提供。内置像素图形由 Canvas 绘制。参考仓库的程序、美术和音频均未复制进本项目。

要运行原版，从 GameStation 打开「超级玛丽」，在顶栏切换到「原版卡带」，选择自己持有的 NTSC `.nes` 文件，按 `R` 或点击「主机开始」。方向键移动，`X` 或空格对应 A，`Z` 或 Shift 对应 B，`Q` 对应 Select。声音由右栏显式开启。NES 核心按 60,000/1,001 帧每秒调度，使用 256×240 原始帧缓冲和像素缩放。卡带字节只留在当前游戏页面内存。关闭游戏后需重新选择文件，内置关卡的存档独立保留。
