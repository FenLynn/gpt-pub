## 一、本轮覆盖

- 原有棋类 7 款：五子棋、中国象棋、国际象棋、黑白棋、四子棋、海战棋、西洋跳棋（原“国际跳棋”实际为 8×8 西洋跳棋，不是 10×10 国际跳棋）。
- 新增中国跳棋：六角星 121 孔，双方各十子，六方向邻走、连续跨子跳跃，目标对面十孔；支持悔棋/暂停/新局/本地 2 人和 3 档 AI。
- 新增飞行棋：**双人变体**，红蓝双方各四机、52 格环道、六点起飞+额外回合、同色四格跳跃/飞行通道、撞机/安全格、终点精确抵达。本轮不声称已实现 4 人完整规则。
- 统一游戏图标采用本机可显示的辨识度高的图形符号和 Emoji，禁止运行时 CDN、远程字体或外部请求。
- 本轮总数：24 款；保留原 22 款入口与规则状态。

## 二、具体修复与 AI 真实差异

| 对象 | 视觉/规则 | AI 档位差异 |
|---|---|---|
| 五子棋 | 完整 15×15 SVG 网格止于第一/最后交叉点；九星位不偏；数字棋子/落子动效 | 原有候选与攻防策略；三档需要持续对局质量校准 |
| 中国象棋 | 每枚棋子严格等宽等高、圆形；真实坐标平移动画 | 现有分层搜索保留；仍需局面基准测试 |
| 国际象棋 | 棋子位移过渡；开局/特殊规则不回退 | 简单随机；中等 2 ply/宽度6；困难 3 ply/宽度8；Alpha-Beta、局面估值 |
| 黑白棋 | 翻子动画 | 简单随机；中等深度2；困难深度4 |
| 四子棋 | 纵向落子动画 | 简单随机；中等深度3；困难深度5 |
| 西洋跳棋 8×8 | 跳跃落位动画；保留强制吃子及连续吃子 | 简单随机、中等静态价值、困难对手一步回应 |
| 中国跳棋 | 121 孔六向网格、十子/方、移动动画 | 简单随机；中等前进距离；困难额外评估对手一步进攻 |
| 飞行棋（双人） | 本机 SVG 棋盘、骰子、四机/方及跑道 | 简单随机选机；中等前进/撞机收益；困难再评估下一骰风险 |

**注意：搜索层数、候选宽度属于实现配置，不等于已经建立 AI Elo 或胜率基准。禁止以“有三档按钮”冒充 AI 已经完成棋力校准。**

## 三、验收清单

- [ ] 24 款在 1366×768 与 1440×1000 下真实 Chromium file:// 打开和开始/暂停/继续/新局。
- [ ] 五子棋：线段数量30、九星位9、交叉点225、棋盘宽高差小于1.5%；最后落子有动效。
- [ ] 中国象棋：90 交叉点；棋子实际宽高差不超过1.5px；大小变化时保持圆形。
- [ ] 国际象棋：简单/中等/困难的搜索深度和宽度断言；王车易位、吃过路兵、和棋等规则继续通过。
- [ ] 黑白棋翻子、四子棋落子、西洋跳棋跳跃，均遵守减少动态效果设置。
- [ ] 中国跳棋：121 孔、六个10孔角、两人20棋子、合法跃子与回合切换、AI 档位。
- [ ] 飞行棋：52 格、非六点不可起飞、六点起飞/额外回合、撞机、胜负/重开与三档 AI。
- [ ] P111 CI、Pages CI、hygiene 的同一 SHA 全部通过；保存 48 张游戏截图。
- [ ] 保持 PR 开放、main 未修改、未合并。

## 四、GitHub 可复用基础与许可证

本轮原创代码参考了下列开放代码的功能与实现思路，但 **没有直接复制第三方的游戏代码、图片或音乐**：

1. https://github.com/netmanfisher/chinese-ludo —— 纯 JS、浏览器直接打开、中国飞行棋，同色跳跃/飞行通道/额外回合；MIT。若后续直接复用需保留 MIT 版权/许可证。
2. https://github.com/EndlessPixel/chinese-chess-js —— 纯前端象棋木质棋盘与基础 AI，MIT。
3. https://github.com/tgr11223/chinese-chess-game —— Vite + Alpha-Beta + Canvas 动效；部分需构建，不宜直接搬入严格 file:// 环境，应提取架构思想而非运行时依赖。
4. https://github.com/MattSkala/html5-bombergirl —— 本地 AI/双人炸弹对战，代码 MIT；依赖 EaselJS/Bower/本地 HTTP 服务，音乐 CC BY-SA 4.0，素材亦需逐件核实许可。**泡泡堂风格原创游戏技术可行，但未接入，不得称为已完成**。

保持 P111 一游戏一目录、不依赖服务器、共享 GameBridge。先实现网格移动、泡泡倒计时、十字水波、可破坏砖、道具、玩家/AI 寻路与安全点；单机/本机双人优先。采用自主绘制 Canvas/本地 SVG 与自行生成音效，避免复制原版品牌、角色素材或受限制的音乐；保留所借用 MIT 源码的必要 NOTICE（如将来实际引入）。
