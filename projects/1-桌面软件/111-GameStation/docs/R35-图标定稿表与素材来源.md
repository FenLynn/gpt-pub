# P111 GameStation — R35 图标定稿表与素材来源

## 设计原则

- 恢复此前认可的可爱、熟悉、易辨认的游戏意象，不再使用 24 个自绘通用 Logo。
- 所有图标均为本地 SVG，跨浏览器/操作系统保持一致，不依赖系统 Emoji 字体，不请求 CDN。
- 不使用统一浅色圆角底板；图标本体直接表达棋盘、棋子或游戏物件。
- 首页最近游玩、精选海报和游戏库统一调用同一份资产。
