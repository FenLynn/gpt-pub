# R22｜首页点阵与图标一致性修正

日期：2026-11-07  
项目：P111 GameStation  
分支：`p111-exp`  
范围：仅桌面 Web 首页与相关 Chromium 回归；不涉及游戏规则、AI、CI 工作流、main 或部署配置。

## 产品结构（保持不变）

首页继续承担 Dashboard 职责，不重复建设游戏库入口。全部游戏仍由左侧导航进入。首页主区仅包含：

1. Banner：日期、问候语和五项真实本地统计——首次开始游戏、最近游戏、已使用天数、累计时间、今日时间。
2. 活动热力图：占据左侧主列全部横向空间。
3. 最近游玩：位于热力图下方，按最近启动时间从左到右排列；每款游戏仅显示一个图标和简短名称。
4. 右侧排行榜：与主区等高，延伸至首页内容底部。

不增加“全部游戏”重复入口，不增加精选游戏区，不使用五张统计卡片或一游戏一矩形按钮。

## 本轮修正

### 1. 热力图点阵

- 恢复桌面端 11px × 11px 日期点，间距 3px。
- 窄屏采用 9px × 9px 日期点，间距 2px。
- 53 周点阵保持正方形与原有 GitHub 风格圆角；星期标签与行高对齐。
- 热力图卡片占满左侧主列；点阵、月份刻度和图例在卡片内部水平居中。
- 不再根据超宽屏宽度将日期点放大至 17.5px，不将日期格拉伸成横条或大色块。

### 2. 游戏图标

- 移除自绘 SVG 游戏 Logo 及其样式。
- 游戏目录和最近游玩直接读取游戏注册表中的 `icon` 字段，使用常见系统 Emoji/Unicode 象形符号。
- 保持离线，不引入 CDN、远程图片、在线字体或新增依赖。
- 回归明确检查扫雷炸弹、90 坦克头盔、麻将牌等代表性图形，并确保不再生成自绘 SVG。

### 3. 首页空间与信息层级

- Banner 五项统计维持纯文字布局，不出现单项边框、底色或卡片阴影。
- 最近游玩维持无边框横向图标条带，不为每款游戏增加矩形卡片。
- 最近游玩仅包含真实玩过的游戏，按最近启动时间从左向右排序，最多 8 款。
- 右侧排行榜拉伸至首页内容底部；主列热力图吸收中间剩余高度，最近游玩贴近主列底部。
- 页面不得出现超出视口的纵向滚动或底部大块未使用空白。
