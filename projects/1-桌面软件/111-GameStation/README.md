# P111｜GameStation

GameStation 是一个完全离线、浏览器本地运行的个人游戏中心。主页提供分类、搜索、最近游玩、精选游戏、活动热力图和排行榜；游戏工作区采用中间主画面、左侧按键提示、右侧状态/工具的布局，并支持普通工作区、沉浸工作区与浏览器全屏。

**当前状态：22 款游戏均已接入统一游戏库和独立 iframe 入口。** 其中 12 款具备可直接体验的基本玩法，10 款处于规则/AI/素材完善阶段；“已接入”不等于所有规则均已达到正式发行质量。

## 界面与操作

- 左上角使用四方块品牌 Logo，并作为离线站标；品牌区、左侧导航和顶部标题栏统一底色。
- 人机模式与难度使用胶囊式分段选择器，不再使用左右箭头轮换。
- 游戏顶部统一显示用时、开始/结束、暂停/继续和下一局。
- 棋盘/画布优先占用可用高度；游戏内功能与状态优先放在右侧，按键说明放在左侧。
- 扫雷采用 Windows 7 蓝色立体按钮视觉，支持中键快速展开；俄罗斯方块使用连续帧下落动画。

## 产品边界

1. 正常使用必须完全离线；不访问远程 API、CDN、在线字体、在线图片、账号、广告、排行榜或联机服务。
2. 首选 Chrome / Edge 直接通过 file:// 打开 app/index.html；不得把 localhost、常驻服务器或首次联网缓存作为运行前提。
3. 一个统一主页管理多个独立游戏；每款游戏拥有独立入口、脚本和 iframe 运行上下文。
4. 支持本机双人轮流操作，以及适合人机对战的本地 AI；不做网络对战。
5. 支持普通工作区、沉浸工作区和浏览器全屏；不承诺网页直接控制操作系统窗口最大化。
6. 程序代码与玩家数据分离；本地设置、进度和成绩不得写入公开仓库。
7. AI 难度必须有可验证的实际棋力差异；尚未校准的模块不得标注为正式强度。

## 运行方式

- 宿主与游戏模块通过版本化 `postMessage` 通信，iframe 使用独立页面和沙箱权限。
- 收藏与最近游玩保存在浏览器本地；完整存档、JSON 备份和跨浏览器迁移仍在后续开发。
- GitHub Pages 只用于在线体验；最终离线兼容性必须在断网 Chrome / Edge 直接打开 `app/index.html` 验证。
- 反馈面板只在本机整理并复制文本，不自动上传用户内容。
