# P111｜GameStation

GameStation 是一个完全离线、浏览器本地运行的个人游戏中心。主页提供分类、搜索、最近游玩、精选游戏、活动热力图和排行榜；进入游戏后，游戏画面占据右侧工作区的全部可用空间，不再保留固定左右提示栏或状态栏，统一使用游戏内标题栏与悬浮提示。

**当前状态：24 款游戏接入统一游戏库和独立 iframe 入口。** 原 22 款保持已有的基础玩法/原型分级；R18 新增中国跳棋与双人飞行棋（均为独立离线实现，仍需持续深入测试）。“可玩”不等于已达到全部比赛规则与 AI 棋力的正式发行质量。

## 界面与操作

- 左上角使用四方块品牌 Logo，并作为离线站标；品牌区、左侧导航和宿主顶部标题栏统一底色。
- 游戏用时统一显示于页面最上方的宿主标题栏正中央，不再在游戏子工具栏重复出现；游戏内一行工具栏保留名称、人机/本机双人和难度分段切换，以及开始/结束、暂停/继续、新局、工具、帮助。
- 游戏画面占据右侧工作区全部宽高，禁止固定左右提示栏；根据游戏类型保持正确比例并优先利用可用高度，上下只留少量边缘。
- 重要通知和状态在游戏画面内部顶部悬浮显示；不使用宿主外部 toast 或浏览器弹窗。暂停/结束状态可持续显示，普通提示自动消失。
- 按键与玩法说明只在“帮助”中查看；帮助面板可拖动，只能点击 X 关闭。
- 游戏区域接管右键，阻止浏览器菜单；Enter 统一切换暂停/继续。
- 扫雷采用 Windows 7 蓝色立体按钮视觉，数字、地雷、旗帜按格子尺寸缩放；俄罗斯方块使用连续帧下落动画。

## 产品边界

1. 正常使用必须完全离线；不访问远程 API、CDN、在线字体、在线图片、账号、广告、排行榜或联机服务。
2. 首选 Chrome / Edge 直接通过 file:// 打开 app/index.html；不得把 localhost、常驻服务器或首次联网缓存作为运行前提。
3. 一个统一主页管理多个独立游戏；每款游戏拥有独立入口、脚本和 iframe 运行上下文。
4. 支持本机双人轮流操作，以及适合人机对战的本地 AI；不做网络对战。
5. 支持普通工作区、沉浸工作区和浏览器全屏；不承诺网页直接控制操作系统窗口最大化。
6. 程序代码与玩家数据分离；本地设置、进度和成绩不得写入公开仓库。
7. AI 难度必须有可验证的实际棋力差异；尚未校准的模块不得标注为正式强度。

## 运行方式

- 宿主与游戏模块通过版本化 `postMessage` 通信，iframe 使用独立页面和沙箱权限。
- 收藏与最近游玩保存在浏览器本地；完整存档、JSON 备份和跨浏览器迁移仍在后续开发。
- GitHub Pages 只用于在线体验；最终离线兼容性必须在断网 Chrome / Edge 直接打开 `app/index.html` 验证。
- 反馈面板只在本机整理并复制文本，不自动上传用户内容。

## R18｜棋类精修与新增棋种（2026-11-06）

- 五子棋：将四周半截网格线改为统一 SVG 交叉点线段，九星位精确随棋盘缩放；最后落子轻量动画。
- 中国象棋：棋子强制 1:1 正圆，不再出现椭圆；走子按真实起止坐标平滑移动。国际象棋增加起止坐标移动动画，AI 由静态单层评分升级到简单随机 / 中等两层 / 困难三层 Alpha-Beta 搜索。
- 黑白棋、四子棋、西洋跳棋增加翻子、投子、跳跃反馈，支持减少动态效果设置；不修改原有暂停/悔棋的生命周期。
- 新增**中国跳棋**：121 孔、六角星、每方十子、单步与连续跳跃、悔棋、本机双人、三档本地 AI（困难档考虑对手一回合回应）。
- 新增**飞行棋**：双人红蓝版，52 格跑道、四机、六点起飞和额外回合、同色跳跃、撞机、安全格、精确到终点、悔棋和三档 AI。**本轮不是四人完整版**。
- 图标替换为更容易识别的本机 Unicode/Emoji 字形，不依赖第三方图标 CDN。泡泡堂风格的原创泡泡对战可行，当前仅完成开源与技术路线评估，**尚未作为新游戏接入**。
- 逐款测试与许可证/开源参考见 `docs/R18-棋盘几何-动画-AI与新增棋种.md`；最终状态以 **R18 的最新 SHA 对应 CI** 为准。
