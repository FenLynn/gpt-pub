# P111｜GameStation

GameStation 是一个完全离线、浏览器本地运行的个人游戏中心。主页提供使用概况、全宽活动热力图、横向最近游玩和全高排行榜；进入游戏后，游戏画面占据右侧工作区的全部可用空间，不再保留固定左右提示栏或状态栏，统一使用游戏内标题栏与悬浮提示。

**当前状态：24 款游戏接入统一游戏库和独立 iframe 入口。** R18 已完成棋类几何、动画、两款新增棋种和双分辨率回归；R19 已完成三国杀 AI 决策公平性改进及右侧工具停靠布局修复。仍按基础可玩/体验原型分级，不把“能运行”表述为完整比赛规则或已校准 AI。

## 界面与操作

- 左上角使用四方块品牌 Logo，并作为离线站标；品牌区、左侧导航和宿主顶部标题栏统一底色。
- 游戏用时统一显示于页面最上方的宿主标题栏正中央，不再在游戏子工具栏重复出现；游戏内一行工具栏保留名称、人机/本机双人和难度分段切换，以及开始/结束、暂停/继续、新局、工具、帮助。
- 游戏画面默认占据完整工作区；工具打开时停靠在右侧并让出实际布局空间，绝不覆盖棋盘或角色。根据游戏类型保持正确比例并优先利用可用高度，上下只留少量边缘。
- 重要通知和状态在游戏画面内部顶部悬浮显示；不使用宿主外部 toast 或浏览器弹窗。暂停/结束状态可持续显示，普通提示自动消失。
- 按键与玩法说明只在“帮助”中查看；帮助面板可拖动，只能点击 X 关闭。
- 游戏区域接管右键，阻止浏览器菜单；Enter 统一切换暂停/继续。
- 扫雷采用 Windows 7 蓝色立体按钮视觉，数字、地雷、旗帜按格子尺寸缩放；俄罗斯方块使用连续帧下落动画。

## 产品边界

1. 正常使用必须完全离线；不访问远程 API、CDN、在线字体、在线图片、账号、广告、排行榜或联机服务。
2. 首选 Chrome / Edge 直接通过 file:// 打开 app/index.html；不得把 localhost、常驻服务器或首次联网缓存作为运行前提。
3. 一个统一主页管理多个独立游戏；每款游戏拥有独立入口、脚本和 iframe 运行上下文。
4. 支持本机双人轮流操作，以及适合人机对战的本地 AI；不做网络对战。
5. 支持普通工作区、沉浸工作区和浏览器全屏；不承诺网页直接控制操作系统窗口最大化。
6. 程序代码与玩家数据分离；本地设置、进度和成绩不得写入公开仓库。
7. AI 难度必须有可验证的实际棋力差异；尚未校准的模块不得标注为正式强度。

## 运行方式

- 宿主与游戏模块通过版本化 `postMessage` 通信，iframe 使用独立页面和沙箱权限。
- 收藏与最近游玩保存在浏览器本地；完整存档、JSON 备份和跨浏览器迁移仍在后续开发。
- GitHub Pages 只用于在线体验；最终离线兼容性必须在断网 Chrome / Edge 直接打开 `app/index.html` 验证。
- 反馈面板只在本机整理并复制文本，不自动上传用户内容。
