# P111｜GameStation

GameStation 是一个完全离线、浏览器本地运行的个人游戏中心。主页统一管理多个独立游戏，左侧选择游戏，右侧运行游戏；支持普通工作区、沉浸工作区和浏览器全屏。

**当前状态：规划建档。** 本分支当前只包含立项、架构、接口、范围和开源候选调研文档；尚无可运行程序、游戏代码、第三方依赖或发布产物。

## 产品边界

1. 正常使用必须完全离线；不访问远程 API、CDN、在线字体、在线图片、账号、广告、排行榜或联机服务。
2. 首选 Chrome / Edge 直接通过 file:// 打开 app/index.html；不得把 localhost、常驻服务器或首次联网缓存作为运行前提。
3. 一个统一主页管理多个独立游戏；游戏逻辑、AI、渲染和资源各自隔离，不能形成互相污染的巨型脚本。
4. 支持本机双人轮流操作，以及适合人机对战的单人对多 AI；不做网络对战。
5. 支持普通工作区、隐藏导航的沉浸工作区和浏览器全屏；不承诺网页直接控制操作系统窗口最大化。
6. 程序代码与玩家数据分离；本地设置、进度和成绩不得写入公开仓库。
7. 游戏 AI 的简单、中等、困难必须有可验证的实际棋力差异；单人游戏使用难度参数，不强行伪装成 AI 对手。

## 首批规划

- 平台验证：主页、左侧导航、右侧 iframe 工作区、模块通信、全屏和离线门禁。
- 首批可玩游戏：五子棋、中国象棋、扫雷、Windows 经典纸牌（Klondike）、俄罗斯方块、贪吃蛇。
- 2048 作为低成本优先扩展。
- 斗地主、麻将进入后续复杂牌类阶段。
- 三国杀和魂斗罗单独评估素材、许可证、ROM 和规则范围后再实施。

## 当前原则

先验证 file://、iframe、postMessage、Worker、全屏和本地持久化的真实浏览器边界，再决定游戏模块的最终封装方式。任何开源候选都必须逐个审查代码许可证、素材来源和运行时网络请求，不能仅凭项目 README 宣称离线或开源就直接打包。
