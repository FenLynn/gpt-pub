# 工作记录

## 2026-09-19｜v0.4.14 独立模块页纠偏

v0.4.13 实机截图显示独立 Power 页被错误实现成“顶部 breadcrumb + 三张大读数卡 + 右侧配置”。本轮按用户原始定义纠正：

- 去掉模块页 breadcrumb，模块自身顶部标题行直接承担状态显示。
- 标题行增加“就绪 / 采集中”状态点，不重复显示 Dashboard 的紧凑结果条。
- 左上读数取消卡片背景、圆角和四周边框，改成直接嵌入壳体的读数区。
- 左下保留主图；右侧配置改成整列侧栏，只保留左分隔线，不做浮动卡片。
- Dashboard 本身不做结构性重排。


## 2026-09-19｜v0.4.13 可读性与独立模块页

基于 v0.4.12 实机截图继续做小步精修，不改变 Dashboard 信息架构：

- 刻度数字由 9 px 提升到约 10.5 px，同时只小幅增加 gutter，保持数据区尽量大。
- 模块标题行从 26 px 调到 31 px，并取消额外加深底色，直接融入 Dashboard 壳体。
- 选中采集模块的顶部图标和模块左上图标统一变绿；真正 running 时同步绿色呼吸。
- 顶部选择勾向下调整，减少贴顶感。
- 软件图标从 LB 改为艺术化单 L，Run 缩为 28 px 圆形按钮。
- 截图动画 z-index 提升到最高 Web UI 层级；录像时长始终显示 00:00:00 三级格式并预留宽度。
- Big Readout 从 520×300 基准压缩为 400×205，并同步减小内部 padding。
- 独立模块页单独建立宽松布局，不再复用 Dashboard 极限紧凑样式；右侧配置固定，左侧上方为数据显示，左下为主要图形。


## 2026-09-19｜v0.4.12 绘图区边界与读数窗精修

按实机截图继续收紧 UI：用户明确要求“只有数据区白色、XY 标题不要显示、四周空白最小化、不要额外内框线”。

- PlotCanvas 画布底色改为深色壳体，只在实际数据矩形内填白。
- 删除 X/Y 轴标题渲染；刻度值保留在深色边缘，并把左右/底部 gutter 压到可读的最小范围。
- 删除绘图区 strokeRect 内框；模块间距缩到 2 px。
- 四个模块标题和关键数值恢复为 26 px 极窄深色标题行，避免压在白色图面上。
- Big Readout 改成无传统标题栏的单读数监视窗，增加黑/白主题切换和右下角拖拉手柄；拖拉只改变统一 scale，保持所有内部元素比例。
- 版本更新为 0.4.12，并继续只在 p107-exp 验证。


## 2026-09-19｜v0.4.11 图优先 Dashboard 重构

基于用户对 v0.4.10 实机界面的反馈，本轮不继续做“网页卡片式”美化，而是把观测逻辑改为实验仪器工作台：图最大化，参数贴边，低频配置离开 Dashboard。

- Dashboard 壳体改为冷深蓝灰，仅实际 Plot / 图像区域保持白底。
- 四模块标题与结果改为紧凑悬浮信息层，坐标标题移入图内边缘，缩减 Canvas 外侧边距。
- Power 页面新增 power1 / power2 / math1 独立显示开关并持久化，Dashboard 只画选择的 Trace；该选择不改变 Test 采集勾选。
- Power 历史窗口、OSA 起止波长、Scope 时间窗/FFT/通道设置移动到对应模块聚焦页；全局 Settings 回归跨模块设置。
- Beam Z、自动浏览与 Attenuation 仍在 Dashboard 常驻，因为属于高频实验控制。
- Power、Spectrum 指标、Beam M²、Scope 当前值均可点击打开单实例 Big Readout；后续点击复用同一监视窗，支持拖动、缩放和应用内最大化。
- 版本推进到 0.4.11；本轮先留在 p107-exp，通过 CI 与用户视觉验收后再决定是否提升 stable。


## 2026-09-19｜v0.4.10 维护基线收口

接管审计确认 v0.4.9 的源码、PR #438 和 Windows CI 已进入稳定候选，但 HANDOFF、阶段记录、目录状态和 C 级技术栈仍残留 v0.2 时代描述；同时生产 UI 已在 v0.3 起切换到 WebView2/Vue，旧规则却仍禁止 WebView2。

本轮不新增实验功能，按真实实现整理为 v0.4.10 维护基线：

- 统一 README、HANDOFF、阶段记录、设计记录、分类/根目录状态与版本号。
- 正式确认 WinForms Host + WebView2 + Vue/TypeScript/Vite/Canvas 为生产 UI 架构，旧 WinForms UI 仅保留回滚参考。
- 将 .NET 8 Desktop Runtime x64 与 WebView2 Evergreen Runtime 同时纳入基础依赖；NativeAOT Launcher 预检两者。
- 新增官方 Microsoft WebView2 在线安装脚本，并更新离线准备说明和 Portable 包清单。
- 修正 Scope Simulator 时间窗未实际作用于数据的问题。
- 修正 Scope CH1/CH2 开关只过滤 FFT、不同时过滤时域的问题，并让读数区按实际显示 Trace 渲染。
- 修正 Web UI demo fallback 的 Scope 时间/FFT 坐标单位。
- 明确 Web UI 生产版尚未恢复拖出 Floating / 拖回嵌入，不再在 README 中误报。
- 0.5.x 真机接入顺序保持 Ophir Juno → Yokogawa AQ6370D → BeamSquared/SP920 → Tektronix MSO44。

## 2026-09-17｜v0.2.0 Dashboard Refactor

基于 v0.1.3 实机截图，确认主页面虽然已经稳定启动，但仍有明显工程原型感：Power 数值层级弱、OSA Simulator 峰形方向错误、Beam 光斑与 caustic 信息层级不足、Scope 轴线与网格缺乏统一精修。

本轮按既定产品约束集中重构主页面，不改变 Portable、采集、目录和设备抽象边界：

- 保留 Windows 原生标题栏、极窄顶栏、折叠导航和四象限主页面。
- 四模块仍只用中央细虚线分隔，不改成大卡片布局。
- 应用壳体统一浅蓝灰，绘图区白底；图内网格统一虚线，绘图区边界统一实线。
- Power 左图重做为物理功率左轴 + 数学百分比右轴，底部保留独立时间总览条；右侧重排 Alias、颜色短线、实时值、单位和最大值统计。
- Spectrum 顶部压成单行指标；Simulator 改为真实峰形而不是凹谷。
- Beam Z 继续作为轴向光斑浏览位置，Simulator caustic 与 Z 浏览解耦；左侧光斑、右侧 caustic、底部 Z / 浏览播放 / Att / M² 同步精修。
- Scope 保持上下两张图，只显示双通道时域和 FFT，统一虚线网格、实线边界、透明图内 Legend 和坐标刻度。
- 版本推进到 0.2.0，后续先完成 Windows 11 实机 UI 验收，再进入真实仪器 Probe。
