# 工作记录

## 2026-09-17｜v0.1.0 第一轮实现

本轮把此前 UI 与采集讨论第一次落到正式 P107 工程。

已完成的设计决策：

- P107 正式命名 LaserBench。
- 使用 `p107-exp / p107-stable / main` 长期分支模型。
- 基础技术栈为 C#、.NET 8、WinForms、Windows x64。
- 采用 NativeAOT 轻量启动器 + framework-dependent 主程序，基础包不重复携带完整 .NET Runtime。
- 依赖缺失时提供在线 Microsoft 安装动作和离线说明。
- 内置四类 Simulator，真实设备 SDK 延后逐个验证。
- Dashboard 采用单行窄顶栏、窄侧栏、Power/Spectrum/Beam/Scope 四模块高密度布局。
- Test 支持按模块选择采集，Label 在点击瞬间冻结。
- 数据路径固定为 `data/exp`、`data/pic`、`data/video`，其中只有 `exp` 使用日期或自定义实验目录。
- 文件永不覆盖，冲突追加 `_1`、`_2`。
- 截图写入 `data/pic`，录像写入 `data/video`。
- 录屏首版使用内置 MJPEG AVI，避免引入 FFmpeg。
- 模块支持双击进入独立页、拖出浮动并拖回主窗自动嵌回原槽位。

当前仍需 CI 验证源码能在 Windows Runner 原生编译、NativeAOT 启动器能生成、self-test 全部通过并形成可下载 Portable Artifact。
