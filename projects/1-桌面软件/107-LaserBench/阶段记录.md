# 阶段记录

## v0.4.11 Graph-first Dashboard（p107-exp）

状态：**开发中；进入 p107-exp 后由 Windows CI 验证，仍需用户实机视觉验收，不是 stable/main/Release。**

本轮按实验台使用方式重新收紧信息架构：

- Dashboard 改为“图优先”：绘图区最大化，冷深蓝灰壳体，只有真实 Plot / 图像区域保持白底。
- 模块名、坐标标题、Legend 与关键读数尽量贴边/图内悬浮，减少独立标题栏和无效留白。
- Power 独立页新增逐 Channel / Math Channel 的 Dashboard 显示选择；显示选择与 Test 采集选择彻底分离并持久化。
- Power 历史窗口、Spectrum 扫描范围、Scope 时间窗/FFT 上限/通道选择从全局 Settings 移入对应模块页；全局 Settings 只保留跨模块设置。
- Beam 的 Z / 播放 / Attenuation 继续常驻 Dashboard，作为高频操作白名单。
- Dashboard 关键输出统一可进入单实例 Big Readout；当前 Power、Spectrum、Beam M² 与 Scope 读数均可点击放大，同一时间只保留一个监视窗，并支持拖动、缩放和应用内最大化。
- Big Readout 复用实时 Snapshot，不建立第二套设备会话。


## v0.4.10 Maintenance Baseline

状态：**0.4.x 维护稳定候选；自动验证以当前 P107 CI 的准确 head 为准，Windows 实机视觉验收仍需保留。**

本阶段不增加真实仪器功能，目标是把已经形成的 v0.4.x 产品事实整理成可继续开发的干净基线。

本阶段收口内容：

- 生产 UI 技术栈正式确认为 WinForms Host + WebView2 + Vue 3 / TypeScript / Vite + Canvas。
- C 级开发约束、HANDOFF、README、设计记录、离线依赖说明和目录状态统一到当前实现。
- 版本统一推进到 0.4.10，避免修改后的维护基线继续冒用 0.4.9。
- NativeAOT 启动器同时预检 .NET 8 Desktop Runtime x64 与 WebView2 Evergreen Runtime。
- Portable 包同时提供 `install-dotnet8.ps1` 与 `install-webview2.ps1`，并保留离线安装说明。
- Scope Simulator 的时间窗使用持久配置；CH1/CH2 选择同时作用于时域与 FFT。
- Browser/demo fallback 的 Scope 坐标单位与生产 bridge 对齐。
- 旧 WinForms UI 文件继续只作为回滚参考；Web UI 尚未恢复的拖出浮窗功能明确列为未完成，不再在入口文档中误报。

自动准入继续要求：

- P107 PR 范围门禁。
- .NET 8 主程序与 NativeAOT 启动器 Windows x64 构建。
- `--self-test`：Simulator、Web UI 资源、选择性采集、Scope 时间窗、目录规则与 never-overwrite。
- 真实 GUI startup smoke 进入 `webui-ready` 和 `workspace-ready`。
- Portable Runtime/Data 边界检查。
- 启动器确认 .NET 8、WebView2、主程序和 Portable 状态。
- 生成 `LaserBench_v0.4.10_portable.zip`、manifest、SHA-256 与限期 Artifact。

仍未完成或不在 0.4.x 宣称范围：

- Windows 11 不同 DPI、多显示器和长时间使用的最终人工视觉验收。
- Web UI 拖出 Floating / 拖回嵌入交互。
- Ophir、Yokogawa、BeamSquared、Tektronix 真实 Driver。
- 多真实设备并行采集、独立设备源时间戳与掉线恢复的硬件级验证。
