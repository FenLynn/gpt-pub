# 阶段记录

## v0.5.1 Industrial UI / Channel Workstation（p107-exp）

状态：**开发候选；完成源码与 Windows CI 后生成候选 EXE/ZIP，仍需 Windows 实机视觉和四类物理仪器验收，不是 stable/main/Release。**

- PlotCanvas 统一 major tick 与 grid 源，时间轴按跨度选取至少 10 s 的刻度步长；跨度 <10 s 时只显示一个时间标签，消除同一分钟重复标签。
- 独立页 Plot 支持点击 X/Y/右 Y 轴端点数字直接输入范围；Power 纵轴在轴标题附近提供 kW/W/mW 快速切换，右栏仍保留完整范围设置。
- Dashboard Spectrum 恢复中心波长/3 dB/RMS 的 nm 和积分功率 dBm；所有 metric chip 统一数字/单位 baseline 与对称上下 padding。
- 顶栏文件夹按钮改暖橙棕色，右侧无框文本显示当前实验目录最后一级名称；顶栏采集源选中改蓝青色，模块图标用绿/黄/灰/红表达真实健康状态。
- 子页身份区放大静态图标和模块标题，去掉细小“就绪”字；设置/结果 Tab、右栏 label/section、顶部辅助文字整体提升可读字号并保持无横向滚动。
- Power power1–4 / math1–4 改为 4×2 顶部通道入口；现有通道点击后切换右栏上下文，支持显示名、物理单位/数学自定义单位、Dashboard 显示和独立纵轴范围。
- Scope CH1/CH2 改为顶部通道入口；右栏按当前通道管理 Alias、显示、V/div、Offset、Coupling。MSO44 Driver 对 CH1/CH2 分别下发 SCALE/OFFSET/COUPLING。
- Beam 左侧增加 30 px Frame Quality 条；Simulator 根据衰减给出过亮/正常/偏暗，真实 BeamSquared 未映射 frame-quality API 时只给中性状态。左 profile 与右 caustic 重新按共同工作区基线约束。
- Dashboard Beam profile/caustic 外框和 Power overview gutter 再次按 PlotCanvas 共用 gutter 对齐。
- Power 历史曲线采集逻辑本轮不改；只改显示单位、范围和 UI/绘图基础设施。


## v0.5.0 Real Hardware Data Plane（p107-exp）

状态：**真实驱动开发候选；代码/CI 可以验证通信实现与安全边界，但仍必须逐台完成实验室实机验收，不是 stable/main/Release。**

- 将单一 Simulator Provider 改为 `HybridInstrumentProvider`。Power/Spectrum/Beam/Scope 可分别处于真实硬件或 Simulator，形成 SIM / WAITING / MIXED / HW 数据平面状态。
- 对启用真实接口但尚未读取到真实样本的模块，禁止静默回退 Simulator；Test 选择到该模块时直接阻止保存并报告未 ready 原因。
- Juno：独立 STA 线程加载 `OphirLMMeasurement.CoLMMeasurement`，执行 ScanUSB → OpenUSBDevice → StartStream → GetData；支持 AUTO 或序列号选择，维护真实 power history，并将 W 统一换算到当前 Power 工作区的 kW。
- AQ6370D：原生 TCP/SCPI worker，默认 socket 10001；执行 LAN anonymous authentication、CFORM1、*IDN?、扫描参数设置、TRA X/Y ASCII 读取与断线重连；X 波长由 m 转为 nm。
- MSO44：原生 TCP/SCPI worker，默认 raw socket 4000；读取 CH1/CH2 WFMOutpre 与 CURVe?，使用 XINCR/XZERO/PT_OFF/YMULT/YOFF/YZERO 还原真实时域，本地 Hann FFT 生成上方频谱。
- BeamSquared/SP920：新增独立 `LaserBench.BeamSquaredBridge` net48 进程，反射加载厂商 M2.Automation.dll；主 .NET 8 进程通过 stdin/stdout IPC 读取 RailControl、QuantitativeResults 与 LaserResults，避免把 .NET Remoting 依赖塞进主进程。
- 四类 worker 具备后台连接、状态快照、错误计数、重试/重连与手动“立即重新探测”；Web UI 结果页显示设备身份与最后真实样本。
- 驱动数学核心加入 endpoint/SCPI parser、光谱 3 dB/RMS 分析和真实时域本地 FFT self-test。
- 右侧设备接口区域增加明确通信方式、live state、设备身份和 Probe；面板继续收紧横向 overflow，保持只纵向滚动。
- 最终控制真实性审计：AQ6370D 只显示有明确设备映射的采集参数，本地平滑单独标注；波长偏移真机写入 WAVELENGTH:SHIFT、Simulator 本地模拟；移除可见 VBW/未映射峰值阈值；BeamSquared 真机启用时锁定未映射的 Z/Att/Run/算法/outlier 控件，并在右栏明确“只读结果桥 / Run·rail·Ultracal 由 BeamSquared 管理”。
- 当前阶段不宣称任何一台具体实验室实机已验收；实机通过后要把设备型号/固件/厂商软件版本和 Probe 结果写入工作记录。
