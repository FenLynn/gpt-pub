# 班末密集打卡压力审查

核查版本：R108 / 0.2.34-preview。日期：2026-10-29。只加强测试，未改变业务判断。

## 结论与适用条件

在方向明确的测试中，同一次离岗后，在允许窗口内完成班末打卡或短时返回，没有发现误标早退。默认允许窗口是临时外出10分钟＋冗余2分钟，恰好12分钟包含在内。该结论覆盖上午、下午和单人单日最多50张卡，不代表任意缺卡、未知方向或报备冲突都能自动判正常。

保护窗口从对应的原始离岗出卡起算；不是从最后一张重复出卡重新起算，也不是只看最后一张卡是否晚于下班。已经有一张有效班末出卡落在窗口内，后续额外重复出卡不会撤销这项证据。每次班中外出在班末前返回，仍属于班中外出；其红绿另行计算。

## 压力样本

| 测试组 | 数量 | 结果 |
|---|---:|---|
| 一个允许窗口内混合进出、重复方向，末张为班末出卡 | 1,000 | 0次早退误标 |
| 多次班内往返，最终有完整班末出卡 | 1,000 | 0次早退误标 |
| 默认12分钟边界的前1秒、恰好、多1秒返岗 | 1,000 | 与预期一致 |
| 密集重复出卡，不允许逐张串联延长窗口 | 1,000 | 与“有效窗口保护／超出后早退或待核”一致 |
| 真正提前离开、没有返回或有效班末卡 | 1,000 | 均保留早退 |
| 同秒进出及正常班末卡 | 1,000 | 0次早退误标；不承诺整日无其他待核 |
| 四组可调参数，逐秒扫描1–1,801秒，上午下午分别执行 | 14,408 | 0处边界差异 |
| 定向保护、报备及真正早退 | 32 | 全部通过 |

共20,440个保护规则与对照检查通过。随机组每组上午500、下午500；单人每天最多50次，没有使用上万张卡的日常假设。所有检查均核对原始打卡未被分析修改。另对8组用完整重分析索引交叉检查，结果一致。固定种子用于复现，不应把构造样本比例当作真实业务错误率。

四组参数为“限额＋冗余”：10＋2、5＋1、0＋0、20＋5分钟。恰好在班末返回仍有班末出勤证据，即使容差为0，也不能仅因前面短暂离开便判早退。

典型例子：

- 11:38出、11:42进、11:43出：不判上午早退。
- 17:08出、17:10:30再出：不判早退。
- 17:08出、17:20进、17:20:01出：恰好12分钟，不判早退。
- 17:08出、17:20:01进、17:20:02出：超过12分钟，保留早退。
- 17:08只有出卡，之后没有回来或有效班末卡：不能仅因距下班两分钟就豁免早退。
- 16:40出，16:50、17:00、17:10连续再出，没有进卡：不能按每段10分钟无限续窗；应保留早退或配对待核。

## 独立诊断：仍存在的漏标

另有4个独立的“无关夜间孤立卡”检查，3个未达到“仍保留明确早退”的预期。这4项与前述20,440项分开计数，没有将失败改称通过。

| 本来明确的早退 | 后加的无关记录 | 当前结果 |
|---|---|---|
| 08:30进、11:20出；下午正常 | 23:00孤立出卡 | 上午早退降为“午休提前离岗待核” |
| 同上 | 22:00未闭合进卡 | 上午早退降为待核 |
| 上午正常；13:30进、16:50出 | 22:00未闭合进卡 | 下午早退消失，整日待核 |

原因是早退判断仍受全日配对不确定状态和未闭合进入记录影响。异常日没有被判正常，但明确早退次数可能少计。本轮未修复，仍属此前压力审查已记录的待办，不能宣称所有早退边界均已解决。独立诊断结果输出在测试JSON和控制台的`KNOWN_ISSUES`中；允许窗口内的保护检查是必须通过的回归断言。

## 测试预期的校核

初版生成器曾把“16:40出、17:10再出，中间没有进卡”误当成已完成班内往返；也曾要求重复出卡必须最后一张仍在12分钟内。这两种预期不符合实际规则：前者没有返回证据，后者应看是否已经存在窗口内的有效班末卡。正式样本已修正生成约束和独立预期，并保留上述解释；这些调整不是程序修复。未知方向或长时间只有重复出卡时，显示待核是保守结果，不能与明确早退指标混淆。
