# R102 · 项目移除与锁定恢复

R102 将“移除项目记录”和“关闭当前工作”明确分开。移除当前目录或便携项目后，当前页面、未关闭的会话、磁盘目录和本机缓存保持不变；自动载入标记被关闭，继续保存不会把该标记静默打开。刷新或下次启动回到 Demo / Work 选择，Work 提供手动恢复上次本机缓存。重新选择、连接或明确恢复自动载入后，才再次建立默认项目。

周期使用门槛的等待状态不再改变页面清晰度。页面保持原亮度和细节，只显示约两秒一周的非匀速圆环；动画间隔数周随机暂停 0.1 至 0.5 秒，解锁后清理计时器。动画节点不写业务状态、不操作目录和缓存，也不取消已经开始的异步文件工作。

锁定恢复时，连续点击设置后只显示本地运行与版本区域，窗口以透明背景悬浮在页面上方，等待圆环继续运行。设置窗口和版本状态窗口均忽略背景点击和 Escape；锁定恢复设置隐藏底部操作，右上角关闭按钮是唯一退出入口。密钥确认、刷新或撤销均在原窗口更新状态，成功解锁后立即停止等待动画。

专项测试覆盖：便携缓存保存、移除后当前会话保持、再次保存不恢复自动载入、刷新回到模式选择、手动恢复缓存、透明等待层、两秒非匀速动画、随机低频暂停、设置与版本窗口关闭边界，以及解锁后动画停止。
