# R88 · 界面与手工区间清理

版本：0.2.14-preview。数据格式仍为 schema 3，兼容读取 schema 2。仅维护 `p109-exp` 的 P109；原始导入、已冻结快照及旧备份不原位修改。

## 七项调整

1. 删除主页左下临时外出卡片；保留个人单日右侧汇总、状态筛选及统计分析业务。
2. 个人时间轴外出、加班轨道名称与出差、请假统一右对齐，悬浮 ＋ 放在名称左侧。
3. 手工外出和手工加班的 × 直接移除补录事实、颜色/纳入选择和相关工作修订，不保留虚线背景。自动区间的 × 仍是排除统计并留痕，可恢复。
4. 自动临时外出的起始出卡已明确判为早退，且班内外出时长严格小于本月短时限额加冗余时，不重复计临时外出。默认小于 12 分钟，恰好 12 分钟仍计入。中途往返、待核证据和明确手工补录不受此排除影响。
5. ＋、红绿点、× 和 ✓ 统一用 SVG 及固定按钮盒，取消悬停位移，分别按轨道或色块中心定位。
6. 主页右侧四个总量排为一行；趋势采用较大的空心点和纵向渐变阴影，组别排行条加粗。
7. 个人右侧行为筛选只高亮，选中外出等业务不再改变文字位置。

## 删除、跨月与兼容

删除手工加班后，其覆盖的真实自动候选重新出现，合计不一定归零。自动候选仍依据实际打卡和本月门槛计算。跨月手工加班从任一日期切片删除，都移除其开始月份的同一事实，并将涉及月份标为未保存；目录模式按提示逐月保存，便携模式下载新完整包。

R87 已排除的手工区间在读取工作状态时清理，标为未保存以便检查后落盘；自动排除决定保留。加载过程先复制数据，不改写传入载荷或历史快照文件。当前工作删除不影响已冻结历史，打开旧历史仍可看到当时事实。

升级仍从“导入 → 程序升级 ZIP”进入；清单兼容 schema 2/3，版本为 0.2.14-preview，无新增运行时依赖。程序与业务项目继续分开，线上与离线共用同一运行文件集。
