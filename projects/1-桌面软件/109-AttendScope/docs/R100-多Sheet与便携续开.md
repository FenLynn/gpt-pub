# R100 · 多 Sheet 导入与便携项目续开

版本：0.2.26-preview；数据 schema 7，分析引擎 R94。

## 多 Sheet

XLS 和 XLSX 会读取工作簿的工作表目录。导入页顶部显示工作表下拉框：可以选择任意一张非空表，也可以选择“合并全部非空表”。合并时每张表分别应用“跳过开头/首行为表头”，表头必须与第一张业务表完全一致；结构不同的说明页或汇总页会隔离并列入检查结果，不静默导入。每条记录保留实际 Sheet 名与原始行号，同一行号位于不同 Sheet 时仍生成不同记录身份。整个工作簿只保存一份原件。

空 Sheet 只显示在清单中并禁用。公式使用文件中已经保存的结果值；图形、宏、排版和加密工作簿不作为业务数据执行。

## ZIP / 便携模式续开

首次“新建便携项目”或“打开项目 ZIP”后，完成导入或人工修改，再点击顶部“保存”。成功提示“仅写入本机浏览器缓存，需下载项目包写入磁盘”表示完整项目缓存已写入并读回校验。此后在同一台电脑、同一浏览器内核、同一程序路径打开 `index.html`，自动恢复最近有效缓存并直接进入项目，不需要再次拖入 ZIP。

以下情况需要重新选择项目 ZIP：清理站点数据、浏览器禁止或耗尽 IndexedDB、切换 360 极速/兼容内核、换浏览器、换电脑，或移动程序后浏览器将 `file://` 页面识别为不同存储位置。项目 ZIP 是独立磁盘备份；缓存不是。每次关键修改后仍应下载带时间戳的新项目包。

## 验证

`tests/r100-audit.cjs` 现场生成含两张同结构业务表、一张不同结构说明页和一张空表的压缩 XLSX，检查工作表发现、单表默认、安全合并、来源 Sheet、记录身份、单份原件，以及保存后重载 `index.html` 自动恢复便携项目。
