# R91 · 独立日历与时间轴操作

候选版本 0.2.17-preview，业务 schema 4，固定日历文件 schema 1。

## 工作日管理

- 数据管理 → 工作日管理。年份用左右箭头增减，月份下拉；范围 2000–2100 年，自动处理闰月。
- 日历编辑与顶部业务年月分开，不创建项目或业务月份，可一次设置全年。
- 选中多个日期后批量工作/休息，或按普通周末重置。编辑仅为草稿，点击“确认保存当月”才存入浏览器。
- 无项目时可确认，跨编辑月份先提示是否放弃未确认草稿；草稿也参与关闭提示。
- 确认会同步当前项目中已载入的同月普通工作状态，并记修订、重算、标为待保存。业务数据仍需顶部保存；冻结与修订副本保留自己的日历。
- 新业务月优先使用固定日历，没有设置的月份按周一至周五工作、周末休息。已有工作状态中明确保存的日历优先，不无声覆盖尚未打开的历史月。
- working 保存完整当月日历；新冻结额外捕获相邻月日历，避免跨月加班随默认日历变化。旧冻结缺少的日期保留原有普通周末基准。

## 存储与备份

独立日历在浏览器本地存储和项目历史数据库的独立配置键中保存，不写入 raw，也不要求目录权限。重开比较更新时间，读取较新的有效版本，避免某种存储失效后被旧副本覆盖。

“导出全部日历”生成独立 JSON；在另一个浏览器、移动后的程序目录或线上版里用“导入日历”恢复。同月替换，其他月份保留；文件必须完整、日期有效且只含工作/休息。无效或取消导入不改变当前配置。

两种浏览器存储都不可写时，下载完整日历 JSON，界面明确提示尚未持久保存，草稿关闭提醒保留。下载必须由使用者实际保存，页面不把下载发起等同于落盘成功。清理浏览器或移动程序前先导出日历；业务项目另做完整备份。

## 时间轴与概况

- 迟到早退提示框避开标签及外侧 ×/✓，鼠标或键盘进入按钮时收起黑色提示；排除、灰色留底、恢复沿用原事实层。
- 概况用独立左右列、24px 间隔和浅分隔线，左列首进/在岗，右列末出/班内工时；标题和值在各自列内对齐。紧凑尺寸避免新增无效滚动。
- 临时外出和加班红/绿/×/✓ 放在色块右侧，靠近图表右边缘则放在色块右上方，不遮挡本块内容。连续残余片段仍只有一套操作。
- 根据色块与菜单的实际几何判断悬浮，跨小间隙和图表刷新仍可到达菜单；键盘操作继续可用。自动排除保留底稿，手工删除不留幽灵区间；外出/加班 ＋ 仍按各自行分别显示。
