# R89 · 日历与独立核查

版本：0.2.15-preview；数据 schema 4，升级包兼容 schema 2/3/4。仅修改 P109，维护分支 p109-exp。

## 逐项行为

| 反馈 | 实现与验收口径 |
|---|---|
| 主页和分组标题对齐 | 左侧标题放进矩阵列，与右侧考勤概况同一行；五种桌面宽度核对坐标和溢出 |
| 顶部顺序与保存尺寸 | 导入、导出、项目、保存；保存 28px 高，以蓝色边框、浅底和未保存点强调 |
| 迟到早退可排除 | 每一班次的标签独立 ×；自动标签变灰留底，✓ 恢复。过滤、统计和明细导出用同一纳入口径 |
| 初始与最终判定 | 初始保留原诊断；排除只改变对应异常事实，其他问题仍参与最终判定，人工日判定优先 |
| 日期标记 | 迟到早退蓝点，加班粉点，全部迟到早退排除时灰色空心点；下划线保留当日考勤状态 |
| 日期底纹 | 只有工作/休息；新月周一至周五工作，周末休息，每月可人工调整 |
| 跨午休临时外出 | 上午、下午分别计数、判色、人工选择和排除；纯午休不产生区间 |
| 右侧概况 | 移除重复加班指标和常驻规则说明；悬浮或 Tab 提示原因，恢复操作在可展开区间明细内 |
| 授权 | 无离线授权、激活、机器绑定；静态托管与正常离线包使用相同程序 |
| Python 外观分发包 | 独立构建工具生成加密文本分块，Windows Python 3 无第三方依赖还原；与正常程序和升级 ZIP 分开 |

## 一次完整核查的操作

1. 先通过“项目 → 完整项目备份 ZIP”保存旧工作。顶部“导入 → 程序升级 ZIP”选择正常 P109 升级包，按向导完成，重新打开程序。
2. 选目标月份，进入“数据管理 → 工作规则 → 工作与休息日”。点击具体日期切换工作/休息；新月不会自动下载节假日安排。重置按钮可恢复普通周末规则，取消不应用。
3. 进入个人单日，核对蓝色迟到早退标记。鼠标移至具体标签，点 × 排除；标签变灰但原打卡不删除。灰色标签上的 ✓ 只恢复这一项。初始判定按钮同时清除人工日判定、恢复该日被排除的迟到早退。
4. 核对外出轨道。默认 11:30 出、13:45 进拆为上午 10 分钟和下午 15 分钟，午休不累计，默认上午绿、下午红。两段各有自己的红/绿/×，不共用人工选择。
5. 对已明确早退的短时外出，R88 的去重规则继续用于单班次区间；真实跨午休区间的两半保留供独立核查，不因上午几分钟早退而整段消失。
6. 右侧临时外出概要只显示次数、颜色和时长；展开“区间明细”可恢复自动。规则和加班原因悬浮或键盘聚焦查看。
7. 保存，重开完整项目 ZIP 或重连目录后检查结果。原始 Excel/CSV、打卡记录、在岗与班内工时、已冻结文件不因排除标记而修改。

## 旧数据兼容

- 读取旧 schema 2/3，在内存中转换，原 working、raw 和 snapshot 不在升级时改写。用户下次保存才采用 schema 4。
- 旧节假日值转换为休息、调休上班转换为工作。旧版本隐含的 2026 年 10 月安排也固定保留，因此已有历史月和新建月可能不同；这是保护历史事实，用户可自行修改。
- 旧跨午休自动外出的整段人工选择作为两段的初始选择。用户只改其中一段时，另一段保留旧选择；不会跟着变色。
- 旧手工外出在工作状态中拆成两个有独立身份的分段，旧人工选择和工作修订继承到两段。删除一段只清理该段补录和工作痕迹，保存重开不会重新生成另一半。
- 读取 R87 旧排除补录时继续执行 R88 清理；自动排除仍保留。schema 4 被 R88 及更早程序拒绝，防止旧引擎回写丢失新字段。需要降级时使用升级前备份。

## 两种分发包

正常升级 ZIP 本身就是完整离线程序，可解压后直接打开 index.html，也可通过现有程序右上角导入升级。静态 Pages 部署只需要正常源码或正常程序包，不需要 Python、包装密码或授权。

Python 外观包是可选的另一份分发产物。它不冒充第三方库，目录使用自有名称 analysis_toolkit，所有外层文件为 Python 文本。程序 ZIP、内部路径和内容封装在加密分块中；外层只暴露还原脚本及数值分析式模块目录。

生成：

```text
python tools/package-camouflage.py 正常程序.zip analysis-toolkit.zip
```

在有普通 Python 3.8 或更高版本的 Windows 上，将外层 ZIP 解压到全新、可写目录，在该目录打开终端运行：

```text
python lib/init.py
```

输入包装密码（输入过程不显示字符）。工具先验证密码、认证标签、原包 SHA-256、内部清单和文件哈希，再暂存、安装并读回核对。成功后删除外层包装和 lib/init.py，留下与正常程序包逐字节一致的代码，随后直接打开 index.html。

密码错误、内容篡改在写入前拒绝。遇到写入或读回错误会回滚；若系统权限连回滚也拒绝，保留备份目录并报告位置，避免清理掉恢复材料。断电或强制结束进程不是可捕获异常，应保留原 ZIP，改用可写的新空目录重新解压还原。目录混入其他文件时拒绝覆盖；不要在装有业务数据的项目目录中运行。

使用 Windows 自带 CNG AES-GCM 与标准库 PBKDF2，不需 pip 或联网。密码不进入脚本、仓库、正常程序或 Pages。包装只保护分发时的内容；正确还原后的普通 HTML 源码仍能被读取和复制，不是授权机制。
