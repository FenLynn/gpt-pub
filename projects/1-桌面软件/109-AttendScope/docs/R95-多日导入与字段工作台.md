# R95 · 多日导入与字段工作台

版本 0.2.21-preview，业务 schema 6、计算引擎 R94 不变。本轮只更新导入、规范数据导出和教程。

## 时间范围

请假、登记加班和外出采用连续起止日期时间；不再要求多日请假拆源表，也不将外出日期范围解释为每天重复同一时刻。

| 输入 | 结果 |
| --- | --- |
| 开始日期 2026-10-23，开始时间 18:00:00；结束日期 2026-10-25，结束时间 08:30:00 | 23 日 18:00–24:00、24 日全天、25 日 00:00–08:30，三段连续，共 38.5 小时的原始覆盖 |
| 开始日期时间 2026-10-23 18:00:00；结束日期时间 2026-10-25 08:30:00 | 与分列完全相同 |
| 开始合列，结束日期与时刻分列 | 独立识别，两端可混用 |
| 2026-09-30 22:00 至 2026-10-02 02:00，导入 10 月 | 只保存 10 月 1 日及 2 日的日段；9 月需另行导入 |
| 结束日期 2026-10-24，结束时间 00:00 | 截止 24 日开始，不生成 24 日的空段 |
| 出差 2026-10-23 至 2026-10-25 | 整天覆盖，包含 25 日，不要求时刻 |

支持 `YYYY-MM-DD`、斜杠、点、中文年月日、八位年月日、Excel 数值日期及时间小数；XLSX 的 1904 日期系统按工作簿标记处理，不更改原始单元格。日期时间支持空格和 T，时间保留秒。无歧义的日/月/年或月/日/年可识别；如 `03/04/2026` 则拒绝，提示改为年月日。非法日期、非法时刻、时区后缀、同一或倒置起止、超过 366 天及与目标月无交集均明确提示。

24:00 仅作结束，等于次日 00:00。请假缺省时刻保留使用班次边界的旧行为；半天假应明确给时刻。外出、登记加班必须有两端时刻。结束日期同日可选无；只有旧单日期加班允许结束早于开始时按次日解释。明确给了结束日期后绝不静默顺延。

## 数据与兼容

源行先校验成完整范围，再按自然日与目标月份相交生成已有模型的每日行。中间完整日用 00:00:00–24:00:00，首末日精确保留秒；每个日段 ID 含日期，来源 importId、文件、工作表和原始行号仍保留。附带完整源范围用于追溯，不修改原件。

已有工作及冻结不迁移、不重写；日段仍符合 schema 6，优先级、工作班次扣除与加班并集沿用 R94。日段条数表示规范化每日记录，不冒充审批源行数。按相关业务核算实际工时，不能把原始连续覆盖分钟直接当请假班内工时或加班时长。

旧单日模板、旧保存的字段映射继续可用。已有外出历史范围仍按其保存时的每天重复口径分析；将旧表重新导入新版时应明确：新范围连续，真正每日重复时段须逐日写多行。规范数据导出为明确每日起止日期时间，旧外出重复范围也逐日展开导出，避免重新导入改变时长。

## 界面

标题与导入月份、文件日期同排。左侧约 320px，每行标题在左、下拉在右；开始和结束各自选择分列或合列。右侧默认显示可读的识别结果，Excel 序号和时间小数不占主预览；原始表格仍可切换。底部区分源行数与日段数，失败行保留具体原因。高级设置折叠，核心导入/取消按钮保持可见，取消不修改工作区。

教程、空白模板与五类练习 CSV 同步更新。请假练习包含跨日，登记加班练习包含跨午夜。源文件多选继续逐个确认、合并与保留原件。
