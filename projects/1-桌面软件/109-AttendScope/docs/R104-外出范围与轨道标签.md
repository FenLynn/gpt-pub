# R104 · 外出范围与轨道标签

版本：`0.2.30-preview / R104`

## 判定边界

员工在下午下班前出卡、下班后返岗并再次出卡时，系统先比较该次缺岗与“临时外出默认时长 + 冗余”。在当前默认 10 + 2 分钟下，17:04 出、17:15 进不会判为早退；17:04 出、17:17 进超过阈值，仍以 17:04 作为早退依据。班末前已经返岗的班中外出继续只进入临时外出核查，不与早退重复。

## 外出导入

外出导入提供两种明确模式：

- 传统起止字段：开始日期、开始时间、结束日期、结束时间，或两列完整日期时间。
- 起止范围字段：一列日期范围、一列时间范围。例如 `2026-09-06-2026-09-06` 与 `09:30-10:40`。

范围模式识别 `-`、`至`、`到`、`~`、`～` 等分隔符；只有分钟的时间自动规范为 `HH:MM:00`。结束早于开始、日期结构不完整或无法识别的行不会静默导入。

## 轨道文字

请假、出差、外出导入界面可选择任意一个或多个源列作为轨道标签。默认选择类型、地点、备注中实际存在的列；字段可上移、下移和移除，结果以 `·` 连接。每类业务单独保存选择和顺序。

时间轴优先把文字放在对应色块内部，色块过窄时放在其右侧；文字默认半透明，悬浮时恢复清晰，提示框显示完整内容。文字仅用于展示，不参与业务去重、时长或优先级计算。

## 验证

`tests/r104-audit.cjs` 覆盖：

- 下午班末短间隔不早退、超阈值仍早退；
- 连字符日期范围不会把日期自身的连字符误当成错误分隔；
- 分钟时间补秒、中文分隔符及逆序拒绝；
- 双范围列自动识别和规范记录；
- 标签默认列、增加、排序、跨文件记忆和时间轴连接文本；
- 传统外出格式仍可选择并通过检查。
