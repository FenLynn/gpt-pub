# R106 · 午夜推算、独立区间与班末保护

版本：0.2.32-preview；数据 schema 8；引擎 R106。

## 凌晨只有出卡

优先查找相邻月份、前一天的真实进入记录。23:50 进、次日 00:10 出仍作为连续 20 分钟，前日与当日各分摊 10 分钟。

找不到有效进卡时，只有当天第一张记录为出、且处于可配置的凌晨截止时间内，才从 00:00 推算到第一次出卡。默认开启，截止 06:00；设置 → 考勤规则可关闭或调整为 00:00–12:00。单独 02:00 出推算 120 分钟；17:10 出不补算。未知方向、前一天未完成的进卡，或跨午夜很近的重复出卡均不会用午夜规则掩盖证据冲突。

推算经过正常班次排除、最低加班时长、登记/补录去重，与其他加班合并为时间并集。原始表保留真实出卡，不插入 00:00 进卡。轨道悬浮明确标注“午夜推算加班”，可使用 × 排除、✓ 恢复并保存。

## 异常按区间处理

新口径下，一条未闭合进卡、孤立出卡或重复出卡不再将当天其他完整区间的加班清零。未知方向会切断其所在的配对，不能跨过去拼接，但后续独立完整区间仍计算。例如 18:00 进、18:10 未标注、18:20 出、19:00 进、20:00 出，只计最后完整的 60 分钟。

连续在岗默认超过 16 小时后，自动加班显示待确认色块，初始不计入统计。检查原始记录后，使用该色块右侧 ✓ 确认纳入；× 保留灰色证据并排除。阈值可在设置调整为 1–36 小时，恰好等于阈值仍自动计入。一次确认或排除作用于同一跨日会话的全部切片，并保存到月度工作状态。人工补录和明确登记时段保持其独立来源，照常排除班内时段并取并集。

## 下班附近密集进出

保护窗口复用临时外出短时限额＋冗余，默认 10＋2 分钟，无需另维护一套容差。上午与下午采用相同口径：

| 原始打卡片段 | 早退判断 |
| --- | --- |
| 11:39 出、11:39:10 进、11:40:30 出 | 不判早退 |
| 17:08 出、17:12 进、17:13 出 | 短时返岗，不判早退 |
| 17:08 出、17:10:30 又出 | 同一窗口跨过下班点，不判早退，保留重复出卡提示 |
| 17:08 出、17:20 出 | 恰好 12 分钟，受保护 |
| 17:08 出、17:20:01 出 | 超过窗口，保留早退 |
| 17:08 出，之后没有返岗或跨班末证据 | 保留早退 |
| 17:08 出、17:30 进、17:31 出 | 长时间离岗跨过班末，保留早退 |
| 16:40 出、16:50 出、17:00 出、17:10 出 | 不允许逐次延长保护，保留早退 |
| 14:00 出、14:25 进、17:10 出 | 班中返岗，只核查红色临时外出 |

全部原始卡保留。未知方向不会作为有效返岗或重复出卡链的桥梁。报备优先、逐段红绿改判与原有迟到早退 ×/✓ 继续适用。

## 升级与保存

普通工作月份读取旧文件后采用新口径并标为未保存；旧冻结及基于旧冻结的修订保留原口径，在独立副本的考勤规则页应用后才切换。新数据保存为 schema 8，R105 及更早程序拒绝读取，避免忽略超长待核确认等字段。新导出的配置包要求 R106，仍可导入 R105 配置并补齐新参数。

ZIP 模式保存仍先进入本机缓存，需下载带时间戳的完整项目 ZIP 才形成独立磁盘备份。程序升级包与业务项目 ZIP 继续分开。
