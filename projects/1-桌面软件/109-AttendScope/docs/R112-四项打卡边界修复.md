# R112 四项打卡边界修复

版本0.2.38-preview，schema 14。仅修改P109，沿用R111报备与实际分开统计以及文字可读性修复。

## 修复

1. 同秒冲突：计算层按人员和时间簇处理；不同方向或混有未知方向统一断开不确定配对、提示待核。相同方向重复只在计算层合并，原始行与箭头保留，重复仍提示。相同记录ID的行换序不改变工时、外出或加班；不假装能恢复未知的真实先后顺序。
2. 下午迟到：返岗配对覆盖整个下午班次，不再截断在班首两小时；有完整下午证据时15:45返岗也核查。未知方向处于午间返岗证据范围仍保守待核，无关夜间孤立卡不抹掉白天迟到。请假、出差、报备覆盖及可调宽限保留；请假晚返仍只计临时外出。
3. 连续出卡：从首次出卡到下一进卡，期间重复出卡不缩短实际离岗。10:00出、10:20出、10:25进，实际25分钟、默认红色；未知方向打断链，不复用重复进卡。旧人工排除或红绿可继承到对应实际区间，恢复自动不受遗留别名重新覆盖；旧下午排除不误排新识别上午区间。原始打卡和报备不改写。
4. 午夜陈旧记录：前序证据限制为36小时，与完整跨夜配对最大窗口一致。更早的未知或未闭合记录不阻止当天00:00起的推算；近期未知仍阻止猜测，真实跨夜优先、近午夜重复出卡防重、推算开关、超长确认保持有效。

## 兼容

新增`punchEvidenceRuleVersion`，普通旧工作缺省升级2并提示保存，旧冻结及其独立修订缺省保留1。在规则页明确应用才切换。旧版程序拒绝schema 14，配置包最低程序版本0.2.38-preview。项目原件、冻结不改写，程序ZIP不包含业务数据。升级前下载完整项目ZIP备份。

## 验证

先运行新增专项，原程序复现四类缺陷。修复后38项检查包含100个下午晚返时间点、600次保留ID乱序、200组单人不超过50卡的连续出卡样本；覆盖报备优先、请假晚返、36小时边界、真实跨夜、旧冻结、旧人工选择继承/恢复和ZIP重开。另运行20,444项班末压力及相关历史专项，确保不重新制造早退误判。
