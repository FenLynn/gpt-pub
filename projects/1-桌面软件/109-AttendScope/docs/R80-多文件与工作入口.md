# R80 · 多文件、原件浏览与工作入口

版本：0.2.6-preview / R80。仅修改 P109，保留 schema 2，工作分支为 `p109-exp`。

## 使用方式

- 首次进入选择 Demo 或 Work，并在当前浏览器记住。Demo 使用公开虚构数据；Work 进入空白工作区，可新建或连接独立项目。Work 重开时继续使用 R79 的最近项目与自动载入机制。
- 顶部第二行显示当前目录名称；最近项目设置了显示名时使用该名称。点击打开真实项目文件浏览器，旁边的 Demo / Work 可切换模式。切换会检查未保存工作。
- 五类导入都可一次选择多个文件，逐个预览、检查、确认；默认合并，后一个文件保留前一个文件的数据。跳过当前文件会进入下一个；取消结束剩余队列，已完成的导入保留。
- 字段中的“无”适用于类型、地点、备注、进出方向等可选项。姓名和业务所需的日期/时间仍须有效。结束日期可省略为开始日期；请假起止时刻可显式使用当月班次起止；外出及登记加班必须提供有效起止时刻。
- 没有方向的考勤保存为“未标注”，使用中性标记并提示待核，不推断进出，不把这些点组成在岗或加班会话。源列有值但无法识别的方向仍须修正映射/规则，不能作为无方向静默放行。
- 更多选项中的“替换本月此类数据”须再次确认，只替换该月该类型的工作集合；其他类型和所有历史原件保留。
- 数据管理“原始记录”默认展示导入原件，支持原文件预览、原字节下载和所在文件夹浏览；“合并数据”查看统一后的业务表。导入历史、文件树、项目名称和库存数量也提供浏览入口。
- 名册用勾选加批量加入组别，跨搜索保留选择，目标组别持续保留。完成一批后清空已选人员，便于继续下一批；分组和勾选更新保留列表滚动位置。长期固定名单仍用左右箭头管理。

## 合并与来源

按业务字段核对文件间重合记录：考勤使用规范人员、秒级时间与方向；其他业务使用人员、日期、起止时间、类型及相应地点/备注。内容不同的记录保留。

同一文件内的重复打卡属于原始证据，保留其次数。多个文件重叠时，每个签名保留已有文件与新文件中的较大次数，避免重复导出造成打卡数翻倍。原有记录 ID 保持不变；合并的来源通过 `sources` 保存文件、导入 ID、工作表、原始行号和原记录 ID。每个导入事件都有独立 raw 副本及哈希，不改写既有 raw。

先校验并保存新原件，再更新名册和工作数据；写入失败保留原工作，预览内可重试。仍需点击“保存”保存 working。原件不嵌入工作 JSON；未连接项目时仅本次会话可预览刚导入的文件，关闭前须自行保留原文件。

## 浏览与兼容边界

文件浏览器只读已授权目录，不构造 Windows 绝对路径，不承诺定位系统资源管理器。CSV/XLSX 按原单元格分页预览，JSON/文本按纯文本展示，HTML/脚本不执行。其他格式提供原字节下载；40 MB 以上文件不进行页内解析，文本最多预览前 1 MB。缺失原件、无权限或无效索引明确提示，不以工作表冒充原文件。

目录句柄和模式偏好属于当前浏览器配置；换浏览器、清理站点数据或改变程序所在位置后可能需要重新选择模式/项目。程序 ZIP 仍只有代码，项目数据单独保存。旧版 schema 2 项目由 R80 读取并继续使用；含“未标注”方向及多来源合并的新工作应使用 R80 或更新版本核查，不承诺旧引擎解释新语义。降级应使用升级前备份。

`r80-audit.cjs` 使用浏览器真实 OPFS、IndexedDB、文件流和字节下载，验证首次模式、双文件合并、可选方向、同源重复与跨源重叠、五类导入、队列取消、原件浏览、滚动保留和保存重开。系统原生目录弹窗及外部目录授权交互仍待目标电脑实际点选；接口替身和 OPFS 不替代该项验收。
