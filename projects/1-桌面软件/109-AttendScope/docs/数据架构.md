# AttendScope 数据架构

目标结构：

```text
project.json
config/
data/YYYY/MM/
  raw/
    attendance/NNNN/原文件.xlsx
    leave/NNNN/原文件.xlsx
    trip/NNNN/原文件.xlsx
  imports.json
  working/
    state.json
    revisions.json
    derived/
  snapshots/Fxxxx/
    snapshot.json
  branches/Bxxxx/
  output/
```

`raw` 永不原位修改；`working` 可持续保存；`snapshots` 不可变；历史冻结版本修订时进入 `branches` 子空间。
