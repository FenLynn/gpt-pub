# AttendScope 数据架构

目标结构：

```text
project.json
config/
data/YYYY/MM/
  raw/
    attendance/<importId>/原文件.xlsx
    leave/<importId>/原文件.xlsx
    trip/<importId>/原文件.xlsx
  imports.json
  working/
    state.json
    revisions.json
    derived/
  snapshots/Fxxxx/
    snapshot.json
  branches/Bxxxx/
  output/
```

`raw` 永不原位修改；`working` 可持续保存；`snapshots` 不可变；历史冻结版本修订时进入 `branches` 子空间。

从 R33 开始，importId 为导入事务的独立键；规范化数据包含 `importId`、`source`、`sheet`、真实 `row`。导入清单尽可能保存 SHA-256。working state 保存该月员工名册、组别、系统/人工判断所需规则及来源记录，snapshot 同时保留冻结的配置与 working 状态。不要向公开仓库提交真实个人数据。

注意：当前快照只支持创建不可覆盖的独立目录；历史快照 branch 级二次编辑工作流尚未完整交付，不应描述成已验收功能。
