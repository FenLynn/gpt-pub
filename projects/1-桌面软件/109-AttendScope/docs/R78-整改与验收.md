# R78：项目隔离、恢复一致性与操作精简

版本 0.2.4-preview，数据 schema 保持 2，分析引擎保留 R68。修改范围仅限 P109。

## 数据修复

新目录先暂存并校验配置、磁盘月份、working/previous 和活动修订；成功后整体替换项目。不同月份、相同月份的 A→B→A 不共享缓存、人员、导航历史或截图。失败、取消与权限拒绝保留原项目；连接不写入目录。

月份完整替换日历、规则、导入映射及外观；缺失字段按兼容默认处理。冻结与独立修订不继承当前默认配置残留。连接目录后，冻结 JSON 恢复进入独立副本，主 working 和冻结保持原字节。损坏 working 可恢复有效 previous，显式保存保留最后有效备用状态。

文件操作限制冲突切换；保存期间新增事实仍为未保存。初始化要求空目录或干净程序目录，写入失败恢复之前的会话。运行、项目、工作文件、冻结、设置与打包版本统一。

## 界面与维护

顶部收敛为月份、导入、项目、保存、冻结、导出及设置。项目菜单区分月度 JSON 和整项目 ZIP，集中备份与更新。统计 CSV/XLSX 共用完整字段和范围，保留明确命名的全月明细 XLSX；CSV 编码及文本公式防护共用实现。

五类空白模板按固定列定义生成，不读取当前人员或业务。个人清除日期共用返回全览函数，去掉重复日期下拉；统计页移除无效月历，数据管理仅原始记录显示有效日期筛选。固定名单只用批量箭头，移除逐行 ×；冻结保留顶部主入口；项目弹窗只保留顶部关闭；名册按钮明确为下月默认。

项目分类共用扫描工具栏。删除 `39-workspaces.js` 被覆盖的旧数据页，在 `45-console.js` 保留唯一活动渲染入口，不再运行时覆盖同名函数。

专项使用虚构人员及实际临时磁盘，覆盖跨项目/同月隔离、取消和失败、权限拒绝、初始化回滚、损坏恢复、冻结 JSON/磁盘派生隔离、五类模板文件、CSV 字段与编码、有效月历和菜单键盘操作。

完整回归保留业务口径、自动加班、人工覆盖、原件、图形几何、XLSX/CSV、截图/PDF、保存/冻结、ZIP、修订及更新。UI 检查五工作区、十数据页、七设置页和 1280–1920 宽度。

升级使用准确旧提交 `71caeaa99b7eb41b71ee457d1334a8bcff2de561` 的程序，运行旧版保存数据后经实际更新包升级，比较原件与 working 字节并检查重启恢复。没有通过改低版本标记代替历史程序。

目录接口由浏览器和临时磁盘桥接，不宣称验证原生系统目录弹窗。权限保留和撤销需目标电脑点选。数据 schema 2 的兼容得到测试；更高 schema 拒绝写入，没有推测实现未来迁移。
