# P109 · R68 数据管理、项目总览、分析侧栏与自动加班保护

日期：2026-10-21。仓库：FenLynn/gpt-pub；分支：p109-exp。

## 1. 用户可见变化

### 数据管理：重新设计界面

- 内容区左右保留独立内边距，顶部用 5 个精简事实卡、正文用具有一致边距与圆角的轻量卡片，右侧为项目状态与真实文件树。中间内容和右侧卡片适配 1600px/1920px，窄屏时侧栏移到下方。
- 二级导航统一为「原始记录／名册与分组／工作规则／导入模板／导入历史／冻结与修订」。
- 名册默认只展示「姓名／组别／来源／操作」，去掉「部门与组别」的重复双列；可搜索姓名或组别、筛选全部／未分组／本月导入，勾选一个或多个员工后批量设组，保留单人编辑与固定项目级名册入口。
- 工作规则与导入模板集中展示，并明确哪些规则需要固定为以后月份的默认。原始表格仍沿用既有 Tabulator 数据源和权限，不另存一份事实。
- 右侧文件树严格读取当前连接的 File System Access 目录，文件大小来自实际 File 对象。未连接目录时明确标明不可扫描，不虚构项目数据；对频繁重绘复用最近结果，提供项目总览跳转。

### 项目总览：独立工作空间

- 新增「项目总览」顶层标签，左侧提供月份、健康、存储和文件结构快捷定位。
- 头部概况、按磁盘发现的月份表、working/previous 状态、每月 raw/冻结/修订数量、项目健康结果、按实际文件大小统计的存储构成、可折叠实际文件树与安全操作入口。
- 项目健康沿用 R65–R67 的只读审计和经用户批准的安全补全索引；不自动覆盖 raw、working 或任何快照，也不把浏览器内存的模拟月份冒充本地已存月份。
- 文件树单次最多展示 1600 个节点和 8 层以控制 UI 占用，超过上限标示限制；完整项目 ZIP 备份仍使用已有专门的安全校验流程。

### 全员／分组的右侧分析

- 取消宽大的环形饼图和无明确比较口径的密集条图。
- 保留紧凑的工作人日 KPI、每日异常趋势。状态构成改为一条 100% 堆叠比例条（正常、异常、缺勤）。
- 下半区变成按异常及缺勤、缺勤或异常率切换的风险排行，并提供异常峰值日期和优先核对的组别／人员。
- 全员侧重组别风险；分组侧重组内人员。排行的率分母采用当前筛选范围内对应的有效工作人日，不能与原始打卡次数混淆。
- 趋势和排行继续使用同一 analysis 数据模型和工作日筛选；点击日期及排行可以切换相应分析上下文。

## 2. 用户明确要求：下班加班的 20 分钟保护

当前默认班次：上午 08:30–11:40、下午 13:30–17:10。自动加班的最小门槛从 5 分钟提高至**20 分钟，且按“严格超过”判断**。旧 working 中即使带有旧参数，重开时运行时也按不低于 20 分钟执行。

| 单次完整进出例子（工作日） | 自动加班 |
| --- | --- |
| 上午工作后 11:59 离开 | 0 |
| 12:00 离开 | 0 |
| 12:05 离开 | 25 分钟，起点为 11:40，不扣除前 20 分钟 |
| 下午工作后 17:29 离开 | 0 |
| 17:30 离开 | 0 |
| 17:35 离开 | 25 分钟，起点为 17:10，不扣除前 20 分钟 |
| 08:30 进入一直到 17:35 才离开 | 25 分钟；**午休不是整段额外加班** |
| 18:00–18:12 单独返岗 | 0（未超过 20 分钟） |

判断依据必须是完整进出配对，同向重复、缺出记录仍按既有可疑打卡安全规则处理。一个完整连续会话超过门槛后才参与登记加班的重叠扣除：门槛不因重叠碎片拆分或累计而改变。自动加班是候选统计，人工勾选只管理纳入统计，不代表正式审批。

规则说明同步到设置页（最小值为 20）、当前月工作规则卡及随包演示配置。没有更改考勤的法定或人事审批定义。

## 3. 实际验收范围

- 原有 R63/R67 统计、5 类数据导入、跨月历史、手工修订、冻结和备份回归保持不变。
- Chromium 离线测试新增午间与晚间门槛精确分钟断言、连续跨午休保护、登记加班覆盖碎片保护，所有事实条目不被修改。
- R68 工作区验收：新建并保存项目 → 全局月份清单/真实文件树 → 名册页显示、批量调整组别并保存 → 全员及分组右侧实际截图 → ZIP 备份、恢复、程序更新与原始数据字节比较。
- 涉及 File System Access 的 CI 使用实际磁盘映射模拟文件句柄，不等于 Windows Chrome/Edge 原生选择目录的实机权限测试。
- 保留 data/YYYY/MM，未对真实历史数据做缺少专用迁移器的扁平化重排，不修改主分支、P108 或 p109-stable。
