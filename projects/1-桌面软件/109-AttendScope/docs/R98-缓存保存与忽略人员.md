# R98 · 缓存保存与忽略人员

版本：0.2.24-preview；数据结构：schema 7；分析算法沿用 R94。

## 保存流程

便携 Work 和未连接目录的 Work：顶部“保存”将完整项目 ZIP 字节写入独立 IndexedDB 缓存，包含工作月份、导入原件、配置、冻结和修订。事务完成且重新读取 SHA-256 一致后，才解除未保存提醒。提示固定为“仅写入本机浏览器缓存，需下载项目包写入磁盘”。目录模式仍保存到实际项目文件夹。

“项目 → 下载项目包 ZIP（独立备份）”生成磁盘下载。完整项目、目录备份和救援 JSON 名称包含本地 YYYYMMDD-HHMMSS-mmm 时间戳，连续调用也区分名称。浏览器下载需要检查实际文件；不能把发起下载宣称为可靠落盘。

同一浏览器和程序位置重开时优先恢复最近缓存；原生目录仍保留原有默认项目逻辑。缓存保留上一份有效记录，校验损坏时尝试恢复前一份并保持未保存。浏览器配额不足、禁用存储、读回不一致或同项目其他页面已保存时，保留原缓存和未保存状态，提示下载备份。缓存不是独立备份；换环境或清理缓存前下载 ZIP。

缓存并发检测针对同一个缓存项目的版本；原生目录仍没有跨窗口写锁。最近缓存仅为一个当前项目加一份前次版本，多个磁盘项目仍由原目录历史管理，不承诺多项目缓存库。

## 忽略人员

名册右侧两标签：长期固定人员、忽略人员名单。忽略标签使用现有左右勾选及箭头操作：左侧添加为忽略；右侧“加入全员”恢复。原始打卡、业务、证据和个人分析保留，右侧提供查看入口。默认从全员/分组首页、趋势、排行、人数分母和日常考勤导出排除。

统计左侧“忽略人员”默认“不统计”，可选择“包含统计”。图表、排行、汇总与导出共用人员集合；沿用 CSV 字段契约，在统计范围标注包含忽略人员。忽略名单随 working、缓存、ZIP 与冻结保存。普通月份使用项目默认名单，冻结/修订使用自身名单。旧数据默认无忽略名单。

数据升至 schema 7，使旧程序明确拒绝新项目，避免旧程序无视忽略名单后错误统计。升级器支持 schema 2 至 7；迁移不改原件和旧冻结。

## 兼容边界

用项目复制函数替换 structuredClone，缺失时保留 Map、Set、日期、循环引用和类型数组；补齐 Array.at、Object.hasOwn、随机标识生成与 SHA-256。浏览器不提供目录接口时隐藏目录入口。导入弹窗提供 vh 回退。

IE 内核不属于支持范围。旧 Chromium 没有 XLSX deflate 解压时仍需 CSV。缺失能力模拟覆盖可证明兼容分支，但不能代替实际 Win7/360 验收。可选 BAT/本地文件助手未在本次交付加入，直接打开 HTML 无需脚本。
