# R94 · 请假边界与加班并集

候选0.2.20-preview，只维护P109的p109-exp。业务working、冻结及项目索引使用schema 6，读取schema 2/3/4/5；固定日历仍为schema 1。

## 计算顺序

1. 使用当月实际工作/休息日和上午、下午班次，不把普通周末或节假日硬编码为固定安排。
2. 出差按日期覆盖全天，请假按日内时段；重叠、相接的覆盖取并集。班内缺岗先扣这些覆盖，完全覆盖不生成临时外出，部分覆盖只处理剩余片段。
3. 未覆盖片段按班次拆开，使用短时限额与冗余判红绿。Excel外出报备仍能将完整覆盖的未豁免片段判绿；原始打卡和登记不改写。
4. 所有加班来源先排除工作日两班的班内时间。班外的登记、补录和自动推算取时间并集，重合不重复累计。

出差不是“整天禁止加班”：有完整打卡、登记或补录证据的19:00–22:00仍可计3小时。请假也不会让正常班内分钟变成加班。正常午休位于两个班次之外，连续在岗仍按R93的三参数处理；自动班后扣除和最低时长不裁剪明确登记/补录的班外时段。

## 请假边界实例

默认短时10分钟、冗余2分钟。

| 请假与实际出进 | 结果 |
|---|---|
| 请假10:00–11:00，10:10出、10:50进 | 全部在假内，不生成临时外出 |
| 请假10:00–11:00，09:50出、11:10进 | 09:50–10:00、11:00–11:10各10分钟，两段均绿 |
| 请假10:00–11:00，09:45出、11:15进 | 两段各15分钟，分别红色，可独立改判/排除 |
| 请假10:00–11:00，09:48出、11:12:01进 | 前段恰好12分钟绿，后段12分1秒红 |
| 请假11:30–13:40，11:20出、13:50进 | 扣掉请假与正常午休，两侧各10分钟，分别绿 |
| 请假08:30–09:00，首次09:10进，且有闭合在岗证据 | 09:00–09:10按10分钟临时外出核查 |
| 请假16:00–17:10，最后15:50出，且有闭合在岗证据 | 15:50–16:00按10分钟临时外出核查 |

请假开始后才走、请假结束前已到，都不生成该项迟到早退或临时外出。请假边缘保留自己的短时核查，不再被“班末小于12分钟不重复计早退”的规则误删。一般无请假的班末短时规则继续保留。未知方向仍不猜测；假期覆盖内的未知点不遮掉两端已有明确出进证据，但原卡与诊断提示仍保留。没有真实卡和闭合证据时不凭空构造边界。

## 加班并集与冲突

| 来源 | 计入 |
|---|---|
| 工作日登记或补录10:00–11:00 | 0，保留原登记；班内冲突提示 |
| 登记08:00–14:00，默认班次 | 08:00–08:30及11:40–13:30共140分钟 |
| 登记18:00–18:30，补录18:00–18:40 | 40分钟 |
| 登记18:00–18:30，补录18:20–19:00 | 60分钟 |
| 自动18:00–19:00，同时登记18:10–18:40、补录18:20–18:50 | 合计60分钟 |
| 全天出差，有19:00–22:00完整进出或登记 | 180分钟 |

加班行的“!”只表示原登记/补录含有班内时段，悬停可看去重后的已扣分钟；原件不覆盖，原始记录中可核查。全处班内的手工新增被拒绝。相邻日期按各自日历与班次扣除；休息日不扣工作班次。次数指标区分原始登记条目、自动/补录会话和实际并集独立区间，时长始终去重。

## 界面

右侧继续用横线分五块：初始/人工、四个指标单行、业务两列、临时外出两行、打卡来源。不加额外模块标题和大卡片；拉开数值间距，空区间不显示无意义的禁用明细链接。密集临时外出仍在独立明细弹窗全部可读。

时间轴＋、−和reset只在鼠标进入图表及其缩放区域时显示，离开时隐藏；键盘Tab聚焦时可见，触屏保持可见。外出/加班左侧补录＋继续分别按所在轨道显隐。

## 升级与历史

新增businessRuleVersion区分新规则与历史冻结。普通旧working迁移后重算、标为待保存；旧冻结和从中派生的副本保留旧口径，包括旧临时外出与登记加班的计算。只有在独立修订的考勤规则页应用规则才切换，原冻结字节不变。新冻结保留其请假、出差原始事实和相邻月班次上下文；历史镜像使用自身规则，后改默认配置不会追改镜像。

schema 6阻止R93及更早程序回写新状态。升级ZIP支持schema 2/3/4/5/6，先保存和完整备份，再从导入菜单升级。降级使用升级前备份，不手动改小schema。

## 验证边界

R94专项使用独立手算案例核查请假内进出、未覆盖两侧、秒级阈值、合并覆盖、独立排除、首末边缘、手工删除、所有来源班内扣除与并集、跨日、日历、冻结口径、悬浮与键盘。实际R93源码安装、保存、升级和旧程序拒绝schema 6列入生命周期。旧UI测试改为先进入图表再点击隐藏工具，业务断言不删减；旧出差临时外出两段绿色预期改为新规则的完全豁免。

最终结论以准确提交CI、交付ZIP清单和实际截图为准。原生Windows目录选择与权限仍需要目标浏览器实际点选，不用自动化句柄替身冒充该项实点验收。
