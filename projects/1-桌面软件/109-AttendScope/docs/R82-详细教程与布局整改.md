## 详细教程

原先一页概述无法帮助首次使用者完成实际工作，现改为带目录的教程阅读器。正文由 `50-guide-content.js` 集中维护，应用阅读与下载的离线文字版共用它，避免两份说明逐渐不一致。

- 8 章快速入门：学习路线、建立/连接项目、月份/规则、第一笔导入、核查单日证据、名册分组、保存/冻结/备份/重开、下月继续。
- 12 个专题：考勤、请假、出差、外出、加班、人员、统计、存储、保存冻结、恢复迁移更新、导出、按症状排错。
- 每章按实际功能写操作步骤、字段与示例、预期结果和错误排查。明确进出未知、跨文件去重、原件与规范化导出、独立修订及不同备份格式的边界。
- 三张程序界面图只用虚构演示/教程数据，随离线包携带，可打开原图。
- 五类练习 CSV 按当前月份生成、UTF-8 BOM 输出；只下载，需使用者自行选入练习项目。每种文件都经实际导入预览、校验和提交，而不是只检查生成的字符串。
- 全文搜索覆盖全部章节；支持章内目录、前后章、关闭重开和切章时的阅读位置。首次 Demo/Work 选择页可以先看入门教程。
- “下载离线文字教程”生成独立 HTML，包含全部文字与表格，没有脚本、图片和外部依赖；练习下载与图片在程序帮助中使用。

本次逐项对照导入器时纠正了 R81 帮助中的一处错误：**请假只有单日日期，并无开始/结束日期两个映射字段**，多日请假要逐日拆行。外出可用日期范围表达每天相同的时刻窗口，但不接受结束时刻早于开始；登记加班的结束时刻早于开始则按跨夜处理。教程分别说明，专项测试直接核对解析器的差别。

另明确单日判定面板的“恢复初始判断”与左侧“初始/人工”显示切换：前者撤销当天人工判定，后者仅改变显示口径。

## 目录只放在存储页面

主页保留左上角项目名及其原件浏览入口。顶部项目路径栏和底部程序路径页脚移除，相关目录信息、复制、路径备注及未保存月份汇总统一放在 **数据管理 → 存储与文件 → 目录位置**。存储库存异步刷新不会移走这张卡片。

程序目录可以由当前 file:// 地址去掉文件名取得；目录句柄只提供项目文件夹名称，网页无法从句柄得出 Windows 绝对路径。手动记录的完整项目路径仍标记来源，只在本机浏览器保存，不写入业务 JSON 或备份。点击目录名仍在页面内浏览已授权的实际文件，不引入原生启动器。

API 依据：[FileSystemHandle.name](https://developer.mozilla.org/en-US/docs/Web/API/FileSystemHandle/name)、[FileSystemDirectoryHandle.resolve](https://developer.mozilla.org/en-US/docs/Web/API/FileSystemDirectoryHandle/resolve)。后者返回相对于另一个已授权目录的子路径，不提供操作系统绝对位置。

## 滚动与弹窗

20 人的矩阵实际需要 573 像素，而旧固定容器只有 570 像素，因而即使下方仍有空白也产生竖向滚动。全员和分组矩阵现按内容自然伸展，最大高度由剩余窗口空间决定；长列表仍保留内部滚动并可到达末行。移除常驻路径栏同时删除其 36 + 32 像素的全局占位，避免页面本身被额外撑高。

帮助阅读器桌面宽度为窗口的 86%、高度 88%；导入、原件浏览、项目管理这类需要展示数据的弹窗也使用约 84%–86% 宽。短确认和简单输入不强制放大。窄窗口适配到 92% 宽，并保留必要的内容滚动与底部操作按钮。

没有使用全局隐藏溢出或遮挡滚动条来掩盖内容截断。
