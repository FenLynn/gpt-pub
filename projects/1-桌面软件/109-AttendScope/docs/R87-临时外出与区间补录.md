# R87 · 临时外出与区间补录

版本：0.2.13-preview。数据格式：3；兼容读取旧 schema 2。范围仅 P109 日常开发分支，原始导入文件不改写。

## 计算口径

同一人员同一日的打卡按时间排序，只取相邻“出 → 进”。连续出卡取最近的一张，重复进卡不复用，未知方向打断，不跨日推算未闭合外出。只计算当前规则中工作日两个班次与候选区间的交集；午休、下班和非工作日不计。跨午休的一次外出可以有两块班内图形，仍只统计一次。

两个按月保存的可调参数：`tempOutingMinutes` 默认 10 分钟，范围 0–240；`tempOutingGraceMinutes` 默认 2 分钟，范围 0–60，可设为 0。

1. 班内实际时长 ≤ 限额 + 冗余：绿，包含等于边界，按秒判断。
2. 否则检查当天该人员的 Excel 外出报备，合并重叠报备，避免重复行放大时长。须先与实际班内区间有正长度的重叠，端点接触不算。
3. 报备覆盖所有班内片段、每个起止边界误差均不超过冗余：绿。
4. 起止错位但有实际重叠，班内总时长差的绝对值 ≤ 冗余：绿。
5. 其余：红。分离的无关报备不累加为时长额度；没有把请假、出差自动当成外出报备。

默认例子：10:00–10:12 为绿，10:12:01 返回则红；实际 10:00–10:20 与报备 10:10–10:30 有重叠且同长，为绿；实际延长到 10:25，报备仍是后者则红。实际 10:00–10:24、报备 10:02–10:22，前后各在 2 分钟内，按覆盖规则为绿。11:30–13:40 只算班内 20 分钟、一次；纯午休不生成临时外出。

临时外出是独立核查维度，不改写整日考勤判定。所有主页、个人、统计与导出读取同一分析事实。

## 操作与图形

- 原有六轨不变。外出轨道先画蓝色 Excel 报备，再画半透明红绿色块；临时块占上部，保留报备底部可视部分。
- 悬停临时块显示原因、班内时长与红点/绿点/×。键盘可聚焦操作。人工红绿优先；× 保留灰色虚线证据，从次数、时长、人数完全排除。右侧“恢复自动”清除人工选择。
- 外出与加班文字右侧均提供悬浮 ＋，填写起止时间和可选备注。取消、Escape 不改数据；弹窗限制键盘焦点。
- 手工临时外出使用相同工作日/班内规则，不充当报备。与已计入区间重叠时拒绝新增；先排除错误原区间，再补录。恢复被排除的原区间也检查重复。
- 补录加班不受自动加班门槛限制，支持同日及结束早于开始时跨夜，最长 24 小时，起止相同拒绝。按登记、已纳入补录、自动证据的顺序扣重；补录 × 后自动证据可重新纳入，避免连带抹掉真实打卡。×/✓ 共享跨夜会话标识。
- 主页左下角按全员/组别/个人范围统计临时外出；筛选新增临时外出，矩阵按最终红绿显示。统计页新增六个临时外出指标，明细 CSV/XLSX 增加对应字段。

## 保存与升级

新增月度字段 `tempOutingReview`、`manualTempOutings`、`manualOvertime`，纳入 working、月份切换、冻结、修订、完整 ZIP、救援 JSON、未保存保护和重命名关联。导入回滚保留这些字段，新建空项目或新月份不会携带旧月补录。

数据 schema 提升至 3，避免旧程序接受新数据后静默丢掉人工补录。新程序读取旧 schema 2 时补空字段和默认参数；保存后写 schema 3。原文件在升级程序过程中不会迁移或覆盖，保存仍保留 previous。旧冻结保持原字节，重新计算必须使用独立修订。

升级清单声明支持数据 schema 2/3，使旧程序可以安装 R87；新版数据不能回到旧程序继续保存。需要降级时使用升级前完整项目备份，而非手改 schema。新包仍通过“导入 → 程序升级 ZIP”安装，也可完整解压初装；线上构建与离线使用同一套源文件。

## 验证范围

R87 专项覆盖短时阈值与秒边界、零冗余与自定义限额、报备覆盖/错位/不重叠/时长不足/重复去重、午休两片一次、班后排除、最近邻与未知方向、真实悬浮改判、× 排除、恢复自动、手工补录、重复区间拒绝、补录加班门槛与跨夜、登记/自动/补录并集、月切换与完整项目 ZIP 往返、旧数据默认与坏数据拒绝。

生命周期回归在临时文件系统验证历史 R77、R83 和 R86 的实际程序升级、数据原字节保留，以及旧程序拒绝 schema 3。旧格式测试使用没有任何新增人工事实的独立模拟 fixture，不是产品降级功能。Windows 原生目录授权仍需实际点选，不以测试替身冒充原生权限验收。最终通过结论以对应提交的浏览器报告及 CI 为准。
