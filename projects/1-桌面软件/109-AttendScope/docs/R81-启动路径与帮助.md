# R81 · 启动、路径与帮助

版本：0.2.7-preview / R81，schema 2 不变。保持纯 HTML 离线运行；不增加本地服务器、启动器、浏览器扩展或协议注册。

## 启动

没有默认 Work 项目时，每次加载都显示 Demo / Work 选择，之前选择过 Demo 或临时 Work 不会绕过入口。成功连接或初始化的最近项目作为默认工作项目；重新打开后尝试载入它，需要读写权限时提供继续授权入口。即使上次体验了 Demo，下一次仍恢复已有默认 Work。

最近项目可切换、重命名显示名称或移除。移除默认项目的历史记录后，不再自动打开它，也不删除磁盘数据。历史不可用时退回模式选择，不循环加载或清空当前用户操作。

## 两个目录与复制

- 顶部“项目数据目录”显示实际目录句柄提供的名称；点击在页面内浏览已授权的实际文件，不打开系统资源管理器。
- 普通网页无法从目录句柄取得绝对路径。第一次点击项目“复制路径”可以粘贴在资源管理器复制的完整文件夹地址；只校验绝对路径形式、末级目录名，不声称能核实其真实位置。顶部明确标为“手动记录”，可编辑或清空。
- 备注在当前浏览器项目历史中保存，不进入 project.json、working、原件、项目备份或公开源码。浏览器存储失败时仍支持本次记录与复制，并说明下次需重填。
- 底部“程序目录”由当前本地 HTML 地址计算并解码中文，去掉入口文件名、查询和片段，只复制文件夹级路径。网页预览无法提供本机程序目录时明确提示，不构造虚假路径。
- 两处均提供复制按钮。浏览器禁止自动写剪贴板时，弹出已选中的准确路径供 Ctrl+C 复制。不会改动项目连接或移动文件。

## 关闭与保存

当前月或其他工作月份有未保存修改，或者正在写入项目文件时，通过 beforeunload 阻止直接离开。真实浏览器提示允许取消关闭；保存后不产生误报。底部显示未保存月份，并提供保存当前月按钮；其他月份须切换过去分别保存。

浏览器控制提示文字，无法在原生关闭提示中加入自定义“保存”按钮。选择留在页面后再保存；不在卸载时启动无法可靠完成的异步写入。浏览器强制结束、系统断电及没有有效用户交互时不能保证出现提示，提示不代替主动保存或备份。原始 Demo 体验不作为正式工作月份拦截。

## 帮助

顶部“帮助”提供两类内容：

- 快速入门：Work 与独立项目、年月和班次、五类导入、核查分组、保存冻结与备份。
- 专题指南：考勤、请假、出差、外出、加班、人员组别、存储结构、保存与恢复。必要字段、合并及证据、班次边界和各类文件用途按现有实现说明。

支持滚动阅读、键盘焦点循环与 Escape 关闭，关闭回到帮助按钮。全部内容随程序离线打包。

## 验证边界

`tests/r81-audit.cjs` 验证两种临时模式重开、默认 Work 恢复、路径备注持久化及文件名拒绝、帮助专题导航、真实浏览器 beforeunload 的取消离开、保存后不误报、后台月份未保存拦截、本地 HTML 程序目录复制和复制被拒绝的回退。目录持久化使用真实 OPFS/IndexedDB；系统外部目录授权仍不由该测试代替。剪贴板通过隔离捕获验证写入内容，不改动用户系统剪贴板。
