# R96 · 导入规则与设置记忆

版本 0.2.22-preview，schema 6 与 R94 计算口径不变。只修改导入工作台、设置记忆和使用说明。

## 进出规则

左侧仅显示规则序号和关键字，不再内嵌关键字、方向、匹配方式和删除按钮的大表单。点击标题或任一关键字打开宽弹窗，统一增删和编辑全部规则。

弹窗用关键字、进/出、完全匹配/包含关键字进行配置。应用后更新预览并自动记忆；取消、Esc或点击遮罩放弃未应用修改。编辑时底层导入框保持不可操作，Tab在弹窗内循环，关闭后回到原控件。空关键字或重复的同类匹配规则拒绝应用，保留当前有效规则。匹配优先级继续使用完全匹配优先、较长关键字优先，旧有歧义仍拒绝猜测。未知方向不自动补成进或出。

窄栏摘要和批量弹窗均检查 1280、1366、1600、1920 桌面尺寸，不再向右侵入数据预览。只有实际规则超出可用高度时才滚动摘要或弹窗。

## 五类独立设置

考勤、请假、出差、外出、登记加班各有自己的最近设置。修改字段对应、表头、跳过行、CSV编码、日期时间合列/分列和合并/替换方式时自动记忆；考勤规则只属于考勤，不由其他业务覆写。右上角“保留导入设置”可立即执行并报告记忆是否成功。取消导入不改业务记录，但操作偏好保留供下次使用；弹窗内尚未应用的规则不记忆。

本机记忆使用带 schemaVersion 1 的浏览器设置，支持刷新后恢复；不保存业务记录、源文件内容、文件名或导入月份。成功导入也把当前业务配置写入项目 working 的 importProfile.templates，考勤继续兼容旧 importProfile.rules。保存项目后可随项目转移。已有项目设置、本机记忆和会话记忆取最近更新者。

浏览器存储不可用或写满时，当前会话继续记忆，不阻止正常导入；手动保留会明确提示限制，成功导入后仍可把设置随项目保存。新离线目录、更换浏览器或清理站点数据不保证继承原路径的浏览器记忆，可打开已保存项目取得配置。

同列名、同结构直接复用。列重排按唯一列名重对应；表头前的说明行数量改变时，唯一匹配表头可重新定位。缺失、重复列名或其他结构变化会提示核对，并重新推断，不套用旧位置。之前没有进出列、新文件出现进出列时重新识别；同结构显式选“无”仍保留。无表头文件只在列数相同的情况下复用位置。合列/分列切换保留 R95 的起止范围校验和多日处理。

修改编码时暂停提交与保存设置，取消后异步结果不能重新打开导入框；解码失败恢复之前的编码与有效预览。

## 拖放

导入菜单的各业务行可接收 XLSX/CSV 拖放，按对应业务读取最近设置。打开预览后可拖入同类新文件，只替换预览，不提交业务数据；文件读取失败保留旧预览。多文件继续逐个确认，已有队列不被另一次拖放打断。不支持的后缀拒绝且保留现有工作。

## 分发与验证

本轮仅交付普通程序 ZIP；初装完整解压打开 index.html，升级使用右上角导入向导，不需要密码、解包脚本或授权。

`tests/r96-audit.cjs` 纳入完整 smoke，验证弹窗应用/取消、重复/空值、焦点循环、四尺寸防溢出、自动与手动保留、刷新恢复、五类隔离、列重排及表头移动、真实菜单/预览拖放、成功导入携带配置、存储受限回退、编码取消/失败以及规则文本转义。R95 的旧勾选交互改为新的保留按钮，其多日、跨月、Excel、导出重导与几何检查保留。生命周期测试也改用保留按钮，仍核对设置随项目保存及旧版升级的数据字节完整性，新增 R95 实际安装升级及原有请假配置继承。

最终按准确提交的 CI、浏览器截图、本地 ZIP 清单和实际 Windows 接收账户原生解压确认。
