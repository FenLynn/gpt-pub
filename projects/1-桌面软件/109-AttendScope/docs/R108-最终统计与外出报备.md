# R108 · 最终统计与外出报备

版本：0.2.34-preview，工作格式 schema 10。

## 操作与统计口径

| 操作 | 最终统计 | 保留内容 |
|---|---|---|
| 人工将当天改为正常 | 当天不计迟到、早退次数和人日；最终正常人日计入 | 原始诊断、打卡和班内工时；灰色迟到早退标签 |
| 人工正常，但存在红色临时外出 | 红色次数、时长继续统计 | 可以逐段改绿、× 或恢复 |
| 将外出改绿 | 次数、时长保留，红色转绿色 | 原自动判断和处理记录 |
| 自动外出点 × | 排除有效次数、时长与红绿分项 | 自动底稿、原打卡与报备 |
| 自动加班点 × | 排除该自动区间的有效加班 | 自动底稿；独立登记加班仍有效 |
| 删除手工补录 | 移除该补录区间 | 原打卡和导入原件不受影响 |

人工正常并不改写 `attendanceReview` 的各项选择。撤销整日人工判断后，程序恢复按迟到早退的单项选择统计；初始判定按钮沿用原来的恢复功能，会恢复该日单项排除。外出和加班选择不随整日判断改变。左侧初始/人工视图只是显示口径；统计和导出使用最终事实。

## 外出报备与实际统计

Excel 外出只作为覆盖和合规依据。实际次数来自有效自动外出与手工补录；实际时长取这些区间的班内并集。跨午休的上午、下午独立计数，午休不算外出。

- 实际10:00–10:20，报备09:55–10:25：1次、20分钟、绿色，不能相加成50分钟。
- 两条重复报备覆盖同一实际外出：仍是1次、20分钟。
- 对实际外出点 ×：该段统计归零，报备原件不会将其重新计入。
- 只有报备，没有识别或手工补录的实际区间：实际外出为0，原件仍可查。
- “实际外出”和“外出合规”查看的是同一批区间，不能相加为总外出。

报备解释班内缺岗的既有规则继续保留；这次统一的是统计口径。出差、请假覆盖和迟到早退的优先级没有改动。

加班仍按自动、登记、补录有效区间的并集计时，扣除工作日班内时段。若自动19:00–20:00被 ×，但Excel明确登记19:15–19:45，最终仍计30分钟；取消自动并不删除独立登记。

## 升级和冻结

新增 `statisticsRuleVersion`：2为本轮规则，1为旧冻结口径。旧普通工作首次打开迁移为2并标记需要保存；旧冻结与修订保持1，应用规则后才切换。历史报备统计使用“报备外出（历史口径）”标签。

新版配置最低程序版本为0.2.34-preview，新工作格式为schema 10。旧程序会拒绝回写新工作。升级前先下载完整项目ZIP；程序升级包不包含业务数据。

## 验证范围

专项覆盖人工正常与恢复、逐项 ×/✓、红绿独立选择、CSV明细、个人摘要、矩阵筛选、重复报备、仅有报备、时长并集、独立登记加班、旧冻结及真实ZIP重开。

本轮针对统计一致性。先前压力审查中的同秒冲突顺序、下午超两小时晚返漏标、重复出卡缩短外出、无关孤立卡影响早退、午夜陈旧证据仍为待修项，不能视为本轮已解决。测试实际目标以一天50次以内为日常规模；没有新增打卡数量限制。
