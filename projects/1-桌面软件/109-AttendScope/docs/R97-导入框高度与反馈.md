# R97 · 导入框高度与反馈

版本 0.2.23-preview。schema 6、R94 计算口径与 R96 导入配置结构均不变。

导入框在桌面窗口固定占可视高度的 80%。标题和底部确认区保持可见，正文区域在内容超出时独立滚动，不再随字段数量和预览内容改变整个弹窗高度。

全局操作提示提升到导入遮罩之上。“保留导入设置”成功或受限回退的提示不会再处于模糊遮罩后方；提示不接收鼠标事件，不影响弹窗操作。

专项检查覆盖 1280×720、1366×768、1600×900、1920×1080，核对固定高度、正文滚动、标题与底部可见、提示文字、可见区域及层级。普通 ZIP 分发与升级流程不变。
