# R90 · 侧栏、工作日管理与分发包装

版本 0.2.16-preview，数据 schema 仍为 4。仅维护 p109-exp 的 P109 项目。

## 界面与操作

- 全员、分组、个人：顶部月历，其次状态筛选与判定视图，再放组别和人员。内容自然排列，不用空白推到底部；只有超出可用高度才滚动。
- 统计：范围、组别、人员及五个图表筛选均为左标签、右下拉框，每字段一行。
- 左下角固定齿轮与“设置”，浅横线分隔，导航滚动不带走入口；关闭恢复焦点。
- 顶部顺序：导入、导出、项目、帮助、保存，移除原帮助/设置区分隔线。
- 数据管理“项目状态”“数据维护”使用更大、更深的粗体；菜单选中为完整细框，不使用左侧装饰条。
- 迟到早退标签按文字紧凑显示，外侧悬浮 × / ✓，键盘聚焦同样可用；计算与灰色底稿规则不变。
- 外出、加班分别按所在轨道显示 ＋，指针离开隐藏；键盘焦点可独立显示对应按钮。

## 工作日管理

独立入口在数据维护的名册与分组上方。月份选择沿用工作区切月逻辑，创建新月份需确认；取消保留原月。点击日期只多选，按钮批量设为工作日或休息日；全选、清除和普通周末重置可用。

批量修改进入当前月修订、重算与未保存状态，通过顶部保存。其他月份、原始文件和已冻结快照不改写；换月保留内存修改，目录模式需逐月保存，便携模式可以下载所有工作月份。旧日历迁移规则与 R89 一致。

## 可选 Python 包装

正常 ZIP 本身可初装或导入升级。外观包装为单独的 Windows Python 3.8+ 分发包，不增加授权、联网或第三方依赖。

解压到新空目录，在 analysis_toolkit 中运行 `python lib/init.py`。提示为 `please input:`，输入分发说明提供的密码；错误统一 `error input`，成功仅 `done`。脚本为 ASCII，无说明性注释、中文文字或异常堆栈输出。包装密码只在本地说明，不进入公开源码。

正确输入后，在 analysis_toolkit 中新增原文件名的正常升级 ZIP。它是封装时的原始 ZIP 字节，包含正常升级清单，不重新压缩；可以直接在程序导入菜单升级，也能另行解压运行。包装分块与脚本保留，不删除、不原地展开。存在相同 ZIP 时复核后成功返回，存在不同内容时拒绝覆盖。

输出前验证认证标签、包哈希、文件清单和路径；先暂存和读回，最后改名并复核。写入失败保留包装原件；不再需要移动代码文件或删除自身。Windows 限制来自标准库调用系统 CNG；Pages 与正常 HTML 程序不需要 Python 或密码。

正常包构建器按 POSIX 相对路径显式排序，避免 Windows 与 Linux 的大小写排序差异，包内程序与完整性清单逐字节一致；ZIP 容器时间戳不作为跨机器一致性判据。
