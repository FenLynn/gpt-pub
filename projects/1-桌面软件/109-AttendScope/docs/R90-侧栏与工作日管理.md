# R90 · 侧栏、工作日管理与分发包装

版本 0.2.16-preview，数据 schema 仍为 4。仅维护 p109-exp 的 P109 项目。

## 界面与操作

- 全员、分组、个人：顶部月历，其次状态筛选与判定视图，再放组别和人员。内容自然排列，不用空白推到底部；只有超出可用高度才滚动。
- 统计：范围、组别、人员及五个图表筛选均为左标签、右下拉框，每字段一行。
- 左下角固定齿轮与“设置”，浅横线分隔，导航滚动不带走入口；关闭恢复焦点。
- 顶部顺序：导入、导出、项目、帮助、保存，移除原帮助/设置区分隔线。
- 数据管理“项目状态”“数据维护”使用更大、更深的粗体；菜单选中为完整细框，不使用左侧装饰条。
- 迟到早退标签按文字紧凑显示，外侧悬浮 × / ✓，键盘聚焦同样可用；计算与灰色底稿规则不变。
- 外出、加班分别按所在轨道显示 ＋，指针离开隐藏；键盘焦点可独立显示对应按钮。

## 工作日管理

独立入口在数据维护的名册与分组上方。月份选择沿用工作区切月逻辑，创建新月份需确认；取消保留原月。点击日期只多选，按钮批量设为工作日或休息日；全选、清除和普通周末重置可用。

批量修改进入当前月修订、重算与未保存状态，通过顶部保存。其他月份、原始文件和已冻结快照不改写；换月保留内存修改，目录模式需逐月保存，便携模式可以下载所有工作月份。旧日历迁移规则与 R89 一致。

## 分发方式（后续修订）

正常 ZIP 本身可初装或导入升级。R90 曾实现的 Python 包装已按后续决定完全取消，工具与对应测试已经删除。正常包构建器按 POSIX 相对路径显式排序，包内程序与完整性清单逐文件一致；ZIP 容器时间戳不作为跨机器一致性判据。
