# R101 · ZIP 兼容、班末容差与周期使用门槛

版本：0.2.27-preview；数据 schema 7，分析引擎 R94。

## 兼容降级

- 完整项目包继续由程序统一生成并校验。打开项目包同时兼容无压缩 ZIP 与普通 Deflate ZIP，并允许压缩工具额外套一层目录。
- 每个文件仍核对中央目录、解压长度、CRC32 和项目清单 SHA-256；拒绝分卷、加密、ZIP64、异常路径、重复路径及超过 180 MB 的解压内容。
- 启动前增加旧内核能力检查。缺少现代语法或核心浏览器 API 时显示明确提示，避免只有空白页或无法解释的按钮失效。
- 下载 API 不可用时，救援操作改为显示可全选、复制的 JSON 文本。它只保留已载入工作状态，不冒充含原件的完整项目包。

## 班末短时往返

上午和下午使用同一规则。班末前的最后一次出卡若在“临时外出限额 + 冗余”内重新进场，则不因跨过班末而直接判早退；之后再次出场也不改变这一结论。

默认 10 + 2 分钟时：11:38 出、11:42 进、11:43 出不判上午早退；11:38 出、12:00 进仍判上午早退。下午班末采用相同判断。阈值直接复用考勤规则中的临时外出限额和冗余，没有新增隐含参数。

## 周期使用门槛

- 直接打开本地 `index.html` 时，新环境进入 Demo 或 Work 后，未启用状态拦截业务交互；设置入口保留弱反馈与恢复路径。HTTP/HTTPS 静态托管用于公开测试，不启用这道本机门槛。
- 设置入口连续触发五次可进入高级设置，版本号连续触发五次打开状态窗口。
- 首次校验只在浏览器本机保存通过状态与截止时间；版本号变绿表示当前周期有效。
- 周期为七天。到期后保留已校验状态，必须由使用者再次进入状态窗口手动刷新七天；可随时撤销并回到未启用状态。
- 程序只保存校验摘要，不保存明文口令。该机制定位为轻量使用门槛，不能阻止能修改源码或浏览器存储的人绕过，也不承担数据加密或正式许可证职责。

## 容量边界

便携保存当前仍缓存完整项目包，并保留上一份有效缓存用于损坏回退，因此浏览器占用约为完整项目包的两倍，保存瞬间还需要额外工作内存。完整项目包的读取上限保持 180 MB。

长期使用建议按年度或组织周期新建项目，把已结束项目下载为带时间戳的完整 ZIP 后归档；日常只在当前项目保留仍需联动核查的月份。后续若实际项目接近 100 MB，宜单独实施按内容哈希分块的缓存格式：当前/上一快照只保存清单，相同原件共用一个 blob，并在无快照引用后回收。外部下载的完整项目 ZIP 格式无需改变。该迁移不与本轮兼容和业务规则修改混做，以免临近投入使用时扩大存储风险。
