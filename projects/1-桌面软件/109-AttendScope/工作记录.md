## 2026-10-15 UI 第二轮重构

- 取消“右侧统计 + 页面底部时间轴”的双详情结构。
- 右侧改为统一分析台：概览 / 时间轴 / 统计 / 记录。
- 点击日期或方块会自动进入正确时间轴上下文，不再滚动到页面下方。
- 单人时间轴改为“进 / 在岗 / 出”三轨，工作时段淡背景、确认在岗细轨、未配对记录黄色证据点。
- 全员单日时间轴改为紧凑多行轨道，点击任一人员行直接进入个人当天。
- 图表和时间轴现在共享同一上下文区域，统计图可反向定位矩阵。
