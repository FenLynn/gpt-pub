# AttendScope 设计与演进

## D-01｜工作台以状态矩阵为核心

**决策：** 主界面采用顶部单行标题栏、左侧月历与配置状态、中央“人员横向 × 日期纵向”矩阵，矩阵下方为上下文详情。

**原因：** 约 50–100 人、单月最多 31 日时，日期纵向高度可控；宽屏可以把大量人员横向比较。点击人名进入个人月度统计，点击日期进入单日全员时间轴，点击格子进入个人当天时间轴和原始记录。

## D-02｜三色严重度与业务角标分离

**决策：** 绿色=无明确问题；黄色=疑似/数据完整性异常；红色=明确考勤问题。请假、出差不另占严重度颜色，用“假/差”角标或解释状态表达。休息日采用中性灰，非工作日出勤采用独立提示色。

**原因：** 避免把“多进一出”等无法凭三列数据定性的情况误判为纪律问题，同时仍能快速发现需要人工核实的点。

## D-03｜保存、冻结、历史修订采用不同空间

**决策：** working 可持续保存；snapshot 不可变；从 snapshot 修订时创建隔离 branch，修订完成再冻结并返回主工作区。

**原因：** 确保历史月份被冻结后不会受后续全局班次、名册和规则变化影响，同时仍允许可追溯地修订历史月份。

## D-04｜三类 Excel 独立导入

**决策：** 考勤、请假、出差分别导入，保持各自事实边界。当前预览自带 50 人模拟数据和最小 XLSX 读写能力。

**原因：** 请假和出差是业务事实，不应混入原始打卡或人工 revisions；它们在分析阶段覆盖对应应出勤义务。


## D-05｜时间轴采用证据优先的微动效

**决策：** 单人单日时间轴采用中央时间基线，进入事件向上、离开事件向下；工作时段只作为极淡背景窗，可确认在岗区间只使用细轨表达。疑似与异常不靠持续闪烁提醒，而靠矩阵严重度、事件选择态和问题摘要表达。

**动效规则：**

- 首次展开：工作窗淡入，确认在岗轨迹从左向右生长，打卡点按时间轻微错峰浮现。
- 选择打卡：选中点轻微放大，精确时间游标平滑滑到该时刻，原始记录同步高亮并淡入详情。
- 缩放：不重建详情 DOM，只平滑改变时间轴宽度；Ctrl/Cmd + 滚轮围绕鼠标位置缩放，按钮缩放围绕视口中心。
- 平移：放大后可拖动空白区域平移；双击空白区域恢复 100%。
- 全员单日视图：保持低高度行轨，只显示工作窗、在岗细轨和进出节点，悬停再强调。
- 禁止常驻闪烁、无限脉冲和装饰性循环动画。动画必须帮助理解状态变化或空间关系。
- 尊重 `prefers-reduced-motion`，用户要求减少动态时退化为静态界面。

**视觉来源：** 对齐 DavBridge v0.4.25 的 quiet / soft / panel surface 层级和 LocalSub v0.1.24 的“简洁清晰、空间给主内容、小字进 tooltip”原则，不复制其具体业务布局。


## D-06｜矩阵与分析台分工，取消双详情区

**决策：** 主工作区只保留两个职责明确的区域：左侧月度状态矩阵用于“发现”，右侧统一分析台用于“解释”。统计图、时间轴、原始记录和人工处理不再分别放在右栏与页面底部，而统一进入同一个分析台，通过“概览 / 时间轴 / 统计 / 记录”切换。

**交互：**

- 点击姓名：分析台进入个人月度概览。
- 点击日期：分析台自动进入该日全员时间轴。
- 点击状态方块：分析台自动进入该人当天时间轴。
- 点击打卡点：不跳页面，只在同一分析台内显示精确时间与原始来源。
- 统计图中的日期或条目可以反向定位矩阵。

**原因：** 避免矩阵、右侧统计和底部时间轴形成三个竞争焦点，减少视线大跨度跳转。

## D-07｜时间轴改为固定语义日程轨

**决策：** 放弃“中央粗基线 + 上下浮动标签 + 多层弹跳动画”的时间轴。单人单日时间轴固定为三条语义轨：“进 / 在岗 / 出”。工作时段仅作为淡背景，在岗区间使用细蓝灰条，进出记录使用小节点。只有节点被悬停或选中时才显示时间。

**证据原则：**

- 已成功配对的进出记录才形成在岗区间。
- 未配对记录不推断持续时间，只用黄色描边节点标识“记录完整性需核实”。
- 原始文件、Sheet、行号和 Record ID 只在用户选择具体记录后展开。
- 动画只用于位置与状态过渡，不做常驻闪烁、循环脉冲或大幅弹跳。

**参考：** 时间组织参考 Apple Calendar 日视图的稳定时间尺度和低视觉噪声，视觉层级继续遵循 DavBridge / LocalSub 的 quiet surface 原则。

## D-08｜MATQ 风格的统一视觉设计基线

**决策：** 以 MATQ 的信息层级和可视化图形质感为主，DavBridge 的浅蓝灰柔和表面为辅，LocalSub 的一致控件与桌面交互为规范。参考设计不引入外部运行依赖。P109 仍为可直接打开的离线 HTML。

- 46 px 单行全局工具栏，左侧 2026 年 10 月月历和项目事实，中间紧凑固定 31 列矩阵，右侧统一分析工作台。
- 矩阵宽度不因窗口拉伸。四个业务状态使用绿（正常）、黄（疑似）、红（确定问题）、浅蓝（非工作日出勤）。休息日是中性底色，不能错误表达成第五种业务状态。
- 右侧的每种选中上下文都具有明确目的：全月摘要/异常及趋势、个人月度摘要及趋势、单日全员时间轴及分布、单人单日的关键时间/双轴/打卡证据/异常解释/人工处理。
- 单人双时间轴保留本地 ECharts custom series 与 dataZoom，时间线中“进”向上、“出”向下；全局导航调节局部窗口，聚合记录可以随缩放拆分。首尾箭杆禁用 SVG 滤镜，避免 Chrome 裁剪。
- 四个时段数据遵循同一 daily facts，不得通过仅为了 UI 好看而伪造在岗时间。
- 离线浏览器 CI 在 1920×1080、1600×900、1366×768 检查四种上下文和截图，视觉交付不能只依据 node 语法检查或图表 DOM 存在判定。
- 展示用模拟数据需可复现但不能形成明显人为规律，如非工作日加班的斜线排列。


## D-10｜矩阵整行/整列焦点与上图下表

MATQ 式高密度矩阵为分析入口；姓名、日期与单元格三种选中上下文分别形成整行、整列和交叉焦点发光。颜色语义仍只属于正常、待核实、明确异常、非工作日出勤；假期和姓名采用低对比底色而非新的严重度颜色。

右侧上部在同一容器中采用约 3:1 图表/事实摘要，下部独立原始记录 Tabulator 工作台，提供考勤/请假/出差三种类别。表格直接从导入或演示的 raw arrays 取得数据，且仅按当前人/日/单元格条件过滤；上下两个层级不互相计算数据。可在表格里定位打卡原始来源，不允许编辑原始数据。引用 Tabulator 6.3.1 MIT 官方产物并本地打包，网络禁止仍以应用层静态守卫和真正 file:// 浏览器测试共同验证。


## D-11｜月份为工作空间；图表与证据分层；固定矩阵二维定位

月份位于顶栏，支持尚无记录月份创建空白工作区。切月前先保留当前月内存数据，创建不复制上月数据。完整 working JSON 与冻结快照都带 year/month 并收录原始规范化记录及人员组别；组别独立于部门。顶部操作须与月份同域，不得保留左栏重复月份选择。

矩阵表头 sticky top、姓名 sticky left、左上角 sticky 双轴。选中整行和整列需一条连续外框与光晕，选择单个单元时淡化两轴框、单格放大浮起。工作日历日期表头不得以大面积假期底色掩盖数字。

右侧唯一面板只有标题、图表/数据的左右隔线和原始数据的水平隔线。图表有总览、时间轴、统计、异常四选项，右侧指标从当前图表状态推导，人员默认月度总览；切至时间轴优先展示最近有记录的日期。原始 Tabulator 不参与计算或修改源事实，保持顶部分页、自适应隐藏低优先级列、悬浮窗口拖动/缩放/停靠的联动。严格离线、共享 Pages 同时保留 P108。


## D-12 R13｜专业矩阵与分类工作流
默认矩阵只突出正常（绿）、缺勤（黄）、异常（红）。其他加班、请假、出差、外出各具独立业务颜色，紫色专供人员/日期/单格选择。CSS 统一连续框层而不是对每一格染底。点击日期时，如果已经定位某个人，无论当前图表 Tab 为何，都继续保留人员视角；点击“全部”清除所有选择。筛选器不破坏底层事实，使用 opacity/scale 过渡。

时间轴默认箭头朝向事件基线（设置可切换），独立小型全天打卡事件缩略图，0:00/24:00 两端固定，选中区深灰、其余浅灰；缩放联动；个人每日在岗折线每个状态点独立配色。原始 Tabulator 去除分页并保留本地虚拟滚动，追加 outing/overtime 空接口，只读不参与目前已验收的出勤计算。工作规则、字号、动态效果和箭头方向纳入当前月份 working 与冻结快照。所有功能严格离线，暂为预览。
