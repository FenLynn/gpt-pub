# AttendScope

P109 AttendScope 是一个面向月度考勤核查的纯离线 HTML 工作台。核心交互是“人员 × 日期状态矩阵 → 人员/月、日期/全员、单元格/个人当天”三级下钻，并在单人单日视图追溯到原始打卡记录。

## 当前入口

- 当前工作：[工作记录](工作记录.md)
- 当前基线：[阶段记录](阶段记录.md)
- 长期规则：[开发约束](开发约束.md)
- 设计原因：[设计与演进](设计与演进.md)

## 运行

直接双击 `index.html`。运行时不使用 CDN、不请求网络、不依赖 Node/Python/MATLAB。

推荐 Windows + 最新 Chrome/Edge。浏览器支持 File System Access API 时，可通过“连接项目目录”把原始导入文件、working 状态和冻结快照写入用户选择的本地目录；不支持时退化为下载 JSON 保存。

GitHub Pages 只用于静态预览，不改变离线运行能力。

## 当前演示

默认生成 50 名虚构员工的 2026 年 10 月模拟数据，覆盖正常、迟到、早退、全天缺勤、多进一出、一进多出、连续同向、漏刷、短间隔重复刷卡、午间长时间外出、非工作日出勤、半天/全天请假和单日/多日出差。

2026 年 10 月工作日历示例采用国务院 2026 年国庆安排：10 月 1–7 日放假调休，10 月 10 日上班。

## 数据导入

三类文件独立导入：

1. 考勤 `.xlsx/.csv`：`姓名 / 打卡时间 / 进出`
2. 请假 `.xlsx/.csv`：`姓名 / 日期 / 开始时间 / 结束时间 / 类型 / 备注`
3. 出差 `.xlsx/.csv`：`姓名 / 开始日期 / 结束日期 / 类型 / 地点 / 备注`

页面可以直接生成三类模拟 XLSX 文件，再重新导入验证。

## 输出

- “导出表格”生成一个纯传统 XLSX：一人一天一行，不包含图。
- “打印 / PDF”使用浏览器打印样式输出当前可视化视图。
- 可视化、时间轴、传统表格都读取同一份分析事实层。

## 工程结构

```text
index.html
project.json
src/
  core/xlsx-lite.js
  app/
    00-state.js
    10-analysis.js
    20-shell.js
    30-detail.js
    40-storage.js
  css/app.css
config/
data/
```

`xlsx-lite.js` 是项目内的最小离线 XLSX/CSV 读写器，不依赖在线库。XLSX 读取需要现代浏览器的 `DecompressionStream('deflate-raw')`；项目自身生成的 XLSX 使用无压缩 ZIP，可直接读取。

## 2026-10-16 最新交互

顶部按月份切换或新建空白工作空间，导入、目录、保存和冻结均按月操作。左栏为放大月历、当前月信息和状态筛选。中部固定日期表头及姓名列，支持整行/整列发光框和单格浮起。右侧采用无内部卡片的分析工作台，提供总览、时间轴、统计、异常四个图表标签，右上数值随图表变化。原始 Tabulator 表格始终保持独立，顶部可分页、调整每页条数并弹出可拖动、可缩放窗口。每位员工独立于部门拥有可编辑组别。

新建月份默认零条原始记录，不从演示月复制数据。保存写入 `data/YYYY/MM/working/state.json` 并包含当月规范化打卡、请假、出差、组别及修订。冻结写入对应月份快照；选择已存在的项目目录可恢复已保存的月度数据。没有目录权限时仍退化为下载对应月份 JSON。请勿把真实考勤数据提交到公共仓库。
