# 考勤 · AttendScope

P109，当前版本 **0.2.32-preview / R106**。纯离线月度考勤核查工作台，支持人员 × 日期矩阵、个人六轨时间轴、分组统计、原始证据追溯和人工判定。直接打开 `index.html`，无需安装运行环境、服务器或联网。

## 首次使用

1. 将完整离线 ZIP 解压到长期使用的文件夹，用 Chrome、Edge 或 360 极速模式打开其中的 `index.html`。
2. 没有默认工作项目时，每次打开选择 **Demo · 体验** 或 **Work · 工作**；有默认 Work 项目则尝试恢复。Work 可新建空白项目或连接已有项目；新建时，在浏览器中选择独立的空白数据文件夹并授权读写。程序文件夹只放 index.html、src 和程序说明；每个项目使用自己的 project.json、config、data。新建项目不能选择程序目录。
3. 初始化建立空名册、本月 working 与配置，演示员工不会进入新项目。无法授权目录时，选择 **Work → 新建便携项目**；已有完整项目 ZIP 可直接打开，无需先恢复到目录。便携模式点保存将整个项目（含原件）写入本机浏览器缓存，成功读回校验后才解除未保存提醒；下次打开同一程序和浏览器可自动恢复。项目 → 下载项目包 ZIP 可另存独立磁盘备份，文件名包含本地日期、时分秒和毫秒。
4. 选择或创建月份，通过 **导入** 分别载入五类数据；可多选文件，逐个核对后默认合并，后一个保留前一个文件的数据。预览会显示目标月份、文件日期范围和必要字段，并自动完成业务校验。选错月份时可直接改为文件的主要月份，确认前不会切换或修改工作区。
5. 检查矩阵、时间轴和原始证据，必要时人工改判，然后点击顶部醒目的 **保存**。阶段完成后执行 **项目 → 冻结当前月**，并定期执行 **项目 → 完整项目备份 ZIP**。

首次进入 Work 时连接一次已有数据目录，此后程序在当前浏览器的 IndexedDB 中记住授权的目录和上次项目。重新打开 index.html 时，若读写权限仍有效便自动载入上次已保存的项目；需要授权时显示“继续打开”，点击即可重新授权，无需寻找目录。主页左上角保留当前项目名，点击可浏览项目真实文件。**数据管理 → 存储与文件 → 目录位置**集中显示项目目录和程序目录，并提供文件夹级路径复制，不包含入口文件名；主页面不再常驻路径栏或路径页脚。项目绝对路径无法从浏览器取得，可手动记录后复制，明确标注来源。**项目 → 最近项目**可直接切换，**管理已打开的项目**支持改显示名称、移除历史记录。同名文件夹按实际目录区分，移除历史不会删除数据。

项目历史属于当前浏览器配置；清理浏览器站点数据或换浏览器后需重新选择目录，磁盘业务文件不受影响。移除当前项目记录不会清空当前页面、目录文件或便携缓存，但会立即取消下次自动载入；继续保存也不会静默重新启用。刷新或下次打开回到 Demo / Work 选择，Work 中可手动恢复上次本机缓存；需要时也可在项目管理中明确恢复当前项目的自动载入。取消、目录失效或连接失败保留当前工作；切换项目有未保存月份时会提示。旧版代码与数据放在同一目录的项目仍可连接，新版不自动搬动其文件。

## 关闭保护与使用帮助

工作月份有未保存修改，或便携项目有未保存到缓存的文件变化时，关闭或刷新触发浏览器离开确认；选择留在页面，再保存。目录模式的保存只处理当前月；便携模式一次缓存所有工作月份及完整原件。浏览器强退或断电不能保证提示，不在卸载时启动异步保存。

顶部“帮助”提供 **8 章快速入门 + 12 个专题**：从新建独立项目、第一笔导入、核查与分组，到保存、冻结、重开和下月继续；专题覆盖五类业务、统计、人员、存储、备份恢复、导出与排错。每章包含具体步骤、字段/示例、结果核对和常见错误，附真实程序截图，以及五类按当前月份生成的虚构练习 CSV。首次模式选择页也可先看教程。

教程支持全文搜索、章内目录、前后章节、返回阅读位置和离线文字版下载；阅读不会修改业务数据。帮助和数据量较大的弹窗按桌面窗口约 86% 宽展示，实际内容超出后才在对应区域滚动。矩阵随有效人数伸展，未填满可用高度时不出现多余竖向滚动。

目录路径备注只在本机浏览器中记录，不进入业务 JSON 或项目备份；禁止自动复制时提供 Ctrl+C 手动复制。最新操作调整和隔夜加班验收见 [R83 项目操作与隔夜加班验收](docs/R83-项目操作与隔夜加班验收.md)；详细教程改造见 [R82 说明](docs/R82-详细教程与布局整改.md)。

## 操作入口

| 操作 | 作用 |
|---|---|
| 导入 | 五类业务 XLS/XLSX/CSV、空白模板，以及独立的“程序升级 ZIP”向导 |
| 项目 | 最近项目、连接目录、初始化、便携项目新建/打开/下载、项目管理与修订、冻结、恢复与备份 |
| 保存（顶部蓝色强调按钮） | 目录模式更新当前 working 并保留上一个有效版本；便携或无目录 Work 将完整项目写入本机缓存，下载项目包为独立操作 |
| 项目 → 冻结当前月 | 创建唯一、不可覆盖的快照，与保存和完整备份分别独立 |
| 导出 | 当前统计或全月明细 XLSX/CSV、当前视图 PNG、已选截图 PDF、五类当前原始数据 XLSX |

统计页的“当前统计 XLSX/CSV”共用字段和范围：月份、统计范围、对象、业务、指标、统计方式、数值、单位、员工数、应出勤人日。榜单数量不截断导出。另有明确命名的“全月考勤明细 XLSX”。非统计页的“全月考勤明细”按整个月份输出，不冒充当前人员/日期筛选结果。

CSV 使用 UTF-8 BOM、引号及换行转义和文本公式防护，真正数值保留数值形式。XLSX 文本按字符串写入。“空白模板”不读取当前工作数据；导出已有记录请用“导出当前原始数据”。

## 工作区

请假、登记加班、外出导入均支持连续多日的开始/结束日期时间。两端各自选择“日期 / 时间分列”或“日期时间同列”，允许混用。支持常见年月日分隔符、中文日期、八位年月日、Excel 1900/1904 日期序号及小数时刻，保留秒；有歧义的日月顺序会拒绝并提示改为 YYYY-MM-DD。出差仍按整天范围，包含结束日。

导入窗口将目标月份与文件日期放在标题同一行，左侧窄栏逐行显示标题和下拉，右侧默认显示可读的识别结果，可切回原始表格。跨日连续范围按自然日拆段，只保存目标月份的交集；跨月需分别导入相关月份。底部区分源记录条数与日段数。旧版单日模板及已有工作文件不变；旧版仅有一个日期的跨夜加班继续兼容，新模板明确填写结束日期。多天每天重复同一时段应逐日写行。导出规范数据按日段给出明确起止日期，可再次导入；原始文件及行号仍可回溯。

- 全员/分组：矩阵发现问题，人员、日期、单元格分别定位与下钻，“清除选择”重置定位。
- 个人：默认月度全览，日期条进入单日六轨时间轴，前后日按钮切日；“返回全览”和“个人全览”共用同一状态入口。
- 统计：范围、业务、指标、对比、统计方式、榜单控制统计，不再显示无效月历；导出集中在顶部。
- 数据管理：项目概况、月份库存、健康、存储、工作日管理、名册、规则、模板、原始记录、导入历史、冻结与修订。工作日管理在名册上方，年份左右增减、月份下拉，多选后设为工作日或休息日，点击页面内“确认保存当月”。日历独立存于浏览器，不要求项目或业务月份；支持全年预设、导入导出与受限存储下载回退。确认后同步已载入的同月普通工作数据，冻结与修订保留原安排。原始记录包含“导入原件”和“合并数据”；只有后者显示日期过滤。原件可浏览、下载，文件树和库存数量提供真实目录入口。

全员、分组和个人左侧按月历、筛选、组别、人员顺序排列；统计筛选为左侧标签、右侧下拉框，每个字段一行。所有工作区左下角固定齿轮“设置”，与上方内容用浅横线分开。顶部操作依次为导入、导出、项目、帮助、保存。数据管理大标题加深加粗，当前菜单使用完整细框高亮。

人员分组用勾选和批量加入组别，支持跨搜索连续选择；完成后清空选择，保留目标组别与滚动位置，便于下一批继续加入。长期固定人员用双栏勾选和中间左右箭头管理。“保存下月默认名册”只保存已选固定人员及组别，不会自动固定当前所有人。

## 临时外出与手工补录

同一人员、同一日按时间排序，最近相邻的“出 → 进”生成临时外出。只计算工作日班次内部分，午休和下班后排除；跨午休拆成上午和下午两次，分别按各自班内时长判色、改判或排除。未知方向打断配对，没有返回进卡或跨日间隔不凭空推算。对自动区间，若完整在岗配对的终出卡位于班末之前、返回已在该班次结束后，且这一班次的离岗时长严格小于短时限额与冗余之和，不重复计临时外出。这也适用于跨午休的上午段，且不依赖早退标签是否已被报备豁免；班中往返、未配对出卡和明确手工补录仍保留。

**出差、请假优先：先从班内缺岗扣除出差/请假覆盖，只核查未覆盖部分。** 出差按日期范围覆盖全天；请假按当日起止时间，重叠或相接记录先取并集。10:00–11:00请假，10:10出、10:50进无需处理；09:50出、11:10进，仅前后各10分钟分别按红绿判断。两侧均15分钟时分别红色，可单独改判或排除；跨午休仍按班次分别处理。请假延后走、提前回都不算异常。对于覆盖班首/班末的假期，实际首进晚于结束、实际末出早于开始时，也核查未覆盖边缘；没有真实卡和已闭合证据时不凭空推断。外出报备继续作为未覆盖临时外出的绿色依据，完全覆盖时人工红色不盖过报备。原件和历史选择保留。

**短时限额默认 10 分钟、冗余默认 2 分钟，均可在考勤规则里修改，冗余可设为 0。** 未完全被报备覆盖的班内时长不超过限额加冗余为绿；超过时，外出报备须覆盖班内外出（起止各容许冗余），或与实际区间确有重叠且班内时长差不超过冗余。否则为红。报备重叠先合并去重，无关报备不累加充当配额。

外出轨道底层保留蓝色 Excel 报备，上层绘制半透明红绿色块，底部仍可辨认报备。悬停临时外出出现红点、绿点和 ×；未被报备完全覆盖时可人工指定颜色，完全覆盖时红色按钮禁用并解释原因。自动区间点 × 从统计排除并保留灰色虚线证据，右侧“区间明细”弹窗可恢复自动；手工区间点 × 直接删除本次补录、颜色选择和相关工作修订，不留虚线色块。该红绿与每日考勤判定独立，已冻结文件与原始 Excel 不改写。

个人单日右侧显示临时外出红绿次数及班内时长，主页左下不再显示临时卡片。状态筛选保留“临时外出”；统计分析提供次数、红绿次数、班内时长和人数，明细 XLSX/CSV 使用同一口径。主页右侧四个总量单行展示，趋势采用空心数据点和渐变阴影，组别排行条加粗。

悬停时间轴，**外出、加班文字左侧的 ＋**可选择起止时间补录，轨道文字保持统一右对齐。临时外出须同日且与班次相交，按相同规则判断；补录本身不是报备。与已有临时外出重叠时先排除原自动区间或删除原补录再添加，避免重复。补录加班支持跨夜且不受自动候选门槛限制，与登记及自动区间扣重；手工加班 × 直接删除，自动加班 × / ✓ 控制统计纳入。删除补录后下方真实的自动候选会重新显现，不代表加班合计必然归零。跨月补录从次日删除时，开始月份同样标为未保存，应一并保存或下载新完整项目包。

R106 的月度 working、冻结和项目索引采用 **schema 8**，新增午夜推算、区间独立核算、超长在岗确认和班末密集打卡保护口径，读取 schema 2/3/4/5/6/7。旧普通月份更新后重算并标为未保存；旧冻结及其修订保留原口径，在独立副本的考勤规则页应用后才切换。升级包兼容 schema 2/3/4/5/6/7/8；R105 及更早程序拒绝 schema 8，防止旧引擎回写改变结果。原始文件、旧冻结和既有人工选择保留。独立日历仍为 schema 1；升级前保存并保留完整项目备份。

R106：若当天第一张为凌晨出卡，优先衔接前一天真实进卡；无法衔接时，默认允许将 00:00 至该出卡作为“午夜推算加班”，默认截止 06:00，开关和截止时间可在设置调整。不会生成虚构原始进卡，多张出卡只取第一张，近午夜重复出卡不扩充时长，推算区间仍可 × 排除、✓ 恢复。完整加班区间独立计算，一条缺卡或重复卡不再取消当天其他完整区间。连续在岗默认超过 16 小时需通过加班色块右侧 ✓ 确认后才计入，待核阈值可调为 1–36 小时；确认和排除跨日生效并随保存保留。班末短时出入与同一短窗口内跨下班点的重复出卡共用“临时外出限额＋冗余”保护，默认 12 分钟，超时、未知方向或一直未返的真正早退仍保留。详见 [R106 说明](docs/R106-午夜推算与班末保护.md)。

个人单日的迟到、早退标签悬停可点 × 排除，变灰留底；✓ 恢复。各班次标签独立处理，统计、筛选和导出共用纳入后的事实；原始打卡、工时、冻结文件不变。初始诊断保留，最终判定仍受其他问题和人工日判定影响。右侧用横线分为判定、四项指标一行、四类业务两列排列、临时外出、所选打卡来源五块，取消额外标题，不在概况内滚动；区间明细在单独弹窗完整列出。

时间轴默认 **08:00–20:00**。有效打卡或加班区间超出时，向外扩展至最早前 30 分钟、最晚后 30 分钟，保留区间另一端的默认范围，并限制在当天 00:00–24:00。隔夜按自然日切片，凌晨及夜间加班不裁掉。图表右上角的＋、−与重置仅在鼠标进入时间轴区域时显示，键盘聚焦也可显示，触屏保持可用；重置图标恢复本日初始范围，不修改数据或所选证据。滚轮、缩放条及新增的 ＋/− 可放大至 **10 秒跨度**；10 分钟以内显示秒级刻度，打卡按实际像素间距解聚合，不再限制为最少 15 分钟或强制合并 27 秒内的卡。

Demo 的“极端测试组”含 10 人，仍为总计 50 人的虚构演示。个人名称提示场景，覆盖隔夜与登记扣重、门槛差 1 秒、11:39 连刷至 11:40:30 正常终卡、报备优先、缺卡未知、60 段密集外出及宽幅范围。R93 增补扣除缓冲后恰好 5 分钟、少 1 秒、多 1 秒，以及跨午夜 5 分钟案例；普通对照日按班次开始进入，避免额外班前加班干扰。只在 Demo 中生成，Work 空项目不注入演示记录。

## 自动加班三参数

在 **设置 → 考勤规则** 修改，应用后重算本月，保存后保留。班后、班前分别支持 0–240 分钟，最低时长支持 1–240 分钟。

| 参数 | 默认 | 计算方式 |
|---|---|---|
| 班后不计时长 | 20 分钟 | 从每班下班时刻扣除，默认午间 12:00、晚间 17:30 后才累计 |
| 班前起算门槛 | 5 分钟 | 提前达到门槛后计完整提前时长，不扣除这 5 分钟 |
| 最低加班时长 | 5 分钟 | 连续有效区间达到才计入，恰好达到也计入；不同区间不拼凑 |

默认示例：12:10 下班计 10 分钟，17:36 下班计 6 分钟；17:35 恰好计 5 分钟，17:34:59 不计。08:24 上班计 6 分钟，08:25 计 5 分钟，08:26 不计。连续在岗跨午休也计算加班：08:30 进、17:10 出且无午间出进，计 12:00–13:30 共 90 分钟。休息日完整进出只判断最低时长；前一工作日尚未结束的班后缓冲仍须扣完，即使跨午夜也不提前失效。

23:50–次日 00:10 是连续 20 分钟，先整体达标再按日各计 10 分钟；23:58–00:03 先整体达到 5 分钟，再计 2＋3 分钟。跨月优先使用已载入的开始月份规则；未载入开始月份时使用当前月规则，核查前应载入相邻月份。新冻结捕获相邻月规则，后续默认设置改变不追改其口径。跨工作时段隔开的两个 4 分钟不拼成 8 分钟，两个独立 4 分钟进出也不拼凑。

**工作日班内时间不能计加班，无论自动、登记还是手工补录。** 所有来源先扣除实际工作日的上午、下午班次，再按时间并集统计，包含和交错重叠均只算一次。全天出差不阻止有证据的晚间19:00–22:00加班；请假也不把班内时段变成加班。登记/补录与班次冲突时，加班行显示提示，悬停查看已扣分钟，原件保留；全处于班内的手工新增会被拒绝。正常午休位于班次之外，连续在岗仍按三参数计算。自动班后缓冲和最低值不裁剪明确登记/补录的班外时段。

最低时长先作用于完整有效区间，再扣除登记或补录重叠，不能对残余片段反复套门槛。登记及明确手工补录按自身时段保留，不受自动缓冲门槛裁剪；统计仍合并去重，自动 ×/✓ 与跨日共享会话选择保留。

每月只分工作/休息。新月默认周一至周五工作、周末休息，在 **数据管理 → 工作规则 → 工作与休息日**逐日调整，应用后保存。旧月保留升级前的有效安排，不静默重算成普通周末。日期蓝点表示纳入的迟到早退，灰色空心点表示排除底稿，粉点表示推算/补录加班。

交付统一采用普通程序 ZIP，同一包用于初装、离线使用和程序内升级；离线与静态托管保持同一源码。

## 多文件与可选字段

五类业务的导入设置分别自动保留：字段对应、表头/跳过行、CSV编码、日期时间模式及合并/替换方式。考勤进出规则独立，左侧只显示序号和关键字，点击后在弹窗统一编辑；应用才生效，取消不改当前规则。右上角“保留导入设置”可随时确认保留。取消导入不修改业务记录，已调整的导入偏好仍可供下次使用。

当前浏览器自动记忆最近设置，成功导入也写入项目working，保存项目后可携带到其他环境。目标月份与原始数据不进入本机设置。列顺序变化按唯一列名重对应，表头移动可定位，结构变化会提示核对；无表头只在列数一致时按位置复用。浏览器禁止记忆时回退到当前会话，并在手动保留时提示。可以把 XLS、XLSX、CSV 拖到导入菜单对应业务行，或拖入已打开的同类预览；导入仍需核对并确认。R99 随程序离线携带 SheetJS 0.20.3 完整解析器，压缩 XLSX 不再依赖浏览器的 `DecompressionStream('deflate-raw')`，并支持 Excel 97–2003 `.xls`。R100 会列出工作簿的全部 Sheet，可选择单张或合并全部非空且表头一致的 Sheet；结构不同的说明页会隔离并提示。加密工作簿仍不支持。

五类数据默认追加合并，跨文件重合按业务字段核对，同一文件内的重复打卡仍保留。重合记录保留每个来源文件、工作表和行号，原记录 ID 不变；每次导入的原件独立保存，不覆盖旧原件。合并数据里的文件名可点击查看来源，多个来源可展开。更多选项中的“替换本月此类数据”需要确认，历史原件与其他类型保留。

类型、地点、备注和进出方向等可选字段可选“无”；姓名与业务必要的日期/时间须有效。结束日期可省略为开始日期，请假起止时刻可使用班次边界。无进出方向的考勤标为“未标注 / 待核”，不推断方向或跨这些点组成在岗、加班会话。非空但无效的日期/时刻必须修正。

原件浏览器支持 CSV/XLS/XLSX 分页表格及 JSON/文本，不执行 HTML 或脚本。文件夹在页面内浏览；不定位 Windows 资源管理器。未连接项目时，原件仅本次页面会话可浏览，关闭前需自行保留原文件。更多细节见 [R80 使用与兼容说明](docs/R80-多文件与工作入口.md)。

## 保存、恢复、更新

**月度 JSON**支持 working 与冻结。恢复时完整还原所存日历，不继承当前残留日期调整。连接目录后恢复冻结/修订 JSON 会进入独立修订副本，后续保存不覆盖主 working 或原冻结，可在项目管理返回主状态。

项目索引的可选 `monthBranches` 保存每个月正在使用的独立修订，不再只记录当前月的修订。切到其他月份后保存/打包，重开仍可回到原月份的修订；主 working 不被覆盖。R86 也从旧 R85 救援 JSON 的各月状态恢复背景修订，避免漏载月份。旧程序不识别此索引，编辑多月份修订后应使用 R86 或更高版本继续。

**整个项目 ZIP**校验项目标识、文件清单与 SHA-256，仅向空目录恢复；完成后重新连接目标目录。它与月度 JSON 是独立格式和入口。

同一完整项目 ZIP 可从 **项目 → 打开项目 ZIP / 救援 JSON** 进入便携模式。顶部保存写入浏览器 IndexedDB 缓存，包含所有工作月份、导入原件、配置、可读取的冻结和修订；事务成功并读回校验后提示“仅写入本机浏览器缓存，需下载项目包写入磁盘”。缓存不是独立磁盘备份。项目菜单的下载项目包生成带时间戳的完整 ZIP，下载成功须自行检查。下次在同一浏览器打开同一程序会恢复最近有效缓存；损坏时回退上一份并保留未保存提醒。配额不足、缓存被禁止或并发覆盖冲突时拒绝宣称保存成功，仍可下载 ZIP。清缓存、换浏览器、程序位置或站点后可能需要手动打开备份 ZIP。

**项目配置与分期封存**：项目菜单可导出带 SHA-256 完整性信息的小型配置 JSON，内容包括默认名册、忽略人员、组别、姓名别名、考勤规则、导入模板、全部持久界面偏好和固定日历，不包含历史业务记录与原始文件。“从配置创建新项目”生成只有一个空白起始月份的独立项目 ZIP；“封存并创建续用项目”先生成当前项目完整封存包，用户确认下载后再生成续用包，当前项目不会被清空或覆盖。新项目使用独立实例标识并记录来源项目，适合按年、半年或自定义周期接续。

目录连接、初始化、导入、保存、冻结或备份遇到权限/写入问题时，保留当前页面，提供重新授权、便携项目和救援入口。**救援 JSON**保存全部已加载月份的工作状态，不含原始文件字节及未加载的冻结/修订；缺少原件或原目录不可读时，不会伪装生成“完整”包。救援下载不解除未保存提醒。浏览器连下载也禁止时无法可靠落盘，必须保留当前页面并恢复下载能力。

截图与 PDF 在目录写入失败时自动改为浏览器下载，提示检查实际文件；目录截图暂时不可读时，PDF 仍可使用本次页面截图。便携模式的输出先加入内存项目，需下载新的完整项目包带走。

**数据管理 → 存储与文件 → 环境与备用方案**统一显示目录写入、Excel 导入、安全哈希、项目历史与剪贴板能力。XLS/XLSX 由本地随包解析器处理，不依赖旧内核缺失的 `deflate-raw`；无历史存储时每次手动打开项目 ZIP；剪贴板不可用时选中文本 Ctrl+C；无原生安全哈希时使用经过标准向量校核的兼容 SHA-256，仍严格校验 ZIP 与原件。详见 [R99 Win7 表格兼容](docs/R99-Win7表格兼容.md)及 [R85 环境兼容与便携项目](docs/R85-环境兼容与便携项目.md)。

working 损坏或缺失时尝试有效的 `state.previous.json`，恢复后标为未保存供检查。再次保存保留最后有效备用版本。新目录成功校验前不替换当前目录、月份和人员；连接本身不创建数据目录。

**程序升级 ZIP**统一从右上角 **导入 → 程序升级 ZIP** 进入。先保存所有月份，选择包；首次授权正在使用、含 index.html 与 src 的程序目录（本机记住目录），点击开始升级，自动备份、更新和核验，完成后点击重新载入。无需手动解压覆盖，也无需重新导入业务；未连接项目时也可单独更新程序。纯 HTML 无法绕过浏览器的首次文件夹授权。

升级器校验产品、语义版本（含预览后缀）、数据 schema、最低升级器版本、包格式、每个文件及入口依赖。拒绝降级，同版本为修复安装。恢复日志在覆盖前写盘；入口最后更新，清单一并更新。部分写入失败会回滚并核验旧文件；中途退出后再次选择同一程序目录，可从日志和校验过的备份恢复。升级前备份存于程序目录 backups，连接项目时也保存项目侧副本。持续断电、磁盘故障或权限失效不能保证自动恢复，需保留备份。包哈希用于完整性核验，不是发布者数字签名。

便携项目也可授权程序目录进行原地更新，备份实际写到程序目录。环境不能写程序目录时，先下载确认项目包，再将新版程序完整解压到新文件夹、打开新版并载入项目包；纯 HTML 不能绕过系统权限完成原地更新。

R83 及更早版本首次升级仍使用它原来的“项目 → 安全更新程序 ZIP”；装入 R84 后，以后均用导入菜单。历史 R77 与 R83 的实际程序升级及旧 schema 2 数据保留纳入生命周期回归；R87 读取这些旧数据，保存为 schema 3。详见 [R84 升级与发布前校核](docs/R84-升级与发布前校核.md)。

文件操作期间阻止冲突的项目/月份切换；保存期间新增的业务修改仍显示未保存。初始化只接受独立空目录，写入失败恢复之前的会话。

## Cloudflare Pages 临时部署

无需分叉线上版、增加服务器或修改运行时依赖。推荐将**同一份已验证的离线程序 ZIP**直接上传到 Cloudflare Pages 的 Direct Upload，或上传它完整解压后的纯程序目录。根层应有 index.html、src、README.md 和 p109-release-manifest.json。不要上传真实项目 ZIP、data、raw、backups，或把整个仓库作为发布目录。

这使线上和离线使用同一清单下的程序文件。线上/离线及不同域名的项目授权与浏览器历史不会自动互通；进入线上地址后重新授权本地项目，或打开完整便携项目 ZIP。计算和文件导入仍在浏览器本地完成，不增加云端数据同步。

线上网页的升级 ZIP 向导只能更新用户明确授权的本地离线程序目录，不能更新托管网站。网页模式会显示说明，完成只关闭向导；网站版本由部署者重新部署。已有页面保存后重新打开，才会载入网站新程序。保持固定域名，避免因每次换预览域名而重复授权。

临时预览无需新增 _headers、Worker、Functions、数据库、Cloudflare GitHub Secrets 或独立分支。使用 Pages 默认缓存，不额外配置长时间 Cache Everything；保持 Web Analytics 等 HTML 脚本注入关闭，避免改变程序响应。部署后应核对版本和清单、验证核心操作后再使用真实工作。

若以后需要 Git 自动部署，仍从 p109-exp 的准确通过 CI 的提交，用现有打包器生成纯程序目录；不要直接把源码项目根目录作为输出。Cloudflare 的普通 Git 自动构建不会自然等待 GitHub 的 P109 CI，通过 CI 后上传同一个候选 Artifact 更容易保证产物一致。配置与边界见 [R86 最后复查与临时部署](docs/R86-最后复查与临时部署.md)。

当前目录项目没有跨窗口/跨域的并发编辑锁；同一项目应由一个页面编辑，保存后再换环境。便携项目包用于转移已保存工作，不是多端实时同步或自动合并。

## 数据边界

- 原始文件按 importId 独立保存，不原位改写；人工判断进入 working、修订、冻结层。
- 姓名经 Unicode NFKC 与空白规范化后作为唯一身份，同名现实员工会合并。
- 默认班次 08:30–11:40、13:30–17:10，四个上下班容差独立配置。自动加班按上述三参数处理，不再“超过 20 分钟后计整段”。连续跨夜先判断有效时长，再按自然日切片；两天共享同一会话标识，一次人工排除同时作用于所有切片。登记加班结束早于开始时按次日解释，最长 24 小时；自动进出会话最长 36 小时。未知方向、缺少出卡、跨日再次进入均不会凭空补成整夜加班。
- 自动加班用于核查，不等于企业审批或工资结算。真实数据不要提交公共源码仓库。
- 项目 ZIP 不设人为体积禁用线；每进入新的 100 MB 档位最多提醒两次，之后到下一个 100 MB 档再提醒，提醒不阻止打开、保存、备份或接续。大包仍受浏览器可用内存、IndexedDB 配额、ZIP32 和磁盘空间的客观限制；建议在出现提醒后使用封存接续，旧包长期归档，新包只带配置和新月份。
- Windows 原生目录弹窗、权限撤销和浏览器重启后的重新授权需在目标电脑实际点选；自动化目录接口不能替代该项验收。

## 忽略人员与旧内核

数据管理 → 名册与分组右侧提供“长期固定人员”和“忽略人员名单”两个标签。切到忽略名单，勾选左侧人员后点“忽略”；默认不出现在首页全员/分组矩阵，也不进入人数、工作人日分母、趋势、排行和考勤统计导出。原始数据、原件导出与分析事实保留，右侧“查看”或个人分析的“（忽略）”人员可单独核查。选择右侧人员点“加入全员”恢复正常显示与统计。

统计分析左侧“忽略人员”默认“不统计”，可显式选“包含统计”。当前统计导出在统计范围中标明该口径。名单随项目缓存、磁盘 working 和 ZIP 保存；普通月份使用项目默认名单，冻结和独立修订保留自己的名单。旧格式升级默认无忽略人员，不自行改变人员范围。

旧 Chromium 缺少 structuredClone、Array.at、Object.hasOwn、crypto.randomUUID 和原生 SHA-256 时使用兼容实现。目录接口不存在时隐藏目录入口；CSV 与完整项目 ZIP 仍可使用。XLS/XLSX 由随包解析器离线处理，不依赖浏览器原生 ZIP 解压。IE 内核和缺少基本现代 JavaScript 语法的浏览器不属于支持范围。缺失能力测试不等于真实 Win7/360 认证，须核对实际内核。
