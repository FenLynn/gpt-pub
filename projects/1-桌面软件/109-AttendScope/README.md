# 考勤 · AttendScope

P109，当前版本 **0.2.8-preview / R82**。纯离线月度考勤核查工作台，支持人员 × 日期矩阵、个人六轨时间轴、分组统计、原始证据追溯和人工判定。直接打开 `index.html`，无需安装运行环境、服务器或联网。

## 首次使用

1. 将完整离线 ZIP 解压到长期使用的文件夹，用 Chrome 或 Edge 打开其中的 `index.html`。
2. 没有默认工作项目时，每次打开选择 **Demo · 体验** 或 **Work · 工作**；有默认 Work 项目则尝试恢复。Work 可新建空白项目或连接已有项目；新建时，在浏览器中选择独立的空白数据文件夹并授权读写。程序文件夹只放 index.html、src 和程序说明；每个项目使用自己的 project.json、config、data。新建项目不能选择程序目录。
3. 初始化建立空名册、本月 working 与配置，演示员工不会进入新项目。未连接时显示“演示数据”或“仅内存”，不代表已写入磁盘。
4. 选择或创建月份，通过 **导入** 分别载入五类数据；可多选文件，逐个核对后默认合并，后一个保留前一个文件的数据。预览会显示目标月份、文件日期范围和必要字段，并自动完成业务校验。选错月份时可直接改为文件的主要月份，确认前不会切换或修改工作区。
5. 检查矩阵、时间轴和原始证据，必要时人工改判，然后 **保存**。阶段完成后 **冻结**，并定期执行 **项目 → 完整项目备份 ZIP**。

首次进入 Work 时连接一次已有数据目录，此后程序在当前浏览器的 IndexedDB 中记住授权的目录和上次项目。重新打开 index.html 时，若读写权限仍有效便自动载入上次已保存的项目；需要授权时显示“继续打开”，点击即可重新授权，无需寻找目录。主页左上角保留当前项目名，点击可浏览项目真实文件。**数据管理 → 存储与文件 → 目录位置**集中显示项目目录和程序目录，并提供文件夹级路径复制，不包含入口文件名；主页面不再常驻路径栏或路径页脚。项目绝对路径无法从浏览器取得，可手动记录后复制，明确标注来源。**项目 → 最近项目**可直接切换，**管理已打开的项目**支持改显示名称、移除历史记录。同名文件夹按实际目录区分，移除历史不会删除数据。

项目历史属于当前浏览器配置；清理浏览器站点数据或换浏览器后需重新选择目录，磁盘业务文件不受影响。取消、目录失效或连接失败保留当前工作；切换项目有未保存月份时会提示。旧版代码与数据放在同一目录的项目仍可连接，新版不自动搬动其文件。

## 关闭保护与使用帮助

工作月份有未保存修改时，关闭或刷新触发浏览器离开确认；选择留在页面，再保存。当前月和后台月份一起检查，数据管理的目录位置卡片列出未保存月份；保存按钮仍只保存当前月。浏览器强退或断电不能保证提示，不在卸载时启动异步保存。

顶部“帮助”提供 **8 章快速入门 + 12 个专题**：从新建独立项目、第一笔导入、核查与分组，到保存、冻结、重开和下月继续；专题覆盖五类业务、统计、人员、存储、备份恢复、导出与排错。每章包含具体步骤、字段/示例、结果核对和常见错误，附真实程序截图，以及五类按当前月份生成的虚构练习 CSV。首次模式选择页也可先看教程。

教程支持全文搜索、章内目录、前后章节、返回阅读位置和离线文字版下载；阅读不会修改业务数据。帮助和数据量较大的弹窗按桌面窗口约 86% 宽展示，实际内容超出后才在对应区域滚动。矩阵随有效人数伸展，未填满可用高度时不出现多余竖向滚动。

目录路径备注只在本机浏览器中记录，不进入业务 JSON 或项目备份；禁止自动复制时提供 Ctrl+C 手动复制。详见 [R82 详细教程与布局整改](docs/R82-详细教程与布局整改.md)；历史启动与关闭保护见 [R81 说明](docs/R81-启动路径与帮助.md)。

## 操作入口

| 操作 | 作用 |
|---|---|
| 导入 | 考勤、请假、出差、外出、登记加班的 XLSX/CSV，以及各自固定表头、不含人员记录的空白模板 |
| 项目 | 最近项目、自动恢复、连接/切换目录、初始化、项目管理与修订、两类恢复、完整 ZIP 备份、程序更新 |
| 保存 | 更新当前 working，保留上一个有效版本并读回核验；无目录时下载 JSON |
| 冻结 | 创建唯一、不可覆盖的快照，与保存和完整备份分别独立 |
| 导出 | 当前统计或全月明细 XLSX/CSV、当前视图 PNG、已选截图 PDF、五类当前原始数据 XLSX |

统计页的“当前统计 XLSX/CSV”共用字段和范围：月份、统计范围、对象、业务、指标、统计方式、数值、单位、员工数、应出勤人日。榜单数量不截断导出。另有明确命名的“全月考勤明细 XLSX”。非统计页的“全月考勤明细”按整个月份输出，不冒充当前人员/日期筛选结果。

CSV 使用 UTF-8 BOM、引号及换行转义和文本公式防护，真正数值保留数值形式。XLSX 文本按字符串写入。“空白模板”不读取当前工作数据；导出已有记录请用“导出当前原始数据”。

## 工作区

- 全员/分组：矩阵发现问题，人员、日期、单元格分别定位与下钻，“清除选择”重置定位。
- 个人：默认月度全览，日期条进入单日六轨时间轴，前后日按钮切日；“返回全览”和“个人全览”共用同一状态入口。
- 统计：范围、业务、指标、对比、统计方式、榜单控制统计，不再显示无效月历；导出集中在顶部。
- 数据管理：项目概况、月份库存、健康、存储、名册、规则、模板、原始记录、导入历史、冻结与修订。原始记录包含“导入原件”和“合并数据”；只有后者显示日期过滤。原件可浏览、下载，文件树和库存数量提供真实目录入口。

人员分组用勾选和批量加入组别，支持跨搜索连续选择；完成后清空选择，保留目标组别与滚动位置，便于下一批继续加入。长期固定人员用双栏勾选和中间左右箭头管理。“保存下月默认名册”只保存已选固定人员及组别，不会自动固定当前所有人。

## 多文件与可选字段

五类数据默认追加合并，跨文件重合按业务字段核对，同一文件内的重复打卡仍保留。重合记录保留每个来源文件、工作表和行号，原记录 ID 不变；每次导入的原件独立保存，不覆盖旧原件。合并数据里的文件名可点击查看来源，多个来源可展开。更多选项中的“替换本月此类数据”需要确认，历史原件与其他类型保留。

类型、地点、备注和进出方向等可选字段可选“无”；姓名与业务必要的日期/时间须有效。结束日期可省略为开始日期，请假起止时刻可使用班次边界。无进出方向的考勤标为“未标注 / 待核”，不推断方向或跨这些点组成在岗、加班会话。非空但无效的日期/时刻必须修正。

原件浏览器支持 CSV/XLSX 分页表格及 JSON/文本，不执行 HTML 或脚本。文件夹在页面内浏览；不定位 Windows 资源管理器。未连接项目时，原件仅本次页面会话可浏览，关闭前需自行保留原文件。更多细节见 [R80 使用与兼容说明](docs/R80-多文件与工作入口.md)。

## 保存、恢复、更新

**月度 JSON**支持 working 与冻结。恢复时完整还原所存日历，不继承当前残留日期调整。连接目录后恢复冻结/修订 JSON 会进入独立修订副本，后续保存不覆盖主 working 或原冻结，可在项目管理返回主状态。

**整个项目 ZIP**校验项目标识、文件清单与 SHA-256，仅向空目录恢复；完成后重新连接目标目录。它与月度 JSON 是独立格式和入口。

working 损坏或缺失时尝试有效的 `state.previous.json`，恢复后标为未保存供检查。再次保存保留最后有效备用版本。新目录成功校验前不替换当前目录、月份和人员；连接本身不创建数据目录。

**程序更新 ZIP**只替换程序，先生成并核验升级前备份，不修改 data、config、raw、working 或 snapshots。数据与程序分离时，更新入口先选择程序目录；升级前备份同时包含数据和旧程序，更新只写入所选程序目录。更新后重新打开 `index.html`。使用真实 R77 提交 `71caeaa99b7e` 验证升级和数据保留，限定在 schema 2；更高 schema 明确拒绝，不宣称任意未来格式都能迁移。R80 可读旧 schema 2；含“未标注”方向的新工作请继续用 R80 或更新版本，降级应使用升级前备份。

文件操作期间阻止冲突的项目/月份切换；保存期间新增的业务修改仍显示未保存。初始化只接受独立空目录，写入失败恢复之前的会话。

## 数据边界

- 原始文件按 importId 独立保存，不原位改写；人工判断进入 working、修订、冻结层。
- 姓名经 Unicode NFKC 与空白规范化后作为唯一身份，同名现实员工会合并。
- 默认班次 08:30–11:40、13:30–17:10，四个上下班容差独立配置。自动加班保留严格超过 20 分钟、达标后计完整区间的门槛，以及跨日、登记扣重和人工纳入口径。引擎 R79 修复漏刷出卡后被次日进入错误延续的会话：跨日再次进入且超过重复刷卡窗口时，旧会话按证据不全待核，不凭空计算整晚加班。
- 自动加班用于核查，不等于企业审批或工资结算。真实数据不要提交公共源码仓库。
- 完整备份上限 5000 文件 / 160 MB，不重复套入旧 backups；超限请用系统文件管理器备份。
- Windows 原生目录弹窗、权限撤销和浏览器重启后的重新授权需在目标电脑实际点选；自动化目录接口不能替代该项验收。

## 开发与验证

仅在 `p109-exp` 维护 P109，遵守 [开发约束](开发约束.md)。版本集中于 `src/app/00-state.js`，打包器读取同一常量。运行依赖均本地打包，图表、表格、导出共享事实层。

`tests/smoke.cjs` 运行业务、图表几何、导入、人工判定、跨月、PNG/PDF、离线回归，以及专项 `r78-audit.cjs` 至 `r82-audit.cjs`、生命周期 `lifecycle-audit.cjs`、界面 `ui-audit.cjs`。R82 增加教程搜索/阅读位置、实际练习 CSV 下载与五类导入、弹窗尺寸、目录仅存储页出现，以及 0/1/20/50/150 人的滚动边界。目录测试使用真实临时磁盘和浏览器接口替身；历史升级使用准确旧提交，而非改低版本标记。R79/R80 的 IndexedDB 原生目录句柄、文件流、重载恢复和双目录更新用本地 HTTP 测试环境下的浏览器 OPFS 验证；这不是外部磁盘目录的原生授权验收。纯 file:// 的离线运行另由完整 smoke 覆盖。

`python tools/package-release.py 项目目录 输出.zip` 生成只含程序、README 和完整性清单的离线包。普通 CI 提供候选 Artifact，不自动创建正式 Release。
