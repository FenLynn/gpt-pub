# R40 · 分析矩阵、右侧统计与个人日期条带

日期：2026-10-19。以当前 `p109-exp` 源码、P109 Chromium CI 与 Shared Pages 为事实源。

## 已确认设计

- 顶部：品牌与四个一级工作区在左，月份/导入/保存/冻结/导出/设置集中在右。
- 左侧：上部仅组别、人员两行（每行左标签右下拉）；下部固定月历，月历下方以“左名称、右操作”方式呈现分析视图、状态和判定模式。数据管理保留专用子菜单。
- 全员/分组：姓名只选中矩阵整行；点击具体日期格进入个人页面。矩阵日列适当收紧，状态块增大，右侧独立显示当前范围的人数、正常/异常/缺勤及真实统计图；所有统计源自同一份 `state.analysis`，且工作人日口径明确。点击组别图表不应误用全员范围。
- 个人：上方单行整月日期条带，下方保留现有六轨时间轴和原始证据。每个日期按 `dayType()` 分类：工作日数字加粗、休息日与节假日淡底区分、调休上班另有淡色；**底部细色条表示当天考勤状态**，不画整格的大色块。
- 人工修正：底部颜色使用原始分析数据的最终人工覆盖（若有）；右上角持续显示紫色 ✓；不可仅在某一显示模式下丢掉标记。
- 个人日期选择：顶部整月条带、左下月历、右上 ‹/›、日期选择框必须联动到同一日，并更新六轨图和原始记录。月初/月末箭头禁用越界，不静默跨月份；内部 `classic` 测试模式仍保留旧版日历行为。
- 个人页右侧分析信息列适度加宽；不把统计图塞进六轨时间轴主绘图区。个人统计仍可从侧栏“分析视图”切换。
- UI 避免长副标题、大数字卡片、碎片化框线和极小字号。R40 完整实现仍以实时 Chromium 截图核对。
