# P110｜WorkStation

WorkStation 是一个**完全离线、浏览器运行、模块化的 All-in-One 工作台**。优先支持 Chrome/Edge 直接通过 `file://` 打开 `index.html`，不要求安装 Zotero、账户、互联网或常驻服务器。

**当前状态：方案规划已记录，尚无可运行产品或真实 Zotero 数据验证。** 第一阶段只开发通用主页/工作区基础与 Zotero 7 离线文献管理模块；其他科研、办公和文件处理能力保留独立模块扩展位，不提前实现。

## 确定的产品边界

1. 一个轻量主页、多个独立模块；Zotero 是**一级模块**，不是整个产品名称。
2. **Runtime/代码与用户 Data/配置严格分离**：只替换程序目录就能升级，不丢失数据、设置、分类与笔记。
3. **Zotero 7 原数据只读导入**：保留原始 `zotero.sqlite`、`storage/` 和可用的来源关系；新增与编辑操作仅写 WorkStation 独立数据。
4. 优先完整实现文献树、搜索/排序、添加/编辑文献、标签、分类和本地 PDF 关联，而非复制完整 Zotero 插件生态。
5. 所有依赖离线打包，不能把 GitHub Pages、CDN、本地网络或云端 API 当作正常使用前提。
